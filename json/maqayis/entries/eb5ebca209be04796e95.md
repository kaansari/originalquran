# لَمَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%85%D9%8E%D9%83%D9%8E/?book=9

(لَمَكَ) اللَّامُ وَالْمِيمُ وَالْكَافُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ تَلَمَّكَ الشَّيْءُ، مِثْلَ تَلَمَّجَ، كَأَنَّهُ يَتَذَوَّقُهُ. يُقَالُ: مَا ذُقْتُ لَمَاكًا، أَيْ شَيْئًا، كَقَوْلِهِمْ: مَا ذُقْتُ لَمَاجًا، وَأَصْلُهُ أَنْ يَلْوِيَ الْبَعِيرُ لَحْيَيْهِ. قَالَ:

فَلَمَّا رَآنِي قَدْ حَمَمْتُ ارْتِحَالَهُ ... تَلَمَّكَ لَوْ يُجْدِي عَلَيْهِ التَّلَمُّكُ.

# لَسِقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B3%D9%90%D9%82%D9%8E/?book=9

(لَسِقَ) اللَّامُ وَالسِّينُ وَالْقَافُ لَيْسَ أَصْلًا، وَأَصْلُهُ الصَّادُ. يُقَالُ اللَّسَقُ: اللَّوَى. وَإِذَا الْتَزَقَتِ الرِّئَةُ بِالْجَنْبِ قِيلَ لَسِقَ لَسَقًا. وَالْأَصْل

قَالَ رُؤْبَةُ:

وَبَلَّ بَرْدُ الْمَاءِ أَعْضَادَ اللَّسَقْ.

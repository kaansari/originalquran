# رَزَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B2%D9%8E%D8%A8%D9%8E/?book=9

(رَزَبَ) الرَّاءُ وَالزَّاءُ وَالْبَاءُ، إِنْ كَانَ صَحِيحًا فَهُوَ يَدُلُّ عَلَى قِصَرٍ وَضِخَمٍ. فَالْإِرْزَبُّ: الرَّجُلُ الْقَصِيرُ الضَّخْمُ. وَالْمِرْزَبَةُ مَعْرُوفَةٌ. وَرَكَبٌ إِرْزَبٌّ: عَظِيمٌ. قَالَ:

إِنَّ لَهَا لَرَكَبًا إِرْزَبَّا

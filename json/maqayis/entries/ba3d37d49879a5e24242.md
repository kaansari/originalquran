# فَزَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B2%D9%8E%D8%B1%D9%8E/?book=9

(فَزَرَ) الْفَاءُ وَالزَّاءُ وَالرَّاءُ أُصَيْلٌ يَدُلُّ عَلَى انْفِرَاجٍ وَانْصِدَاعٍ. مِنْ ذَلِكَ الطَّرِيقُ الْفَازِرُ: وَهُوَ الْمُنْفَرِجُ الْوَاسِعُ. وَالْفِزْرُ: الْقَطِيعُ مِنَ الْغَنَمِ. يُقَالُ فَزَرْتُ الشَّيْءَ: صَدَعْتُهُ. وَالْأَفْرَزُ: الَّذِي يَتَطَامَنُ ظَهْرُهُ ; وَالْقِيَاسُ وَاحِدٌ، كَأَنَّهُ يَنْفَرِقُ لُحْمَتَا ظَهْرِهِ. وَاللَّهُ أَعْلَمُ.

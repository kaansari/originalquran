# حَفَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%81%D9%8E%D8%B4%D9%8E/?book=9

(حَفَشَ) الْحَاءُ وَالْفَاءُ وَالشِّينُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى الْجَمْعِ. يُقَالُ هُمْ يَحْفِشُونَ عَلَيْكَ، أَيْ يُجْلِبُونَ. وَحَفَشَ السَّيْلُ الْمَاءَ مِنْ كُلِّ جَانِبٍ إِلَى مُسْتَنْقَعٍ وَاحِدٍ. قَالَ:

عَشِيَّةَ رُحْنَا وَرَاحُوا لَنَا ... كَمَا مَلَأَ الْحَافِشَاتُ الْمَسِيلَا

وَيُقَالُ جَاءَ الْفَرَسُ يَحْفِشُ، أَيْ يَأْتِي بِجَرْيٍ بَعْدَ جَرْيٍ. وَالْحِفْشُ: بَيْتٌ صَغِيرٌ: وَسُمِّيَ بِذَلِكَ لِاجْتِمَاعِ جَوَانِبِهِ ; وَيُقَالُ لِأَنَّهُ يُجَمِّعُ فِيهِ الشَّيْءَ. وَتَحَفَّشَتِ الْمَرْأَةُ لِلرَّجُلِ، إِذَا أَظْهَرَتْ لَهُ وُدًّا ; وَذَلِكَ أَنَّهَا تَتَحَفَّلُ لَهُ، أَيْ تَتَجَمَّعُ.

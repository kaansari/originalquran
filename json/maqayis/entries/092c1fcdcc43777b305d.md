# بَغَضَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%BA%D9%8E%D8%B6%D9%8E/?book=9

(بَغَضَ) الْبَاءُ وَالْغَيْنُ وَالضَّادُ أَصْلٌ وَاحِدٌ، وَهُوَ يَدُلُّ عَلَى خِلَافِ الْحُبِّ. يُقَالُ: أَبْغَضْتُهُ أُبْغِضُهُ. فَأَمَّا قَوْلُهُ: وَمِنَ الْعَوَادِي أَنْ تَقَتْكَ بِبِغْضَةٍ ... وَتَقَاذُفٍ مِنْهَا وَأَنَّكَ تُرْقَبُ

فَقِيلَ الْبِغْضَةُ الْأَعْدَاءُ، وَقِيلَ أَرَادَ ذَوِي بِغْضَةٍ. وَرُبَّمَا قَالُوا بَغُضَ جَدُّهُ، كَقَوْلِهِمْ عَثَرَ. وَاللَّهُ أَعْلَمُ.

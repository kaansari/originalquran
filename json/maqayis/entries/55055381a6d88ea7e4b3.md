# شَنَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%86%D9%8E%D8%A3%D9%8E/?book=9

(شَنَأَ) الشِّينُ وَالنُّونُ وَالْهَمْزَةُ أَصْلٌ يَدُلُّ عَلَى الْبِغْضَةِ وَالتَّجَنُّبِ لِلشَّيْءِ. مِنْ ذَلِكَ الشَّنُوءَةُ، وَهِيَ التَّقَزُّزُ ; وَمِنْهُ اشْتِقَاقُ أَزْدِشَنُوءَةَ. وَيُقَالُ: شَنِئَ فُلَانٌ فُلَانًا إِذَا أَبْغَضَهُ. وَهُوَ الشَّنَآنُ، وَرُبَّمَا خَفَّفُوا فَقَالُوا: الشَّنَانُ. وَأَنْشَدُوا:

فَمَا الْعَيْشُ إِلَّا مَا تَلَذُّ وَتَشْتَهِي ... وَإِنْ لَامَ فِيهِ ذُو الشَّنَانِ وَأَفْنَدَا

وَالشَّنْءُ: الشَّنَآنُ أَيْضًا. وَرَجُلٌ مِشْنَاءٌ عَلَى مِفْعَالٍ، إِذَا كَانَ يُبْغِضُهُ النَّاسُ. وَأَمَّا قَوْلُهُمْ شَنِئْتُ لِلْأَمْرِ وَبِهِ، إِذَا أَقْرَرْتَ، وَإِنْشَادُهُمْ:

فَلَوْ كَانَ هَذَا الْأَمْرُ فِي جَاهِلِيَّةٍ ... شَنِئْتَ بِهِ أَوْ غَصَّ بِالْمَاءِ شَارِبُهُ

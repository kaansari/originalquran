# عِرْبِسٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%90%D8%B1%D9%92%D8%A8%D9%90%D8%B3%D9%8C/?book=9

(عِرْبِسٌ) وَ (عَرْبَسِيسٌ) : مَتْنٌ مُسْتَوٍ مِنَ الْأَرْضِ. قَالَ الْعَجَّاجُ:

وَعِرْبِسٌ مِنْهَا بِسَيْرٍ وَهْسِ

وَقَالَ الطِّرِمَّاحُ:

تُوَاكِلُ عَرْبَسِيسَ الْأَرْضَ مَرْتًا ... كَظَهْرِ السَّيْحِ مُطَّرِدَ الْمُتُونِ

وَهَذَا مِمَّا زِيدَتْ فِيهِ الْبَاءُ، وَإِنَّمَا هُوَ مِنَ الْمُعَرَّسِ، أَيِ إِنَّهُ مُسْتَوٍ سَهْلٌ لِلتَّعْرِيسِ فِيهِ.

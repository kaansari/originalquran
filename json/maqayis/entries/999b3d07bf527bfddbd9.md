# شَغُمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%BA%D9%8F%D9%85%D9%8E/?book=9

(شَغُمَ) الشِّينُ وَالْغَيْنُ وَالْمِيمُ أَصْلٌ قَلِيلُ الْفُرُوعِ صَحِيحٌ، يَدُلُّ عَلَى حُسْنٍ. يُقَالُ الشُّغْمُومُ: الْحَسَنُ. وَالشُّغْمُومُ: الْمَرْأَةُ الْحَسْنَاءُ. وَالشُّغْمُومُ مِنَ الْإِبِلِ: الْحَسَنُ الْمَنْظَرِ التَّامُّ.

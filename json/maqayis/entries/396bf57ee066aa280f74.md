# زَمْهَرِيرُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%85%D9%92%D9%87%D9%8E%D8%B1%D9%90%D9%8A%D8%B1%D9%8F/?book=9

(الزَّمْهَرِيرُ) فَالْبَرْدُ، مُمْكِنٌ أَنْ يَكُونَ وُضِعَ وَضْعًا، وَمُمْكِنٌ أَنْ يَكُونَ مِمَّا مَضَى ذِكْرُهُ، مِنْ قَوْلِهِمْ: ازْمَهَرَّتِ الْكَوَاكِبُ ; وَذَلِكَ أَنَّهُ إِذَا اشْتَدَّ الْبَرْدُ زَهَرَتْ إِذًا [وَ] أَضَاءَتْ.

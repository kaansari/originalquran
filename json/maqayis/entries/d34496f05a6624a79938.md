# ثَكِلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D9%83%D9%90%D9%84%D9%8E/?book=9

(ثَكِلَ) الثَّاءُ وَالْكَافُ وَاللَّامُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى فُِقْدَانِ الشَّيْءِ، وَكَأَنَّهُ يُخْتَصُّ بِذَلِكَ فُِقْدَانُ الْوَلَدِ. يُقَالُ ثَكِلَتْهُ أُمُّهُ تَثْكَلُهُ ثَكْلًا. وَلِأُمِّهِ الثُّكْلُ. فَإِذَا قَالَ الْقَائِلُ لِآخَرَ وَهُوَ لَيْسَ لَهُ بِوَلَدٍ فَإِنَّمَا يَحْمِلُهُ عَلَى ذَلِكَ، وَإِلَّا فَإِنَّ الْأَصْلَ مَا ذَكَرْنَاهُ.

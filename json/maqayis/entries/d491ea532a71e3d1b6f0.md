# غَوَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D9%88%D9%8E%D8%AC%D9%8E/?book=9

(غَوَجَ) الْغَيْنُ وَالْوَاوُ وَالْجِيمُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْفَرَسُ الْغَوْجُ. إِذَا كَانَ عَرِيضَ الصَّدْرِ. وَرُبَّمَا سَمَّوْا كُلَّ لَيِّنٍ غَوْجًا.

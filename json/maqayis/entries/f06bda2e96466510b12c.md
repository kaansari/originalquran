# هَرَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B1%D9%8E%D8%B4%D9%8E/?book=9

(هَرَشَ) الْهَاءُ وَالرَّاءُ وَالشِّينُ: كَلِمَةٌ وَاحِدَةٌ، هِيَ مُهَارَشَةُ الْكِلَابِ: تَحْرِيشٌ بَعْضِهَا عَلَى بَعْضٍ. وَمِنْهُ يُقَاسُ التَّهْرِيشُ، وَهُوَ الْإِفْسَادُ بَيْنَ النَّاسِ. وَمِمَّا لَيْسَ مِنْ هَذَا الْبَابِ هَرْشَى: هَضْبَةٌ مَعْرُوفَةٌ. قَالَ:

خُذُوا صَدْرَ هَرْشَى [أَوْ قَفَاهَا فَإِنَّهُ ... كِلَا جَانِبَيْ هَرْشَى] لَهُنَّ طَرِيقُ

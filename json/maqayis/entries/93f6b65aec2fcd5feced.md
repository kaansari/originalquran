# قَوَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D9%88%D9%8E%D8%B2%D9%8E/?book=9

(قَوَزَ) الْقَافُ وَالْوَاوُ وَالزَّاءُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْقَوْزُ: الْكَثِيبُ، وَجَمْعُهُ أَقْوَازٌ وَقِيزَانٌ. قَالَ: وَأُشْرِفُ بِالْقَوْزِ الْيَفَاعِ لَعَلَّنِي ... أَرَى نَارَ لَيْلَى أَوْ يَرَانِي بَصِيرُهَا.

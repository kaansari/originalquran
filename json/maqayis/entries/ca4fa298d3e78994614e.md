# مَوَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%88%D9%8E%D9%85%D9%8E/?book=9

(مَوَمَ) الْمِيمُ وَالْوَاوُ وَالْمِيمُ كَلِمَتَانِ مُتَبَايِنَتَانِ جِدًّا: الْمُومُ: الْبِرْسَامُ، وَمِيمَ الرَّجُلُ فَهُوَ مَمُومٌ، وَالْمَوْمَاةُ: الْمَفَازَةُ الْوَاسِعَةُ الْمَلْسَاءُ، جَمْعُهَا مَوَامٍ.

# فَوَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D9%88%D9%8E%D9%81%D9%8E/?book=9

(فَوَفَ) الْفَاءُ وَالْوَاوُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ. يَقُولُونَ: الْفُوفُ: الْقُطْنُ. ثُمَّ يُقَالُ لِلْبَيَاضِ يُرَى فِي أَظْفَارِ الْأَحْدَاثِ: الْفُوفُ. وَمِنْ ذَلِكَ يُقَالُ: بُرْدٌ مُفَوَّفٌ.

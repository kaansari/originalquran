# سَهَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%87%D9%8E%D9%81%D9%8E/?book=9

(سَهَفَ) السِّينُ وَالْهَاءُ وَالْفَاءُ تَقِلُّ فُرُوعُهُ. وَيَقُولُونَ إِنَّ السَّهَفَ: تَشَحُّطُ الْقَتِيلِ فِي دَمِهِ وَاضْطِرَابُهُ. وَيُقَالُ إِنَّ السُّهَافَ: الْعَطَشُ.

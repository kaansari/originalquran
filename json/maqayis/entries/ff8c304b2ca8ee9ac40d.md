# ضَفَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D9%81%D9%8E%D8%B7%D9%8E/?book=9

(ضَفَطَ) الضَّادُ وَالْفَاءُ وَالطَّاءُ أُصَيْلٌ يَقُولُونَ إِنَّهُ صَحِيحٌ، وَأَصْلُهُ الْحُمْقُ وَالْجَفَاءُ. يُقَالُ لِلْأَحْمَقِ: ضَفِيطٌ بَيِّنُ الضَّفَاطَةِ. وَيُقَالُ: الضَّفَّاطُ: الَّذِي يُكْرِي الْإِبِلَ. وَالضَّفَّاطَةُ فِيمَا يُقَالُ: الْإِبِلُ تَحْمِلُ الْمَتَاعَ. وَأَحْسَبُ أَنَّ الْبَابَ كُلَّهُ مِمَّا لَا يُعَوَّلُ عَلَيْهِ.

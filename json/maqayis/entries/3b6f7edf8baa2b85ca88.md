# دَخَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%AE%D9%8E%D8%B4%D9%8E/?book=9

(دَخَشَ) الدَّالُ وَالْخَاءُ وَالشِّينُ لَيْسَ بِشَيْءٍ. وَزَعَمَ ابْنُ دُرَيْدٍ أَنَّ الدَّخَشَ فِعْلٌ مُمَاتٌ، يُقَالُ دَخِشَ دَخَشًا، إِذَا امْتَلَأَ لَحْمًا. وَمِنْهُ اشْتِقَاقُ دَخْشَمٍ.

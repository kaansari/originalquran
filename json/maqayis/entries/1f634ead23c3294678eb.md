# لَزِجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B2%D9%90%D8%AC%D9%8E/?book=9

(لَزِجَ) اللَّامُ وَالزَّاءُ وَالْجِيمُ قَرِيبٌ مِنَ الْبَابِ الَّذِي قَبْلَهُ. يُقَالُ: لَزِجَ بِهِ، إِذَا غَرِيَ بِهِ وَلَازَمَهُ. وَالتَّلَزُّجُ: تَتَبُّعُ الْبُقُولِ وَالرِّعْيِ الْقَلِيلِ.

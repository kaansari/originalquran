# هَرَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B1%D9%8E%D9%85%D9%8E/?book=9

(هَرَمَ) الْهَاءُ وَالرَّاءُ وَالْمِيمُ كَلِمَتَانِ: إِحْدَاهُمَا الْهَرَمُ: كِبَرُ السِّنِّ. وَيُقَالُ: الْهَرِمَةُ: اللَّبُؤَةُ. وَابْنُ هِرْمَةَ: آخِرُ وَلَدِ الرَّجُلِ. وَالْأُخْرَى الْهُرْمَانُ: الْعَقْلُ.

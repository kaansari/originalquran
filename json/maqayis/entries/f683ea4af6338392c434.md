# وَرَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B1%D9%8E%D8%B3%D9%8E/?book=9

(وَرَسَ) الْوَاوُ وَالرَّاءُ وَالسِّينُ: كَلِمَةٌ وَاحِدَةٌ، هِيَ الْوَرْسُ: نَبْتٌ. وَأَوْرَسَ الْمَكَانُ: أَنْبَتَهُ، وَهُوَ وَارِسٌ، وَهُوَ نَادِرٌ. وَمِلْحَفَةٌ وَرِيسٌ: صُبِغَتْ بِالْوَرْسِ.

# هَنَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%86%D9%8E%D8%A8%D9%8E/?book=9

(هَنَبَ) الْهَاءُ وَالنُّونُ وَالْبَاءُ، لَيْسَ فِيهِ إِلَّا هِنْبٌ: اسْمُ رَجُلٍ. وَذَكَرَ ابْنُ دُرَيْدٍ أَنَّ الْهَنَبَ: الْوَخَامَةُ وَالثِّقَلُ. يُقَالُ امْرَأَةٌ هَنْبَاءُ: بَلْهَاءُ. قَالَ:

مَجْنُونَةٌ هُنَّبَاءُ بِنْتُ مَجْنُونِ

# حَبِنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%A8%D9%90%D9%86%D9%8E/?book=9

(حَبِنَ) الْحَاءُ وَالْبَاءُ وَالنُّونُ أَصْلٌ وَاحِدٌ، فِيهِ كَلِمَتَانِ مَحْمُولَةٌ إِحْدَاهُمَا عَلَى الْأُخْرَى. فَالْحِبْنُ كَالدُّمَّلِ فِي الْجَسَدِ، وَيُقَالُ بَلِ الرَّجُلُ الْأَحْبَنُ الَّذِي بِهِ السِّقْيُ. وَالْكَلِمَةُ الْأُخْرَى أُمُّ حُبَيْنٍ، وَهِيَ دَابَّةٌ قَدْرُ كَفِ الْإِنْسَانِ.

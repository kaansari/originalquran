# دَهَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%87%D9%8E%D9%84%D9%8E/?book=9

(دَهَلَ) الدَّالُ وَالْهَاءُ وَاللَّامُ لَيْسَ بِشَيْءٍ. وَيَقُولُونَ: مَرَّ دَهْلٌ مِنَ اللَّيْلِ، أَيْ طَائِفَةٌ. وَيَقُولُونَ لَا دَهْلَ، أَيْ لَا بَأْسَ. وَهَذِهِ نَبَطِيَّةٌ لَا مَعْنَى لَهَا.

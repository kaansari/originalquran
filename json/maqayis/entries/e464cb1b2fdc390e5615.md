# بَذَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B0%D9%8E%D8%A3%D9%8E/?book=9

(بَذَأَ) الْبَاءُ وَالذَّالُ وَالْهَمْزَةُ أَصْلٌ وَاحِدٌ، وَهُوَ خُرُوجُ الشَّيْءِ عَنْ طَرِيقَةِ الْإِحْمَادِ، تَقُولُ: هُوَ بَذِيءُ اللِّسَانِ، وَقَدْ بَذَأْتُ عَلَى فُلَانٍ أَبْذَأُ بُذَاءً. وَيُقَالُ: بَذَأْتُ الْمَكَانَ أَبْذَؤُهُ: إِذَا أَتَيْتَهُ فَلَمْ تُحْمِدْهُ.

# وَدَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AF%D9%8E%D9%83%D9%8E/?book=9

(وَدَكَ) الْوَاوُ وَالدَّالُ وَالْكَافُ: كَلِمَةٌ وَاحِدَةٌ، هِيَ الْوَدَكُ، وَهُوَ مَعْرُوفٌ. وَيُقَالُ دَجَاجَةٌ وَدِيكَةٌ، أَيْ سَمِينَةٌ. وَرَجُلٌ وَادِكٌ: لَهُ وَدَكٌ.

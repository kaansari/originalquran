# جَدَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%AF%D9%8E%D9%85%D9%8E/?book=9

(جَدَمَ) الْجِيمُ وَالدَّالُ وَالْمِيمُ يَدُلُّ عَلَى الْقَمَاءَةِ وَالْقِصَرِ. رَجُلٌ جَدَمَةٌ، أَيْ قَصِيرٌ. وَالشَّاةُ الْجَدَمَةُ: الرَّدِيَّةُ الْقَمِيئَةُ.

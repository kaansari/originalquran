# لَوَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%88%D9%8E%D9%83%D9%8E/?book=9

(لَوَكَ) اللَّامُ وَالْوَاوُ وَالْكَافُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ: لُكْتُ اللُّقْمَةَ أَلُوكُهَا لَوْكًا. وَفُلَانٌ يَلُوكُ أَعْرَاضَ النَّاسِ، إِذَا كَانَ يَغْتَابُهُمْ.

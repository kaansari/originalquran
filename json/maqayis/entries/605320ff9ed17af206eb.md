# ضَيَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D9%8A%D9%8E%D8%AD%D9%8E/?book=9

(ضَيَحَ) الضَّادُ وَالْيَاءُ وَالْحَاءُ أُصَيْلٌ صَحِيحٌ، وَهُوَ اللَّبَنُ الْمَمْزُوجُ، وَهُوَ الضَّيَاحُ. يُقَالُ: ضِحْتُ اللَّبَنَ ضَيْحًا، وَضَيَّحْتُ أَكْثَرُ.

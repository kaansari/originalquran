# ذَفَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D9%81%D9%8E%D9%84%D9%8E/?book=9

(ذَفَلَ) الذَّالُ وَالْفَاءُ وَاللَّامُ لَيْسَ أَصْلًا. عَلَى أَنَّهُمْ يَقُولُونَ إِنَّ الذَِّفْلَ: الْقَطِرَانُ. وَيُنْشِدُونَ لِابْنِ مُقْبِلٍ:

تَمَشَّى بِهِ الظِّلْمَانُ كَالدُّهْمِ قَارَفَتْ ... بِزَيْتِ الرُّهَاءِ الْجَوْنِ وَالذِّفْلِ طَالِيَا

وَاللَّهُ أَعْلَمُ.

# وَصَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B5%D9%8E%D8%AF%D9%8E/?book=9

(وَصَدَ) الْوَاوُ وَالصَّادُ وَالدَّالُ: أَصْلٌ يَدُلُّ عَلَى ضَمِّ شَيْءٍ إِلَى شَيْءٍ. وَأَوْصَدْتُ الْبَابَ: أَغْلَقْتُهُ. وَالْوَصِيدُ: النَّبْتُ الْمُتَقَارِبُ الْأُصُولِ. وَالْوَصِيدُ: الْفِنَاءُ لِاتِّصَالِهِ بِالرَّبْعِ. وَالْمُوصَدُ: الْمُطْبَقُ. وَقَالَ تَعَالَى: {إِنَّهَا عَلَيْهِمْ مُؤْصَدَةٌ} [الهمزة: 8] .

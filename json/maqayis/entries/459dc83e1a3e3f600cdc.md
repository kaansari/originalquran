# كَيَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%8A%D9%8E%D9%81%D9%8E/?book=9

(كَيَفَ) الْكَافُ وَالْيَاءُ وَالْفَاءُ كَلِمَةٌ. يَقُولُونَ: الْكِيفَةُ: الْكِسْفَةُ مِنَ الثَّوْبِ. فَأَمَّا كَيْفَ فَكَلِمَةٌ مَوْضُوعَةٌ يُسْتَفْهَمُ بِهَا عَنْ حَالِ الْإِنْسَانِ فَيُقَالُ: كَيْفَ هُوَ؟ فَيُقَالُ: صَالِحٌ.

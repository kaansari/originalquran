# لَزَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B2%D9%8E%D8%A3%D9%8E/?book=9

(لَزَأَ) اللَّامُ وَالزَّاءُ وَالْهَمْزَةُ كَلِمَتَانِ لَعَلَّهُمَا أَنْ يَكُونَا صَحِيحَتَيْنِ. يَقُولُونَ: لَزَّأَ الْإِبِلَ تَلْزِئَةً، إِذَا أَحْسَنَ رِعْيَتَهَا. وَيَقُولُونَ: لَعَنَ اللَّهُ أُمًّا لَزَأَتْ بِهِ، أَيْ وَلَدَتْهُ.

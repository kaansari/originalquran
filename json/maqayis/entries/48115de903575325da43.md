# هَلَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%84%D9%8E%D8%A7/?book=9

(هَلَا) الْهَاءُ وَاللَّامُ وَالْحَرْفُ الْمُعْتَلُّ. يَقُولُونَ: هَلَا. كِمْلَةٌ تُسَكَّنُ بِهَا الْإِنَاثُ عِنْدَ مُقَارَنَةِ الْفَحْلِ إِيَّاهَا. قَالَ:

أَلَا حَيِّيَا لَيْلَى وَقُولَا لَهَا هَلَا

وَيُقَالُ: ذَهَبَ بِذِي هِلِيَّانِ، أَيْ حَيْثُ لَا يُدْرَى

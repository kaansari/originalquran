# وَسَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B3%D9%8E%D9%81%D9%8E/?book=9

(وَسَفَ) الْوَاوُ وَالسِّينُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ تَوَسَّفَتِ الْإِبِلُ: أَخْصَبَتْ وَسَمِنَتْ وَسَقَطَ وَبَرُهَا الْأَوَّلُ وَنَبَتَ الْجَدِيدُ.

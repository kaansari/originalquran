# مَهَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%87%D9%8E%D8%B4%D9%8E/?book=9

(مَهَشَ) الْمِيمُ وَالْهَاءُ وَالشِّينُ مَا أَحْسَبُهُ أَصْلًا وَلَا فَرْعًا، لَكِنَّهُمْ يَقُولُونَ: نَاقَةٌ مَهْشَاءُ، أَسْرَعَ هُزَالُهَا. وَيَقُولُونَ: امْتَهَشَتِ الْمَرْأَةُ: حَلَقَتْ وَجْهَهَا بِمُوسَى.

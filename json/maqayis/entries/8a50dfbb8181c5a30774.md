# دَرَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%B1%D9%8E%D9%87%D9%8E/?book=9

(دَرَهَ) الدَّالُ وَالرَّاءُ وَالْهَاءُ لَيْسَ أَصْلًا; لِأَنَّ الْهَاءَ مُبْدَلَةٌ مِنْ هَمْزَةٍ. يُقَالُ: دَرَأَ أَيْ طَلَعَ، ثُمَّ يُقْلَبُ هَاءً; فَيُقَالُ دَرَهَ. وَالْمِدْرَهُ: لِسَانُ الْقَوْمِ وَالْمُتَكَلِّمُ عَنْهُمْ.

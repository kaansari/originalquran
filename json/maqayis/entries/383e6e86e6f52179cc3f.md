# خَدَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%AF%D9%91%D9%8E/?book=9

(خَدَّ) الْخَاءُ وَالدَّالُ أَصْلٌ وَاحِدٌ، وَهُوَ تَأَسُّلُ الشَّيْءِ وَامْتِدَادُهُ إِلَى السُّفْلِ. فَمِنْ ذَلِكَ الْخَدِّ خَدُّ الْإِنْسَانِ، وَبِهِ سُمِّيَتِ الْمِخَدَّةُ. وَالْخَدُّ: الشَّقُّ. وَالْأَخَادِيدُ: الشُّقُوقُ فِي الْأَرْضِ. وَالتَّخَدُّدُ: تَخَدُّدُ اللَّحْمِ مِنَ الْهُزَالِ. وَامْرَأَةٌ مُتَخَدِّدَةٌ: مَهْزُولَةٌ. وَالْخِدَادُ: مِيسَمٌ مِنَ الْمَيَاسِمِ، وَلَعَلَّهُ يَكُونُ فِي الْخَدِّ ; يُقَالُ مِنْهُ بَعِيرٌ مَخْدُودٌ.

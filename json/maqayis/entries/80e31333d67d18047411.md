# هَذَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B0%D9%8E%D8%B1%D9%8E/?book=9

(هَذَرَ) الْهَاءُ وَالذَّالُ وَالرَّاءُ: كَلِمَةٌ وَاحِدَةٌ هِيَ الْهَذَرُ، وَهُوَ الْهَذَيَانُ. وَرَجُلٌ مِهْذَارٌ وَهُذَرَةٌ وَهِذْرِيَانٌ، أَيْ كَثِيرُ الْكَلَامِ فِي خَطَلٍ.

# وَلَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%84%D9%8E%D8%AF%D9%8E/?book=9

(وَلَدَ) الْوَاوُ وَاللَّامُ وَالدَّالُ: أَصْلٌ صَحِيحٌ، وَهُوَ دَلِيلُ النَّجْلِ وَالنَّسْلِ، ثُمَّ يُقَاسُ عَلَيْهِ غَيْرُهُ. مِنْ ذَلِكَ الْوَلَدِ، وَهُوَ لِلْوَاحِدِ وَالْجَمِيعِ، وَيُقَالُ لِلْوَاحِدِ وُلْدٌ أَيْضًا. وَالْوَلِيدَةُ الْأُنْثَى، وَالْجَمْعُ وَلَائِدُ. وَتَوَلَّدَ الشَّيْءُ عَنِ الشَّيْءِ: حَصَلَ عَنْهُ. وَاللِّدَةُ نُقْصَانُهُ الْوَاوُ لِأَنَّ أَصْلَهُ وِلْدَةٌ.

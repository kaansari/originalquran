# حَزَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%B2%D9%8E%D9%86%D9%8E/?book=9

(حَزَنَ) الْحَاءُ وَالزَّاءُ وَالنُّونُ أَصْلٌ وَاحِدٌ، وَهُوَ خُشُونَةُ الشَّيْءِ وَشِدَّةٌ فِيهِ. فَمِنْ ذَلِكَ الْحَزْنِ، وَهُوَ مَا غَلُظَ مِنَ الْأَرْضِ. وَالْحُزْنُ مَعْرُوفٌ، يُقَالُ حَزَنَنِي الشَّيْءُ يَحْزُنُنِي ; وَقَدْ قَالُوا أَحْزَنَنِي. وَحُزَانَتُكَ: أَهْلُكَ وَمَنْ تَتَحَزَّنُ لَهُ.

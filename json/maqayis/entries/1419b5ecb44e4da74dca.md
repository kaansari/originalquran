# هَمَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%85%D9%8E%D9%86%D9%8E/?book=9

(هَمَنَ) الْهَاءُ وَالْمِيمُ وَالنُّونُ لَيْسَ بِشَيْءٍ. فَأَمَّا الْمُهَيْمِنُ، وَهُوَ الشَّاهِدُ فَلَيْسَ مِنْ هَذَا، إِنَّمَا هُوَ مِنْ بَابِ أَمِنَ، وَالْهَاءُ مُبْدَلَةٌ مِنْ هَمْزَةٍ.

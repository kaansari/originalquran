# مَزَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B2%D9%8E%D8%B1%D9%8E/?book=9

(مَزَرَ) الْمِيمُ وَالزَّاءُ وَالرَّاءُ كَلِمَتَانِ: الْأُولَى الْمَزِيرُ: الرَّجُلُ الْقَوِيُّ. قَالَ:

تَرَى الرَّجُلَ النَّحِيفَ فَتَزْدَرِيهِ ... وَفِي أَثْوَابِهِ أَسَدٌ مَزِيرٌ

وَالثَّانِيَةُ الْمَزْرُ: الذَّوْقُ وَالشُّرْبُ الْقَلِيلُ، وَكَذَا التَّمَزُّرُ. وَقَالَ:

تَكُونُ بَعْدَ الْحَسْوِ وَالتَّمَزُّرِ ... فِي فَمِهِ مِثْلُ عَصِيرِ السُّكَّرِ

وَيَقُولُونَ: الْمِزْرُ: نَبِيذُ الشَّعِيرِ. وَإِنْ صَحَّ فَهُوَ مِنَ الْبَابِ.

بَابُ الْمِيمِ وَالسِّينِ وَمَا يَثْلُثُهُمَا

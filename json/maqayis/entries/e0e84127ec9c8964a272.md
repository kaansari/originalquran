# هَنَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%86%D9%8E%D9%82%D9%8E/?book=9

(هَنَقَ) الْهَاءُ وَالنُّونُ وَالْقَافُ. حَكَى ابْنُ دُرَيْدٍ: الْهَنَقُ شِبْهُ الضَّجَرِ يَعْتَرِي الْإِنْسَانَ. وَأَنْشَدَ: أَهْنَقَنِي الْيَوْمَ وَفَوْقَ الْإِهْنَاقْ

# صَتَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D8%AA%D9%91%D9%8E/?book=9

(صَتَّ) الصَّادُ وَالتَّاءُ أَصْلٌ يَدُلُّ عَلَى نِزَاعٍ وَخُصُومَةٍ وَافْتِرَاقٍ، يُقَالُ لِلْجَلَبَةِ الصَّتِيتُ. وَمَا زِلْتُ أُصَاتُّ فُلَانًا، أَيْ أُخَاصِمُهُ. وَالصَّتُّ، فِيمَا يُقَالُ: المُ. وَالصَّتِيتُ: الْفِرْقَةُ. وَيَقُولُونَ إِنَّ الصَّتَّ الصَّدُّ.

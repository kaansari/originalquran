# وَسَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B3%D9%8E%D8%AF%D9%8E/?book=9

(وَسَدَ) الْوَاوُ وَالسِّينُ وَالدَّالُ: كَلِمَةٌ وَاحِدَةٌ، هِيَ الْوِسَادَةُ مَعْرُوفَةٌ، وَجَمْعُهَا وَسَائِدُ. وَتَوَسَّدْتُ يَدِيَ. وَالْوِسَادُ: مَا يَتَوَسَّدُهُ الرَّجُلُ عِنْدَ مَنَامِهِ، وَالْجَمْعُ وُسُدٌ. وَاللَّهُ أَعْلَمُ.

# زَهَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%87%D9%8E%D9%83%D9%8E/?book=9

(زَهَكَ) الزَّاءُ وَالْهَاءُ وَالْكَافُ لَيْسَ فِيهِ شَيْءٌ إِلَّا أَنَّ ابْنَ دُرَيْدٍ ذَكَرَ أَنَّهُمْ يَقُولُونَ: زَهَكَتِ الرِّيحُ التُّرَابَ، مِثْلُ سَهَكَتْ.

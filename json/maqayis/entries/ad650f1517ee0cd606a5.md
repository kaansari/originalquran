# وَغَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%BA%D9%8E%D8%A7/?book=9

(وَغَا) الْوَاوُ وَالْغَيْنُ وَالْحَرْفُ الْمُعْتَلُّ. الصَّحِيحُ مِنْهُ الْوَغَى: الْجَلَبَةُ وَالْأَصْوَاتُ. وَكَلِمَةٌ يُقَالُ إِنَّ الْأَوَاغِيَ: مَفَاجِرُ الدِّبَارِ فِي الْمَزَارِعِ.

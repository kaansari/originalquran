# نَعَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B9%D9%8E%D9%82%D9%8E/?book=9

(نَعَقَ) النُّونُ وَالْعَيْنُ وَالْقَافُ كَلِمَةٌ تَدُلُّ عَلَى صَوْتٍ. وَنَعَقَ الرَّاعِي بِالْغَنَمِ يَنْعَقُ وَيَنْعِقِ، إِذَا صَاحَ بِهِ زَجْرًا، نَعِيقًا.

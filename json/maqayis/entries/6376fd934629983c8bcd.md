# مَرَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B1%D9%8E%D8%B3%D9%8E/?book=9

(مَرَسَ) الْمِيمُ وَالرَّاءُ وَالسِّينُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى مُضَامَّةِ شَيْءٍ لِشَيْءٍ بِشِدَّةٍ وَقُوَّةٍ.

مِنْهُ الْمَرَسُ: الْحَبْلُ، سُمِّيَ لِتَمَرُّسِ قُوَاهُ بَعْضِهَا بِبَعْضٍ، وَالْجَمْعُ أَمَرَاسٌ وَمَرِسَ الْحَبْلُ يَمْرَسُ مَرَسًا: وَقَعَ بَيْنَ الْخُطَّافِ وَالْبَكْرَةِ، فَأَنْتَ تُعَالِجُهُ أَنْ تُخْرِجَهُ. وَرَجُلٌ مَرِسٌ: ذُو جَلَدٍ. وَفَحْلٌ مَرَّاسٌ: ذُو مِرَاسٍ شَدِيدٍ. يُقَالُ: امْتَرَسَتِ الْأَلْسُنُفِي الْخُصُومَاتِ: أَخَذَ بَعْضُهَا بَعْضًا. وَمِنْهُ الِامْتِرَاسُ: اللُّزُوقُ بِالشَّيْءِ وَمُلَازَمَتُهُ. قَالَ:

فَنَكِرْنَهُ فَنَفَرْنَ وَامْتَرَسَتْ بِهِ ... هَوْجَاءُ هَادِيَةٌ وَهَادٍ جُرْشُعُ

وَمِنْهُ تَمَرَّسَ فُلَانٌ بِالشَّيْءِ: احْتَكَّ بِهِ. وَالْمَرْمَرِيسُ: الدَّاهِيَةُ.

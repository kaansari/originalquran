# رَهَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%87%D9%8E%D8%B3%D9%8E/?book=9

(رَهَسَ) الرَّاءُ وَالْهَاءُ وَالسِّينُ أَصْلَانِ: أَحَدُهُمَا الِامْتِلَاءُ وَالْكَثْرَةُ، وَالْآخَرُ الْوَطْءُ.

فَالْأَوَّلُ قَوْلُهُمْ: ارْتَهَسَ الْوَادِي: امْتَلَأَ. وَارْتَهَسَ الْجَرَادُ: رَكِبَ بَعْضُهُ بَعْضًا.

وَالْأَصْلُ الْآخَرُ: الرَّهْسُ: الْوَطْءُ. وَمِنْهُ الرَّجُلُ الرَّهْوَسُ: الْأَكُولُ.

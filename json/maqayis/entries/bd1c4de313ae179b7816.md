# وَهَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%87%D9%8E%D8%B5%D9%8E/?book=9

(وَهَصَ) الْوَاوُ وَالْهَاءُ وَالصَّادُ: كَلِمَاتٌ مُتَقَارِبَةٌ، وَهِيَ الْوَهْصُ: شِدَّةُ الْوَطْءِ لِلشَّيْءِ بِالْقَدَمِ. يُقَالُ: وَهَصَ يَهِصُ. وَرَجُلٌ مَوْهُوصُ الْخَلْقِ: تَدَاخَلَتْ عِظَامُهُ. وَوَهَصْتُ الشَّيْءَ: كَسَرْتُهُ.

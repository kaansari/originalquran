# بَيَغَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%8A%D9%8E%D8%BA%D9%8E/?book=9

(بَيَغَ) الْبَاءُ وَالْيَاءُ وَالْغَيْنُ لَيْسَ بِأَصْلٍ. وَالَّذِي جَاءَ فِيهِ تَبَيُّغُ الدَّمِ، وَهُوَ هَيْجُهُ. قَالُوا: أَصْلُهُ تَبَغَّى، فَقُدِّمَتِ الْيَاءُ وَأُخِّرَتِ الْغَيْنُ، كَقَوْلِكَ جَذَبَ وَجَبَذَ، وَمَا أَطْيَبَهُ وَأَيْطَبَهُ.

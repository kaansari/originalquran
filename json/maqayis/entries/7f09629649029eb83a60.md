# بَخَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%AE%D9%8E%D9%84%D9%8E/?book=9

(بَخَلَ) الْبَاءُ وَالْخَاءُ وَاللَّامُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ: الْبُخْلُ وَالْبَخَلُ. وَرَجُلٌ بَخِيلٌ وَبَاخِلٌ. فَإِذَا كَانَ ذَلِكَ شَأْنَهُ فَهُوَ بَخَّالٌ. قَالَ رُؤْبَةُ:

فَذَاكَ بَخَّالٌ أَرُوزُ الْأَرْزِ

# وَثَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AB%D9%8E%D9%82%D9%8E/?book=9

(وَثَقَ) الْوَاوُ وَالثَّاءُ وَالْقَافُ كَلِمَةٌ تَدُلُّ عَلَى عَقْدٍ وَإِحْكَامٍ. وَوَثَّقْتُ الشَّيْءَ: أَحْكَمْتُهُ. وَنَاقَةٌ مُوَثَّقَةُ الْخَلْقِ. وَالْمِيثَاقُ: الْعَهْدُ الْمُحْكَمُ. وَهُوَ ثِقَةٌ. وَقَدْ وَثِقْتُ بِهِ.

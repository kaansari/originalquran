# فَدَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AF%D9%8E%D9%83%D9%8E/?book=9

(فَدَكَ) الْفَاءُ وَالدَّاءُ وَالْكَافُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ فَدَكُ: بَلَدٌ. وَمِنْ طَرَائِفِ ابْنِ دُرَيْدٍ: فَدَكْتُ الْقُطْنَ: نَفَشْتُهُ. قَالَ: وَهِيَ لُغَةٌ أَزْدِيَّةٌ.

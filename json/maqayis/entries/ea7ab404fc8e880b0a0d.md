# هَبَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%A8%D9%8E%D8%B4%D9%8E/?book=9

(هَبَشَ) الْهَاءُ وَالْبَاءُ وَالشِّينُ: كَلِمَةٌ وَاحِدَةٌ. يُقَالُ هُوَ يَتَهَبَّشُ، أَيْ يَتَكَسَّبُ. وَالْهُبَاشَةُ: الْكَسْبُ. قَالَ:

لَوْلَا هُبَاشَاتٌ مِنَ التَّهْبِيشِ ... لِصِبْيَةٍ كَأَفْرُخِ الْعُشُوشِ

وَهُوَ يَتَهَبَّشُ لِأَهْلِهِ.

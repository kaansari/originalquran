# وَأَيَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%A3%D9%8E%D9%8A%D9%8E/?book=9

(وَأَيَ) الْوَاوُ وَالْهَمْزَةُ وَالْيَاءُ كَلِمَتَانِ مُتَبَايِنَتَانِ: الْأُولَى الْوَعْدُ، يُقَالُ وَأَيْتُهُ أَئِيهِ وَأْيًا، وَهُوَ صَادِقُ الْوَأْيِ.

وَالثَّانِيَةُ تَدُلُّ عَلَى قُوَّةٍ أَوْ تَجَمُّعٍ وَعِظَمٍ. يُقَالُ حِمَارٌ وَأًى: قَوِيٌّ، وَكَذَلِكَ الْفَرَسُ. وَقِدْرٌ وَئِيَّةٌ: عَظِيمَةٌ. وَقَوْلُ أَوْسٍ:

وَحَطَّتْ كَمَا حَطَّتْ وَئِيَّةُ تَاجِرٍ ... وَهَى عَقْدُهَا فَارْفَضَّ مِنْهَا الطَّوَائِفُ

وَيُقَالُ الْوَئِيَّةُ: الْجُوَالِقُ. وَاللَّهُ أَعْلَمُ.

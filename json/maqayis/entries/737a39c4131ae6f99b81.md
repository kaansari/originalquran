# مَخَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AE%D9%8E%D8%B7%D9%8E/?book=9

(مَخَطَ) الْمِيمُ وَالْخَاءُ وَالطَّاءُ أُصَيْلٌ، يَدُلُّ عَلَى بُرُوزِ شَيْءٍ مِنْ كِنِّهِ، صَحِيحٌ. وَامْتَخَطَ السَّيْفَ: انْتَضَاهُ. وَأَمْخَطَ السَّهْمَ: أَنْفَذَهُ إِمْخَاطًا. وَرُبَّمَا قَالُوا: امْتَخَطَ مَا فِي يَدِهِ: اخْتَلَسَهُ.

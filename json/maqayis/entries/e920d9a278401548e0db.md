# هَمَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%85%D9%8E%D8%B9%D9%8E/?book=9

(هَمَعَ) الْهَاءُ وَالْمِيمُ وَالْعَيْنُ. يَدُلُّ عَلَى سَيَلَانِ شَيْءٍ. وَهَمَعَتِ الْعَيْنُ: سَالَ دَمْعُهَا. وَتَهَمَّعَ الرَّجُلُ: تَبَاكَى. وَسَحَابٌ هَمِعٌ: مَاطِرٌ. وَيُقَالُ: الْهِمْيَعُ: الْمَوْتُ الْوَحِيُّ.

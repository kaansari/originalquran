# نَغَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%BA%D9%8E%D8%B4%D9%8E/?book=9

(نَغَشَ) النُّونُ وَالْغَيْنُ وَالشِّينُ كَلِمَةٌ تَدُلُّ عَلَى اضْطِرَابٍ وَحَرَكَةٍ. مِنْهُ النَّغَشَانُ: الِاضْطِرَابُ. وَيُقَالُ: دَارٌ تَنْتَغِشُ، لِكَثْرَةِ مَنْ فِيهَا. وَيُقَالُ النُّغَاشِيُّ: الرَّجُلُ الْقَصِيرُ.

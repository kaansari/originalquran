# فَشَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B4%D9%91%D9%8E/?book=9

(فَشَّ) الْفَاءُ وَالشِّينُ يَدُلُّ عَلَى انْتِشَارٍ وَقِلَّةِ تَمَاسُكٍ. يُقَالُ: نَاقَةٌ فَشُوشٌ، إِذَا كَانَتْ مُنْتَشِرَةُ الشَّخْبِ. وَانْفَشَّ عَنِ الْأَمْرِ: كَسِلَ. وَالْفَشُّ: تَتَبُّعُ السَّرَقِ الدُّونِ ; وَهُوَ فَشَّاشٌ.

# تَرَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%B1%D9%8E%D8%B3%D9%8E/?book=9

(تَرَسَ) التَّاءُ وَالرَّاءُ وَالسِّينُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ التُّرْسُ، وَهُوَ مَعْرُوفٌ، وَالْجَمْعُ تِرَسَةٌ وَتِرَاسٌ وَتُرُوسٌ. قَالَ:

كَأَنَّ شَمْسًا نَزَلَتْ شُمُوسًا ... دُرُوعَنَا وَالْبَيْضَ وَالتُّرُوسَا

# بَزَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B2%D9%8E%D9%82%D9%8E/?book=9

(بَزَقَ) الْبَاءُ وَالزَّاءُ وَالْقَافُ أَصْلٌ وَاحِدٌ، وَهُوَ إِلْقَاءُ الشَّيْءِ، يُقَالُ: بَزَقَ الْإِنْسَانُ، مِثْلَ بَصَقَ. وَأَهْلُ الْيَمَنِ يَقُولُونَ: بَزَقَ الْأَرْضَ: إِذَا بَذَرَهَا.

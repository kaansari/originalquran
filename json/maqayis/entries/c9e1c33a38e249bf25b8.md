# وَطَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B7%D9%8E%D8%A8%D9%8E/?book=9

(وَطَبَ) الْوَاوُ وَالطَّاءُ وَالْبَاءُ: كَلِمَةٌ وَاحِدَةٌ، هِيَ وَطْبُ اللَّبَنِ: سِقَاؤُهُ. وَيُشَبَّهُ بِهِ الْمَرْأَةُ الْعَظِيمَةُ الثَّدْيِ، فَيُقَالُ وَطْبَاءُ. وَالْوَطْبُ: الرَّجُلُ الْجَافِي، وَهَذَا أَيْضًا مِنَ التَّشْبِيهِ.

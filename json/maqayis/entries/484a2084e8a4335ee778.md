# جَوَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%88%D9%8E%D8%AD%D9%8E/?book=9

(جَوَحَ) الْجِيمُ وَالْوَاوُ وَالْحَاءُ أَصْلٌ وَاحِدٌ، وَهُوَ الِاسْتِئْصَالُ. يُقَالُ جَاحَ الشَّيْءَ يَجُوحُهُ اسْتَأْصَلَهُ. وَمِنْهُ اشْتِقَاقُ الْجَائِحَةِ.

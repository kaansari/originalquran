# هَصَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B5%D9%8E%D8%B1%D9%8E/?book=9

(هَصَرَ) الْهَاءُ وَالصَّادُ وَالرَّاءُ: يَدُلُّ عَلَى قَبْضٍ عَلَى شَيْءٍ وَإِمَالَتِهِ. وَهَصَرْتُ الْعُودَ، إِذَا أَخَذْتَهُ بِرَأْسِهِ فَأَمَلْتَهُ إِلَيْكَ. قَالَ:

هَصَرْتُ بِغُصْنٍ ذِي شَمَارِيخَ مَيَّالِ

وَبِذَلِكَ سُمِّيَ الْأَسَدُ هَصُورًا وَهَيْصَرًا وَهَصَّارًا.

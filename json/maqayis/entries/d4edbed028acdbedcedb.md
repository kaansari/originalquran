# كَيَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%8A%D9%8E%D8%AA%D9%8E/?book=9

(كَيَتَ) الْكَافُ وَالْيَاءُ وَالتَّاءُ كَلِمَةٌ إِنْ صَحَّتْ، يَقُولُونَ: التَّكْيِيتُ تَيْسِيرُ الْجَهَازِ. قَالَ:

كَيِّتْ جِهَازَكَ إِمَّا كُنْتَ مُرْتَحِلًا ... إِنِّي أَخَافُ عَلَى أَذْوَادِكَ السَّبُعَا.

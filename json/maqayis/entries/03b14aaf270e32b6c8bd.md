# قَمَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D9%85%D9%8E%D9%86%D9%8E/?book=9

(قَمَنَ) الْقَافُ وَالْمِيمُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ: هُوَ قَمَنٌ أَنْ يَفْعَلَ كَذَا، لَا يُثَنَّى وَلَا يُجْمَعُ إِذَا فُتِحَتْ مِيمُهُ، فَإِنْ كُسِرَتْ أَوْ قُلْتَ قَمِينٌ ثَنَّيْتَ وَجَمَعْتَ. وَمَعْنَى قَمِينٍ: خَلِيقٌ.

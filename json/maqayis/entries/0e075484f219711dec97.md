# فَجَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AC%D9%8E%D9%84%D9%8E/?book=9

(فَجَلَ) الْفَاءُ وَالْجِيمُ وَاللَّامُ كَلِمَةٌ هِيَ نَبْتٌ، وَقَالَ قَوْمٌ: فَجِلَ الشَّيْءُ: غَلُظَ وَاسْتَرْخَى. وَكُلُّ شَيْءٍ عَرَّضْتَهُ فَقَدْ فَجَّلْتَهُ.

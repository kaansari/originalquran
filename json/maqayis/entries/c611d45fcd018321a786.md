# نَخَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%AE%D9%8E%D8%B7%D9%8E/?book=9

(نَخَطَ) النُّونُ وَالْخَاءُ وَالطَّاءُ يَقُولُونَ: انْتَخَطَ مِنْ أَنْفِهِ رَمَى بِهِ، وَكَأَنَّهُ مِنَ الْإِبْدَالِ وَالْأَصْلُ الْمِيمُ. قَالَ:

نَخَطْنَ بِذِبَّانِ الْمَصِيفِ الْأَزَارِقِ

وَمَا أَدْرِي أَيُّ النَّخْطِ هُوَ، مِنْهُ، أَيْ أَيُّ مَنِ انْتَخَطَ.

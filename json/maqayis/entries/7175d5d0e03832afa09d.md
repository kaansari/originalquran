# كَشَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D8%B4%D9%8E%D8%B7%D9%8E/?book=9

(كَشَطَ) الْكَافُ وَالشِّينُ وَالطَّاءُ كَلِمَةٌ تَدُلُّ عَلَى تَنْحِيَةِ الشَّيْءِ وَكَشْفِهِ. يُقَالُ: كَشَطَ الْجِلْدَ عَنِ الذَّبِيحَةِ. وَيَقُولُونَ: انْكَشَطَ رُوعُهُ، أَيْ ذَهَبَ.

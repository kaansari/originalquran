# جَهَوَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%87%D9%8E%D9%88%D9%8E/?book=9

(جَهَوَ) الْجِيمُ وَالْهَاءُ وَالْحَرْفُ الْمُعْتَلُّ يَدُلُّ عَلَى انْكِشَافِ الشَّيْءِ. يُقَالُ أَجْهَتِ السَّمَاءُ، أَقْلَعَتْ. وَيُقَالُ خِبَاءٌ مُجْهٍ لَا سِتْرَ عَلَيْهِ. وَجَهِيَ الْبَيْتُ يَجْهَى، إِذَا خَرِبَ ; وَهُوَ جَاهٍ. وَيُقَالُ إِنَّ الْجَهْوَةَ السَّهُ مَكْشُوفَةً.

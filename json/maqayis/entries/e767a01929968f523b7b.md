# نَظُفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B8%D9%8F%D9%81%D9%8E/?book=9

(نَظُفَ) النُّونُ وَالظَّاءُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ قَوْلُهُمْ: شَيْءٌ نَظِيفٌ: نَقِيٌّ، بَيِّنُ النَّظَافَةِ. وَقَدْ نَظُفَ يَنْظُفُ. وَاسْتَنْظَفْتُ مَا عِنْدَ فُلَانٍ: اسْتَوْفَيْتُهُ وَأَخَذْتُهُ كُلَّهُ. وَنَظَّفْتُهُ: نَقَّيْتُهُ، تَنْظِيفًا.

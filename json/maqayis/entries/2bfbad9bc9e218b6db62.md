# عَلِشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D9%84%D9%90%D8%B4%D9%8E/?book=9

(عَلِشَ) الْعَيْنُ وَاللَّامُ وَالشِّينُ لَيْسَ بِشَيْءٍ. عَلَى أَنَّهُمْ يَقُولُونَ إِنَّ الْعِلَّوْشَ: الذِّئْبُ. وَلَيْسَ قِيَاسُهُ [صَحِيحًا] لِأَنَّ الشِّينَ لَا تَكُونُ بَعْدَ اللَّامِ.

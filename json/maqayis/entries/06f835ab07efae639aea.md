# ظَأَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B8%D9%8E%D8%A3%D9%8E%D8%A8%D9%8E/?book=9

(ظَأَبَ) الظَّاءُ وَالْهَمْزَةُ وَالْبَاءُ كَلِمَتَانِ مُتَبَايِنَتَانِ: إِحْدَاهُمَا الظَّأْبُ، وَهُوَ سِلْفُ الرَّجُلِ. وَالْأُخْرَى الْكَلَامُ وَالْجَلَبَةُ. قَالَ:

يَصُوعُ عُنُوقَهَا أَحَوَى زَنِيمٌ ... لَهُ ظَأْبٌ كَمَا صَخِبَ الْغَرِيمُ

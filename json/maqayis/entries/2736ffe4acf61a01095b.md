# وَثَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AB%D9%8E%D8%AC%D9%8E/?book=9

(وَثَجَ) الْوَاوُ وَالثَّاءُ وَالْجِيمُ يَدُلُّ عَلَى اكْتِنَازٍ. وَوَثُجَ الْفَرَسُ وَثَاجَةً: اكْتَنَزَ لَحْمُهُ، وَهُوَ وَثِيجٌ. وَاسْتَوْثَجَ نَبْتُ الْأَرْضِ: عَلِقَ بَعْضُهُ بَعْضًا. وَأَرْضٌ مُؤْتَثِجَةٌ: كَثِيرَةُ الْكَلَأِ.

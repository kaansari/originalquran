# جَيَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%8A%D9%8E%D8%B4%D9%8E/?book=9

(جَيَشَ) الْجِيمُ وَالْيَاءُ وَالشِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ الثَّوَرَانُ وَالْغَلَيَانُ. يُقَالُ جَاشَتِ الْقِدْرُ تَجِيشُ جَيْشًا وَجَيَشَانًا. قَالَ:

وَجَاشَتْ بِهِمْ يَوْمًا إِلَى اللَّيْلِ قِدْرُنَا ... تَصُكُّ حَرَابِيَّ الظُّهُورِ وَتَدْسَعُ

وَمِنْهُ قَوْلُهُمْ: جَاشَتْ نَفْسُهُ، كَأَنَّهَا غَلَتْ. وَالْجَيْشُ مَعْرُوفٌ، وَهُوَ مِنَ الْبَابِ، لِأَنَّهَا جَمَاعَةٌ تَجِيشُ.

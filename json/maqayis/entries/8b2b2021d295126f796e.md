# حِمْلَاقُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%90%D9%85%D9%92%D9%84%D9%8E%D8%A7%D9%82%D9%8F/?book=9

(الْحِمْلَاقُ) وَهُوَ مَا غَطَّتْهُ الْجُفُونُ مِنْ بَيَاضِ الْمُقْلَةِ. وَيُقَالُ حَمْلَقَ، إِذَا فَتَحَ عَيْنَهُ وَنَظَرَ نَظَرًا شَدِيدًا.

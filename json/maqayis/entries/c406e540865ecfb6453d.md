# خَسَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B3%D9%91%D9%8E/?book=9

(خَسَّ) الْخَاءُ وَالسِّينُ أَصْلَانِ: أَحَدُهُمَا حَقَارَةُ الشَّيْءِ، وَالْآخَرُ تَدَاوُلُ الشَّيْءِ.

فَالْأَوَّلُ: الْخَسِيسُ: الْحَقِيرُ ; يُقَالُ خَسَّ الرَّجُلُ نَفْسَهُ وَأَخَسَّ، إِذَا أَتَى بِفِعْلٍ خَسِيسٍ. وَمِنْ هَذَا الْبَابِ جَاوَزَتِ النَّاقَةُ خَسِيسَتَهَا، إِذَا جَاوَزَتْ سِنَّ الْحِقَّةِ وَالْجَذَعَةِ وَالثَّنِيَّةِ وَلَحِقَتْ بِالْبُزُولِ. وَهُوَ الْقِيَاسُ ; لِأَنَّ كُلَّ هَذِهِ الْأَسْنَانِ دُونَ الْبُزُولِ.

وَالْأَصْلُ الثَّانِي قَوْلُ الْعَرَبِ: تَخَاسَّ الْقَوْمُ الْأَمْرَ، إِذَا تَدَاوَلُوهُ وَتَسَابَقُوهُ، أَيُّهُمْ يَأْخُذُهُ. وَيُقَالُ: هَذِهِ الْأُمُورُ خِسَاسُ بَيْنَهُمْ، أَيْ دُوَلٍ. قَالَ ابْنُ الزِّبَعْرَى:

وَالْعَطَيَّاتُ خِسَاسٌ بَيْنَهُمْ ... وَبَنَاتُ الدَّهْرِ يَلْعَبْنَ بِكُلْ

# شَرَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%B1%D9%8E%D8%B5%D9%8E/?book=9

(شَرَصَ) الشِّينُ وَالرَّاءُ وَالصَّادُ مَا أَحْسَبُ فِيهِ شَيْئًا صَحِيحًا ; لِأَنِّي لَا أَرَى قِيَاسَهَ مُطَّرِدًا. عَلَى أَنَّهُمْ يَقُولُونَ إِنَّ الشِّرْصَتَيْنِ: نَاحِيَتَا النَّاصِيَةِ مِمَّا رَقَّ فِيهِ الشَّعَرُ. وَيُقَالُ لِكُلِّ ضَخْمٍ رِخْوٍ: شِرْوَاصٌ. وَيُقَالُ: إِنَّ الشِّرَصَ الْغَلْظُ مِنَ الْأَرْضِ.

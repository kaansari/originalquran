# وَغَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%BA%D9%8E%D9%81%D9%8E/?book=9

(وَغَفَ) الْوَاوُ وَالْغَيْنُ وَالْفَاءُ ثَلَاثُ كَلِمَاتٍ.

الْوَغْفُ: سُرْعَةُ الْعَدْوِ، وَيُقَالُ هُوَ الْإِيغَافُ، وَأَوْغَفَ يُوغِفُ.

وَالثَّانِيَةُ الْوَغْفُ، يُقَالُ: ضَعْفُ الْبَصَرِ.

وَالثَّالِثَةُ: الْوَغْفُ: قِطْعَةُ أَدَمٍ، يُشَدُّ عَلَى بَطْنِ التَّيْسِ لِئَلَّا يَنْزُوَ.

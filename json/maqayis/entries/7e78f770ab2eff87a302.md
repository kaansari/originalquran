# صَلَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%84%D9%8E%D8%AE%D9%8E/?book=9

(صَلَخَ) الصَّادُ وَاللَّامُ وَالْخَاءُ فِيهِ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ: إِنَّ الْأَصْلَخَ الْأَصَمُّ. قَالَ سَلَمَةُ: قَالَ الْفَرَّاءُ: " كَانَ الْكُمَيْتُ أَصَمَّ أَصْلَخَ ".

# وَذَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B0%D9%8E%D9%84%D9%8E/?book=9

(وَذَلَ) الْوَاوُ وَالذَّالُ وَاللَّامُ: كَلِمَتَانِ إِحْدَاهُمَا مَشْهُورَةٌ قَدْ قِيلَتْ، الْوَذِيلَةُ، وَهِيَ الْمِرْآةُ. وَالْأُخْرَى: الْوَذَالَةُ: مَا يَقْطَعُ الْجَزَّارُ مِنَ اللَّحْمِ بِغَيْرِ قَسْمٍ، يُقَالُ: تَوَذَّلُوا مِنْهُ شَيْئًا.

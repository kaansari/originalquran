# زَجَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%AC%D9%8E%D9%89/?book=9

(زَجَى) الزَّاءُ وَالْجِيمُ وَالْحَرْفُ الْمُعْتَلُّ يَدُلُّ عَلَى الرَّمْيِ بِالشَّيْءِ وَتَسْيِيرِهِ مِنْ غَيْرِ حَبْسٍ. يُقَالُ أَزَجَّتِ الْبَقَرَةُ وَلَدَهَا، إِذَا سَاقَتْهُ. وَالرِّيحُ تُزْجِي السَّحَابَ: تَسُوقُهُ سَوْقًا رَفِيقًا. فَأَمَّا الْمُزْجَى فَالشَّيْءُ الْقَلِيلُ، وَهُوَ مِنْ قِيَاسِ الْبَابِ، أَيْ يُدْفَعُ بِهِ الْوَقْتُ. وَهَذِهِ بِضَاعَةٌ مُزْجَاةٌ، أَيْ يَسِيرَةُ الِانْدِفَاعِ.

وَمِنَ الْبَابِ زَجَا الْخَرَاجُ يَزْجُو، أَيْ تَيَسَّرَتْ جِبَايَتُهُ.

# حِسْكِلُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%90%D8%B3%D9%92%D9%83%D9%90%D9%84%D9%8F/?book=9

(الْحِسْكِلُ) : الصِّغَارُ مِنْ كُلِّ شَيْءٍ. وَهَذَا مِمَّا زِيدَتْ فِيهِ الْكَافُ، وَإِنَّمَا الْأَصْلُ الْحِسْلُ. يُقَالُ لِوَلَدِ الضَّبِّ حِسْلٌ.

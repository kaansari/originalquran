# لَعَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B9%D9%91%D9%8E/?book=9

(لَعَّ) اللَّامُ وَالْعَيْنُ أُصَيْلٌ صَحِيحٌ يَدُلُّ عَلَى اضْطِرَابٍ وَبَصْبَصَةٍ. مِنْ ذَلِكَ اللَّعْلَعُ: السَّرَابُ; وَلَعْلَعَتُهُ: بَصْبَصَتُهُ. وَتَلَعْلَعَ الشَّيْءُ: اضْطَرَبَ حَتَّى تَكَسَّرَ. وَلَعْلَعَ الْكَلْبُ: دَلَعَ لِسَانَهُ. وَامْرَأَةٌ لَعَّةٌ: خَفِيفَةٌ. وَتُلَعْلِعُ مِنَ الْجُوعِ: تَضَوَّرَ. وَاللَّعَاعَةُ: بَقْلَةٌ نَاعِمَةٌ. وَأَلَعَّتِ الْأَرْضُ: أَنْبَتَتً اللُّعَاعَ; وَتَلَعَّيْتُ: أَخَذْتُ اللُّعَاعَ. وَهَذِهِ الْكَلِمَةُ الْأَخِيرَةُ شَاذَّةٌ.

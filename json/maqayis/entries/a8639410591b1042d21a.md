# أَنَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D9%86%D9%8E%D8%A8%D9%8E/?book=9

(أَنَبَ) الْهَمْزَةُ وَالنُّونُ وَالْبَاءُ، حَرْفٌ وَاحِدٌ، أَنَّبْتُهُ تَأْنِيبًا، أَيْ: وَبَّخْتُهُ وَلُمْتُهُ. وَالْأُنْبُوبُ مَا بَيْنَ كُلِّ عُقْدَتَيْنِ. وَيَزْعُمُونَ أَنَّ الْأَنَابَ الْمِسْكُ، وَاللَّهُ أَعْلَمُ بِصِحَّتِهِ. وَيُنْشِدُونَ قَوْلَ الْفَرَزْدَقِ:

كَأَنَّ تَرِيكَةً مِنْ مَاءِ مُزْنٍ ... وَدَارِيَّ الْأَنَابِ مَعَ الْمُدَامِ

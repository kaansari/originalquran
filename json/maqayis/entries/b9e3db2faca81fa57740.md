# يَتَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%8A%D9%8E%D8%AA%D9%8E%D9%86%D9%8E/?book=9

(يَتَنَ) الْيَاءُ وَالتَّاءُ وَالنُّونُ: كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْيَتْنُ، وَهُوَ الْفَصِيلُ يَخْرُجُ رِجْلَاهُ عِنْدَ الْوِلَادَةِ قَبْلَ رَأْسِهِ. يُقَالُ: أَيْتَنَتِ النَّاقَةُ وَالْمَرْأَةُ، إِذَا وَلَدَتْ يَتْنًا.

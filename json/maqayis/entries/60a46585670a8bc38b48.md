# جَحَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%AD%D9%8E%D9%86%D9%8E/?book=9

(جَحَنَ) الْجِيمُ وَالْحَاءُ وَالنُّونُ أَصْلٌ وَاحِدٌ، وَهُوَ سُوءُ النَّمَاءِ وَصِغَرُ الشَّيْءِ فِي نَفْسِهِ. فَالْجَحَنُ سُوءُ الْغِذَاءِ، وَالْجَحِنُ السَّيِّئُ الْغِذَاءِ. قَالَ الشَّمَّاخُ:

وَقَدْ عَرِقَتْ مَغَابِنُهَا وَجَادَتْ ... بِدِرَّتِهَا قِرَى جَحِنٍ قَتِينِ

الْقَتِينُ: الْقَلِيلُ الطُّعْمِ. يَصِفُ قُرَادًا، جَعَلَهُ جَحِنًا لِسُوءِ غِذَائِهِ. وَالْمُجْحَنُ مِنَ النَّبَاتِ: الْقَصِيرُ الَّذِي لَمْ يَتِمَّ. وَأَمَّا [جَحْوَانُ فَاشْتِقَاقُهُ مِنْ] الْجَحْوَةِ وَ [هِيَ] الطَّلْعَةُ.

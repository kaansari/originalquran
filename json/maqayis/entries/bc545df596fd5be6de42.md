# نَبَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%A8%D9%8E%D8%AB%D9%8E/?book=9

(نَبَثَ) النُّونُ وَالْبَاءُ وَالثَّاءُ أَصْلٌ يَدُلُّ عَلَى إِبْرَازِ شَيْءٍ. وَنَبَثَ التُّرَابَ: أَخْرَجَهُ مِنَ الْبِئْرِ وَالنَّهْرِ، وَذَلِكَ الْمُسْتَخْرَجِ نَبِيثَةٌ، وَالْجَمْعُ نَبَائِثُ. وَالنَّابِثُ: الْحَافِرُ. وَقَوْلُهُمْ: خَبِيثٌ نَبِيثٌ، إِنَّمَا هُوَ إِتْبَاعٌ.

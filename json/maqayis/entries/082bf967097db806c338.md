# خَلَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%84%D9%8E%D9%85%D9%8E/?book=9

(خَلَمَ) الْخَاءُ وَاللَّامُ وَالْمِيمُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى الْإِلْفِ وَالْمُلَازَمَةِ. فَالْخِلْمُ: كِنَاسُ الظُّبَى، ثُمَّ اشْتُقَّ مِنْهُ الْخِلْمُ، وَهُوَ الْخِدْنُ. وَالْأَصْلُ وَاحِدٌ.

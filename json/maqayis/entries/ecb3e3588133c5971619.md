# حَوَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%88%D9%8E%D8%AA%D9%8E/?book=9

(حَوَتَ) الْحَاءُ وَالْوَاوُ وَالتَّاءُ أَصْلٌ صَحِيحٌ مُنْقَاسٌ، وَهُوَ مِنَ الِاضْطِرَابِ وَالرَّوَغَانِ، فَالْحُوتُ الْعَظِيمُ مِنَ السَّمَكِ، وَهُوَ مُضْطَرِبٌ أَبَدًا غَيْرُ مُسْتَقِرٍّ. وَالْعَرَبُ تَقُولُ: حَاوَتَنِي فُلَانٌ، إِذَا رَاوَغَنِي. وَيُنْشَدُ هَذَا الْبَيْتُ:

ظَلَّتْ تُحَاوِتُنِي رَمْدَاءُ دَاهِيَةٌ ... يَوْمَ الثَّوِيَّةِ عَنْ أَهْلِي وَعَنْ مَالِي

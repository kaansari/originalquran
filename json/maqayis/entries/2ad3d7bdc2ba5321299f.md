# أَضَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%B6%D9%8E%D9%85%D9%8E/?book=9

(أَضَمَ) الْهَمْزَةُ وَالضَّادُ وَالْمِيمُ أَصْلٌ وَاحِدٌ وَكَلِمَةٌ وَاحِدَةٌ، وَهُوَ الْحِقْدُ، يُقَالُ: أَضِمَ عَلَيْهِ: إِذَا حَقَدَ وَاغْتَاظَ. قَالَ الْجَعْدِيُّ:

وَأَزْجُرُ الْكَاشِحَ الْعَدُوَّ إِذَا اغْ ... تَابَكَ زَجْرًا مِنِّي عَلَى أَضَمِ

# كَدَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D8%AF%D9%8E%D9%87%D9%8E/?book=9

(كَدَهَ) الْكَافُ وَالدَّالُ وَالْهَاءُ لَيْسَ بِشَيْءٍ. عَلَى أَنَّهُمْ يَقُولُونَ: الْكَدْهُ: الصَّكُّ بِالْحَجَرِ. يُقَالُ: كَدَهَ يَكْدَهُ. وَسَقَطَ الشَّيْءُ فَتَكَدَّهَ، أَيِ انْكَسَرَ.

# قَلَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D9%84%D9%8E%D8%B7%D9%8E/?book=9

(قَلَطَ) الْقَافُ وَاللَّامُ وَالطَّاءُ لَيْسَ فِيهِ شَيْءٌ يَصِحُّ. غَيْرَ أَنَّ ابْنَ دُرَيْدٍ قَالَ: رَجُلٌ قُلَاطٌ: قَصِيرٌ. وَلَعَلَّ هَذَا مِنْ قَوْلِهِمْ رَجُلٌ قَلَطِيٌّ.

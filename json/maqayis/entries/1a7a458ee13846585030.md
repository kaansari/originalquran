# هَمَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%85%D9%8E%D9%84%D9%8E/?book=9

(هَمَلَ) الْهَاءُ وَالْمِيمُ وَاللَّامُ: أَصْلٌ وَاحِدٌ. أَهْمَلْتُ الشَّيْءَ، إِذَا خَلَّيْتَ بَيْنَهُ وَبَيْنَ نَفْسِهِ. وَالْهَمَلُ: السُّدَى. وَالْهَمَلُ: الْمَالُ لَا مَانِعَ لَهُ. وَهَمَلَتِ الْعَيْنُ، مِثْلَ هَمَرَتْ. وَاللَّهُ أَعْلَمُ بِالصَّوَابِ.

# وَكَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%83%D9%8E%D8%AD%D9%8E/?book=9

(وَكَحَ) الْوَاوُ وَالْكَافُ وَالْحَاءُ: كَلِمَةٌ تَدُلُّ عَلَى صَلَابَةٍ وَشِدَّةٍ. مِنْهُ الْأَوْكَحُ: الْحَجَرُ. وَحَفَرَ حَتَّى أَوْكَحَ، أَيْ وَصَلَ إِلَى حَجَرٍ لَا يَنْفُذُ فِيهِ الْحَدِيدُ. وَاسْتَوْكَحَ الْفَرْخُ: غَلُظَ. وَهَذِهِ فِرَاخٌ وُكَحٌ.

# طَرَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%B1%D9%8E%D9%85%D9%8E/?book=9

(طَرَمَ) الطَّاءُ وَالرَّاءُ وَالْمِيمُ أُصَيْلٌ صَحِيحٌ يَدُلُّ عَلَى تَرَاكُمِ شَيْءٍ. يَقُولُونَ: الطُّرَامَةُ: الْخُضْرَةُ عَلَى الْأَسْنَانِ. وَيَقُولُونَ: الطِّرْمُ: الْعَسَلُ. وَالطِّرْيَمُ: السَّحَابُ الْغَلِيظُ.

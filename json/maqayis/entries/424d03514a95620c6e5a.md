# صَغَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D8%BA%D9%8E%D9%84%D9%8E/?book=9

(صَغَلَ) الصَّادُ وَالْغَيْنُ وَاللَّامُ لَيْسَ بِشَيْءٍ، إِنَّمَا الصَّغِلُ السَّيِّئُ الْغِذَاءِ. وَالْأَصْلُ فِيهِ السِّينُ: سَغِلٌ. وَاللَّهُ أَعْلَمُ بِالصَّوَابِ.

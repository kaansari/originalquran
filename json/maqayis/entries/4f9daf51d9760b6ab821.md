# رَمَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%85%D9%8E%D8%AC%D9%8E/?book=9

(رَمَجَ) الرَّاءُ وَالْمِيمُ وَالْجِيمُ لَيْسَ أَصْلًا، وَفِيهِ مَا يُقْبَلُ وَيُعْتَمَدُ عَلَيْهِ، لَكِنَّهُمْ يَقُولُونَ: رَمَّجَ الْأَثَرَ بِالتُّرَابِ; وَرَمَّجَ السُّطُورَ: أَفْسَدَهَا.

# جَنَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%86%D9%8E%D8%AB%D9%8E/?book=9

(جَنَثَ) الْجِيمُ وَالنُّونُ وَالثَّاءُ أَصْلٌ وَاحِدٌ، وَهُوَ الْأَصْلُ وَالْإِحْكَامُ. يُقَالُ لِأَصْلِ كُلِّ شَيْءٍ جِنْثُهُ. ثُمَّ يُفَرَّعُ مِنْهُ، وَهُوَ الْجُنْثِيُّ، وَهُوَ الزَّرَّادُ ; لِأَنَّهُ يُحْكِمُ عَمَلَ الزَّرَدِ. فَأَمَّا قَوْلُهُ:

أَحْكَمَ الْجِنْثِيُّ مِنْ عَوْرَاتِهَا ... كُلَّ حِرْبَاءٍ إِذَا أُكْرِهَ صَلْ

فَإِنَّهُ أَرَادَ الزَّرَّادَ، أَيْ أَحْكَمَ حَرَابِيَّهَا، وَهِيَ الْمَسَامِيرُ. وَمَنْ نَصَبَ الْجِنْثِيَّ أَرَادَ السَّيْفَ، يَجْعَلُ الْفِعْلَ لِكُلِّ حِرْبَاءٍ، وَيَكُونُ مَعْنَى أَحْكَمَ: مَنَعَ. يَقُولُ: هُوَ زَرَدٌ يَمْنَعُ حِرْبَاؤُهُ السَّيْفَ أَنْ يَعْمَلَ فِيهِ. وَقَالَ الشَّاعِرُ فِي السَّيْفِ:

وَلَكِنَّهَا سُوقٌ يَكُونُ بِيَاعُهَا ... بِجُنْثِيَّةٍ قَدْ أَخْلَصَتْهَا الصَّيَاقِلُ

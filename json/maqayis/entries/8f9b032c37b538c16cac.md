# هَبَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%A8%D9%8E%D8%B5%D9%8E/?book=9

(هَبَصَ) الْهَاءُ وَالْبَاءُ وَالصَّادُ: كَلِمَةٌ وَاحِدَةٌ. الْهَبَصُ: النَّشَاطُ. رَجُلٌ هَبِصٌ. قَالَ: مَرَّ وَأَعْطَانِي رِشَاءً مَلِصَا ... كَذَنَبِ الذِّيبِ يُعَدِّيِ هَبِصَا

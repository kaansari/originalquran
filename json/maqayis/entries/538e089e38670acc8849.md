# رَقَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%82%D9%8E%D8%B7%D9%8E/?book=9

(رَقَطَ) الرَّاءُ وَالْقَافُ وَالطَّاءُ يَدُلُّ عَلَى اخْتِلَاطِ لَوْنٍ بِلَوْنٍ. فَالرُّقْطَةُ: سَوَادٌ يَشُوبُهُ نُقَطُ بَيَاضٍ. يُقَالُ دَجَاجَةٌ رَقْطَاءُ. وَالْأَرْقَطُ: النَّمِرُ. وَيُقَالُ: ارْقَاطَّ الْعَرْفَجُ، إِذَا خَالَطَ سَوَادَهُ نُقَطٌ.

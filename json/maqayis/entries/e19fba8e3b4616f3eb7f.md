# وَبَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%A8%D9%8E%D8%B7%D9%8E/?book=9

(وَبَطَ) الْوَاوُ وَالْبَاءُ وَالطَّاءُ: كَلِمَةٌ تَدُلُّ عَلَى ضَعْفٍ. يُقَالُ: وَبِطَ رَأْيُهُ: ضَعُفَ. وَالْوَابِطُ: الْجَبَانُ. وَوَبَطَنِي فُلَانٌ عَنْ حَاجَتِي: حَبَسَنِي.

# لَبَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%A8%D9%8E%D9%83%D9%8E/?book=9

(لَبَكَ) اللَّامُ وَالْبَاءُ وَالْكَافُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى خَلْطِ شَيْءٍ بِشَيْءٍ. يُقَالُ لَبَكْتُ عَلَى فُلَانٍ الْأَمْرَ أَلْبِكُهُ، إِذَا خَلَطْتَهُ عَلَيْهِ. وَسَأَلَ رَجُلٌ الْحَسَنَ عَنْ شَيْءٍ فَلَمْ يُبَيِّنْ فَقَالَ: " لَبَّكْتَ عَلَيَّ ". وَيُقَالُ: [لَبَكْتُ] الطَّعَامَ بِعَسَلٍ وَغَيْرِهِ، إِذَا خَلَطْتُهُمَا. قَالَ:

إِلَى رُدُحٍ مِنَ الشِّيزَى مِلَاءٍ ...بَ الْبُرِّ يُلْبَكُ بِالشِّهَادِ

وَمِنَ الْبَابِ: مَا ذُقْتُ عَبَكَةً وَلَا لَبَكَةً. يَقُولُونَ: هِيَ اللُّقْمَةُ مِنَ الْحَيْسِ.

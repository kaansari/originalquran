# هَذَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B0%D9%8E%D9%89/?book=9

(هَذَى) الْهَاءُ وَالذَّالُ وَالْحَرْفُ الْمُعْتَلُّ: كَلِمَةٌ وَاحِدَةٌ: الْهَذَيَانُ: كَلَامٌ لَا يُعْقَلُ كَكَلَامِ الْمَعْتُوهِ. يُقَالُ: هَذَى يَهْذِي. وَحَكَى ابْنُ دُرَيْدٍ فِي الْمَهْمُوزِ: هَذَأْتُ اللَّحْمَ بِالسِّكِّينِ هَذْءًا: قَطَعْتُهُ.

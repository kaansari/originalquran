# بَغَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%BA%D9%8E%D8%B4%D9%8E/?book=9

(بَغَشَ) الْبَاءُ وَالْغَيْنُ وَالشِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ الْمَطَرُ الضَّعِيفُ، وَيُقَالُ لَهُ الْبَغْشُ. وَأَرْضٌ مَبْغُوشَةٌ. وَجَاءَ فِي الشِّعْرِ: مَطَرٌ بَاغِشٌ.

# وَفَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%81%D9%8E%D8%B9%D9%8E/?book=9

(وَفَعَ) الْوَاوُ وَالْفَاءُ وَالْعَيْنُ. يَقُولُونَ: الْوَفْعَةُ: خِرْقَةٌ يُقْتَبَسُ فِيهَا نَارٌ. وَالْوَفِيعَةُ كَالسَّلَّةِ تُتَّخَذُ مِنَ الْعَرَاجِينِ. وَيُقَالُ الْوَفْعَةُ: صِمَامُ الْقَارُورَةِ.

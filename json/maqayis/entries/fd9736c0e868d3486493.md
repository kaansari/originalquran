# دَرَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%B1%D9%8E%D8%AD%D9%8E/?book=9

(دَرَحَ) الدَّالُ وَالرَّاءُ وَالْحَاءُ أُصَيْلٌ أَيْضًا. يَقُولُونَ لِلرَّجُلِ الْقَصِيرِ: دِرْحَايَةٌ، وَيَكُونُ مَعَ ذَلِكَ ضَخْمًا. قَالَ:

عَكَوَّكًا إِذَا مَشَى دِرْحَايَهْ

وَاللَّهُ أَعْلَمُ.

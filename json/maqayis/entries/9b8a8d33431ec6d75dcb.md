# ضَمَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D9%85%D9%8E%D8%AC%D9%8E/?book=9

(ضَمَجَ) الضَّادُ وَالْمِيمُ وَالْجِيمُ لَيْسَ بِشَيْءٍ، وَكَذَلِكَ مَا أَشْبَهَهُ. فَأَمَّا الضَّمْخُ بِالْخَاءِ فَصَحِيحٌ. يُقَالُ: تَضَمَّخَ بِالطِّيبِ، وَهُوَ مُتَضَمِّخٌ.

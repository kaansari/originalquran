# يَفَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%8A%D9%8E%D9%81%D9%8E%D8%B9%D9%8E/?book=9

(يَفَعَ) الْيَاءُ وَالْفَاءُ وَالْعَيْنُ: كَلِمَةٌ تَدُلُّ عَلَى الِارْتِفَاعِ. فَالْيَفَاعُ: مَا عَلَا مِنَ الْأَرْضِ. وَمِنْهُ يُقَالُ: أَيْفَعَ الْغُلَامُ: إِذَا عَلَا شَبَابُهُ، فَهُوَ يَافِعٌ، وَلَا يُقَالُ مُوفِعٌ.

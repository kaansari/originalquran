# رَوَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%88%D9%8E%D9%85%D9%8E/?book=9

(رَوَمَ) الرَّاءُ وَالْوَاوُ وَالْمِيمُ أَصْلٌ يَدُلُّ عَلَى طَلَبِ الشَّيْءِ. وَيُقَالُ رُمْتُ الشَّيْءَ أَرُومُهُ رَوْمًا. وَالْمَرَامُ: الْمَطْلَبُ. قَالَ ابْنُ الْأَعْرَابِيِّ: يُقَالُ رَوَّمْتُ فُلَانًا وَبِفُلَانٍ، إِذَا جَعَلْتَهُ يَرُومُ [الشَّيْءَ] وَيَطْلُبُهُ.

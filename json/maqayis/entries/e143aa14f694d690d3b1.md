# وَرَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B1%D9%8E%D8%A8%D9%8E/?book=9

(وَرَبَ) الْوَاوُ وَالرَّاءُ وَالْبَاءُ: كَلِمَتَانِ: إِحْدَاهُمَا الْوَرِبُ وَهُوَ الْفِتْرُ. وَالثَّانِيَةُ الْوَرَبُ: الْفَسَادُ، يُقَالُ عِرْقٌ وَرِبٌ، أَيْ فَاسِدٌ.

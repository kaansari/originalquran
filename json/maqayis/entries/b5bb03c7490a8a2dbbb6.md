# لَكِيَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%83%D9%90%D9%8A%D9%8E/?book=9

(لَكِيَ) اللَّامُ وَالْكَافُ وَالْحَرْفُ الْمُعْتَلُّ أَوِ الْمَهْمُوزُ، يَدُلُّ عَلَى لُزُومِ مَكَانٍ وَتَبَاطُؤٍ. وَلَكِيتُ بِفُلَانٍ لَكًى مَقْصُورٌ، إِذَا لَزِمْتَهُ. وَقَالَ أَبُو بَكْرٍ: لَكِيَ بِالْمَكَانِ، إِذَا أَقَامَ بِهِ، يُهْمَزُ وَلَا يُهْمَزُ. وَتَلَكَّأَ الرَّجُلُ تَلَكُّؤًا: تَبَاطَأَ عَنِ الشَّيْءِ وَيُقَالُ: لَكَأْتُ الرَّجُلَ لَكْأً: جَلَدْتُهُ بِالسَّوْطِ.

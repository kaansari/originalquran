# مَوَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%88%D9%8E%D8%B5%D9%8E/?book=9

(مَوَصَ) الْمِيمُ وَالْوَاوُ وَالصَّادُ كَلِمَةٌ وَاحِدَةٌ، هُوَ الْمَوْصُ: غَسْلُ الثَّوْبِ، يُقَالُ مُصْتُهُ أَمُوصُهُ ; وَالْمُوَاصَةُ: الْغُسَالَةُ، قَالَ امْرُؤُ الْقَيْسِ:

بِأَسْوَدَ مُلْتَفِّ الْغَدَائِرِ وَارِدٍ ... وَذِي أُشَُرٍ تَشُوصُهُ وَتَمُوصُ.

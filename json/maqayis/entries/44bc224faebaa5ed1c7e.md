# لَزَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B2%D9%8E%D8%A8%D9%8E/?book=9

(لَزَبَ) اللَّامُ وَالزَّاءُ وَالْبَاءُ يَدُلُّ عَلَى ثُبُوتِ شَيْءٍ وَلُزُومِهِ. يُقَالُ: لِلَّازِمِ لَازِبٌ. وَصَارَ هَذَا الشَّيْءُ ضَرْبَةَ لَازِبٍ، أَيْ لَا يَكَادُ يُفَارِقُ، قَالَ النَّابِغَةُ:

وَلَا يَحْسِبُونَ الْخَيْرَ لَا شَرَّ بَعْدَهُ ... وَلَا يَحْسِبُونَ الشَّرَّ ضَرْبَةَ لَازِبٍ وَاللَّزْبَةُ: السَّنَةُ الشَّدِيدَةُ، وَالْجَمْعُ لَزْبَاتٌ كَأَنَّ الْقَحْطَ لَزَبَ، أَيْ ثَبَتَ فِيهَا.

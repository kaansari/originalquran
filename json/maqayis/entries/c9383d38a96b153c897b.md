# نَسَغَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B3%D9%8E%D8%BA%D9%8E/?book=9

(نَسَغَ) النُّونُ وَالسِّينُ وَالْغَيْنُ أَصْلٌ يَدُلُّ عَلَى غَرْزِ شَيْءٍ بِشَيْءٍ. وَنَسَغَ الْخُبْزَةَ: غَرَزَهَا بِرِيشِ الطَّائِرِ: وَهِيَ الْمِنْسَغَةُ. وَنَسَغَتِ الْوَاشِمَةُ: غَرَزَتِ الْيَدَ بِالْإِبْرَةِ. ثُمَّ يَقُولُونَ: نَسَغْتُ الدَّابَّةَ بِرِجْلِي لِيَثُورَ.

وَيَتَوَسَّعُونَ فِيهِ فَيَقُولُونَ: نَسَغْتُ اللَّبَنَ بِالْمَاءِ: مَذَقْتُهُ. وَنَسَغَهُ بِالْعَصَا: ضَرَبَهُ.

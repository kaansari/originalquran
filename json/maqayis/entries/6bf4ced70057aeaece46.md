# بَظَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B8%D9%8E%D9%89/?book=9

(بَظَى) الْبَاءُ وَالظَّاءُ وَالْحَرْفُ الْمُعْتَلُّ أَصْلٌ وَاحِدٌ، وَهُوَ تَمَكُّنُ الشَّيْءِ مَعَ لِينٍ وَنَعْمَةٍ فِيهِ. يُقَالُ: بَظِيَ لَحْمُهُ اكْتَنَزَ، وَلَحْمُهُ خَظَا بَظًا. وَرُبَّمَا قَالُوا خَظِيَتِ الْمَرْأَةُ وَبَظِيَتْ، وَهُوَ مِنْ ذَلِكَ الْأَصْلِ، لَكِنَّهَا فِيمَا يُقَالُ: دَخِيلٌ.

# لَغَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%BA%D9%8E%D8%AF%D9%8E/?book=9

(لَغَدَ) اللَّامُ وَالْغَيْنُ وَالدَّالُ كَلِمَةٌ وَاحِدَةٌ. اللَّغَادِيدُ: لَحَمَاتٌ تَكُونُ فِي اللَّهَوَاتِ، وَاحِدُهَا لُغْدُودٌ ; وَيُقَالُ لُغْدٌ وَأَلْغَادٌ. وَجَاءَ فُلَانٌ مُتَلَغِّدًا، أَيْ مُتَغَيِّظًا ; وَهَذَا كَأَنَّهُ بَلَغَ الْغَيْظُ أَلْغَادَهُ.

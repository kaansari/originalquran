# كَهَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%87%D9%8E%D8%A7/?book=9

(كَهَا) الْكَافُ وَالْهَاءُ وَالْحَرْفُ الْمُعْتَلُّ كَلِمَةٌ وَاحِدَةٌ لَا تَنْقَاسُ وَلَا يُفَرَّعُ عَنْهَا. وَيَقُولُونَ لِلنَّاقَةِ الضَّخْمَةِ: كَهَاةٌ. قَالَ:

إِذَا عَرَِضَتْ مِنْهَا كَهَاةٌ سَمِينَةٌ ... فَلَا تُهْدِ مِنْهَا وَاتَّشِقْ وَتَجَبْجَبِ.

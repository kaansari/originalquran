# رَسَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B3%D9%8E%D8%B9%D9%8E/?book=9

(رَسَعَ) الرَّاءُ وَالسِّينُ وَالْعَيْنُ أَصْلٌ يَدُلُّ عَلَى فَسَادٍ. يَقُولُونَ الرَّسَعُ: فَسَاد ُ الْعَيْنِ. يُقَالُ رَسَّعَ الرَّجُلُ فَهُوَ مُرَسِّعٌ. وَيُقَالُ رَسَّعَتْ أَعْضَاؤُهُ، إِذَا فَسَدَتْ.

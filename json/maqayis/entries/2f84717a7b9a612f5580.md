# نَأَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%A3%D9%8E%D8%AF%D9%8E/?book=9

(نَأَدَ) النُّونُ وَالْهَمْزَةُ وَالدَّالُ كَلِمَةٌ وَاحِدَةٌ. يَقُولُونَ: النَّآدُ وَالنَّآدَى: الدَّاهِيَةُ. قَالَ الْكُمَيْتُ:

وَإِيَّاكُمْ وَدَاهِيَةً نَآدَى ... أَظَلَّتْكُمْ بِعَارِضِهَا الْمُخِيلِ.

# نَشَغَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B4%D9%8E%D8%BA%D9%8E/?book=9

(نَشَغَ) النُّونُ وَالشِّينُ وَالْغَيْنُ ثَلَاثُ كَلِمَاتٍ مُتَبَايِنَةٍ، لَيْسَ قِيَاسُهَا وَاحِدًا.

الْأُولَى النَّشْغُ: كَالشَّهِيقِ عِنْدَ الشَّوْقِ. الثَّانِيَةُ النَّاشِغُ: الَّذِي يَحْيَا بَعْدَ جَهْدٍ. الثَّالِثَةُ النَّوَاشِغُ: أَعَالِي الْوَادِي، الْوَاحِدَةُ نَاشِغَةٌ.

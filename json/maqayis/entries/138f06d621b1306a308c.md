# وَرَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B1%D9%8E%D9%85%D9%8E/?book=9

(وَرَمَ) الْوَاوُ وَالرَّاءُ وَالْمِيمُ: كَلِمَةٌ وَاحِدَةٌ، هِيَ الْوَرَمُ، أَنْ يَنْفِرَ اللَّحْمُ. يُقَالُ وَرِمَ يَرِمُ. وَعَلَى مَعْنَى الِاسْتِعَارَةِ: وَرِمَ أَنْفُهُ: غَضِبَ.

# لَخَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AE%D9%8E%D9%81%D9%8E/?book=9

(لَخَفَ) اللَّامُ وَالْخَاءُ وَالْفَاءُ كَلِمَتَانِ، إِحْدَاهُمَا اللِّخَافُ، وَهِيَ حِجَارَةٌ بِيضٌ رِقَاقٌ، وَاحِدَتُهَا لَخْفَةٌ، وَالْأُخْرَى قَوْلُهُمْ: لَخَفَهُ بِالسَّيْفِ: ضَرَبَهُ.

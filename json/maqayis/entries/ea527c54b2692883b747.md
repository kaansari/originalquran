# نَمَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%85%D9%8E%D9%82%D9%8E/?book=9

(نَمَقَ) النُّونُ وَالْمِيمُ وَالْقَافُ أُصَيْلٌ يَدُلُّ عَلَى تَحْسِينِ شَيْءٍ وَتَجْوِيدِهِ. وَنَمَقْتُ الْكِتَابَ وَنَمَّقْتُهُ: نَقَشْتُهُ وَصَوَّرْتُهُ. قَالَ:

كَأَنَّ مَجَرَّ الرَّامِسَاتِ ذُيُولَهَا ... عَلَيْهِ قَضِيمٌ نَمَّقَتْهُ الصَّوَانِعُ.

# عَطَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%B7%D9%8E%D8%B1%D9%8E/?book=9

(عَطَرَ) الْعَيْنُ وَالطَّاءُ وَالرَّاءُ أَصْلٌ وَاحِدٌ لَعَلَّهُ أَنْ يَكُونَ صَحِيحًا، وَهُوَ الْعِطْرُ لِلْأَشْيَاءِ الْمُعَالَجَةِ بِالطِّيبِ، وَفَاعِلُهُ الْعَطَّارُ. وَامْرَأَةٌ عَطِرَةٌ وَمِعْطِيرٌ. وَقَالَ:

يَتْبَعْنَ جَأْبًا كَمُدُقِّ الْمِعْطِيرْ

# لَسَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B3%D9%8E%D8%B9%D9%8E/?book=9

(لَسَعَ) اللَّامُ وَالسِّينُ وَالْعَيْنُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ: لَسَعَتْهُ الْحَيَّةُ تَلْسَعُهُ لَسْعًا. وَيُسْتَعَارُ فَيُقَالُ: لَسَعَهُ بِلِسَانِهِ.

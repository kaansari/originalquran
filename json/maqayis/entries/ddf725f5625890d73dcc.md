# وَعَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B9%D9%91%D9%8E/?book=9

(وَعَّ) الْوَاوُ وَالْعَيْنُ: كَلِمَةٌ تَدُلُّ عَلَى صَوْتٍ. يُقَالُ وَعْوَعَ الذِّئْبُ وَعَلَى التَّشْبِيهِ يُقَالُ لِلشَّهْمِ الظَّرِيفِ: وَعْوَعِيٌّ. وَكُلُّ صَوْتٍ مُخْتَلِطٍ: وَعْوَاعٌ. قَالَ:

فَيَظَلُّ مِنْهُ الْقَوْمُ فِي وَعْوَاعٍ

# قَذَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%B0%D9%8E%D8%B1%D9%8E/?book=9

(قَذَرَ) الْقَافُ وَالذَّالُ وَالرَّاءُ كَلِمَةٌ تَدُلُّ عَلَى خِلَافِ النَّظَافَةِ. يُقَالُ: شَيْءٌ قَذِرٌ، بَيِّنُ الْقَذَرِ. وَقَذِرْتُ الشَّيْءَ، وَاسْتَقْذَرْتُهُ، فَإِذَا وَجَدْتَهُ كَذَلِكَ قُلْتَ: أَقْذَرْتُهُ. وَقَذِرْتُ الشَّيْءَ: كَرِهْتُهُ قَذَرًا قَالَ:

وَقَذَرِي مَا لَيْسَ بِالْمَقْذُورِ

وَرَجُلٌ قَاذُورَةٌ: لَا يُخَالُّ وَلَا يُنَازِلُ النَّاسَ. وَنَاقَةٌ قَذُورٌ: عَزِيزَةُ النَّفْسِ لَا تَرْعَى مَعَ الْإِبِلِ. وَرَجُلٌ مَقْذُورٌ، كَالْمُقْذَرِ. قَالَ الْكِلَابِيُّ: رَجُلٌ قُذَرَةٌ: يَتَنَزَّهُ عَنِ الْمَلَائِمِ.

# هَيَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%8A%D9%8E%D8%B7%D9%8E/?book=9

(هَيَطَ) الْهَاءُ وَالْيَاءُ وَالطَّاءُ كَلِمَتَانِ: إِحْدَاهُمَا [الْهِيَاطُ] : الصِّيَاحُ، وَالْأُخْرَى كَلِمَةٌ حَكَاهَا الْفَرَّاءُ: تَهَايَطَ الْقَوْمُ: اجْتَمَعُوا لِإِصْلَاحِ مَا بَيْنَهُمْ.

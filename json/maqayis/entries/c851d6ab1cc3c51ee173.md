# سَجَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%AC%D9%8E%D9%85%D9%8E/?book=9

(سَجَمَ) السِّينُ وَالْجِيمُ وَالْمِيمُ أَصْلٌ وَاحِدٌ، وَهُوَ صَبُّ الشَّيْءِ مِنَ الْمَاءِ وَالدَّمْعِ. يُقَالُ سَجَمَتِ الْعَيْنُ دَمْعَهَا. وَعَيْنٌ سَجُومٌ، وَدَمْعٌ مَسْجُومٌ. وَيُقَالُ أَرْضٌ مَسْجُومَةٌ: مَمْطُورَةٌ.

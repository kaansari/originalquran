# وَقَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%82%D9%8E%D9%85%D9%8E/?book=9

(وَقَمَ) الْوَاوُ وَالْقَافُ وَالْمِيمُ. يَدُلُّ عَلَى غَلَبَةٍ وَإِذْلَالٍ. وَوَقَمَ اللَّهُ الْعَدُوَّ وَقْمًا: أَذَلَّهُ. وَتَوَقَّمَ فُلَانٌ الْعِلْمَ: قَتَلَهُ خُبْرًا. وَتَوَقَّمْتُ الصَّيْدَ: خَتَلْتُهُ. وَقَالَ الْكِسَائِيُّ: الْمَوْقُومُ: الشَّدِيدُ الْحُزْنِ. وَحَرَّةُ وَاقِمٍ بِالْمَدِينَةِ.

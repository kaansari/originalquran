# هَعَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B9%D9%8E%D8%B1%D9%8E/?book=9

(هَعَرَ) الْهَاءُ وَالْعَيْنُ وَالرَّاءُ وَهَذَا لَا يَكُونُ إِلَّا بِدَخِيلٍ. يَقُولُونَ: الْهَيْعَرَةُ: النَّزِقَةُ مِنَ النِّسَاءِ. وَالْهَيْعَرَةُ: الْغُولُ. وَالْهَيْعَرُورُ: الدَّاهِيَةُ.

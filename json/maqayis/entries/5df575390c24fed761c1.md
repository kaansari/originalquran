# سَقَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%82%D9%8E%D8%B9%D9%8E/?book=9

(سَقَعَ) السِّينُ وَالْقَافُ وَالْعَيْنُ لَيْسَ بِأَصْلٍ ; لِأَنَّ السِّينَ فِيهِ مُبْدَلَةٌ مِنْ صَادٍ. يُقَالُ صُقْعٌ وَسُقْعٌ. وَصَقَعْتُهُ وَسَقَعْتُهُ. وَمَا أَدْرِي أَيْنَ سَقَعَ أَيْ ذَهَبَ.

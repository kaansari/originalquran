# الْمُجْلَنْظِيُّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D9%85%D9%8F%D8%AC%D9%92%D9%84%D9%8E%D9%86%D9%92%D8%B8%D9%90%D9%8A%D9%91%D9%8F/?book=9

(الْمُجْلَنْظِيُّ) : الَّذِي يَسْتَلْقِي عَلَى ظَهْرِهِ وَيَرْفَعُ رِجْلَيْهِ.

وَ (الْمَجْلَعِبُّ) : الْمُضْطَجِعُ. وَسَيْلٌ مُجْلَعِبٌّ: كَثِيرُ الْقَمْشِ.

وَ (الْمُجْلَخِدُّ) : الْمُسْتَلْقِي.

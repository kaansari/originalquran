# لَوَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%88%D9%8E%D8%A8%D9%8E/?book=9

(لَوَبَ) اللَّامُ وَالْوَاوُ وَالْبَاءُ كَلِمَتَانِ مُتَبَايِنَتَانِ، وَيُمْكِنُ أَنْ يُحْمَلَ إِحْدَاهُمَا عَلَى الْأُخْرَى.

فَالْكَلِمَةُ الْأُولَى: اللَّوْبُ وَاللُّوَابُ: الْعَطَشُ، وَالْفِعْلُ لَابَ يَلُوبُ، وَهُوَ لَائِبٌ. وَالْكَلِمَةُ الْأُخْرَى اللَّابَّةُ، وَهِيَ الْحَرَّةُ، وَالْجَمْعُ لُوبٌ. وَالَّذِي يَجْمَعُ بَيْنَ الْكَلِمَتَيْنِ أَنَّ الْحَرَّةَ عَطْشَى، كَأَنَّهَا مُحْتَرِقَةٌ.

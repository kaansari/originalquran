# هَمَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%85%D9%8E%D8%B7%D9%8E/?book=9

(هَمَطَ) الْهَاءُ وَالْمِيمُ وَالطَّاءُ لَيْسَ بِأَصْلٍ، إِلَّا أَنَّهُمْ يَقُولُونَ: هَمَطَ: خَلَطَ بَيْنَ الْبَاطِلِ وَالظُّلْمِ. وَأَهْمَطَ عِرْضَ فُلَانٍ: شَتَمَهُ.

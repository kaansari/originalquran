# نَغَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%BA%D9%8E%D9%84%D9%8E/?book=9

(نَغَلَ) النُّونُ وَالْغَيْنُ وَاللَّامُ كَلِمَةٌ تَدُلُّ عَلَى فَسَادٍ وَإِفْسَادٍ. النَّغِلُ: الْأَدِيمُ الْفَاسِدُ. يَقُولُونَ: " وَقَدْ يُرْقَعُ النَّغِلُ ". يُقَالُ إِنَّ النَّغَلَ: الْإِفْسَادُ بَيْنَ الْقَوْمِ وَالنَّمِيمَةُ.

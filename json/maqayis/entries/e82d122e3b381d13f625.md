# هَيَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%8A%D9%8E%D8%A3%D9%8E/?book=9

(هَيَأَ) الْهَاءُ وَالْيَاءُ وَالْأَلِفُ كَلِمَةٌ تَأْتِي وَهَاؤُهَا زَائِدَةٌ. يُقَالُ: هَيَا، وَالْمُرَادُ: يَا. قَالَ الشَّاعِرُ:

فَيُصِيخُ يَرْجُو أَنْ يَكُونَ حَيًّا ... وَيَقُولُ مِنْ طَرَبٍ هَيَا رَبَّا

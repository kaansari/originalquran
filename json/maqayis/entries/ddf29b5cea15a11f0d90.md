# وَفَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%81%D9%8E%D9%82%D9%8E/?book=9

(وَفَقَ) الْوَاوُ وَالْفَاءُ وَالْقَافُ: كَلِمَةٌ تَدُلُّ عَلَى مُلَاءَمَةِ الشَّيْئَيْنِ. مِنْهُ الْوَفْقُ: الْمُوَافَقَةُ. وَاتَّفَقَ الشَّيْئَانِ: تَقَارَبَا وَتَلَاءَمَا. وَوَافَقْتُ فُلَانًا: صَادَقْتُهُ، كَأَنَّهُمَا اجْتَمَعَا مُتَوَافِقَيْنِ.

# زَعِرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%B9%D9%90%D8%B1%D9%8E/?book=9

(زَعِرَ) الزَّاءُ وَالْعَيْنُ وَالرَّاءُ أُصَيْلٌ يَدُلُّ عَلَى سُوءِ خُلُقٍ وَقِلَّةِ خَيْرٍ. فَالزَّعَارَةُ: شَرَاسَةُ الْخُلُقِ. وَهُوَ عَلَى وَزْنِ فَعَالَةٍ. وَمِنَ الْبَابِ الْأَزْعَرُ: الْمَكَانُ الْقَلِيلُ النَّبَاتِ. وَيُقَالُ إِنَّ الزَّعَارَةَ لَا يُبْنَى مِنْهَا تَصْرِيفُ فِعْلٍ. وَمِنَ الْبَابِ الْأَزْعَرُ: الْقَلِيلُ الشَّعْرِ. وَالْمَرْأَةُ زَعْرَاءُ ; وَقَدْ زَعِرَ يَزْعَرُ. وَاللَّهُ أَعْلَمُ.

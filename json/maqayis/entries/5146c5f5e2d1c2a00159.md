# جَهٌّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%87%D9%91%D9%8C/?book=9

(جَهٌّ) الْجِيمُ وَالْهَاءُ لَيْسَ أَصْلًا ; لِأَنَّهُ صَوْتٌ. يُقَالُ جَهْجَهْتُ بِالسَّبُعِ إِذَا صِحْتَ بِهِ. قَالَ:

فَجَاءَ دُونَ الزَّجْرِ وَالتَّجَهْجُهِ وَحَكَى نَاسٌ: تَجَهْجَهَ عَنِ الْأَمْرِ انْتَهَى. وَهَذَا إِنْ كَانَ صَحِيحًا فَهُوَ فِي بَابِ الْمُقَابَلَةِ ; لِأَنَّكَ تَقُولُ جَهْجَهْتُ بِهِ فَتَجَهْجَهَ.

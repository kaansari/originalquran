# خَذَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B0%D9%8E%D9%82%D9%8E/?book=9

(خَذَقَ) الْخَاءُ وَالذَّالُ وَالْقَافُ لَيْسَ أَصْلًا، وَإِنَّمَا فِيهِ كَلِمَةٌ مِنْ بَابِ الْإِبْدَالِ. يُقَالُ خَذَقَ الطَّائِرُ، إِذَا ذَرَقَ. وَأَرَاهُ خَزَقَ، فَأُبْدِلَتِ الزَّاءُ ذَالًا.

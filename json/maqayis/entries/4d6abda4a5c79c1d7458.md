# ذَرَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D8%B1%D9%8E%D9%82%D9%8E/?book=9

(ذَرَقَ) الذَّالُ وَالرَّاءُ وَالْقَافُ لَيْسَ بِشَيْءٍ. أَمَّا الَّذِي لِلطَّائِرِ فَأَصْلُهُ الزَّاءُ، وَقَدْ ذُكِرَ فِي بَابِهِ. وَالذَّرَقُ: نَبْتٌ; يُقَالُ أَذْرَقَتِ الْأَرْضُ، إِذَا أَنْبَتَتْهُ.

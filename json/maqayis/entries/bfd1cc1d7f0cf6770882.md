# وَشَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B4%D9%8E%D8%AC%D9%8E/?book=9

(وَشَجَ) الْوَاوُ وَالشِّينُ وَالْجِيمُ: كَلِمَةٌ تَدُلُّ عَلَى اشْتِبَاكٍ وَتَدَاخُلٍ. يُقَالُ: وَشَجَتِ الْأَغْصَانُ. اشْتَبَكَتْ. وَكُلُّ شَيْءٍ اشْتَبَكَ فَهُوَ وَاشِجٌ. وَالْوَشِيجُ مِنَ الْقَنَا ; مَا نَبَتَ مِنَ الْأَرْضِ مُعْتَرِضًا، وَلَعَلَّ ذَلِكَ يَشْتَبِكُ بَعْضُهُ بِبَعْضٍ.

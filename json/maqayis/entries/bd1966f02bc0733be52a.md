# كَنَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%86%D9%8E%D8%B1%D9%8E/?book=9

(كَنَرَ) الْكَافُ وَالنُّونُ وَالرَّاءُ لَيْسَ هُوَ عِنْدَنَا أَصْلًا، وَفِيهِ كَلِمَتَانِ أَظُنُّهُمَا فَارِسِيَّتَيْنِ. يُقَالُ الْكِنَّارُ: الشُّقَّةُ مِنَ الثِّيَابِ الْكَتَّانِ. وَيَقُولُونَ: الْكِنَّارَاتُ: الْعِيدَانُ أَوِ الدُّفُوفُ، تُفْتَحُ كَافُهَا وَتُكْسَرُ.

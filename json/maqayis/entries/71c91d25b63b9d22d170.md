# فَشَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B4%D9%8E%D8%AC%D9%8E/?book=9

(فَشَجَ) الْفَاءُ وَالشِّينُ وَالْجِيمُ. يَقُولُونَ: فَشَجَتِ النَّاقَةُ: تَفَاجَّتْ لِتَبُولَ. كَذَلِكَ فِي كِتَابِ الْخَلِيلِ. وَقَالَ ابْنُ دُرَيْدٍ: فَشَحْتُ، بِالْحَاءِ، وَأَنْشَدَ:

إِنَّكِ لَوْ صَاحَبْتِنَا مَذِحْتِ ... وَحَكَّكِ الْحِنْوَانُ فَانْفَشَحْتِ

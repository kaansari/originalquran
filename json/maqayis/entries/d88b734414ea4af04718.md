# هَرَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B1%D9%8E%D8%AF%D9%8E/?book=9

(هَرَدَ) الْهَاءُ وَالرَّاءُ وَالدَّالُ كَلِمَاتٌ تَدُلُّ عَلَى مُعَالَجَةِ شَيْءٍ بِصِبْغٍ أَوْ مَا أَشْبَهَهُ. وَثَوْبٌ مَهْرُودٌ: صُبِغَ أَصْفَرَ. وَهَرَّدْتُ الثَّوْبَ شَقَقْتُهُ. وَهَرَدْتُ عِرْضَهُ: ثَلَبْتُهُ. وَهَرَّدْتُ اللَّحْمَ: أَنْضَجْتُهُ شَيْئًا، تَهْرِيدًا.

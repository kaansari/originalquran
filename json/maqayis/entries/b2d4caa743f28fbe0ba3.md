# يَلَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%8A%D9%8E%D9%84%D9%8E%D9%82%D9%8E/?book=9

(يَلَقَ) الْيَاءُ وَاللَّامُ وَالْقَافُ. يَقُولُونَ: الْيَلَقُ: الْأَبْيَضُ مِنْ كُلِّ شَيْءٍ. وَأَنْشَدُوا:

وَأَتْرُكُ الْقِرْنَ فِي الْغُبَارِ وَفِي ... حِضْنَيْهِ زَرْقَاءُ مَتْنُهَا يَلَقُ

وَيُقَالُ الْيَلَقَةُ: الْعَنْزُ الْبَيْضَاءُ.

# أَجَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%AC%D9%8E%D8%B5%D9%8E/?book=9

(أَجَصَ) الْهَمْزَةُ وَالْجِيمُ وَالصَّادُ لَيْسَتْ أَصْلًا، لِأَنَّهُ لَمْ يَجِئْ عَلَيْهَا إِلَّا الْإِجَّاصُ. وَيُقَالُ: إِنَّهُ لَيْسَ عَرَبِيًّا، وَذَلِكَ أَنَّ الْجِيمَ تَقِلُّ مَعَ الصَّادِ.

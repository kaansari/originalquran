# سَجَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%AC%D9%8E%D9%81%D9%8E/?book=9

(سَجَفَ) السِّينُ وَالْجِيمُ وَالْفَاءُ أَصْلٌ وَاحِدٌ، وَهُوَ إِسْبَالُ شَيْءٍ سَاتِرٍ. يُقَالُ أَسْجَفْتُ السِّتْرَ: أَرْسَلْتُهُ. وَالسَّجْفُ وَالسِّجْفُ: سِتْرُ الْحَجَلَةِ. وَيُقَالُ أَسْجَفَ اللَّيْلُ، مِثْلُ أَسْدَفَ.

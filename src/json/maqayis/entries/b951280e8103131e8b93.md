# سَدُنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%AF%D9%8F%D9%86%D9%8E/?book=9

(سَدُنَ) السِّينُ وَالدَّالُ وَالنُّونُ أَصْلٌ وَاحِدٌ لِشَيْءٍ مَخْصُوصٍ. يُقَالُ إِنَّ السَّدَانَةَ الْحِجَابَةُ. وَسَدَنَةُ الْبَيْتِ: حَجَبَتُهُ. وَيَقُولُونَ: السَّدَنُ السِّتْرُ. فَإِنْ كَانَ صَحِيحًا فَهُوَ مِنْ بَابِ الْإِبْدَالِ، وَالْأَصْلُ السُِّدْلُ.

# هَنَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%86%D9%8E%D9%81%D9%8E/?book=9

(هَنَفَ) الْهَاءُ وَالنُّونُ وَالْفَاءُ: كَلِمَةٌ وَاحِدَةٌ: هِيَ الْمُهَانَفَةُ: الضَّحِكُ فَوْقَ التَّبَسُّمِ. قَالُوا: وَلَا يُقَالُ لِلرَّجُلِ تَهَانَفَ ; فَهُوَ نَعْتٌ فِي ضَحِكِ النِّسَاءِ خَاصَّةً، حَكَاهُ الْخَلِيلُ. وَيُقَالُ: بَلِ التَّهَانُفُ: ضَحِكُ الْمُسْتَهْزِئِ.

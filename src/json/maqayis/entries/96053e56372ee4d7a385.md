# خَنَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%86%D9%8E%D8%B9%D9%8E/?book=9

(خَنَعَ) الْخَاءُ وَالنُّونُ وَالْعَيْنُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى ذُلٍّ وَخُضُوعٍ وَضَعَةٍ، فَيُقَالُ: خَضَعَ لَهُ وَخَنَعَ. وَفِي الْحَدِيثِ: " إِنَّ أَخْنَعَ الْأَسْمَاءِ " أَيْ أَذَلَّهَا. وَيُقَالُ أَخْنَعَتْنِي إِلَيْهِ الْحَاجَةُ، إِذَا أَلْجَأَتْهُ إِلَيْهِ وَأَذَلَّتْهُ لَهُ. وَمِنَ الْبَابِ الْخَانِعُ: الْفَاجِرُ. يُقَالُ: اطَّلَعْتُ مِنْهُ عَلَى خَنْعَةٍ، أَيْ فَجْرَةٍ. وَهُوَ قَوْلُهُ:

وَلَا يُرَوْنَ إِلَى جَارَاتِهِمْ خُنُعًا

وَمِنْهُ قَوْلُ الْآخَرِ:

لَعَلَّكَ يَوْمًا أَنْ تُلَاقَى بِخَنْعَةٍ ... فَتَنْعَبَ مِنْ وَادٍ عَلَيْكَ أَشَائِمُهُ

وَخُنَاعَةُ: قَبِيلَةٌ.

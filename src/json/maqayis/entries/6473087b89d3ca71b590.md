# مَيَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%8A%D9%8E%D8%B7%D9%8E/?book=9

(مَيَطَ) الْمِيمُ وَالْيَاءُ وَالطَّاءُ كَلِمَةٌ صَحِيحَةٌ تَدُلُّ عَلَى دَفْعٍ وَمُدَافَعَةٍ. وَمَاطَهُ عَنْهُ: دَفَعَهُ. وَمِطْتُ الْأَذَى عَنِ الطَّرِيقِ. يُقَالُ أَمَاطَهُ إِمَاطَةً. وَلِذَلِكَ يُقَالُ: " هُمْ فِي هِيَاطٍ وَمِيَاطٍ ". الْهِيَاطُ: الصِّيَاحُ: وَالْمِيَاطُ: الدَّفْعُ. وَقَالَ الْفَرَّاءُ: تَمَايَطُوا: تَبَاعَدُوا وَفَسَدَ مَا بَيْنَهُمْ، تَمَايُطًا.

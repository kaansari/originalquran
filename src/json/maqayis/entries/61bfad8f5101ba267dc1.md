# شَوُسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%88%D9%8F%D8%B3%D9%8E/?book=9

(شَوُسَ) الشِّينُ وَالْوَاوُ وَالسِّينُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى نَظَرٍ بِتَغَيُّظٍ. مِنْ ذَلِكَ الشَّوَسِ: النَّظَرُ بِأَحَدِ شِقَّيِ الْعَيْنِ تَغَيُّظًا. وَرَجُلٌ أَشْوَسُ مِنْ قَوْمٍ شُوسٍ. وَيُقَالُ هُوَ [الَّذِي] يُصَغِّرُ عَيْنَيْهِ وَيَضُمُّ أَجْفَانَهُ.

# نَسَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B3%D9%8E%D8%B9%D9%8E/?book=9

(نَسَعَ) النُّونُ وَالسِّينُ وَالْعَيْنُ كَلِمَةٌ تَدُلُّ عَلَى جَدْلِ الشَّيْءِ.

فَالنِّسْعُ: سَيْرٌ مَضْفُورٌ كَهَيْئَةِ أَعِنَّةِ الْبِغَالِ. وَيُقَالُ لِلْعُنُقِ الطَّوِيلِ نَاسِعٌ، كَأَنَّهُ طُوِّلَ وَجُدِلَ جَدْلًا. وَالْمِنْسَعَةُ: الْأَرْضُ السَّرِيعَةُ النَّبْتِ بِطُولِ نَبْتِهَا وَبَقْلِهَا.

# شَكَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%83%D9%8E%D8%AF%D9%8E/?book=9

(شَكَدَ) الشِّينُ وَالْكَافُ وَالدَّالُ أَصْلٌ. يَقُولُونَ: إِنَّ الشُّكْدَ: الشُّكْرُ. وَسَمِعْتُ عَلِيَّ بْنَ إِبْرَاهِيمَ الْقَطَّانَ يَقُولُ: سَمِعْتُ عَلِيَّ بْنَ عَبْدِ الْعَزِيزِ يَقُولُ: سَمِعْتُ أَبَا عُبَيْدٍ يَقُولُ: سَمِعْتُ الْأُمَوِيَّ يَقُولُ: الشُّكْدُ: الْعَطَاءُ، وَالشُّكْمُ: الْجَزَاءُ، وَالْمَصْدَرُ: الشَّكْدُ. وَقَالَ الْكِسَائِيُّ: الشُّكْمُ: الْعِوَضُ. وَالْأَصْمَعِيُّ يَقُولُ الشُّكْمُ وَالشُّكْدُ: الْعَطَاءُ.

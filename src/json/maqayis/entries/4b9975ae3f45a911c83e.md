# مَرَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B1%D9%8E%D8%AA%D9%8E/?book=9

(مَرَتَ) الْمِيمُ وَالرَّاءُ وَالتَّاءُ كَلِمَةٌ وَاحِدَةٌ، هِيَ الْمَرْتُ: الْفَلَاةُ الْقَفْرُ. وَمَكَانٌ مَرْتٌ: بَيِّنُ الْمُرُوتَةِ، إِذَا لَمْ يَكُنْ فِيهِ خَيْرٌ. وَجَمْعُ مَرْتٍ أَمْرَاتٌ وَمُرُوتٌ. وَبَلَغَنَا أَنَّ اشْتِقَاقَ مَارُوتَ مِنْهُ. وَيُقَالُ الْمَرْتُ: أَرْضٌ لَا يَجِفُّ ثَرَاهَا وَلَا يَنْبُتُ مَرْعَاهَا.

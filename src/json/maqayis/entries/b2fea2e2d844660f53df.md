# الْعُطْبُولُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8F%D8%B7%D9%92%D8%A8%D9%8F%D9%88%D9%84%D9%8F/?book=9

(الْعُطْبُولُ) : الْوَطِيئَةُ مِنَ النِّسَاءِ الْمُمْتَلِئَةِ. قَالَ:

فَسِرْنَا وَخَلَّفْنَا هُبَيْرَةَ بَعْدَنَا ... وَقُدَّامُهُ الْبَيْضُ الْحِسَانُ الْعَطَابِلُ

وَهَذَا مِمَّا زِيدَتْ فِيهِ الطَّاءُ، وَإِنَّمَا هُوَ مِنْ عَبَالَةِ الْجِسْمِ. وَمُمْكِنٌ أَنْ يَكُونَ مَنْحُوتًا مِنْ عَطَلَ، فَالْعُطُلُ: الْجِسْمُ الْمُجَرَّدُ، كَأَنَّهُ يَقُولُ: عُطُلُهَا عَبْلٌ. وَهَذَا أَجْوَدُ.

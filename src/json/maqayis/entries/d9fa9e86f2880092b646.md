# زَحَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%AD%D9%8E%D9%86%D9%8E/?book=9

(زَحَنَ) الزَّاءُ وَالْحَاءُ وَالنُّونُ أَصْلٌ يَدُلُّ عَلَى الْإِبْطَاءِ. تَقُولُ: زَحَنَ يَزْحَنُ زَحْنًا، وَكَذَلِكَ التَّزَحُّنُ. يُقَالُ تَزَحَّنَ عَلَى الشَّيْءِ، إِذَا تَكَارَهَ عَلَيْهِ وَهُوَ لَا يَشْتَهِيهِ.

# رَدَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%AF%D9%8E%D8%AC%D9%8E/?book=9

(رَدَجَ) الرَّاءُ وَالدَّالُ وَالْجِيمُ لَيْسَ بِشَيْءٍ. عَلَى أَنَّهُمْ يَقُولُونَ إِنَّ الرَّدَجَ مَا يُلْقِيهِ [الْمُهْرُ] مِنْ بَطْنِهِ سَاعَةَ يُولَدُ. وَيُنْشِدُونَ:

لَهَا رَدَجٌ فِي بَيْتِهَا تَسْتَعِدُّهُ ... إِذَا جَاءَهَا يَوْمًا مِنَ الدَّهْرِ خَاطِبُ

# شَأَوَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%A3%D9%8E%D9%88%D9%8E/?book=9

(شَأَوَ) الشِّينُ وَالْهَمْزَةُ وَالْوَاوُ كَلِمَتَانِ مُتَبَاعِدَتَانِ جِدًّا.

فَالْأَوَّلُ السَّبْقُ، يُقَالُ شَأَوْتُهُ أَيْ سَبَقْتُهُ.

وَالْكَلِمَةُ الْأُخْرَى الشَّأْوُ: مَا يَخْرُجُ مِنَ الْبِئْرِ إِذَا نُظِّفَتْ. وَيُقَالُ لِلزَّبِيلِ الَّذِي يُخْرَجُ بِهِ ذَلِكَ الْمِشْآةُ.

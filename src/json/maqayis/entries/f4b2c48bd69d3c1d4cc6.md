# قَيَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D9%8A%D9%8E%D8%A3%D9%8E/?book=9

(قَيَأَ) الْقَافُ وَالْيَاءُ وَالْهَمْزَةُ كَلِمَةٌ وَاحِدَةٌ. قَاءَ يَقِيءُ قَيْئًا، وَاسْتَقَاءَ اسْتَفْعَلَ مِنَ الْقَيْءِ. وَيَقُولُونَ لِلثَّوْبِ الْمُشْبَعِ الصِّبْغِ: هُوَ يَقِيءُ الصِّبْغَ.

# لَبَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%A8%D9%8E%D9%82%D9%8E/?book=9

(لَبَقَ) اللَّامُ وَالْبَاءُ وَالْقَافُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى خَلْطِ شَيْءٍ لِتَطْيِيبِهِ. يُقَالُ لَبَقْتُ الطَّعَامَ وَلَبَّقْتُهُ، إِذَا لَيَّنْتَهُ وَطَيَّبْتَهُ. وَمِنَ الْبَابِ اللَّبِقُ: الْحَاذِقُ بِالشَّيْءِ يَعْمَلُهُ. وَرَجُلٌ لَبِقٌ وَلَبِيقٌ. وَالْمَصْدَرُ اللَّبَاقَةُ. قَالَ الشَّاعِرُ:

لَبِيقًا بِتَصْرِيفِ الْقَنَاةِ بَنَانِيَا.

# سَكَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%83%D9%8E%D8%AA%D9%8E/?book=9

(سَكَتَ) السِّينُ وَالْكَافُ وَالتَّاءُ يَدُلُّ عَلَى خِلَافِ الْكَلَامِ. تَقُولُ: سَكَتَ يَسْكُتُ سُكُوتًا، وَرَجُلٌ سِكِّيتٌ. وَرَمَاهُ بِسُكَاتَةٍ، أَيْ بِمَا أَسْكَتَهُ. وَسَكَتَ الْغَضَبُ، بِمَعْنَى سَكَنَ. وَالسُّكْتَةُ: مَا أَسْكَتَّ بِهِ الصَّبِيَّ. فَأَمَّا السُّكَيْتُ فَإِنَّهُ مِنَ الْخَيْلِ الْعَاشِرُ عِنْدَ جَرْيِهَا فِي السِّبَاقِ. وَيُمْكِنُ أَنْ يَكُونَ سُمِّي سُكَيْتًا لِأَنَّ صَاحِبَهُ يَسْكُتُ عَنِ الِافْتِخَارِ، كَمَا يُقَالُ أَجَرَّهُ كَذَا، إِذَا مَنَعَهُ مِنَ الِافْتِخَارِ، وَكَأَنَّهُ جَرَّ لِسَانَهُ.

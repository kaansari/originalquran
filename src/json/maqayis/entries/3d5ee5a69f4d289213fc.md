# كَلَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%84%D9%8E%D8%B2%D9%8E/?book=9

(كَلَزَ) الْكَافُ وَاللَّامُ وَالزَّاءُ يَقُولُونَ إِنَّهُ صَحِيحٌ، وَإِنَّ الْكَلْزَ: الْجَمْعُ. يُقَالُ: كَلَزْتُ الشَّيْءَ وَكَلَّزْتُهُ، إِذَا جَمَعْتُهُ. وَقَدْ رُوِيَتْ كَلِمَةٌ فِيهِ صَحِيحَةٌ لَا يُرْتَابُ بِهَا، يَقُولُونَ: اكْلَازَّ الرَّجُلُ: تَقَبَّضَ.

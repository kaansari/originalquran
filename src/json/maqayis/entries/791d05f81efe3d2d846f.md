# لَمَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%85%D9%8E%D8%A3%D9%8E/?book=9

(لَمَأَ) اللَّامُ وَالْمِيمُ وَالْهَمْزَةُ كَلِمَتَانِ تَدُلَّانِ عَلَى الِاشْتِمَالِ. يَقُولُونَ: أَلْمَأْتُ بِالشَّيْءِ، إِذَا اشْتَمَلَتْ عَلَيْهِ فَذَهَبَتْ بِهِ. وَيُقَالُ: تَلَمَّأَتْ عَلَيْهِ الْأَرْضُ، إِذَا اسْتَوَتْ عَلَيْهِ. فَأَمَّا قَوْلُهُمْ: الْتُمِئَ لَوْنُهُ، فَيُمْكِنُ أَنْ يَكُونَ مِنْ هَذَا، وَيُمْكِنُ أَنْ يَكُونَ مِنَ الْإِبْدَالِ، كَأَنَّ الْهَمْزَةَ بَدَلٌ مِنَ الْعَيْنِ، وَالْأَصْلُ الْتُمِعَ.

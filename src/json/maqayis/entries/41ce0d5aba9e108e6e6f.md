# دَأَظَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%A3%D9%8E%D8%B8%D9%8E/?book=9

(دَأَظَ) الدَّالُ وَالْهَمْزَةُ وَالظَّاءُ كَلِمَةٌ وَاحِدَةٌ. يَقُولُونَ الدَّأْظُ: الْمَلْءُ. وَيُقَالُ دَأَظْتُ الْمَتَاعَ فِي الْوِعَاءِ. قَالَ:

وَالدَّأْظُ حَتَّى لَا يَكُونَ غَرْضُ

الدَّأْظُ: الِامْتِلَاءُ. وَالْغَرْضُ: أَنْ يَبْقَى مَوْضِعٌ لَا يَبْلُغُهُ الْمَاءُ.

# الْعَقْرَبُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D9%82%D9%92%D8%B1%D9%8E%D8%A8%D9%8F/?book=9

(الْعَقْرَبُ) : مَعْرُوفَةٌ، وَالْبَاءُ فِيهِ زَائِدَةٌ، وَإِنَّمَا هُوَ مِنَ الْعَقْرِ، ثُمَّ يُسْتَعَارُ فَيُقَالُ لِلَّذِي يَقْرُصُ النَّاسَ: إِنَّهُ لَتَدِبُّ عَقَارِبُهُ. وَدَابَّةٌ مُعَقْرَبُ الْخَلْقِ، أَيْ مُلَزَّزٌ مُجْتَمِعٌ شَدِيدٌ.

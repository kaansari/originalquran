# هَصَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B5%D9%91%D9%8E/?book=9

(هَصَّ) الْهَاءُ وَالصَّادُ كَلِمَةٌ تَدُلُّ عَلَى غَمْزِ الشَّيْءِ. يَقُولُونَ لِلذِّئْبِ: هُصْهُصٌ. وَهَصْهَصْتُ الشَّيْءَ: غَمَزْتُهُ. وَيَقُولُونَ، وَمَا أَدْرِي كَيْفَ هُوَ: إِنَّ الْهَاصَّةَ: عَيْنُ الْفِيلِ، وَهُوَ عِنْدِي مِمَّا يُسْمَعُ.

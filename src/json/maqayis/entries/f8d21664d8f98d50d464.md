# وَفَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%81%D9%8E%D9%89/?book=9

(وَفَى) الْوَاوُ وَالْفَاءُ وَالْحَرْفُ الْمُعْتَلُّ: كَلِمَةٌ تَدُلُّ عَلَى إِكْمَالٍ وَإِتْمَامٍ. مِنْهُ الْوَفَاءُ: إِتْمَامُ الْعَهْدِ وَإِكْمَالُ الشَّرْطِ. وَوَفَى: أَوْفَى، فَهُوَ وَفِيٌّ. وَيَقُولُونَ: أَوْفَيْتُكَ الشَّيْءَ، إِذَا قَضَيْتَهُ إِيَّاهُ وَافِيًا. وَتَوَفَّيْتُ الشَّيْءَ وَاسْتَوْفَيْتُهُ ; [إِذَا أَخَذْتَهُ كُلَّهُ] حَتَّى لَمْ تَتْرُكْ مِنْهُ شَيْئًا. وَمِنْهُ يُقَالُ لِلْمَيِّتِ: تَوَفَّاهُ اللَّهُ.

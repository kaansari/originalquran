# سَدَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%AF%D9%8E%D8%AE%D9%8E/?book=9

(سَدَخَ) السِّينُ وَالدَّالُ وَالْخَاءُ لَا أَصْلَ لَهُ فِي كَلَامِ الْعَرَبِ. وَلَا مَعْنًى لِقَوْلِ مَنْ قَالَ: انْسَدَخَ مِثْلُ انْسَدَحَ، إِذَا اسْتَلْقَى عِنْدَ الضَّرْبِ أَوِ انْبَطَحَ. وَاللَّهُ أَعْلَمُ.

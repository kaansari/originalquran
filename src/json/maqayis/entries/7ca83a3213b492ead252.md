# لَتَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AA%D9%91%D9%8E/?book=9

(لَتَّ) اللَّامُ وَالتَّاءُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ: لَتَّ السَّوِيقَ بِالسَّمْنِ يَلُتُّهُ لَتًّا، وَالْفَاعِلُ لَاتٌّ. وَذُكِرَ عَنِ ابْنِ الْأَعْرَابِيِّ: لُتَّ فُلَانٌ بِفُلَانٍ، إِذَا قُرِنَ بِهِ. فَإِنْ صَحَّ فَهُوَ مِنْ بَابِ الْإِبْدَالِ، كَأَنَّ التَّاءَ مُبْدَلَةٌ مِنْ زَاءٍ.

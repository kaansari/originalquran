# غَنَظَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D9%86%D9%8E%D8%B8%D9%8E/?book=9

(غَنَظَ) الْغَيْنُ وَالنُّونُ وَالظَّاءُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ: إِنَّ الْغَنْظَ: الْهَمُّ اللَّازِمُ. غَنَظَهُ الْأَمْرُ يَغْنِظُهُ. قَالَ:

وَلَقَدْ رَأَيْتُ فَوَارِسًا مِنْ قَوْمِنَا ... غَنَظُوكَ غَنْظَ جَرَادَةِ الْعَيَّارِ

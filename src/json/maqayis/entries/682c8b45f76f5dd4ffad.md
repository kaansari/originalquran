# هَشَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B4%D9%8E%D9%85%D9%8E/?book=9

(هَشَمَ) الْهَاءُ وَالشِّينُ وَالْمِيمُ أَصْلٌ يَدُلُّ عَلَى كَسْرِ الشَّيْءِ الْأَجْوَفِ وَغَيْرِ الْأَجْوَفِ وَهَشَمْتُهُ هَشْمًا. وَالْهَاشِمَةُ: الشَّجَّةُ تَهْشِمُ عَظْمَ الرَّأْسِ. وَمُجْمَعٌ عَلَى أَنَّ هَاشِمًا سُمِّيَ بِهِ لِأَنَّهُ هَشَمَ الثَّرِيدَ، وَاسْمُهُ عَمْرٌو. وَالْهَشِيمُ مِنَ النَّبَاتِ: الْيَابِسُ الْمُتَكَسِّرُ. وَرَجُلٌ هَشِيمٌ: ضَعِيفُ الْبَدَنِ. وَرُبَّمَا قَالُوا: تَهَشَّمَ فُلَانٌ عَلَى فُلَانٍ، أَيْ تَعَطَّفَ. وَهُوَ مِنَ الْبَابِ. وَاهْتَشَمَ مَا فِي ضَرْعِ النَّاقَةِ: احْتَلَبَهُ، وَهُوَ الْقِيَاسُ.

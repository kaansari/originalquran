# الْعَشَنْزَرُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D8%B4%D9%8E%D9%86%D9%92%D8%B2%D9%8E%D8%B1%D9%8F/?book=9

(الْعَشَنْزَرُ) : الشَّدِيدُ. وَهَذَا مِمَّا زِيدَتْ فِيهِ الْعَيْنُ وَالنُّونُ، وَأَصْلُهُ مِنَ الشَّزْرِ، وَقَدْ مَرَّ. قَالَ:

ضَرْبًا وَطَعْنًا بَاقِرًا عَشَنْزَرَا

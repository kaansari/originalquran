# يَهَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%8A%D9%8E%D9%87%D9%8E%D9%85%D9%8E/?book=9

(يَهَمَ) الْيَاءُ وَالْهَاءُ وَالْمِيمُ. الْيَهْمَاءُ: الْمَفَازَةُ لَا عَلَمَ بِهَا. وَيُقَالُ الْأَيْهَمَانِ: السَّيْلُ وَالْحَرِيقُ. وَيُقَالُ الْأَيْهَمُ مِنَ الرِّجَالِ: الْأَصَمُّ. وَيُقَالُ لِلشُّجَاعِ أَيْهَمُ، وَهُوَ مِنَ الْبَابِ، كَأَنَّهُ لَا مَأْتَى لِأَحَدٍ إِلَيْهِ.

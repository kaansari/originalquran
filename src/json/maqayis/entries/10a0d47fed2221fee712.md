# لَحَظَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AD%D9%8E%D8%B8%D9%8E/?book=9

(لَحَظَ) اللَّامُ وَالْحَاءُ وَالظَّاءُ كَلِمَتَانِ مُتَبَايِنَتَانِ. فَاللَّحْظُ: لَحْظُ الْعَيْنِ، وَلِحَاظُهَا: مُؤَخِّرُهَا عِنْدَ الصُّدْغِ.

وَالْكَلِمَةُ الْأُخْرَى اللِّحَاظُ: مَا يَنْسَحِي مَعَ الرِّيشِ إِذَا سُحِيَ مَعَ الْجَنَاحِ.

# أَجَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%AC%D9%8E%D8%A3%D9%8E/?book=9

(أَجَأَ) جَبَلٌ لِطَيٍّ. وَقَدْ قُلْنَا إِنَّ الْأَمَاكِنَ لَا تَكَادُ تَنْقَاسُ أَسْمَاؤُهَا. وَقَالَ شَاعِرٌ فِي أَجَأَ:

وَمِنْ أَجَأٍ حَوْلِي رِعَانٌ كَأَنَّهَا ... قَنَابِلُ خَيْلٍ مِنْ كُمَيْتٍ وَمِنْ وَرْدِ

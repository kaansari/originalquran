# مُزْلَعِبٌّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8F%D8%B2%D9%92%D9%84%D9%8E%D8%B9%D9%90%D8%A8%D9%91%D9%8C/?book=9

سَيْلٌ (مُزْلَعِبٌّ) ، وَهُوَ الْمُتَدَافِعُ الْكَثِيرُ الْقَمْشِ. وَهَذَا مِمَّا زِيدَتْ فِيهِ اللَّامُ. وَهُوَ مِنَ السَّيْلِ الزَّاعِبِ، وَهُوَ الَّذِي يَتَدَافَعُ.

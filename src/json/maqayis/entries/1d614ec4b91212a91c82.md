# مَعَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B9%D9%8E%D9%82%D9%8E/?book=9

(مَعَقَ) الْمِيمُ وَالْعَيْنُ وَالْقَافُ لَيْسَ بِأَصْلٍ وَإِنَّمَا هُوَ مِنْ بَابِ الْقَلْبِ. وَأَرْضٌ مَعِيقَةٌ كَعَمِيقَةٍ. وَالْأَمَاعِقُ: أَطْرَافُ الْمَفَازَةِ. وَيُقَالُ: الْمَعْقُ: الْأَرْضُ لَا نَبَاتَ بِهَا. وَتَمَعَّقَ الرَّجُلُ: سَاءَ خُلُقُهُ.

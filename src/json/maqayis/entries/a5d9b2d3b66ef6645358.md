# وَطَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B7%D9%8E%D8%B4%D9%8E/?book=9

( [وَطَشَ) الْوَاوُ وَالطَّاءُ وَالشِّينُ] : كَلِمَتَانِ إِنْ صَحَّتَا. يَقُولُونَ: ضَرَبُوهُ فَمَا وَطَشَ إِلَيْهِمْ، أَيْ لَمْ يَدْفَعْ عَنْ نَفْسِهِ.

وَالْأُخْرَى: وَطِّشْ لِي شَيْئًا أَذْكُرُهُ، مَعْنَاهُ افْتَحْ.

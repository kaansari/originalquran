# هَكَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%83%D9%8E%D9%85%D9%8E/?book=9

(هَكَمَ) الْهَاءُ وَالْكَافُ وَالْمِيمُ تَدُلُّ عَلَى تَقَحُّمٍ وَتَهَدُّمُ. وَهَكَمَ هَكْمًا: تَقَحَّمَ عَلَى النَّاسِ وَتَعَرَّضَهُمْ بِشَرٍّ. وَالتَّهَكُّمُ: التَّهَزُّؤُ. وَتَهَكَّمَتِ الْبِئْرُ: تَهَدَّمَتْ.

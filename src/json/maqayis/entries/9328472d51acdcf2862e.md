# حِثْرِمَةُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%90%D8%AB%D9%92%D8%B1%D9%90%D9%85%D9%8E%D8%A9%D9%8F/?book=9

(الْحِثْرِمَةُ) وَهِيَ الدَّائِرَةُ الَّتِي تَحْتَ الْأَنْفِ وَسَطَ الشَّفَةِ الْعُلْيَا.

وَهَذِهِ مَنْحُوتَةٌ مِنْ حَثَمَ وَثَرَمَ. فَحَثَمَ مِنَ الْجَمْعِ ; وَثَرَمَ مِنْ أَنْ يَنْثَرِمَ الشَّيْءُ.

# ضَغَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D8%BA%D9%8E%D8%B2%D9%8E/?book=9

(ضَغَزَ) الضَّادُ وَالْغَيْنُ وَالزَّاءُ لَيْسَ بِأَصْلٍ صَحِيحٍ، إِلَّا أَنْ يَأْتِيَ بِهِ شِعْرٌ. غَيْرَ أَنَّ الْخَلِيلَ ذَكَرَ أَنَّ الضِّغْزَ مِنَ السِّبَاعِ: السَّيِّئُ الْخُلُقِ. وَاللَّهُ أَعْلَمُ بِالصَّوَابِ.

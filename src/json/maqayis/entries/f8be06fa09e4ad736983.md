# رَزَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B2%D9%8E%D8%AD%D9%8E/?book=9

(رَزَحَ) الرَّاءُ وَالزَّاءُ وَالْحَاءُ أَصْلٌ يَدُلُّ عَلَى ضَعْفٍ وَفُتُورٍ. فَيَقُولُونَ رَزَحَ، إِذَا أَعْيَا; وَهِيَ إِبِلٌ مَرَازِيحُ، وَرَزْحَى، وَرَزَاحَى. وَيَقُولُونَ إِنَّ أَصْلَهُ الْمِرْزَحُ، وَهُوَ مَا تَوَاضَعَ مِنَ الْأَرْضِ وَاطْمَأَنَّ.

وَذُكِرَ فِي الْبَابِ كَلَامٌ آخَرُ لَيْسَ مِنَ الْقِيَاسِ الْمَذْكُورِ، قَالَ الشَّيْبَانِيُّ:

الْمِرْزِيحُ: الصَّوْتُ. قَالَ:

ذَرْ ذَا وَلَكِنْ تَبَصَّرْ هَلْ تَرَى ظُعُنًا ... تُحْدَى، لِسَاقَتِهَا بِالدَّوِّ مِرْزِيحُ

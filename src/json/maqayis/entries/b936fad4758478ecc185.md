# وَخَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AE%D9%8E%D8%B7%D9%8E/?book=9

(وَخَطَ) الْوَاوُ وَالْخَاءُ وَالطَّاءُ: كَلِمَتَانِ: إِحْدَاهُمَا وَخَطَ الشَّيْبُ فِي رَأْسِهِ. وَالْأُخْرَى: الْوَخْطُ: الطَّعْنُ. وَوَخَطَهُ بِالسَّيْفِ: تَنَاوَلَهُ مِنْ بَعِيدٍ. وَذَكَرُوا كَلِمَةً ثَالِثَةً، قَالُوا: مَرَّ يَخِطُ، وَهُوَ مَشْيٌ فَوْقَ الْعَنَقِ.

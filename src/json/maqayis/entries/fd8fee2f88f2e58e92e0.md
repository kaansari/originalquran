# رَمَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%85%D9%8E%D8%B3%D9%8E/?book=9

(رَمَسَ) الرَّاءُ وَالْمِيمُ وَالسِّينُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى تَغْطِيَةٍ وَسَتْرٍ. فَالرَّمْسُ: التُّرَابُ.

وَالرِّيَاحُ الرَّوَامِسُ: الَّتِي تُثِيرُ التُّرَابَ فَتَدْفِنُ الْآثَارَ. وَيُقَالُ رَمَسْتُ عَلَى فُلَانٍ الْخَبَرَ; إِذَا كَتَمْتَهُ إِيَّاهُ. وَرَمَسْتُ الرَّجُلَ وَأَرْمَسْتُهُ: دَفَنْتُهُ.

# قَعَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%B9%D9%8E%D9%84%D9%8E/?book=9

(قَعَلَ) الْقَافُ وَالْعَيْنُ وَاللَّامُ ثَلَاثُ كَلِمَاتٍ غَيْرُ مُتَجَانِسَةٍ وَلَا قِيَاسَ لَهَا.

فَالْأُولَى الْقُعَالُ: مَا تَنَاثَرَ مِنْ نَوْرِ الْعِنَبِ. وَالثَّانِيَةُ: الْقَوَاعِلُ: رُؤُوسُ الْجِبَالِ، وَاحِدَتُهَا قَاعِلَةٌ. وَالثَّالِثَةُ الْقَعْوَلَى: مِشْيَةٌ يَسْفِي مَاشِيهَا التُّرَابَ بِصُدُورِ قَدَمَيْهِ.

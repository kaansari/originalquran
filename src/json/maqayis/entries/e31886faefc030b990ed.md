# سَنَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%86%D9%8E%D8%AA%D9%8E/?book=9

(سَنَتَ) السِّينُ وَالنُّونُ وَالتَّاءُ لَيْسَ أَصْلًا يُتَفَرَّعُ مِنْهُ، لَكِنَّهُمْ يَقُولُونَ السَّنُوتُ، فَقَالَ قَوْمٌ: هُوَ الْعَسَلُ، وَقَالَ آخَرُونَ: هُوَ الْكَمُّونُ. قَالَ الشَّاعِرُ:

هُمُ السَّمْنُ وَالسَّنُّوتُ لَا أَلْسَ فِيهِمُ ... وَهُمْ يَمْنَعُونَ جَارَهُمْ أَنْ يُقَرَّدَا

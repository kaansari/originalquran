# خَمِجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%85%D9%90%D8%AC%D9%8E/?book=9

(خَمِجَ) الْخَاءُ وَالْمِيمُ وَالْجِيمُ يَدُلُّ عَلَى فُتُورٍ وَتَغَيُّرٍ. فَالْخَمَجُ فِي الْإِنْسَانِ: الْفُتُورُ. يُقَالُ أَصْبَحَ فُلَانٌ خَمِجًا، أَيْ فَاتِرًا. وَهُوَ فِي شِعْرِ الْهُذَلِيِّ:

أَخْشَى دُونَهُ الْخَمَجَا

وَيَقُولُونَ خَمِجَ اللَّحْمُ، إِذَا تَغَيَّرَ وَأَرْوَحَ.

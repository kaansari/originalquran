# أَيَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D9%8A%D9%8E%D9%86%D9%8E/?book=9

(أَيَنَ) الْهَمْزَةُ وَالْيَاءُ وَالنُّونُ يَدُلُّ عَلَى الْإِعْيَاءِ، وَقُرْبِ الشَّيْءِ. أَمَّا الْأَوَّلُ فَالْأَيْنُ الْإِعْيَاءُ. وَيُقَالُ: لَا يُبْنَى مِنْهُ فِعْلٌ. وَقَدْ قَالُوا آنَ يَئِينُ أَيْنًا. وَأَمَّا الْقُرْبُ فَقَالُوا: آنَ لَكَ يَئِينُ أَيْنًا.

وَأَمَّا الْحَيَّةُ الَّتِي تُدْعَى (الْأَيْنُ) فَذَلِكَ إِبْدَالٌ وَالْأَصْلُ الْمِيمُ. قَالَ شَاعِرٌ:

يَسْرِي عَلَى الْأَيْنِ وَالْحَيَّاتِ مُحْتَفِيًا ... نَفِسي فِدَاؤُكَ مِنْ سَارٍ عَلَى سَاقِ

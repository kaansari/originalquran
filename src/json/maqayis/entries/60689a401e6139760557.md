# عَثَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%AB%D9%8E%D9%84%D9%8E/?book=9

(عَثَلَ) ذَكَرُوا فِيهِ كَلِمَةً إِنْ صَحَّتْ. يُقَالُ: إِنَّ الْعِثْوَلَّ مِنَ الرِّجَالِ: الْجَافِي. قَالُوا: وَالْعَثُولُ: النَّخْلَةُ الْجَافِيَةُ الْغَلِيظَةُ. قَالَ:

هَزَزْتُ عَثُولًا مَصَّتِ الْمَاءَ وَالثَّرَى ... زَمَانًا فَلَمْ تَهْمُمْ بِأَنْ تَتَبَرَّعَا

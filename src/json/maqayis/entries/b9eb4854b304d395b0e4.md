# حَيَضَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%8A%D9%8E%D8%B6%D9%8E/?book=9

(حَيَضَ) الْحَاءُ وَالْيَاءُ وَالضَّادُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ حَاضَتِ السَّمُرَةُ إِذَا خَرَجَ مِنْهَا مَاءٌ أَحْمَرُ. وَلِذَلِكَ سُمِّيَتِ النُّفَسَاءُ حَائِضًا، تَشْبِيهًا لِدَمِهَا بِذَلِكَ الْمَاءِ.

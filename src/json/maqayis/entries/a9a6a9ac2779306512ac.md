# زَأَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%A3%D9%8E%D8%A8%D9%8E/?book=9

(زَأَبَ) الزَّاءُ وَالْهَمْزَةُ وَالْبَاءُ كَلِمَتَانِ. يُقَالُ زَأَبَ الشَّيْءَ، إِذَا حَمَلَهُ. وَالِازْدِئَابُ: الِاحْتِمَالُ. وَالْكَلِمَةُ الْأُخْرَى زَأَبَ، إِذَا شَرِبَ شُرْبًا شَدِيدًا. وَلَا قِيَاسَ لَهُمَا.

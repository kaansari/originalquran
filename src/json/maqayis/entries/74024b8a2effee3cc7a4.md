# وَعَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B9%D9%8E%D9%82%D9%8E/?book=9

(وَعَقَ) الْوَاوُ وَالْعَيْنُ وَالْقَافُ: كَلِمَتَانِ: إِحْدَاهُمَا الْوَعِيقُ: صَوْتٌ يَخْرُجُ مِنْ قُنْبِ الدَّابَّةِ. وَالثَّانِيَةُ الْوَعْقَةُ، هُوَ الرَّجُلُ السَّيِّئُ الْخُلُقِ، وَكَذَلِكَ الْوَعْقُ.

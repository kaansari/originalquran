# نَأَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%A3%D9%8E%D9%85%D9%8E/?book=9

(نَأَمَ) النُّونُ وَالْهَمْزَةُ وَالْمِيمُ أُصَيْلٌ يَدُلُّ عَلَى صَوْتٍ. النَّئِيمُ: [صَوْتٌ] فِيهِ ضَعْفٌ كَالْأَنِينِ. وَنَأَمَ الْأَسَدُ يَنْئِمُ. وَسَمِعْتُ لَهُ نَأْمَةً وَاحِدَةً. وَنَأَمَتِ الْقَوْسُ نَئِيمًا.

# نَزَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B2%D9%8E%D9%82%D9%8E/?book=9

(نَزَقَ) النُّونُ وَالزَّاءُ وَالْقَافُ كَلِمَةٌ تَدُلُّ عَلَى عَجَلَةٍ. مِنْ ذَلِكَ النَّزَقِ: الْخِفَّةُ وَالْعَجَلُ. وَنَزَّقْتُ الْفَرَسَ فَنَزِقَ. وَيَقُولُونَ: أَنْزَقَ فُلَانٌ بِالضَّحِكِ.

# وَسَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B3%D9%8E%D9%86%D9%8E/?book=9

(وَسَنَ) الْوَاوُ وَالسِّينُ وَالنُّونُ: كَلِمَتَانِ مُتَقَارِبَتَانِ. الْوَسَنُ: النُّعَاسُ، وَكَذَا السِّنَةُ. وَرَجُلٌ وَسْنَانُ. وَتَوَسَّنَ الْفَحْلُ أُنْثَاهُ: أَتَاهَا نَائِمَةً.

وَالْكَلِمَةُ الْأُخْرَى قَوْلُهُمْ: دَعْ هَذَا الْأَمْرَ فَلَا يَكُونَنَّ لَكَ وَسَنًا، أَيْ لَا تَطْلُبْهُ وَلَا يَكُونَنَّ مِنْ هَمِّكَ.

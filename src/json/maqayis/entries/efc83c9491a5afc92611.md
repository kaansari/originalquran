# رَعَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B9%D9%91%D9%8E/?book=9

(رَعَّ) الرَّاءُ وَالْعَيْنُ أَصْلٌ مُطَّرِدٌ يَدُلُّ عَلَى حَرَكَةٍ وَاضْطِرَابٍ. يُقَالُ تَرَعْرَعَ الصَّبِيُّ: تَحَرَّكَ. وَهَذَا شَابٌّ رَُعْرَُعٌ وَرَعْرَاعٌ، وَالْجَمْعُ رَعَارِعُ. قَالَ:

أَلَا إِنَّ أَخْدَانَ الشَّبَابِ الرَّعَارِعُ

وَقَصَبٌ رَعْرَعٌ: طَوِيلٌ. وَإِذَا كَانَ كَذَا فَهُوَ مُضْطَرِبٌ. وَمِنَ الْبَابِ الرَّعَاعُ، وَهُمْ سِفْلَةُ النَّاسِ. وَيَقُولُونَ: الرَّعْرَعَةُ: تَرَقْرُقُ الْمَاءِ عَلَى وَجْهِ الْأَرْضِ. فَإِنْ كَانَ صَحِيحًا فَهُوَ الْقِيَاسُ.

# ثَأْيٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%A3%D9%92%D9%8A%D9%8C/?book=9

(ثَأْيٌ) الثَّاءُ وَالْهَمْزَةُ وَالْيَاءُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى فَسَادٍ وَخَرْمٍ. فَالثَّأْيُ عَلَى مِثَالِ الثَّعْيِ الْخَرْمِ ; يُقَالُ: أَثَأَتُِ الْخَارِزَةَ الْخَرْزَ تُثْئِيهِ إِذَا خَرَمْتَهُ. وَيُقَالُ أَثْأَيْتُ فِي الْقَوْمِ إِثْآءً جَرَحْتُ فِيهِمْ. قَالَ:

يَا لَكَ مِنْ عَيْثٍ وَمِنْ إِثْآءِ ... يُعْقِبُ بِالْقَتْلِ وَبِالسِّبَاءِ

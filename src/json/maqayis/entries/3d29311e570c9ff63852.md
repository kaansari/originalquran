# تَعِسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%B9%D9%90%D8%B3%D9%8E/?book=9

(تَعِسَ) التَّاءُ وَالْعَيْنُ وَالسِّينُ كَلِمَةٌ وَاحِدَةٌ وَهُوَ الْكَبُّ، يُقَالُ تَعَسَهُ اللَّهُ وَأَتْعَسَهُ. قَالَ:

غَدَاةً هَزَمْنَا جَمْعَهُمْ بِمُتَالِعٍ ... فَآبُوا بِإِتْعَاسٍ عَلَى شَرِّ طَائِرِ

# مَسَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B3%D9%91%D9%8E/?book=9

(مَسَّ) الْمِيمُ وَالسِّينُ أَصْلٌ صَحِيحٌ وَاحِدٌ يَدُلُّ عَلَى جَسِّ الشَّيْءِ بِالْيَدِ. وَمَسِسْتُهُ أَمَسُّهُ. وَرُبَّمَا قَالُوا: مَسَسْتُ أَمُسُّ. وَالْمَمْسُوسُ: الَّذِي بِهِ مَسٌّ، كَأَنَّ الْجِنَّ مَسَّتْهُ. وَالْمَسُوسُ مِنَ الْمَاءِ: مَا نَالَتْهُ الْأَيْدِي. قَالَ:

لَوْ كُنْتُ مَاءً كُنْتُ لَا ... عَذْبَ الْمَذَاقِ وَلَا مَسُوسًا.

# وَخَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AE%D9%8E%D8%B4%D9%8E/?book=9

(وَخَشَ) الْوَاوُ وَالْخَاءُ وَالشِّينُ: كَلِمَةٌ وَاحِدَةٌ هِيَ الْوَخْشُ: الدُّنَاةُ مِنَ الرِّجَالِ وَالْأَخْلَاطُ. وَيُقَالُ: أَوْخَشُوا الشَّيْءَ: خَلَطُوهُ. قَالَ:.

وَأَلْقَيْتُ سَهْمِي بَيْنَهُمْ حِينَ أَوْخَشُوا

قَالَ أَبُو بَكْرٍ: الْوَخْشُ: الرَّدِيُّ مِنْ كُلِّ شَيْءٍ.

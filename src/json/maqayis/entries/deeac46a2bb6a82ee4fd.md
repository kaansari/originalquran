# صَنَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%86%D9%8E%D9%85%D9%8E/?book=9

(صَنَمَ) الصَّادُ وَالنُّونُ وَالْمِيمُ كَلِمَةٌ وَاحِدَةٌ لَا فَرْعَ لَهَا، وَهِيَ الصَّنَمُ. وَكَانَ شَيْئًا يُتَّخَذُ مِنْ خَشَبٍ أَوْ فِضَّةٍ أَوْ نُحَاسٍ فَيُعْبَدُ.

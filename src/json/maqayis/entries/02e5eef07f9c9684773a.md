# نَأَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%A3%D9%8E%D8%B4%D9%8E/?book=9

(نَأَشَ) النُّونُ وَالْهَمْزَةُ وَالشِّينُ كَلِمَةٌ تَدُلُّ عَلَى أَخْذٍ وَبَطْشٍ. وَرَجُلٌ نَؤُوشٌ: ذُو بَطْشٍ. وَقَدْ ذُكِرَتْ كَلِمَةٌ إِنْ صَحَّتْ فَلَيْسَتْ مِنْ قِيَاسِ الْأُولَى، يَقُولُونَ لِمَنْ جَاءَ فِي أَوَاخِرِ النَّاسِ: جَاءَ نَئِيشًا. قَالَ:

تَمَنَّى نَئِيشًا أَنْ يَكُونَ أَطَاعَنِي ... وَقَدْ حَدَثَتْ بَعْدَ الْأُمُورِ أُمُورُ

وَالَّذِي سَمِعْنَاهُ: " تَمَنَّى أَخِيرًا ".

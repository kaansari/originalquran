# مَضَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B6%D9%8E%D8%B1%D9%8E/?book=9

(مَضَرَ) الْمِيمُ وَالضَّادُ وَالرَّاءُ أَصْلٌ صَحِيحٌ قَلِيلُ الْفُرُوعِ. فَالْمَضْرُ بِنَاءُ قَوْلِكَ لَبَنٌ مَضِرٌ وَمَاضِرٌ: شَدِيدُ الْحُمُوضَةِ. وَيُقَالُ: اشْتِقَاقُ مُضَرَ مِنْهُ.

وَالتَّمَضُّرُ: التَّعَصُّبُ لِمُضِرَ. وَقَوْلُهُمْ: ذَهَبَ دَمُهُ خِضْرًا مِضْرًا، أَيْ بَاطِلًا، إِتْبَاعٌ وَلَيْسَ مِنَ الْبَابِ.

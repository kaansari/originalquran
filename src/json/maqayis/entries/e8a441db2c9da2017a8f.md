# بَشَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B4%D9%91%D9%8E/?book=9

(بَشَّ) الْبَاءُ وَالشِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ اللِّقَاءُ الْجَمِيلُ. وَالضَّحِكُ إِلَى الْإِنْسَانِ سُرُورًا بِهِ. أَنْشَدَ ابْنُ دُرَيْدٍ:

لَا يَعْدَمُ السَّائِلُ مِنْهُ وَفْرَا ... وَقَبْلَهُ بَشَاشَةً وَبِشْرَا

يُقَالُ: بَشَّ بِهِ بَشًّا وَبَشَاشَةً.

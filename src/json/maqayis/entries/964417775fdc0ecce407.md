# ذَأَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D8%A3%D9%8E%D9%85%D9%8E/?book=9

(ذَأَمَ) الذَّالُ وَالْهَمْزَةُ وَالْمِيمُ أَصْلٌ يَدُلُّ عَلَى كَرَاهَةٍ وَعَيْبٍ. يُقَالُ أَذْأَمْتَنِي عَلَى كَذَا، أَيْ أَكْرَهْتَنِي عَلَيْهِ. وَيَقُولُونَ ذَأَمْتُهُ، أَيْ حَقَرْتُهُ. وَالذَّأْمُ الْعَيْبُ، وَهُوَ مَذْءُومٌ. فَأَمَّا الذَّانُ بِالنُّونِ، فَلَيْسَ أَصْلًا، لِأَنَّ النُّونَ فِيهِ مُبْدَلَةٌ مِنْ مِيمٍ. قَالَ: رَدَدْنَا الْكَتِيبَةَ مَلْمُومَةً ... بِهَا أَفْنُهَا وَبِهَا ذَانُهَا

# مَشَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B4%D9%8E%D9%86%D9%8E/?book=9

(مَشَنَ) الْمِيمُ وَالشِّينُ وَالنُّونُ أَصْلٌ يَدُلُّ عَلَى تَنَاوُلِ الشَّيْءِ بِضَرْبٍ وَاسْتِلَالٍ وَمَا أَشْبَهَ ذَلِكَ. فَالْمَشْنُ: الضَّرْبُ بِالسَّوْطِ، وَمَشَنَهُ. وَامْتَشَنَ السَّيْفَ: اسْتَلَّهُ. وَامْتَشَنَ الشَّيْءَ: اقْتَطَعَهُ. وَمَشَنَ الْجِلْدَ: سَلَخَهُ. وَمِمَّا يُحْمَلُ عَلَى هَذَا مَشَّنَتِ النَّاقَةُ: دَرَّتْ كَارِهَةً.

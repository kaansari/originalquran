# نَغَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%BA%D9%8E%D9%85%D9%8E/?book=9

(نَغَمَ) النُّونُ وَالْغَيْنُ وَالْمِيمُ لَيْسَ إِلَّا النَّغْمَةُ: جَرْسُ الْكَلَامِ وَحُسْنُ الصَّوْتِ بِالْقِرَاءَةِ وَغَيْرِهَا. وَهُوَ النَّغْمُ. وَتَنَغَّمَ الْإِنْسَانُ بِالْغِنَاءِ وَنَحْوِهِ.

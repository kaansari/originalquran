# فَحَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AD%D9%91%D9%8E/?book=9

(فَحَّ) الْفَاءُ وَالْحَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ الْفَحِيحُ: صَوْتُ الْأَفْعَى. قَالَ:

كَأَنَّ نَقِيقَ الْحَبِّ فِي حَاوِيَائِهِ ... فَحِيحُ الْأَفَاعِي أَوْ نَقِيقُ الْعَقَارِبِ

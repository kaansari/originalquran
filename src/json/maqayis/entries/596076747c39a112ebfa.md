# غَسَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D8%B3%D9%91%D9%8E/?book=9

(غَسَّ) الْغَيْنُ وَالسِّينُ لَيْسَ فِيهِ إِلَّا قَوْلُهُمْ: رَجُلٌ غُسٌّ، إِذَا كَانَ ضَعِيفًا. وَمِنْهُ قَوْلُ أَوْسٍ:

مُخَلَّفُونَ وَيَقْضِي النَّاسُ أَمْرَهُمْ ... غُسُّو الْأَمَانَةِ صُنْبُورٌ فَصُنْبُورُ

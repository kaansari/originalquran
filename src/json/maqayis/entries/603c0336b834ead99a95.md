# الْعَجَنْجَرُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D8%AC%D9%8E%D9%86%D9%92%D8%AC%D9%8E%D8%B1%D9%8F/?book=9

(الْعَجَنْجَرُ) : الْغَلِيظُ، يُقَالُ زُبْدٌ عَجَنْجَرٌ. وَهَذَا مِمَّا زِيدَتْ حُرُوفُهُ لِلْمَعْنَى الَّذِي ذَكَرْنَاهُ. وَهُوَ مَنْ تَعَجَّرَ، إِذَا تَعَقَّدَ. قَالَ:

مَخَضْتُ وَطْبِي فَرَغَا وَجَرْجَرَا ... أَخْرَجَ مِنْهُ زَبَدًا عَجَنْجَرَا

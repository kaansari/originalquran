# دَحَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%AD%D9%8E%D9%86%D9%8E/?book=9

(دَحَنَ) الدَّالُ وَالْحَاءُ وَالنُّونُ لَيْسَ بِأَصْلٍ، لِأَنَّهُ مِنْ بَابِ الْإِبْدَالِ. يُقَالُ رَجُلٌ دَحِنٌ، وَهُوَ مِثْلُ الدَّحِلِ. وَقَدْ فَسَّرْنَاهُ.

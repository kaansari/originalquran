# جَسَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%B3%D9%8E%D8%A3%D9%8E/?book=9

(جَسَأَ) الْجِيمُ وَالسِّينُ وَالْهَمْزَةُ يَدُلُّ عَلَى صَلَابَةٍ وَشِدَّةٍ. يُقَالُ جَسَا الشَّيْءُ، إِذَا اشْتَدَّ، وَجَسَأَ أَيْضًا بِالْهَمْزَةِ. وَجَسَأَتْ يَدُهُ إِذَا صَلُبَتْ.

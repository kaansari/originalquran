# مَكَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%83%D9%8E%D8%B1%D9%8E/?book=9

(مَكَرَ) الْمِيمُ وَالْكَافُ وَالرَّاءُ كَلِمَتَانِ مُتَبَايِنَتَانِ: إِحْدَاهُمَا الْمَكْرُ: الِاحْتِيَالُ وَالْخِدَاعُ. وَمَكَرَ بِهِ يَمْكُرُ. وَالْأُخْرَى الْمَكْرُ: خَدَالَةُ السَّاقِ. وَامْرَأَةٌ مَمْكُورَةُ السَّاقَيْنِ.

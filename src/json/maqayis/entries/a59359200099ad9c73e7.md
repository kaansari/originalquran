# وَأَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%A3%D9%8E%D8%AF%D9%8E/?book=9

(وَأَدَ) الْوَاوُ وَالْهَمْزَةُ وَالدَّالُ: كَلِمَةٌ تَدُلُّ عَلَى إِثْقَالِ شَيْءٍ بِشَيْءٍ. يُقَالُ لِلْإِبِلِ إِذَا مَشَتْ بِثَقَلِهَا: لَهَا وَئِيدٌ. قَالَ:

مَا لِلْجِمَالِ مَشْيُهَا وَئِيدَا

أَيْ مَشْيًا بِثِقَلٍ. وَالْمَوْءُودَةُ مِنْ هَذَا، لِأَنَّهَا تُدْفَنُ حَيَّةً، فَهِيَ تُثْقَلُ بِالتُّرَابِ الَّذِي يَعْلُوهَا. وَأَدَهَا يَئِدُهَا وَأْدًا. وَمِنْ ذَلِكَ قَوْلُهُ:

وَأَحْيَا الْوَئِيدَ فَلَمْ يُوأَدِ

# دَوَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%88%D9%8E%D8%AF%D9%8E/?book=9

(دَوَدَ) الدَّالُ وَالْوَاوُ وَالدَّالُ لَيْسَ أَصْلًا يُفَرَّعُ مِنْهُ. فَالدُّودُ مَعْرُوفٌ. يُقَالُ دَادَ الشَّيْءُ يَدَادُ، وَأَدَادَ يَدِيدُ. وَالدَّوَادِي: آثَارُ أَرَاجِيحِ الصِّبْيَانِ، وَاحِدَتُهَا دَوْدَاةٌ.

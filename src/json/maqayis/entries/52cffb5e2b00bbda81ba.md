# طَلَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D9%84%D9%8E%D8%AD%D9%8E/?book=9

(طَلَحَ) الطَّاءُ وَاللَّامُ وَالْحَاءُ أَصْلَانِ صَحِيحَانِ، أَحَدُهُمَا جِنْسٌ مِنَ الشَّجَرِ، وَالْآخَرُ بَابٌ مِنَ الْهُزَالِ وَمَا أَشْبَهَهُ.

فَالْأَوَّلُ الطَّلْحُ، وَهُوَ شَجَرٌ مَعْرُوفٌ، الْوَاحِدَةُ طَلْحَةٌ، وَذُو طُلُوحٍ: مَكَانٌ، وَلَعَلَّ بِهِ طَلْحًا. وَيُقَالُ: إِبِلٌ طَلَاحَى وَطَلِحَةٌ، إِذَا شَكَتْ عَنْ أَكْلِ الطَّلْحِ.

وَالثَّانِي: قَوْلُهُمْ نَاقَةٌ طِلْحُ أَسْفَارٍ، إِذَا جَهَدَهَا السَّيْرُ وَهَزَلَهَا ; وَقَدْ طَلِحَتْ. وَالطِّلْحُ ; الْمَهْزُولُ مِنَ الْقِرْدَانِ. قَالَ:

إِذَا نَامَ طِلْحٌ أَشْعَثُ الرَّأْسِ خَلْفَهَا ... هَدَاهُ لَهَا أَنْفَاسُهَا وَزَفِيرُهَا

وَمِنَ الْبَابِ الطَّلَاحُ: ضِدُ الصَّلَاحِ، وَكَأَنَّهُ مِنْ سُوءِ الْحَالِ وَالْهُزَالِ.

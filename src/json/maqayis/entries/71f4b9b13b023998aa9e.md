# خَضِلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B6%D9%90%D9%84%D9%8E/?book=9

(خَضِلَ) الْخَاءُ وَالضَّادُ وَاللَّامُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى نَعْمَةٍ وَنَدًى. يُقَالُ أَخْضَلَ الْمَطَرُ [الْأَرْضَ] فَهُوَ مُخْضِلٌ، وَالْأَرْضُ مُخْضَلَةٌ. وَاخْضَلَّ الشَّيْءُ: ابْتَلَّ. وَالْخَضِلُ: النَّبَاتُ النَّاعِمُ. وَيُقَالُ إِنَّ الْخَضِيلَةَ الرَّوْضَةُ. وَيُقَالُ لِامْرَأَةِ الرَّجُلِ خُضُلَّتُهُ، وَهُوَ مِنْ هَذَا وَذَلِكَ، كَمَا سُمِّيَتْ طَلَّةً، لِأَنَّهَا كَالطَّلِّ فِي عَيْنِهِ. وَكُلُّ نِعْمَةٍ خُضُلَّةٌ. قَالَ:

إِذَا قُلْتُ إِنَّ الْيَوْمَ يَوْمُ خَضُلَّةٍ ... وَلَا شَرْزَ لَاقَيْتُ الْأُمُورَ الْبَجَارِيَا

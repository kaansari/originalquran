# قَامَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%A7%D9%85%D9%8E/?book=9

(قَامَ) الْقَافُ وَالْأَلِفُ وَالْمِيمُ قَدْ مَضَى ذِكْرُ ذَلِكَ، وَالْأَصْلُ فِي جَمِيعِهِ الْوَاوُ. وَالْقَامَةُ: الْبَكَرَةُ بِأَدَاتِهَا. قَالَ:

لَمَّا رَأَيْتُ أَنَّهَا لَاقَامَهْ ... وَأَنَّنِي مُوفٍ عَلَى السَّآمَهْ

نَزَعْتُ نَزْعًا زَعْزَعَ الدِّعَامَهُ.

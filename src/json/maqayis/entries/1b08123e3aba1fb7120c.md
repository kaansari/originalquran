# ثَدْيٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%AF%D9%92%D9%8A%D9%8C/?book=9

(ثَدْيٌ) الثَّاءُ وَالدَّالُ وَالْيَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ ثَدْيُ الْمَرْأَةِ. وَالْجَمْعُ. أَثْدٍ. وَالثَّدْيَاءُ: الْكَبِيرَةُ الثَّدْيِ. ثُمَّ فُرِّقَ بَيْنَهُ وَبَيْنَ الَّذِي لِلرَّجُلِ، فَقِيلَ فِي الرَّجُلِ الثُّنْدُؤَةُ بِالضَّمِّ وَالْهَمْزَةِ، وَالثَّنْدُوَةُ بِالْفَتْحِ غَيْرُ مَهْمُوزٍ.

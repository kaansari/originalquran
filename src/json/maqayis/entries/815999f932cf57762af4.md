# ثَرِبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%B1%D9%90%D8%A8%D9%8E/?book=9

(ثَرِبَ) الثَّاءُ وَالرَّاءُ وَالْبَاءُ كَلِمَتَانِ مُتَبَايِنَتَا الْأَصْلِ، لَا فُرُوعَ لَهُمَا. فَالتَّثْرِيبُ اللَّوْمُ وَالْأَخْذُ عَلَى الذَّنْبِ. قَالَ اللَّهُ تَعَالَى: {لَا تَثْرِيبَ عَلَيْكُمُ الْيَوْمَ} [يوسف: 92] فَهَذَا أَصْلٌ وَاحِدٌ. وَالْآخَرُ الثَّرْبُ، وَهُوَ شَحْمٌ قَدْ غَشَّى الْكَرِشَ وَالْأَمْعَاءَ رَقِيقٌ ; وَالْجَمْعُ ثُرُوبٌ.

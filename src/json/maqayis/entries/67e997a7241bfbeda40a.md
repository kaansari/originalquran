# اعْلَنْكَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D8%B9%D9%92%D9%84%D9%8E%D9%86%D9%92%D9%83%D9%8E%D8%B3%D9%8E/?book=9

(اعْلَنْكَسَ) : الشَّعْرُ، إِذَا اشْتَدَّ سَوَادُهُ، وَكَثُرَ. وَهَذَا هُوَ مِنَ الْأَوَّلِ، وَاللَّامُ بَدَلٌ مِنَ الرَّاءِ، وَقَدْ فَسَّرْنَاهُ. عَرْكَسْتُ الشَّيْءَ: جَمَعْتُ بَعْضَهُ عَلَى بَعْضٍ، وَهَذَا مِنْ عَكَسَ وَرَكَسَ، وَقَدْ فُسِّرَا.

# نَهَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%87%D9%8E%D8%B3%D9%8E/?book=9

(نَهَسَ) النُّونُ وَالْهَاءُ وَالسِّينُ كَلِمَةٌ تَدُلُّ عَلَى عَضٍّ عَلَى شَيْءٍ. وَنَهَسَ اللَّحْمَ: قَبَضَ عَلَيْهِ وَنَتَرَهُ عِنْدَ أَكْلِهِ إِيَّاهُ. وَمِنْهُ نَهَسَتْهُ الْحَيَّةُ.

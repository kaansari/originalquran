# الْعَرْصَمُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D8%B1%D9%92%D8%B5%D9%8E%D9%85%D9%8F/?book=9

(الْعَرْصَمُ) : الرَّجُلُ الْقَوِيُّ الشَّدِيدُ الْبَضْعَةِ. وَهَذَا مِنَ الْعَرَصِ، وَهُوَ النَّشَاطُ. وَيُقَالُ الْعِرْصَمُّ. وَقِيَاسُهُ وَاحِدٌ.

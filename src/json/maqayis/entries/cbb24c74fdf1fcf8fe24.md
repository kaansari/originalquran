# دَرَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%B1%D9%8E%D8%B2%D9%8E/?book=9

(دَرَزَ) الدَّالُ وَالرَّاءُ وَالزَّاءُ لَيْسَ بِشَيْءٍ، وَلَا أَحْسَبُ الْعَرَبَ قَالَتْ فِيهِ. إِلَّا أَنَّ ابْنَ الْأَعْرَابِيِّ حُكِيَ أَنَّهُ قَالَ: يَقُولُ الْعَرَبُ لِلسِّفْلَةِ: هُمْ أَوْلَادُ دَرْزَةَ، كَمَا تَقُولُ لِلُّصُوصِ وَأَشْبَاهِهِمْ: بَنُو غَبْرَاءَ. وَأَنْشَدَ:

أَوْلَادُ دَرْزَةً أَسْلَمُوكَ وَطَارُوا

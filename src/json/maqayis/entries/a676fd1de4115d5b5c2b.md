# مَتَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AA%D9%8E%D8%B3%D9%8E/?book=9

(مَتَسَ) الْمِيمُ وَالتَّاءُ وَالسِّينُ فِيهِ كَلِمَةٌ حَكَاهَا ابْنُ دُرَيْدٍ، هِيَ مَتَسَهُ يَمْتِسُهُ مَتْسًا: أَرَاغَهُ لِيَنْتَزِعَهُ مِنْ بَيْتٍ أَوْ غَيْرِهِ.

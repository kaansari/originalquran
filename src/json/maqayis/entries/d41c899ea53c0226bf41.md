# هَوَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%88%D9%8E%D8%AA%D9%8E/?book=9

(هَوَتَ) الْهَاءُ وَالْوَاوُ وَالتَّاءُ: قَرِيبٌ مِنَ الَّذِي قَبْلَهُ. يَقُولُونَ: الْهَوْتَةُ: الطَّرِيقُ إِلَى الْمَاءِ. وَصَبَّ اللَّهُ عَلَيْهِ الْهَوْتَةَ وَالْمَوْتَةَ، شَتْمٌ، قَالَهُ الْخَلِيلُ.

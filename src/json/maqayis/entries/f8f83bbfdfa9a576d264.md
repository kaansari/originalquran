# رَوَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%88%D9%8E%D9%84%D9%8E/?book=9

(رَوَلَ) الرَّاءُ وَالْوَاوُ وَاللَّامُ أَصْلٌ يَدُلُّ عَلَى لَطْخِ شَيْءٍ بِشَيْءٍ. يُقَالُ رَوَّلْتُ الْخُبْزَ بِالسَّمْنِ، مِثْلُ رَوَّغْتُ. وَالرُّوَالُ: بُزَاقُ الدَّابَّةِ. يُقَالُ رَوَّلَ [فِي] مِخْلَاتِهِ. وَقَرِيبٌ مِنْ هَذَا الْبَابِ رَوَّلَ الْفَرَسُ: أَدْلَى.

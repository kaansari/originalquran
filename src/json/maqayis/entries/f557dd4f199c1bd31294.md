# نَفَتْ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%81%D9%8E%D8%AA%D9%92/?book=9

(نَفَتْ) النُّونُ وَالْفَاءُ وَالتَّاءُ. يَقُولُونَ: نَفَتَتِ الْقِدْرُ: غَلَتْ وَيَبِسَ مَرَقُهَا عَلَيْهَا. قَالَ:

وَصَاحِبٍ لِصَدْرِهِ كَتِيتُ ... عَلَيَّ مِثْلَ الْمِرْجَلِ النَّفُوتِ

وَنَفَتَ صَدْرُهُ بِالْعَدَاوَةِ: غَلَا.

# عَنْجَرِدٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D9%86%D9%92%D8%AC%D9%8E%D8%B1%D9%90%D8%AF%D9%8C/?book=9

(عَنْجَرِدٌ) : الْمَرْأَةُ الْجَرِيئَةُ السَّلِيطَةُ. وَهَذَا مَعْنَاهُ أَنَّهَا تَتَجَرَّدُ لِلشَّرِّ. الْعَيْنُ وَالنُّونُ زَائِدَةٌ. [بَابِ الْغَيْنِ وَمَا مَعَهَا فِي الْمُضَاعَفِ وَالْمُطَابِقِ]

# ذَمَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D9%85%D9%8E%D9%89/?book=9

(ذَمَى) الذَّالُ وَالْمِيمُ وَالْحَرْفُ الْمُعْتَلُّ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى حَرَكَةٍ. فَالذَّمَاءُ: الْحَرَكَةُ; يُقَالُ ذَمَى يَذْمِي، إِذَا تَحَرَّكَ. وَالذَّمَيَانُ: الْإِسْرَاعُ. وَيُقَالُ لِبَقِيَّةِ النَّفْسِ الذَّمَاءُ، وَذَلِكَ أَنَّهَا بَقِيَّةُ حَرَكَتِهِ. وَمِنَ الْبَابِ: خُذْ مَا ذَمَى لَكَ، أَيْ مَا ارْتَفَعَ، وَهُوَ مِنَ الْبَابِ لِأَنَّهُ يَسْنَحُ. وَيُقَالُ ذَمَتْنِي رِيحُ كَذَا، أَيْ آذَتْنِي.

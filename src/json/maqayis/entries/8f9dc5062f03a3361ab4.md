# خَسِرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B3%D9%90%D8%B1%D9%8E/?book=9

(خَسِرَ) الْخَاءُ وَالسِّينُ وَالرَّاءُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى النَّقْصِ. فَمِنْ ذَلِكَ الْخُسْرِ وَالْخُسْرَانِ، كَالْكُفْرِ وَالْكُفْرَانِ، وَالْفُرْقُ وَالْفُرْقَانُ. وَيُقَالُ خَسَرْتُ الْمِيزَانَ وَاخْسَرْتُهُ، إِذَا نَقَصْتَهُ. وَاللَّهُ أَعْلَمُ.

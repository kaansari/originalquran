# أَثْوَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%AB%D9%92%D9%88%D9%8E%D9%89/?book=9

(أَثْوَى) الْهَمْزَةُ وَالثَّاءُ وَالْوَاوُ وَالْيَاءُ أَصْلٌ وَاحِدٌ، تَخْتَلِطُ الْوَاوُ فِيهِ بِالْيَاءِ، وَيَقُولُونَ أَثَى عَلَيْهِ يَأْثِي إثَاوَةً وَإثَايَةً وَأَثْوًا وَأَثْيًا: إِذَا نَمَّ عَلَيْهِ. وَيُنْشِدُونَ:

وَلَا أَكُونُ لَكُمْ ذَا نَيْرَبٍ آثِ

وَالنَّيْرَبُ: النَّمِيمَةُ. وَقَالَ:

وَإِنَّ امْرَأً يَأْثُو بِسَادَةِ قَوْمِهِ ... حَرِيٌّ لَعَمْرِي أَنْ يُذَمَّ وَيُشْتَمَا

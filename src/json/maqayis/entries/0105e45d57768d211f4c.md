# لَحَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AD%D9%8E%D9%83%D9%8E/?book=9

(لَحَكَ) اللَّامُ وَالْحَاءُ وَالْكَافُ أَصْلٌ يَدُلُّ عَلَى مُلَاءَمَةٍ وَمُدَاخَلَةٍ. يُقَالُ: لُوحِكَ فَقَارُ النَّاقَةِ، فَهُوَ مُلَاحَكٌ، إِذَا دَخَلَ بَعْضُهُ فِي بَعْضٍ. وَيُقَالُ ذَلِكَ فِي الْبُنْيَانِ أَيْضًا.

# غَيَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D9%8A%D9%8E%D9%85%D9%8E/?book=9

(غَيَمَ) الْغَيْنُ وَالْيَاءُ وَالْمِيمُ كَلِمَةٌ تَدُلُّ عَلَى سَتْرِ شَيْءٍ لِشَيْءٍ. مِنْ ذَلِكَ: الْغَيْمُ، وَهُوَ مَعْرُوفٌ. يُقَالُ: غَامَتِ السَّمَاءُ، وَتَغَيَّمَتْ، وَأَغَامَتْ.

وَمِنَ الْبَابِ: الْغَيْمُ، وَهُوَ الْعَطَشُ وَحَرَارَةُ الْجَوْفِ، لِأَنَّهُ شَيْءٌ يَغْشَى الْقَلْبَ.

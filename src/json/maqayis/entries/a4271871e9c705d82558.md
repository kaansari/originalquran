# حَرَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%B1%D9%8E%D9%83%D9%8E/?book=9

(حَرَكَ) الْحَاءُ وَالرَّاءُ وَالْكَافُ أَصْلٌ وَاحِدٌ، فَالْحَرَكَةُ ضِدُّ السُّكُونِ. وَمِنَ الْبَابِ الْحَارِكَانِ، وَهُمَا مُلْتَقَى الْكَتِفَيْنِ، لِأَنَّهُمَا لَا يَزَالَانِ يَتَحَرَّكَانِ. وَكَذَلِكَ الْحَرَاكِيكُ، وَهِيَ الْحَرَاقِفُ، وَاحِدَتُهَا حَرْكَكَةٌ.

# تَرَفٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%B1%D9%8E%D9%81%D9%8C/?book=9

(تَرَفٌ) التَّاءُ وَالرَّاءُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ التُّرْفَةُ. يُقَالُ رَجُلٌ مُتْرَفٌ مُنَعَّمٌ، وَتَرَّفَهُ أَهْلُهُ إِذَا نَعَّمُّوهُ بِالطَّعَامِ الطَّيِّبِ وَالشَّيْءِ يُخَصُّ بِهِ. وَفِي كِتَابِ الْخَلِيلِ: التُّرْفَةُ الْهَنَةُ فِي الشَّفَةِ الْعُلْيَا. وَهَذَا غَلَطٌ، إِنَّمَا هِيَ التُِّفْرَةُ وَقَدْ ذُكِرَتْ.

# لَبَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%A8%D9%8E%D8%AE%D9%8E/?book=9

(لَبَخَ) اللَّامُ وَالْبَاءُ وَالْخَاءُ. يَقُولُونَ: اللُّبَاخِيَّةُ: الْمَرْأَةُ التَّامَّةُ الْخَلْقِ. قَالَ الْأَعْشَى:

عَبْهَرَةُ الْخَلْقِ لُبَاخِيَّةٌ ... تَزِينُهُ بِالْخُلُقِ الطَّاهِرِ.

# أَيَضَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D9%8A%D9%8E%D8%B6%D9%8E/?book=9

(أَيَضَ) الْهَمْزَةُ وَالْيَاءُ وَالضَّادُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى الرُّجُوعِ وَالْعَوْدِ، يُقَالُ: آضَ يَئِيضُ: إِذَا رَجَعَ. وَمِنْهُ قَوْلُهُمْ قَالَ ذَاكَ أَيْضًا، وَفَعَلَهُ أَيْضًا.

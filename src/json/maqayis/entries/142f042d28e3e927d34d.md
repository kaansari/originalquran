# قَلَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D9%84%D9%8E%D9%81%D9%8E/?book=9

(قَلَفَ) الْقَافُ وَاللَّامُ وَالْفَاءُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى كَشْطِ شَيْءٍ عَنْ شَيْءٍ. يُقَالُ: قَلَفْتُ الشَّجَرَةَ، إِذَا نَحَّيْتُ عَنْهَا لِحَاءَهَا. وَقَلَفْتُ الدَّنَّ: فَضَضْتُ عَنْهُ طِينَهُ. وَقَلَفَ الْخَاتِنُ غُرْلَةَ الصَّبِيِّ، وَهِيَ الْقُلْفَةُ، إِذَا قَطَعَهَا.

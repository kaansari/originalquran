# هَطَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B7%D9%8E%D9%84%D9%8E/?book=9

(هَطَلَ) الْهَاءُ وَالطَّاءُ وَاللَّامُ: كَلِمَةٌ تَدُلُّ عَلَى تَتَابُعٍ فِي قَطْرٍ وَغَيْرِهِ. وَهَطَلَ الْمَطَرُ هَطَلَانًا: تَتَابَعَ، وَكَذَلِكَ الدَّمْعُ. وَدِيمَةٌ هَطْلَاءُ. وَإِبِلٌ هَطْلَى: تَجِيءُ رُوَيْدًا مُتَتَابِعَةً. وَكَذَلِكَ يَقُولُونَ لِلْمُعْيِي مِنْهَا: هَطِلٌ.

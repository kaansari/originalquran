# هَكَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%83%D9%8E%D8%B1%D9%8E/?book=9

(هَكَرَ) الْهَاءُ وَالْكَافُ وَالرَّاءُ كَلِمَتَانِ: الْهَكْرُ: الْعَجَبُ. قَالَ:

فَاعْجَبْ لِذَلِكَ رَيْبَ دَهْرٍ وَاهْكَرِ.

قَالَ الْخَلِيلُ: تَقُولُ هَكْرًا لَكَ.

وَالْكَلِمَةُ الْأُخْرَى: اعْتِرَاءُ النُّعَاسِ. قَالَ: وَهَكِرَ الرَّجُلُ: اعْتَرَاهُ نُعَاسٌ وَكَلَّ، وَاسْتَرْخَتْ عِظَامُهُ وَمَفَاصِلُهُ.

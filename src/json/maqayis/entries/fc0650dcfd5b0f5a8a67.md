# بَلَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%84%D9%8E%D9%82%D9%8E/?book=9

(بَلَقَ) الْبَاءُ وَاللَّامُ وَالْقَافُ أَصْلٌ وَاحِدٌ مُنْقَاسٌ مُطَّرِدٌ، وَهُوَ الْفَتْحُ. يُقَالُ أَبْلَقَ الْبَابَ وَبَلَقَهُ، إِذَا فَتَحَهُ كُلَّهُ. قَالَ:

وَالْحِصْنُ مُنْثَلِمٌ وَالْبَابُ مُنْبَلِقٌ

وَالْبَلَقُ الْفُسْطَاطُ، وَهُوَ مِنَ الْبَابِ. وَقَدْ يُسْتَبْعَدُ الْبَلَقُ فِي الْأَلْوَانِ، وَهُوَ قَرِيبٌ، وَذَلِكَ أَنَّ الْبَهِيمَ مُشْتَقٌّ مِنَ الْبَابِ الْمُبْهَمِ، فَإِذَا ابْيَضَّ بَعْضُهُ فَهُوَ كَالشَّيْءِ يُفْتَحُ.

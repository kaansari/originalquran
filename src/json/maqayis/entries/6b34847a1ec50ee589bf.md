# فَثَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AB%D9%8E%D8%A3%D9%8E/?book=9

(فَثَأَ) الْفَاءُ وَالثَّاءُ وَالْهَمْزَةُ يَدُلُّ عَلَى تَسْكِينِ شَيْءٍ يَغْلِي وَيَفُورُ. يُقَالُ: فَثَأْتُ الْقِدْرَ: سَكَّنْتُ مِنْ غَلَيَانِهَا. قَالَ:

وَنَفْثَؤُهَا عَنَّا إِذَا حَمْيُهَا غَلَا

وَيُقَالُ: عَدَا حَتَّى أَفْثَأَ، أَيْ أَعْيَا.

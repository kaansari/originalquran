# هَرَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B1%D9%8E%D8%A8%D9%8E/?book=9

(هَرَبَ) الْهَاءُ وَالرَّاءُ وَالْبَاءُ كَلِمَةٌ وَاحِدَةٌ، هِيَ هَرَبَ، إِذَا فَرَّ. وَمَا لَهُ هَارِبٌ وَلَا قَارِبٌ، أَيْ صَادِرٌ عَنِ الْمَاءِ وَلَا وَارِدٌ، أَيْ لَا شَيْءَ لَهُ.

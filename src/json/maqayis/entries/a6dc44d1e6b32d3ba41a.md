# سَعَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%B9%D9%8E%D9%86%D9%8E/?book=9

(سَعَنَ) السِّينُ وَالْعَيْنُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ. يَقُولُونَ مَالَهُ سَعْنَةٌ وَلَا مَعْنَةٌ، أَيْ مَا لَهُ قَلِيلٌ وَلَا كَثِيرٌ. وَيُقَالُ إِنْ كَانَ صَحِيحًا إِنَّ السُّعْنَ شَيْءٌ كَالدَّلْوِ.

# هَلَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%84%D9%8E%D9%81%D9%8E/?book=9

(هَلَفَ) الْهَاءُ وَاللَّامُ وَالْفَاءُ: كَلِمَاتٌ مُتَقَارِبَةُ الْقِيَاسِ تَدُلُّ عَلَى كِبَرٍ وَضِخَمٍ. وَالْهِلَّوْفُ: الشَّيْخُ الضَّخْمُ. وَاللِّحْيَةُ الضَّخْمَةُ هِلَّوْفَةٌ، وَالْجَمَلُ الْكَبِيرُ هِلَّوْفٌ.

# هَتَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%AA%D9%8E%D9%85%D9%8E/?book=9

(هَتَمَ) الْهَاءُ وَالتَّاءُ وَالْمِيمُ: كَلِمَةٌ تَدُلُّ عَلَى كَسْرِ شَيْءٍ. يُقَالُ: هَتَمْتُ الشَّيْءَ. وَالْهُتَامَةُ: مَا تَهَتَّمَ مِنْ شَيْءٍ. وَالْهَتْمُ: كَسْرُ الثَّنَايَا مِنْ أَصْلِهَا ; وَرَجُلٌ أَهْتَمُ.

# ذَرَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D8%B1%D9%8E%D9%81%D9%8E/?book=9

(ذَرَفَ) الذَّالُ وَالرَّاءُ وَالْفَاءُ ثَلَاثُ كَلِمَاتٍ، لَا يَنْقَاسُ. فَالْأُولَى ذَرَفَتِ الْعَيْنُ دَمْعَهَا. وَذَرَفَ الدَّمْعُ يَذْرِفُ ذَرْفًا. وَمَذَارِفُ الْعَيْنِ: مَدَامِعُهَا. وَالثَّانِيَةُ ذَرَفَ يَذْرِفُ ذَرَفَانًا، وَذَلِكَ إِذَا مَشَى مَشْيًا ضَعِيفًا. وَالثَّالِثَةُ ذَرَّفَ عَلَى الْمِائَةِ، أَيْ زَادَ عَلَيْهَا.

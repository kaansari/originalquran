# لَطَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B7%D9%8E%D8%AD%D9%8E/?book=9

(لَطَحَ) اللَّامُ وَالطَّاءُ وَالْحَاءُ كَلِمَةٌ وَاحِدَةٌ. اللَّطْحُ: الضَّرْبُ بِبَاطِنِ الْكَفِّ لَيْسَ بِالشَّدِيدِ. وَفِي الْحَدِيثِ عَنِ ابْنِ عَبَّاسٍ: " «فَجَعَلَ يَلْطَحُ أَفْخَاذَنَا وَيَقُولُ أُبَيْنِيَّ لَا تَرْمُوا جَمْرَةَ الْعَقَبَةِ حَتَّى تَطْلُعَ الشَّمْسُ» ".

# حَثَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%AB%D9%91%D9%8E/?book=9

(حَثَّ) الْحَاءُ وَالثَّاءُ أَصْلَانِ: أَحَدُهُمَا الْحَضُّ عَلَى الشَّيْءِ، وَالْآخَرُ يَبِيسٌ مِنْ يَبِيسِ الشَّيْءِ.

فَالْأَوَّلُ قَوْلُهُمْ: حَثَثْتُهُ عَلَى [الشَّيْءِ] أَحُثُّهُ. وَمِنْهُ الْحَثِيثُ ; يُقَالُ وَلَّى حَثِيثًا، أَيْ مُسْرِعًا. قَالَ سَلَامَةُ:

وَلَّى حَثِيثًا وَهَذَا الشَّيْبُ يَطْلُبُهُ ... لَوْ كَانَ يُدْرِكُهُ رَكْضُ الْيَعَاقِيبِ

وَمِنْهُ الْحَثْحَثَةُ، وَهُوَ اضْطِرَابُ الْبَرْقِ فِي السَّحَابِ.

وَأَمَّا الْآخَرُ فَالْحُثُّ وَهُوَ الْحُطَامُ الْيَبِيسُ، وَيُقَالُ الْحُثُّ الرَّمْلُ الْيَابِسُ الْخَشِنُ. قَالَ:

حَتَّى يُرَى فِي يَابِسِ الثَّرْيَاءِ حُثْ

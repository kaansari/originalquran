# سَكَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%83%D9%8E%D9%81%D9%8E/?book=9

(سَكَفَ) السِّينُ وَالْكَافُ وَالْفَاءُ لَيْسَ أَصْلًا، وَفِيهِ كَلِمَتَانِ: أَحَدُهُمَا أُسْكُفَّةُ الْبَابِ: الْعَتَبَةُ الَّتِي يُوطَأُ عَلَيْهَا. وَأُسْكُفُّ الْعَيْنِ، مُشَبَّهٌ بِأُسْكُفَّةِ الْبَابِ. وَأَمَّا الْإِسْكَافُ فَيُقَالُ إِنَّ كُلَّ صَانِعٍ إِسْكَافٌ عِنْدَ الْعَرَبِ. وَيُنْشَدُ قَوْلُ الشَّمَّاخِ:

وَشُعْبَتَا مَيْسٍ بَرَاهَا إِسْكَافْ

قَالُوا: أَرَادَ الْقَوَّاسَ.

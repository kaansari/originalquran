# شَخَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%AE%D9%8E%D8%B2%D9%8E/?book=9

(شَخَزَ) الشِّينُ وَالْخَاءُ وَالزَّاءُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى عَنَاءٍ وَأَذًى. قَالُوا: الشَّخْزُ: الْمَشَقَّةُ وَالْعَنَاءُ. قَالَ الرَّاجِزُ: إِذَا الْأُمُورُ أُولِعَتْ بِالشَّخْزِ

وَيُقَالُ: إِنَّ الشَّخْزَ الطَّعْنُ.

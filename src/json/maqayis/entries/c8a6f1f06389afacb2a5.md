# جَمَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%85%D9%8E%D9%86%D9%8E/?book=9

(جَمَنَ) الْجِيمُ وَالْمِيمُ وَالنُّونُ لَيْسَ فِيهِ غَيْرُ الْجُمَانِ، وَهُوَ الدَّرُّ. قَالَ الْمُسَيَّبُ:

كَجُمَانَةِ الْبَحْرِيِّ جَاءَ بِهَا غَوَّاصُهَا مِنْ لُجَّةِ الْبَحْرِ

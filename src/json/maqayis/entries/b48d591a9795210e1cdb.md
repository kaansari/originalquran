# قَضَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%B6%D9%8E%D9%81%D9%8E/?book=9

(قَضَفَ) الْقَافُ وَالضَّادُ وَالْفَاءُ أُصَيْلٌ يَدُلُّ عَلَى دِقَّةٍ وَلَطَافَةٍ. فَالْقَضَفُ: الدِّقَّةُ; يُقَالُ عُودٌ قَضِفٌ وَقَضِيفٌ. وَجَمْعُ قَضِيفٍ قِضَافٌ. وَمِنْهُ الْقَضَفَةُ، وَالْجَمْعُ قُِضْفَانٌ: قِطْعَةٌ مِنْ رَمْلٍ تَنْقَضِفُ مِنْ مُعْظَمِهِ، أَيْ تَنْكَسِرُ.

# مَكَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%83%D9%8E%D9%86%D9%8E/?book=9

(مَكَنَ) الْمِيمُ وَالْكَافُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ. الْمَكْنُ: بَيْضُ الضَّبِّ. وَضَبٌّ مَكُونٌ. [قَالَ] :

وَمَكْنُ الضِّبَابِ طَعَامُ الْعُرَيْبِ ... وَلَا تَشْتَهِيهِ نُفُوسُ الْعَجَمْ وَالْمُكُنَاتُ: أَوْكَارُ الطَّيْرِ، وَيُقَالُ مَكِنَاتٌ.

# وَفَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%81%D9%8E%D8%B1%D9%8E/?book=9

(وَفَرَ) الْوَاوُ وَالْفَاءُ وَالرَّاءُ: كَلِمَةٌ تَدُلُّ عَلَى كَثْرَةٍ وَتَمَامٍ. وَفَرَ الشَّيْءُ يَفِرُ، وَهُوَ مَوْفُورٌ، وَوَفَرَهُ اللَّهُ. وَمِنْهُ وَفْرَةُ الشَّعْرِ: دُونَ الْجُمَّةِ. وَاشْتِقَاقُ اسْمِ الْمَالِ الْوَفْرِ مِنْهُ. قَالَ: تَمَنَّيْتُ مِنْ حُبِّي بُثَيْنَةَ أَنَّنَا ... عَلَى رَمَثٍ فِي الشَّرْمِ لَيْسَ لَنَا وَفْرُ

وَالْوَفْرَاءُ: الْمَزَادَةُ لَمْ يُنْقَصْ مِنْ أَدِيمِهَا شَيْءٌ.

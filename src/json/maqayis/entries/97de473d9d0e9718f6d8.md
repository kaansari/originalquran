# قَتَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%AA%D9%91%D9%8E/?book=9

(قَتَّ) الْقَافُ وَالتَّاءُ فِيهِ كَلِمَتَانِ مُتَبَايِنَتَانِ، إِحْدَاهُمَا الْقَتُّ، وَهُوَ نَمُّ الْحَدِيثِ. وَجَاءَ فِي الْأَثَرِ: " «لَا يَدْخُلُ الْجَنَّةَ قَتَّاتٌ» "، وَهُوَ النَّمَّامُ. وَالْقَتُّ: نَبَاتٌ. وَالْقَتُّ وَالتَّقْتِيتُ: تَطْيِيبُ الدُّهْنِ بِالرَّيَاحِينِ.

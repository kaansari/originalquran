# نَهِلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%87%D9%90%D9%84%D9%8E/?book=9

(نَهِلَ) النُّونُ وَالْهَاءُ وَاللَّامُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى ضَرْبٍ مِنَ الشُّرْبِ. وَنَهِلَ: شَرِبَ فِي أَوَّلِ الْوِرْدِ. وَأَنْهَلْتُ الدَّوَابَّ. وَالْمَنْهَلُ: الْمَوْرِدُ. وَالنَّاهِلُ: الرَّيَّانُ. وَرُبَّمَا قَالُوا لِلْعَطْشَانِ نَاهِلٌ. وَهَذَا لَعَلَّهُ أَنْ يَكُونَ عَلَى مَعْنَى الْفَأْلِ. قَالَ:

يَنْهَلُ مِنْهُ الْأَسَلُ النَّاهِلُ

أَيْ تُرْوَى مِنْهُ الرِّمَاحُ الْعِطَاشُ.

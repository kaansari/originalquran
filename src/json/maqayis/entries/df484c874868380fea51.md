# رَعَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B9%D9%8E%D8%A8%D9%8E/?book=9

(رَعَبَ) الرَّاءُ وَالْعَيْنُ وَالْبَاءُ أُصُولٌ ثَلَاثَةٌ: أَحَدُهَا الْخَوْفُ، وَالثَّانِي الْمَلْءُ، وَالْآخَرُ الْقَطْعُ. فَالْأَوَّلُ الرَّعْبُ وَهُوَ الْخَوْفُ، رَعَبْتُهُ رَعْبًا، وَالِاسْمُ الرُّعْبُ. وَيُقَالُ إِنَّ الرَّعْبَ رُقْيَةٌ، يَزْعُمُونَ أَنَّهُمْ يُرْعِبُونَ ذَا السِّحْرِ بِكَلَامٍ، أَيْ يُفْزِعُونَهُ. وَفَاعِلُهُ رَاعِبٌ وَرَعَّابٌ.

وَالْأَصْلُ الْآخَرُ قَوْلُهُمْ: سَيْلٌ رَاعِبٌ، إِذَا مَلَأَ الْوَادِيَ. وَرَعَبْتُ الْحَوْضَ إِذَا مَلَأْتَهُ.

وَالثَّالِثُ قَوْلُهُمْ لِلشَّيْءِ الْمُقَطَّعِ: مُرَعَّبٌ. وَيُقَالُ لِلْقِطْعَةِ مِنَ السَّنَامِ رُعْبُوبَةٌ. وَتُسَمَّى الشَّطْبَةُ مِنَ النِّسَاءِ رُعْبُوبَةً; تَشْبِيهًا لَهَا بِقِطْعَةِ السَّنَامِ. وَيُقَالُ سَنَامٌ مَرْعُوبٌ إِذَا كَانَ يَقْطُرُ دَسَمًا.

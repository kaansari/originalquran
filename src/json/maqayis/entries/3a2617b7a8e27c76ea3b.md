# فَيَظَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D9%8A%D9%8E%D8%B8%D9%8E/?book=9

(فَيَظَ) الْفَاءُ وَالْيَاءُ وَالظَّاءُ كَلِمَةٌ. يُقَالُ: فَاظَ الْمَيِّتُ فَيْظًا، وَلَا يُقَالُ فَاظَتْ نَفْسُهُ. قَالَ:

لَا يَدْفِنُونَ مِنْهُمُ مَنْ فَاظَا

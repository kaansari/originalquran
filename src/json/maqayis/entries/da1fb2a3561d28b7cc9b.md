# هَبَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%A8%D9%8E%D8%B7%D9%8E/?book=9

(هَبَطَ) الْهَاءُ وَالْبَاءُ وَالطَّاءُ: كَلِمَةٌ تَدُلُّ عَلَى انْحِدَارٍ. وَهَبَططًا. وَالْهَبُوطُ: الْحُدُورُ. وَهَبَطْتُ أَنَا وَهَبَطْتُ غَيْرِي، وَهَبَطَ الْمَرَضُ لَحْمَ الْعَلِيلِ. وَالْهَبِيطُ: الضَّامِرُ مِنَ الْإِبِلِ.

# ذَأَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D8%A3%D9%8E%D9%89/?book=9

(ذَأَى) الذَّالُ وَالْهَمْزَةُ وَالْحَرْفُ الْمُعْتَلُّ يَدُلُّ عَلَى ضَرْبٍ مِنَ السَّيْرِ. يُقَالُ ذَأَى يَذْأَى ذَأْيًا. وَيُقَالُ الذَّأْوُ. السَّوْقُ الشَّدِيدُ.

# لَقَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%82%D9%8E%D8%A8%D9%8E/?book=9

(لَقَبَ) اللَّامُ وَالْقَافُ وَالْبَاءُ كَلِمَةٌ وَاحِدَةٌ. اللَّقَبُ: النَّبَزُ، وَاحِدٌ. وَلَقَّبْتُهُ تَلْقِيبًا قَالَ اللَّهُ تَعَالَى: {وَلَا تَنَابَزُوا بِالْأَلْقَابِ} [الحجرات: 11] .

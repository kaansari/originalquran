# لَكَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%83%D9%8E%D9%85%D9%8E/?book=9

(لَكَمَ) اللَّامُ وَالْكَافُ وَالْمِيمُ كَلِمَةٌ وَاحِدَةٌ، هِيَ اللَّكْمُ: الضَّرْبُ بِالْيَدِ مَجْمُوعَةً. قَالُوا: وَقِيَاسُهُ مِنَ الْخُفِّ الْمُلَكَّمِ، وَهُوَ الصُّلْبُ الشَّدِيدُ.

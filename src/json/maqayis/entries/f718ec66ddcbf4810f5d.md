# هُوَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8F%D9%88%D9%8E/?book=9

(هُوَ) الْهَاءُ وَالْوَاوُ لَيْسَتْ مِنْ شَرْطِ اللُّغَةِ، وَهِيَ مِنَ الْعَرَبِيَّةِ، وَالْأَصْلُ هَاءٌ ضُمَّتْ إِلَيْهِ وَاوٌ. مِنَ الْعَرَبِ مَنْ يُثَقِّلُهَا فَيَقُولُ: هُوَّ. وَمِنْهُمْ مَنْ يَقُولُ هُوْ.

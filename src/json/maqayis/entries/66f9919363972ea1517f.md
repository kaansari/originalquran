# أَيَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D9%8A%D9%8E%D9%87%D9%8E/?book=9

(أَيَهَ) وَأَمَّا الْهَمْزَةُ وَالْيَاءُ وَالْهَاءُ فَهُوَ حَرْفٌ وَاحِدٌ، يُقَالُ: أَيَّهَ تَأْيِيهًا: إِذَا صَوَّتَ. وَقَدْ قُلْنَا إِنَّ الْأَصْوَاتَ لَا يُقَاسُ عَلَيْهَا.

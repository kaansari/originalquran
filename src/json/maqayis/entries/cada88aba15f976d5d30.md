# قَذَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%B0%D9%8E%D9%84%D9%8E/?book=9

(قَذَلَ) الْقَافُ وَالذَّالُ وَاللَّامُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْقَذَلُ: جِمَاعُ مُؤَخَّرِ الرَّأْسِ. وَيُقَالُ: قَذَلْتُهُ: ضَرَبْتُ قَذَالَهُ. وَيَقُولُونَ: إِنَّ الْقَذْلَ: الْمَيْلُ وَالْجَوْرُ.

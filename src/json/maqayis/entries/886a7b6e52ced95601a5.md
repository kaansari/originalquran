# تَلَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D9%84%D9%8E%D9%81%D9%8E/?book=9

(تَلَفَ) التَّاءُ وَاللَّامُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ ذَهَابُ الشَّيْءِ. يُقَالُ تَلِفَ يَتْلَفُ تَلَفًا. وَأَرْضٌ مَتْلَفَةٌ، وَالْجَمْعُ مَتَالِفُ.

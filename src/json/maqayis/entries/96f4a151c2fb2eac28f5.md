# كَرَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D8%B1%D9%8E%D9%81%D9%8E/?book=9

(كَرَفَ) الْكَافُ وَالرَّاءُ وَالْفَاءُ كَلِمَتَانِ مُتَبَايِنَتَانِ جِدًّا، فَالْأُولَى الْكَرْفُ، وَهُوَ تَشَمُّمُ الْحِمَارِ الْبَوْلَ وَرَفْعُهُ رَأْسَهُ. وَالثَّانِيَةُ الْكِرْفِئُ: السَّحَابُ الْمُرْتَفِعُ الَّذِي يُرَى بَعْضُهُ فَوْقَ بَعْضٍ.

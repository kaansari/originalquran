# خَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%A3%D9%8E/?book=9

(خَأَ) الْخَاءُ وَالْهَمْزَةُ الْمَمْدُودَةُ لَيْسَتْ أَصْلًا يَنْقَاسُ، بَلْ ذُكِرَ فِيهِ حَرْفٌ وَاحِدٌ لَا يُعْرَفُ صِحَّتُهُ. قَالُوا: خَاءِبُكَ عَلَيْنَا، أَيِ اعْجَلْ. وَأَنْشَدُوا لِلْكُمَيْتِ:

بِخَاءِبِكَ الْحَقْ يَهْتِفُونَ وَحَيَّ هَلْ

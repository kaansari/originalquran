# خَذَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B0%D9%8E%D8%A7/?book=9

(خَذَا) الْخَاءُ وَالذَّالُ وَالْحَرْفُ الْمُعْتَلُّ وَالْمَهْمُوزُ يَدُلُّ عَلَى الضَّعْفِ وَاللِّينِ. يُقَالُ خَذَا الشَّيْءُ يَخْذُو خَذْوًا: اسْتَرْخَى. وَخَذِيَ يَخْذَى. وَيَنَمَةٌ خَذْوَاءُ: لَيِّنَةٌ، وَهِيَ بَقْلَةٌ. وَأُذُنٌ خَذْوَاءُ: مُسْتَرْخِيَةٌ. وَيُكْرَهُ مِنَ الْفَرَسِ الْخَذَا فِي الْأُذُنِ.

وَمِنَ الْبَابِ خَذِئْتُ وَخَذَأْتُ أَخْذَأُ، إِذَا خَضَعْتُ لَهُ خُذُوءًا وَخَذْءًا. وَيُقَالُ اسْتَخْذَيْتُ وَاسْتَخْذَأْتُ، لُغَتَانِ، وَهُمْ إِلَى تَرْكِ الْهَمْزِ فِيهَا أَمْيَلُ. وَقَدْ قَالَ كُثَيِّرٌ:

فَمَا زِلْتُمُ بِالنَّاسِ حَتَّى كَأَنَّهُمْ ... مِنَ الْخَوْفِ طَيْرٌ أَخْذَأَتْهَا الْأَجَادِلُ

فَهَمَزَ. يُقَالُ أَخْذَيْتُ فُلَانًا، أَيْ أَذْلَلْتُهُ.

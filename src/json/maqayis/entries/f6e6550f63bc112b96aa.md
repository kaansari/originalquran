# رَخَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%AE%D9%91%D9%8E/?book=9

(رَخَّ) الرَّاءُ وَالْخَاءُ قَلِيلٌ، إِلَّا أَنَّهُ يَدُلُّ عَلَى لِينٍ. يُقَالُ إِنَّ الرَّخَاخَ لِينُ الْعَيْشِ. وَأَرْضٌ رَخَّاءُ: رِخْوَةٌ. وَيُقَالُ - وَهُوَ مِمَّا يُنْظَرُ فِيهِ - إِنَّ الرَّخَّ مَزْجُ الشَّرَابِ.

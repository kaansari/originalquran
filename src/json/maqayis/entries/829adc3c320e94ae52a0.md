# فَطَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B7%D9%8E%D8%A3%D9%8E/?book=9

(فَطَأَ) الْفَاءُ وَالطَّاءُ وَالْهَمْزَةُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى تَطَامُنٍ. يُقَالُ لِلرَّجُلِ الْأالْأَفْطَأُ. وَيَقُولُونَ: فَطِئَ الْبَعِيرُ، إِذَا تَطَامَنَ ظَهْرُهُ خِلْقَةً.

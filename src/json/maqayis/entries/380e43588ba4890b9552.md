# زَعَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%B9%D9%91%D9%8E/?book=9

(زَعَّ) الزَّاءُ وَالْعَيْنُ أَصْلٌ يَدُلُّ عَلَى اهْتِزَازٍ وَحَرَكَةٍ. يُقَالُ: زَعْزَعْتُ الشَّيْءَ وَتَزَعْزَعَ هُوَ، إِذَا اهْتَزَّ وَاضْطَرَبَ. وَسَيْرٌ زَعْزَعٌ: شَدِيدٌ تَهْتَزُّ لَهُ الرِّكَابُ.

قَالَ الْهُذَلِيُّ:

وَتَرْمَدُّ هَمْلَجَةً زَعْزَعًا ... كَمَا انْخَرَطَ الْحَبْلُ فَوْقَ الْمَحَالِ

# خَرَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B1%D9%8E%D8%B2%D9%8E/?book=9

(خَرَزَ) الْخَاءُ وَالرَّاءُ وَالزَّاءُ يَدُلُّ عَلَى جَمْعِ الشَّيْءِ إِلَى الشَّيْءِ وَضَمِّهِ إِلَيْهِ. فَمِنْهُ خَرْزُ الْجِلْدِ. وَمِنْهُ الْخَرَزُ، وَهُوَ مَعْرُوفٌ، لِأَنَّهُ يُنْظَمُ وَيُنْضَدُ بَعْضُهُ إِلَى بَعْضٍ. وَفَقَارُ الظَّهْرِ خَرَزٌ لِانْتِظَامِهِ، وَخَرَزَاتُ الْمَلِكِ، كَانَ الْمَلِكُ مِنْهُمْ كُلَّمَا مَلَكَ عَامًا زِيدَتْ فِي تَاجِهِ خَرَزَةٌ ; لِيُعْلَمَ بِذَلِكَ عَدَدُ سِنِي مُلْكِهِ. قَالَ:

رَعَى خَرَزَاتِ الْمُلْكِ عِشْرِينَ حِجَّةً ... وَعِشْرِينَ حَتَّى فَادَ وَالشَّيْبُ شَامِلُ

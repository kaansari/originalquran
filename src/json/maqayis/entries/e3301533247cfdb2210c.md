# لَزِكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B2%D9%90%D9%83%D9%8E/?book=9

( [لَزِكَ) اللَّامُ وَالزَّاءُ وَالْكَافُ] لَيْسَ هُوَ عِنْدِي بِشَيْءٍ. عَلَى أَنَّهُمْ يَقُولُونَ: لَزِكَ الْجُرْحُ، إِذَا اسْتَوَى نَبَاتُ لَحْمِهِ وَلَمْ يَبْرَأْ. وَهَذَا لَا يُشْبِهُ كَلَامَ الْعَرَبِ.

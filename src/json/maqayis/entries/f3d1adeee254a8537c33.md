# وَعَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B9%D9%8E%D9%86%D9%8E/?book=9

(وَعَنَ) الْوَاوُ وَالْعَيْنُ وَالنُّونُ: لَيْسَ بِأَصْلٍ، لَكِنَّهُمْ يَقُولُونَ: الْوَعْنَةُ الْأَرْضُ الْبَيْضَاءُ. وَيَقُولُونَ: تَوَعَّنَتِ الْإِبِلُ: أَخَذَ فِيهَا السِّمَنُ.

# حَتَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%AA%D9%8E%D9%83%D9%8E/?book=9

(حَتَكَ) الْحَاءُ وَالتَّاءُ وَالْكَافُ يَدُلُّ عَلَى مُقَارَبَةٍ وَصِغَرٍ. فَالْحَتْكُ: أَنْ يُقَارِبَ الْخَطْوَ وَيُسْرِعَ رَفْعَ الرِّجْلِ وَوَضْعَهَا. وَهُوَ صَحِيحٌ مِنَ الْكَلَامِ مَعْرُوفٌ. وَيُبْنَى مِنْهُ الْحَتَكَانُ، وَهُوَ غَيْرُ الْحَيَكَانِ. وَالْحَوَاتِكُ: صِغَارُ النَّعَامِ. وَالْحَوْتَكُ: الْقَصِيرُ.

# وَدَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AF%D9%8E%D8%AC%D9%8E/?book=9

(وَدَجَ) الْوَاوُ وَالدَّالُ وَالْجِيمُ: كَلِمَةٌ وَاحِدَةٌ: الْوَدَجَانِ: عِرْقَانِ فِي الْأَخْدَعَيْنِ. ثُمَّ يُشَبَّهُ بِذَلِكَ، فَيُقَالُ لِلْأَخَوَيْنِ: وَدَجَانِ. قَالَ:

فَقُبِّحْتُمَا مِنْ وَافِدَيْنِ اصْطُفِيتُمَا ... وَمِنْ وَدَجَيْ حَرْبٍ تَلَقَّحُ حَائِلِ

وَوَدَجْتُ بَيْنَ الْقَوْمِ: أَصْلَحْتُ بَيْنَهُمْ، مَأْخُوذٌ مِنَ الْوَدَجَيْنِ، أَيِ اتَّفَقُوا كَاتِّفَاقِ الْوَدَجَيْنِ.

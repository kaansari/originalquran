# مَهَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%87%D9%8E%D9%86%D9%8E/?book=9

(مَهَنَ) الْمِيمُ وَالْهَاءُ وَالنُّونُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى احْتِقَارٍ وَحَقَارَةٍ فِي الشَّيْءِ. مِنْهُ قَوْلُهُمْ مَهِينٌ، أَيْ حَقِيرٌ. وَالْمَهَانَةُ: الْحَقَارَةُ، وَهُوَ مَهِينٌ بَيِّنُ الْمَهَانَةِ. وَمِنَ الْبَابِ الْمَهْنُ: الْخِدْمَةُ، وَالْمَِهْنَةُ. وَالْمَاهِنُ: الْخَادِمُ. وَمَهَنْتُ الثَّوْبَ: جَذَبْتُهُ وَثَوْبٌ مَمْهُونٌ. وَرُبَّمَا قَالُوا: مَهَنْتُ الْإِبِلَ: حَلْبَتُهَا.

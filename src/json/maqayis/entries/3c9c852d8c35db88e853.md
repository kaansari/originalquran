# ثَعَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%B9%D9%8E%D8%B1%D9%8E/?book=9

(ثَعَرَ) التَّاءُ وَالْعَيْنُ وَالرَّاءُ بِنَاءٌ إِنْ صَحَّ دَلَّ عَلَى قَمَاءَةٍ وَصِغَرٍ. فَالثُّعْرُورَانِ كَالْحَلَمَتَيْنِ تَكْتَنِفَانِ ضَرْعَ الشَّاةِ. وَعَلَى هَذَا قَالُوا لِلرَّجُلِ الْقَصِيرِ ثُعْرُورٌ.

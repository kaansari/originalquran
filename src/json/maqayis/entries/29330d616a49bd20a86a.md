# طَرَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%B1%D9%8E%D8%B2%D9%8E/?book=9

(طَرَزَ) الطَّاءُ وَالرَّاءُ وَالزَّاءُ كَلِمَةٌ يُظَنُّ أَنَّهَا فَارِسِيَّةٌ مُعَرَّبَةٌ، وَهِيَ فِي شِعْرِ حَسَّانَ:

بَيْضُ الْوُجُوهِ كَرِيمَةٌ أَحْسَابُهُمْ ... شُمُّ الْأُنُوفِ مِنَ الطِّرَازِ الْأَوَّلِ وَيَقُولُونَ: طِرْزُهُ، أَيْ هَيْئَتُهُ.

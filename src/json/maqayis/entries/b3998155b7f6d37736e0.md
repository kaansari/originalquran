# أَبَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%A8%D9%8E%D8%B4%D9%8E/?book=9

(أَبَشَ) الْهَمْزَةُ وَالْبَاءُ وَالشِّينُ لَيْسَ بِأَصْلٍ، لِأَنَّ الْهَمْزَةَ فِيهِ مُبْدَلَةٌ مِنْ هَاءٍ. قَالَ ابْنُ دُرَيْدٍ: أبَشْتُ الشَّيْءَ وَهَبَشْتُهُ: إِذَا جَمَعْتُهُ.

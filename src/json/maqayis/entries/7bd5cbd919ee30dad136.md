# غَصَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D8%B5%D9%8E%D9%86%D9%8E/?book=9

(غَصَنَ) الْغَيْنُ وَالصَّادُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ غُصْنُ الشَّجَرَةِ، وَالْجَمْعُ غُصُونٌ وَأَغْصَانٌ. وَيُقَالُ: غَصَنْتُ الْغُصْنَ: قَطَعْتُهُ.

# عَرَنْدَسٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%B1%D9%8E%D9%86%D9%92%D8%AF%D9%8E%D8%B3%D9%8C/?book=9

(عَرَنْدَسٌ) : شَدِيدٌ. كُلُّ مَا زَادَ فِيهِ عَلَى الْعَيْنِ وَالرَّاءِ وَالدَّالِ فَهُوَ زَائِدٌ، وَأَصْلُهُ عُرُدٌّ، وَهُوَ الشَّدِيدُ، وَقَدْ ذَكَرْنَاهُ.

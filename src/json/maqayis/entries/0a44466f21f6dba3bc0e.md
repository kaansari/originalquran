# نَبَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%A8%D9%8E%D8%AD%D9%8E/?book=9

(نَبَحَ) النُّونُ وَالْبَاءُ وَالْحَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ نُبَاحُ الْكَلْبِ وَنَبِيحُهُ. وَرُبَّمَا [قَالُوا] لِلظَّبْيِ نَبَحَ. قَالَ أَبُو دُوَادَ:

وَقُصْرَى شَنِجِ الْأَنْسَا ... ءِ نَبَّاحٍ مِنَ الشُّعْبِ

وَفِي الْحَدِيثِ: " اقْعُدْ مَنْبُوحًا "، أَيْ مَشْتُومًا.

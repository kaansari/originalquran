# فَأَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%A3%D9%8E%D8%B3%D9%8E/?book=9

(فَأَسَ) الْفَاءُ وَالْأَلِفُ وَالسِّينُ كَلِمَةٌ وَاحِدَةٌ، وَتُسْتَعَارُ. الْفَأْسُ مَعْرُوفَةٌ، وَالْعَدَدُ أَفْؤُسٌ، وَالْجَمْعُ فُؤُوسٌ. وَيُسْتَعَارُ فَيُقَالُ لِمُؤَخَّرِ الْقَمَحْدُوَةِ: فَأْسٌ. [وَفَأْسُ] اللِّجَامِ: الْحَدِيدَةُ الْقَائِمَةُ فِي الْحَنَكِ.

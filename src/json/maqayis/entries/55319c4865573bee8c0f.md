# عَوَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D9%88%D9%8E%D8%B3%D9%8E/?book=9

(عَوَسَ) الْعَيْنُ وَالْوَاوُ وَالسِّينُ كَلِمَةٌ قَدْ ذَكَرَهَا أَهْلُ اللُّغَةِ، وَقِيَاسُهَا قِيَاسٌ صَحِيحٌ بَعِيدٌ. قَالُوا: الْعَوَاسَاءُ: الْحَامِلُ مِنَ الْخَنَافِسِ، وَأَنْشَدُوا:

بِكْرًا عَوَاسَاءَ تَفَاسَى مُقْرِبًا

أَيْ دَنَا أَنْ تَضَعَ حَمْلَهَا. وَيَقُولُونَ: الْعَوَسَانُ وَالْعَوْسُ: الطَّوَفَانُ بِاللَّيْلِ. وَيَقُولُونَ أَيْضًا: الْأَعْوَسُ: الصَّيْقَلُ. وَالْأَعْوَسُ: الْوَصَّافُ لِلشَّيْءِ. وَكُلُّ هَذَا مِمَّا لَا يَكَادُ الْقَلْبُ يَسْكُنُ إِلَى صِحَّتِهِ.

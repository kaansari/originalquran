# غَثَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D8%AB%D9%8E%D9%85%D9%8E/?book=9

(غَثَمَ) الْغَيْنُ وَالثَّاءُ وَالْمِيمُ كَلِمَتَانِ مُتَبَايِنَتَانِ. فَالْأَغْثَمُ مِنَ الشَّعَرِ: مَا غَلَبَ بَيَاضُهُ سَوَادَهُ. قَالَ:

إِمَّا تَرَيْ دَهْرًا عَلَانِي أَغْثَمُهْ

وَالْكَلِمَةُ الْأُخْرَى: غَثَمْتُ لَهُ مِنْ مَالِي: أَعْطَيْتُهُ.

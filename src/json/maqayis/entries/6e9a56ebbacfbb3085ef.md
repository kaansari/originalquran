# مَيَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%8A%D9%8E%D8%AB%D9%8E/?book=9

(مَيَثَ) الْمِيمُ وَالْيَاءُ وَالثَّاءُ كَلِمَةٌ تَدُلُّ عَلَى سُهُولَةٍ فِي شَيْءٍ: يُقَالُ مِثْتُ الشَّيْءَ فِي الْمَاءِ مَيْثًا، إِذَا دُفْتُهُ، وَالْمَيْثَاءُ: الْأَرْضُ السَّهْلَةُ.

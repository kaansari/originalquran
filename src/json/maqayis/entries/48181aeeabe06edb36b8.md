# ثَوَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D9%88%D9%8E%D8%AE%D9%8E/?book=9

(ثَوَخَ) الثَّاءُ وَالْوَاوُ وَالْخَاءُ لَيْسَ أَصْلًا ; لِأَنَّ قَوْلَهُمْ ثَاخَتِ الْإِصْبَعُ إِنَّمَا هِيَ مُبْدَلَةٌ مِنْ سَاخَتْ ; وَرُبَّمَا قَالُوا بِالتَّاءِ: تَاخَتْ. وَالْأَصْلُ فِي ذَلِكَ كُلِّهِ الْوَاوُ. قَالَ أَبُو ذُؤَيْبٍ:

فَهْيَ تَثُوخُ فِيهَا الْإِصْبَعُ

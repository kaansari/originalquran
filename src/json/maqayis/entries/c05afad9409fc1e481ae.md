# خَوَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%88%D9%8E%D8%A8%D9%8E/?book=9

(خَوَبَ) الْخَاءُ وَالْوَاوُ وَالْبَاءُ أُصَيْلٌ يَدُلُّ عَلَى خُلُوٍّ وَشِبْهِهِ. يُقَالُ أَصَابَتْهُمْ خَوْبَةٌ، إِذَا ذَهَبَ مَا عِنْدَهُمْ وَلَمْ يَبْقَ شَيْءٌ. وَالْخَوْبَةُ: الْأَرْضُ لَا تُمْطَرُ بَيْنَ أَرَضَيْنِ قَدْ مُطِرَتَا ; وَهِيَ كَالْخَطِيطَةِ.

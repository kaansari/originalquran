# نَفَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%81%D9%8E%D8%B9%D9%8E/?book=9

(نَفَعَ) النُّونُ وَالْفَاءُ وَالْعَيْنُ: كَلِمَةٌ تَدُلُّ عَلَى خِلَافِ الضَّرِّ. وَنَفَعَهُ يَنْفَعُهُ نَفْعًا وَمَنْفَعَةً. وَانْتَفَعَ بِكَذَا. وَاللَّهُ أَعْلَمُ بِالصَّوَابِ.

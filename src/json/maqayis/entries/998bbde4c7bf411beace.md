# بَنَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%86%D9%8E%D9%82%D9%8E/?book=9

(بَنَقَ) الْبَاءُ وَالنُّونُ وَالْقَافُ كَلِمَةٌ وَاحِدَةٌ، وَأَرَاهَا مِنَ الْحَوَاشِي غَيْرَ وَاسِطَةٍ. وَهِيَ الْبَنِيقَةُ، وَهُوَ جُِرُِبَّانُ الْقَمِيصِ. وَيُقَالُ: الْبَنِيقَةُ كُلُّ رُقْعَةٍ فِي الثَّوْبِ كَاللَّبِنَةِ وَنَحْوِهَا. عَلَى أَنَّهَا قَدْ جَاءَتْ فِي الشِّعْرِ. قَالَ:

يَضُمُّ إِلَيَّ اللَّيْلُ أَطْفَالَ حُبِّهَا ... كَمَا ضَمَّ أَزْرَارَ الْقَمِيصِ الْبَنَائِقُ

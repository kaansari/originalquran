# خَبَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%A8%D9%8E%D8%A3%D9%8E/?book=9

(خَبَأَ) الْخَاءُ وَالْبَاءُ وَالْحَرْفُ الْمُعْتَلُّ وَالْهَمْزَةُ يَدُلُّ عَلَى سَتْرِ الشَّيْءِ. فَمِنْ ذَلِكَ خَبَأْتُ الشَّيْءَ أَخْبَؤُهُ خَبْأً. وَالْخُبَأَةُ: الْجَارِيَةُ تُخْبَأُ. وَمِنَ الْبَابِ الْخِبَاءُ ; تَقُولُ أَخْبَيْتُ إِخْبَاءً، وَخَبَّيْتُ، وَتَخَبَّيْتُ، كُلُّ ذَلِكَ إِذَا اتَّخَذْتَ خِبَاءً.

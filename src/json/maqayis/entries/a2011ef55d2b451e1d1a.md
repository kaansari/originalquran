# نَعَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B9%D9%8E%D8%A8%D9%8E/?book=9

(نَعَبَ) النُّونُ وَالْعَيْنُ وَالْبَاءُ: أَصْلَانِ صَحِيحَانِ: أَحَدُهُمَا يَدُلُّ عَلَى صَوْتٍ، وَالْآخَرُ عَلَى حَرَكَةٍ مِنَ الْحَرَكَاتِ.

فَالْأَوَّلُ نَعَبَ الْغُرَابُ: صَوَّتَ، نَعْبًا وَنَعِيبًا وَنَعَبَانًا. وَالْآخَرُ فَرَسٌ مِنْعَبٌ: جَوَادٌ. وَنَاقَةٌ نَعَّابَةٌ: سَرِيعَةٌ. وَيُقَالُ: النَّعْبُ: أَنْ تُحَرِّكَ رَأْسَهَا فِي مَشْيِهَا إِلَى قُدَّامِهَا. وَهِيَ نَاقَةٌ نَعُوبٌ.

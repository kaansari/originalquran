# دَكَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%83%D9%8E%D8%B3%D9%8E/?book=9

(دَكَسَ) الدَّالُ وَالْكَافُ وَالسِّينُ أُصَيْلٌ يَدُلُّ عَلَى غِشْيَانِ الشَّيْءِ بِالشَّيْءِ. قَالَ ابْنُ الْأَعْرَابِيِّ. الدُّكَاسُ: مَا يَغْشَى الْإِنْسَانَ مِنَ النُّعَاسِ. قَالَ:

كَأَنَّهُ مِنَ الْكَرَى الدُّكَاسِ ... بَاتَ بِكَأْسَيْ قَهْوَةٍ يُحَاسِي

وَيُقَالُ: الدَّوْكَسُ: الْعَدَدُ الْكَثِيرُ. وَقَالَ: الدَّكَسُ: تَرَاكُبُ الشَّيْءِ بَعْضِهِ عَلَى بَعْضٍ. وَذُكِرَ عَنِ الْخَلِيلِ أَنَّ الدَّوْكَسَ الْأَسَدَ، فَإِنْ كَانَ صَحِيحًا فَهُوَ مِنَ الْبَابِ; لِجُرْأَتِهِ، وَغِشْيَانِهِ الْأَهْوَالَ.

# غَبَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D8%A8%D9%8E%D9%82%D9%8E/?book=9

(غَبَقَ) الْغَيْنُ وَالْبَاءُ وَالْقَافُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْغَبُوقُ: شُرْبُ الْعَشِيِّ. يُقَالُ: غَبَقْتُ الْقَوْمَ غَبْقًا، وَاغْتَبَقَ اغْتِبَاقًا.

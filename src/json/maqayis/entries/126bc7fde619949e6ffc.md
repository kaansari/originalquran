# رَذَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B0%D9%8E%D8%A7/?book=9

(رَذَا) الرَّاءُ وَالذَّالُ وَالْحَرْفُ الْمُعْتَلُّ يَدُلُّ عَلَى ضَعْفٍ وَهُزَالٍ. فَالرَّذِيَّةُ: النَّاقَةُ الْمَهْزُولَةُ مِنَ السَّيْرِ، وَالْجَمْعُ رَذَايَا. قَالَ أَبُو دُوَادٍ:

رَذَايَا كَالْبَلَايَا أَوْ ... كَعِيدَانٍ مِنَ الْقَضْبِ

يُقَالُ مِنْهُ: أَرْذَيْتُهَا.

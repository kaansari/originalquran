# تَجَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%AC%D9%8E%D8%B1%D9%8E/?book=9

(تَجَرَ) التَّاءُ وَالْجِيمُ وَالرَّاءُ، التِّجَارَةُ مَعْرُوفَةٌ. وَيُقَالُ تَاجِرٌ وَتَجْرٌ، كَمَا يُقَالُ صَاحِبٌ وَصَحْبٌ. وَلَا تَكَادُ تُرَى تَاءٌ بَعْدَهَا جِيمٌ.

# كَوَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%88%D9%8E%D8%AF%D9%8E/?book=9

(كَوَدَ) الْكَافُ وَالْوَاوُ وَالدَّالُ كَلِمَةٌ كَأَنَّهَا تَدُلُّ عَلَى الْتِمَاسِ شَيْءٍ بِبَعْضِ الْعَنَاءِ. يَقُولُونَ: كَادَ يَكُودُ كَوْدًا وَمَكَادًا. وَيَقُولُونَ لِمَنْ يَطْلُبُ مِنْكَ الشَّيْءَ فَلَا تُرِيدُ إِعْطَاءَهُ: لَا وَلَا مَكَادَةَ. فَأَمَّا قَوْلُهُمْ فِي الْمُقَارَبَةِ: كَادَ، فَمَعْنَاهَا قَارَبَ. وَإِذَا وَقَعَتْ كَادَ مُجَرَّدَةً فَلَمْ يَقَعْ ذَلِكَ الشَّيْءُ تَقُولُ: كَادَ يَفْعَلُ، فَهَذَا لَمْ يُفْعَلْ، وَإِذَا قُرِنَتْ بِجَحْدٍ فَقَدْ وَقَعَ، إِذَا قُلْتَ مَا كَادَ يَفْعَلُهُ فَقَدْ فَعَلَهُ. قَالَ اللَّهُ سُبْحَانَهُ: {فَذَبَحُوهَا وَمَا كَادُوا يَفْعَلُونَ} [البقرة: 71] .

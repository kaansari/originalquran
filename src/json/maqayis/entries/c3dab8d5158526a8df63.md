# سَبَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%A8%D9%8E%D9%87%D9%8E/?book=9

(سَبَهَ) السِّينُ وَالْبَاءُ وَالْهَاءُ كَلِمَةٌ، وَهِيَ تَدُلُّ عَلَى ضَعْفِ الْعَقْلِ أَوْ ذَهَابِهِ. فَالسَّبَهُ: ذَهَابُ الْعَقْلِ مِنْ هَرَمٍ، يُقَالُ رَجُلٌ مَسْبُوهٌ وَمُسَبَّهٌ، وَهُوَ قَرِيبٌ مِنَ الْمَسْبُوتِ، وَالْقِيَاسُ فِيهِمَا وَاحِدٌ.

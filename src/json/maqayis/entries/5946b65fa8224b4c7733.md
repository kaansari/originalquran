# فَصَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B5%D9%8E%D8%B9%D9%8E/?book=9

(فَصَعَ) الْفَاءُ وَالصَّادُ وَالْعَيْنُ يَدُلُّ عَلَى خُرُوجِ شَيْءٍ عَنْ شَيْءٍ. يُقَالُ: فَصَعَ الرُّطَبَةَ، إِذَا قَشَرَهَا. وَيَقُولُونَ: الْفُصْعَةُ: غُلْفَةُ الصَّبِيِّ إِذَا اتَّسَعَتْ حَتَّى تَبْدُوَ حَشَفَتُهُ.

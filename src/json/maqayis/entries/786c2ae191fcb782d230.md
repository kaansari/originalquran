# نَقَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%82%D9%8E%D8%AB%D9%8E/?book=9

(نَقَثَ) النُّونُ وَالْقَافُ وَالثَّاءُ كَلِمَةٌ صَحِيحَةٌ تَدُلُّ عَلَى خَلْطِ شَيْءٍ بِشَيْءٍ وَنَقْلِهِ. وَنَقَثَ مَا فِي مَنْزِلِي أَجْمَعَ: نَقَلَهُ كُلَّهُ. وَنَقَّثُوا حَدِيثَهُمْ: خَلَطُوهُ، كَمَا يُنَقَّثُ الطَّعَامُ. وَخَرَجَ يُنَقِّثُ: يُسْرِعُ فِي نَقْلِ قَوَائِمِهِ. وَنَقَثْتُ الْعَظْمَ أَنْقُثُهُ: اسْتَخْرَجْتُ مَا فِيهِ مِنَ الْمُخِّ.

# مَغَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%BA%D9%8E%D8%B5%D9%8E/?book=9

(مَغَصَ) الْمِيمُ وَالْغَيْنُ وَالصَّادُ كَلِمَتَانِ مُتَبَايِنَتَانِ جِدًّا. فَالْأُولَى الْمَغَْصُ: تَقْطِيعٌ فِي الْمِعَى وَوَجَعٌ. وَالْأُخْرَى الْمَغَْصُ يُقَالُ هُوَ الْخِيَارُ مِنَ الْإِبِلِ. قَالَ: أَنْتَ وَهَبْتَ هَجْمَةً جُرْجُورَا ... أُدْمًا وَحُمْرًا مَغَصًا خُبُورًا

قَالَ ابْنُ دُرَيْدٍ: إِبِلٌ أَمْغَاصٌ وَأَمْعَاصٌ، وَهِيَ خِيَارُ الْإِبِلِ، لَا وَاحِدَ لَهَا وَيُقَالُ فُلَانٌ مَغِصٌ، إِذَا كَانَ ثَقِيلًا بَغِيضًا ; وَهُوَ مِنَ الْأَوَّلِ.

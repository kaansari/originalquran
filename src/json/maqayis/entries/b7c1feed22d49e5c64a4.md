# حَوَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%88%D9%8E%D8%AC%D9%8E/?book=9

(حَوَجَ) الْحَاءُ وَالْوَاوُ وَالْجِيمُ أَصْلٌ وَاحِدٌ، وَهُوَ الِاضْطِرَارُ إِلَى الشَّيْءِ، فَالْحَاجَةُ وَاحِدَةُ الْحَاجَاتِ. وَالْحَوْجَاءُ: الْحَاجَةُ. وَيُقَالُ أَحْوَجَ الرَّجُلُ: احْتَاجَ. وَيُقَالُ أَيْضًا: حَاجَ يَحُوجُ، بِمَعْنَى احْتَاجَ. قَالَ:

غَنِيتُ فَلَمْ أَرْدُدْكُمُ عِنْدَ بُغْيَةٍ ... وَحُجْتُ فَلَمْ أَكْدُدْكُمُ بِالْأَصَابِعِ

فَأَمَّا الْحَاجُ فَضَرْبٌ مِنَ الشَّوْكِ، وَهُوَ شَاذٌّ عَنِ الْأَصْلِ.

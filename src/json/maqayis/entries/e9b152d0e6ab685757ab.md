# فَعَيَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B9%D9%8E%D9%8A%D9%8E/?book=9

(فَعَيَ) الْفَاءُ وَالْعَيْنُ وَالْحَرْفُ الْمُعْتَلُّ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْأَفْعَى: حَيَّةٌ وَحَكَى نَاسٌ: تَفَعَّى الرَّجُلُ، إِذَا سَاءَ خُلُقُهُ، مُشْتَقٌّ مِنَ الْأَفْعَى. وَاللَّهُ أَعْلَمُ.

# سَكَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%83%D9%8E%D8%A8%D9%8E/?book=9

(سَكَبَ) السِّينُ وَالْكَافُ وَالْبَاءُ أَصْلٌ يَدُلُّ عَلَى صَبِّ الشَّيْءِ. تَقُولُ: سَكَبَ الْمَاءَ يَسْكُبُهُ. وَفَرَسٌ سَكْبٌ، أَيْ ذَرِيعٌ، كَأَنَّهُ يَسْكُبُ عَدْوَهُ سَكْبًا، وَذَلِكَ كَتَسْمِيَتِهِمْ إِيَّاهُ بَحْرًا.

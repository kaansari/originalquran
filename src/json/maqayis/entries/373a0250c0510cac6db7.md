# فَنَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D9%86%D9%8E%D8%B9%D9%8E/?book=9

(فَنَعَ) الْفَاءُ وَالنُّونُ وَالْعَيْنُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى طِيبٍ وَكَثْرَةٍ وَكَرَمٍ. فَالْفَنَعُ: الْكَرَمُ. وَيُقَالُ إِنَّ نَشْرَ الْمِسْكِ فَنَعٌ. وَيُقَالُ نَشْرُ الثَّنَاءِ الْحَسَنِ. وَيُقَالُ مَالٌ ذُو فَنَعٍ، أَيْ كَثْرَةٍ. قَالَ:

وَقَدْ أَجُودُ وَمَا مَالِي بِذِي فَنَعٍ ... عَلَى الصِّدِّيقِ وَمَا خَيْرِي بِمَمْنُونِ

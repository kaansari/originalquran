# صَمَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%85%D9%8E%D8%AE%D9%8E/?book=9

(صَمَخَ) الصَّادُ وَالْمِيمُ وَالْخَاءُ أَصْلٌ وَاحِدٌ وَكَلِمَةٌ وَاحِدَةٌ، وَهُوَ الصِّمَاخُ: خَرْقُ الْأُذُنِ. يُقَالُ: صَمَخْتُهُ، إِذَا ضَرَبْتَ صِمَاخَهُ.

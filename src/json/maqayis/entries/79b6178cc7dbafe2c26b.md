# قَتَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%AA%D9%8E%D8%AF%D9%8E/?book=9

(قَتَدَ) الْقَافُ وَالتَّاءُ وَالدَّالُ أَصْلٌ صَحِيحٌ، وَهُوَ كَلِمَتَانِ: الْقَتَدُ: خَشَبُ الرَّحْلِ، وَجَمْعُهُ أَقْتَادٌ وَقُتُودٌ. وَالْكَلِمَةُ الْأُخْرَى الْقَتَادُ: ضَرْبٌ مِنَ الْعِضَاهِ لَيْسَ فِيهِ غَيْرُ هَذَا. وَيَقُولُونَ: قَتَائِدُ: مَكَانٌ.

# حَوْأَبُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%88%D9%92%D8%A3%D9%8E%D8%A8%D9%8F/?book=9

(الْحَوْأَبُ) : الْوَادِي الْوَاسِعُ الْعَرْضِ، وَالْحَاءُ فِيهِ زَائِدَةٌ، وَإِنَّمَا الْأَصْلُ الْوَأْبُ، وَالْوَأْبُ الْوَاسِعُ الْمُقَعَّرُ مِنْ كُلِّ شَيْءٍ.

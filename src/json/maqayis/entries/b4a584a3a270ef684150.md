# مُحَصْرَمٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8F%D8%AD%D9%8E%D8%B5%D9%92%D8%B1%D9%8E%D9%85%D9%8C/?book=9

رَجُلٌ (مُحَصْرَمٌ) : قَلِيلُ الْخَيْرِ. وَالْأَصْلُ أَنَّ الْمِيمَ زَائِدَةٌ، وَإِنَّمَا هُوَ مِنَ الْحَصُورِ وَالْحَصِرِ. وَمِنْ هَذَا الْبَابِ (الْحِصْرِمُ)

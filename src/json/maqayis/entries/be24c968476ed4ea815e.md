# الْعَلْهَبُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D9%84%D9%92%D9%87%D9%8E%D8%A8%D9%8F/?book=9

(الْعَلْهَبُ) : التَّيْسُ الطَّوِيلُ الْقَرْنَيْنِ، وَيُوصَفُ بِهِ الثَّوْرُ. قَالَ جَرِيرٌ:

إِذَا قَعِسَتْ ظُهُورُ بَنِي تَمِيمٍ ... تَكَشَّفَ عَنْ عَلَاهِبَةِ الْوُعُولِ وَهَذَا مِمَّا زِيدَتْ فِيهِ الْهَاءُ، وَإِنَّمَا هُوَ مِنَ الْعُلَبِ. وَالْعُلَبُ: النَخْلُ الطُّوَالُ. وَقَدْ مَرَّ.

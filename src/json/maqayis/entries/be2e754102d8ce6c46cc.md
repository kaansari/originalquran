# ثَنَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D9%86%D9%8E%D8%AA%D9%8E/?book=9

(ثَنَتَ) الثَّاءُ وَالنُّونُ وَالتَّاءُ كَلِمَةٌ وَاحِدَةٌ. ثَنِتَ اللَّحْمُ تَغَيَّرَتْ رَائِحَتُهُ. وَقَدْ يَقُولُونَ ثَتِنَ. قَالَ:

وَثَتِنَتْ لِثَاتُهُ دِرْحَايَهْ

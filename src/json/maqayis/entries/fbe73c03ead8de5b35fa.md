# مَعَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B9%D9%8E%D9%84%D9%8E/?book=9

(مَعَلَ) الْمِيمُ وَالْعَيْنُ وَاللَّامُ أَصْلٌ صَحِيحٌ فِيهِ كَلِمَاتٌ تَدُلُّ عَلَى اخْتِلَاسِ شَيْءٍ وَسُرْعَةٍ فِيهِ. وَمَعَلَ الشَّيْءَ: اخْتَلَسَهُ. ثُمَّ يَقُولُونَ: مَعَلَ خُصْيَتَيِ الْفَحْلِ: اسْتَلَّهُمَا. وَمَعَلَ: سَارَ سَيْرًا سَرِيعًا.

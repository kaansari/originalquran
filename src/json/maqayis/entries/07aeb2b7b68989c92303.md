# زَرِبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%B1%D9%90%D8%A8%D9%8E/?book=9

(زَرِبَ) الزَّاءُ وَالرَّاءُ وَالْبَاءُ أَصْلٌ يَدُلُّ عَلَى بَعْضِ الْمَأْوَى. فَالزَّرْبُ زَرْبُ الْغَنَمِ، وَهِيَ حَظِيرَتُهَا. وَيُقَالُ الزَّرِيبَةُ الزُّبْيَةُ. وَالزَّرِيبَةُ: قُتْرَةُ الصَّائِدِ.

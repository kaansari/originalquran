# جَبَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%A8%D9%8E%D8%B2%D9%8E/?book=9

(جَبَزَ) الْجِيمُ وَالْبَاءُ وَالزَّاءُ لَيْسَ عِنْدِي أَصْلًا، وَإِنْ كَانُوا يَقُولُونَ: الْجَبِيزُ الْخُبْزُ الْيَابِسُ. وَفِيهِ نَظَرٌ. وَقَالَ قَوْمٌ: الْجِبْزُ اللَّئِيمُ. فَإِنْ كَانَ صَحِيحًا فَالزَّاءُ مُبْدَلَةٌ مِنْ سِينٍ.

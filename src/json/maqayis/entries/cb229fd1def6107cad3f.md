# مَدَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AF%D9%8E%D8%B4%D9%8E/?book=9

(مَدَشَ) الْمِيمُ وَالدَّالُ وَالشِّينُ. يَقُولُونَ مَدْشَاءُ: لَا لَحْمَ عَلَى يَدَيْهَا. وَقَالَ أَبُو بَكْرٍ: مَدِشَتْ عَيْنُهُ: أَظْلَمَتْ، وَالرَّجُلُ مَدِشٌ.

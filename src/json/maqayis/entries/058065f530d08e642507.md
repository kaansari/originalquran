# حَمِقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%85%D9%90%D9%82%D9%8E/?book=9

(حَمِقَ) الْحَاءُ وَالْمِيمُ وَالْقَافُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى كَسَادِ الشَّيْءِ. وَالضَّعْفِ وَالنُّقْصَانِ. فَالْحُمْقُ: نُقْصَانُ الْعَقْلِ. وَالْعَرَبُ تَقُولُ: انْحَمَقَ الثَّوْبُ. إِذَا بَلِيَ. وَانْحَمَقَتِ السُّوقُ: كَسَدَتْ.

# حَلَتْ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%84%D9%8E%D8%AA%D9%92/?book=9

(حَلَتْ) الْحَاءُ وَاللَّامُ وَالتَّاءُ لَيْسَ عِنْدِي بِأَصْلٍ صَحِيحٍ. وَقَدْ جَاءَتْ فِيهِ كَلِيمَاتٍ ; فَالْحِلْتِيتُ صَمْغٌ. يُقَالُ حَلَتَ دَيْنَهُ: قَضَاهُ; وَحَلَتَ فُلَانًا، إِذَا أَعْطَاهُ، وَحَلَتَ الصُّوفَ: مَرَقَهُ.

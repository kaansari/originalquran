# خَذَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B0%D9%8E%D9%84%D9%8E/?book=9

(خَذَلَ) الْخَاءُ وَالذَّالُ وَاللَّامُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى تَرْكِ الشَّيْءِ وَالْقُعُودِ عَنْهُ. فَالْخِذْلَانُ: تَرْكُ الْمَعُونَةِ. وَيُقَالُ خَذَلَتِ الْوَحْشِيَّةُ: أَقَامَتْ عَلَى وَلَدِهَا ; وَهِيَ خَذُولٌ. قَالَ:

خَذُولٌ تُرَاعِي رَبْرَبًا بِخَمِيلَةٍ ... تَنَاوَلُ أَطْرَافَ الْبَرِيرِ وَتَرْتَدِي

وَمِنَ الْبَابِ تَخَاذَلَتْ رِجْلَاهُ: ضَعُفَتَا. مِنْ قَوْلِهِ: وَخَذُولِ الرِّجْلِ مِنْ غَيْرِ كَسَحْ

وَقَالَ آخَرُ:

صَرْعَى نَوْؤُهَا مُتَخَاذِلُ

وَرَجُلٌ خُذَلَةٌ، لِلَّذِي لَا يَزَالُ يَخْذُلُ.

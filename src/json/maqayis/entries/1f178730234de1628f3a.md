# قَهَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D9%87%D9%91%D9%8E/?book=9

(قَهَّ) الْقَافُ وَالْهَاءُ لَيْسَ فِيهِ إِلَّا حِكَايَةُ الْقَهْقَهَةِ: الْإِغْرَابُ فِي الضَّحِكِ. يُقَالُ: قَهٌّ وَقَهْقَهَةٌ، وَقَدْ يُخَفَّفُ. قَالَ:

فَهُنَّ فِي تَهَانُفٍ وَفِي قَهِ

وَيَقُولُونَ: الْقَهْقَهَةُ: قُرْبُ الْوِرْدِ.

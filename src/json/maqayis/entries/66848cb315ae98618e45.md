# طَخَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%AE%D9%8E%D9%81%D9%8E/?book=9

(طَخَفَ) الطَّاءُ وَالْخَاءُ وَالْفَاءُ أُصَيْلٌ يَدُلُّ عَلَى الشَّيْءِ الرَّقِيقِ. مِنْ ذَلِكَ الطَّخَافُ، وَهُوَ الْغَيْمُ الرَّقِيقُ. وَالطَّخْفُ كَالْهَمِّ يَغْشَى الْقَلْبَ.

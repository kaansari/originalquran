# طَوَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D9%88%D9%8E%D8%A8%D9%8E/?book=9

(طَوَبَ) الطَّاءُ وَالْوَاوُ وَالْبَاءُ لَيْسَ بِأَصْلٍ ; لِأَنَّ الطُّوبَ - فِيمَا أَحْسَبُ - هَذَا الَّذِي يُسَمَّى الْآجُرَّ، وَمَا أَظُنُّ الْعَرَبَ تَعْرِفُهُ. وَأَمَّا طُوبَى فَلَيْسَ مِنْ هَذَا، وَأَصْلُهُ الْيَاءُ، كَأَنَّهَا فُعْلَى مِنَ الطِّيبِ، فَقُلِبَتِ الْيَاءُ وَاوًا لِلضَّمَّةِ.

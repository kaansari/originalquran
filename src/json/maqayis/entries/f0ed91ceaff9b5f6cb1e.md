# خَرَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B1%D9%8E%D8%AB%D9%8E/?book=9

(خَرَثَ) الْخَاءُ وَالرَّاءُ وَالثَّاءُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ أَسَقَّاطُ الشَّيْءِ. يُقَالُ لِأَسْقَاطِ أَثَاثِ الْبَيْتِ خُرْثِيٌّ. قَالَ:

وَعَادَ كُلُّ أَثَاثِ الْبَيْتِ خُرْثِيًّا

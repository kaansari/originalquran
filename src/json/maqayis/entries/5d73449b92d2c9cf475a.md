# فَغَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%BA%D9%91%D9%8E/?book=9

(فَغَّ) الْفَاءُ وَالْغَيْنُ لَيْسَ فِيهِ كَلَامٌ أَصِيلٌ، وَهُوَ شِبْهُ حِكَايَةٍ لِصَوْتٍ. يَقُولُونَ: الْفَغْفَغَةُ: الصَّوْتُ بِالْغَنَمِ. وَيَقُولُونَ: الْفَغْفَغَانِيُّ: الْقَصَّابُ أَوِ الرَّاعِي ; وَكَذَلِكَ الْفَغْفَغِيُّ. وَيَقُولُ: الْفَغْفَغَانُ: الرَّجُلُ الْخَفِيفُ. وَتَفَغْفَغَ فِي أَمْرِهِ: أَسْرَعَ. وَكُلُّ هَذَا قَرِيبٌ بَعْضُهُ مِنْ بَعْضٍ. وَاللَّهُ أَعْلَمُ بِالصَّوَابِ.

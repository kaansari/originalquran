# وَدَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AF%D9%8E%D8%B3%D9%8E/?book=9

(وَدَسَ) الْوَاوُ وَالدَّالُ وَالسِّينُ: كَلِمَتَانِ:

الْأُولَى الْوَدِيسُ: النَّبَاتُ، يُقَالُ أَوْدَسَتِ الْأَرْضُ: أَخْرَجَتْ نَبْتَهَا.

وَالْأُخْرَى: وَدَسَ الشَّيْءَ: خَبَّأَهُ. وَمَا أَدْرِي أَيْنَ وَدَسَ، أَيْ ذَهَبَ.

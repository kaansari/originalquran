# شَبَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%A8%D9%8E%D9%83%D9%8E/?book=9

(شَبَكَ) الشِّينُ وَالْبَاءُ وَالْكَافُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى تَدَاخُلِ الشَّيْءِ. يُقَالُ شَبَّكَ أَصَابِعَهُ تَشْبِيكًا. وَيُقَالُ: بَيْنَ الْقَوْمِ شُبْكَةُ نَسَبٍ، أَيْ مُدَاخَلَةٌ. وَمِنْ ذَلِكَ الشَّبَكَةُ.

# حَبَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%A8%D9%8E%D9%82%D9%8E/?book=9

(حَبَقَ) الْحَاءُ وَالْبَاءُ وَالْقَافُ لَيْسَ عِنْدِي بِأَصْلٍ يُؤْخَذُ بِهِ وَلَا مَعْنَى لَهُ. لَكِنَّهُمْ يَقُولُونَ حَبَّقَ مَتَاعَهُ، إِذَا جَمَعَهُ. وَلَا أَدْرِي كَيْفَ صِحَّتُهُ.

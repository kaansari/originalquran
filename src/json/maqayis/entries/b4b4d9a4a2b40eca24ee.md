# ذَلَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D9%84%D9%8E%D9%81%D9%8E/?book=9

(ذَلَفَ) الذَّالُ وَاللَّامُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ لَا يُقَاسُ عَلَيْهَا، وَهِيَ الذَّلَفُ: اسْتِوَاءٌ فِي طَرَفِ الْأَنْفِ لَيْسَ بِحَدٍّ غَلِيظٍ، وَهُوَ أَحْسَنُ الْأُنُوفِ.

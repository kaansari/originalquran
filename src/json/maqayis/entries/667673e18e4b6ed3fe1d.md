# هَذَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B0%D9%8E%D9%85%D9%8E/?book=9

(هَذَمَ) الْهَاءُ وَالذَّالُ وَالْمِيمُ: كَلِمَةٌ صَحِيحَةٌ، تَدُلُّ عَلَى قَطْعٍ لِشَيْءٍ. وَهَذْمُ السَّيْفِ: قَطْعُهُ. وَسَيْفٌ مِهْذَمٌ وَهُذَامٌ وَهَيْذَامٌ. وَيُسَمَّى الشُّجَاعُ هَيْذَامًا، تَشْبِيهًا لَهُ بِهَذَا السَّيْفِ.

# لَتَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AA%D9%8E%D8%A8%D9%8E/?book=9

(لَتَبَ) اللَّامُ وَالتَّاءُ وَالْبَاءُ كَلِمَةٌ تَدُلُّ عَلَى مُلَازَمَةٍ وَمُخَالَطَةٍ. يَقُولُونَ: لَتَبَ ثَوْبَهُ: لَبِسَهُ. وَاللَّاتِبُ: الْمُلَازِمُ لِلشَّيْءِ لَا يُفَارِقُهُ. وَيَقُولُونَ: لَتَبَ فِي سَبَلَةِ النَّاقَةِ، إِذَا وَجَأَ.

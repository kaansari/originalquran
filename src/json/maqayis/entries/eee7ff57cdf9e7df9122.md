# وَعَظَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B9%D9%8E%D8%B8%D9%8E/?book=9

(وَعَظَ) الْوَاوُ وَالْعَيْنُ وَالظَّاءُ: كَلِمَةٌ وَاحِدَةٌ. فَالْوَعْظُ: التَّخْوِيفُ. وَالْعِظَةُ الِاسْمُ مِنْهُ ; قَالَ الْخَلِيلُ: هُوَ التَّذْكِيرُ بِالْخَيْرِ وَمَا يَرِقُّ لَهُ قَلْبُهُ.

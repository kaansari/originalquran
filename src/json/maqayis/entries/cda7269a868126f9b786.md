# رَشَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B4%D9%8E%D8%AF%D9%8E/?book=9

(رَشَدَ) الرَّاءُ وَالشِّينُ وَالدَّالُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى اسْتِقَامَةِ الطَّرِيقِ. فَالْمَرَاشِدُ: مَقَاصِدُ الطُّرُقِ. وَالرُّشْدُ وَالرَّشَدُ: خِلَافُ الْغَيِّ. وَأَصَابَ فُلَانٌ مِنْ أَمْرِهِ رُشْدًا وَرَشَدًا وَرِشْدَةً. وَهُوَ لِرَِشْدَةٍ خِلَافٌ لِغَِيَّةٍ.

# هَوَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%88%D9%8E%D8%A8%D9%8E/?book=9

(هَوَبَ) الْهَاءُ وَالْوَاوُ وَالْبَاءُ: لَيْسَ بِأَصْلٍ جَيِّدٍ، لَكِنَّهُمْ يَقُولُونَ: الْهَوْبُ: الْمُخَلِّطُ. وَحَكَى ابْنُ دُرَيْدٍ فِي طَرَائِفِهِ أَصَابَنِي هَوْبُ النَّارِ: وَهَجُهَا.

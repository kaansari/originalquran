# هَزَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B2%D9%8E%D9%82%D9%8E/?book=9

(هَزَقَ) الْهَاءُ وَالزَّاءُ وَالْقَافُ، كَلِمَاتٌ فِي قِيَاسٍ وَاحِدٍ. امْرَأَةٌ هِزْقَةٌ: لَا تَسْتَقِرُّ. وَكَذَلِكَ الْمِهْزَاقُ. وَالْهَزِقُ: الرَّعْدُ. وَأَهْزَقَ الرَّجُلُ: ضَحِكَ. وَحِمَارٌ هَزِقٌ: كَثِيرُ الِاسْتِنَانِ.

# بَرَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B1%D9%8E%D8%B4%D9%8E/?book=9

(بَرَشَ) الْبَاءُ وَالرَّاءُ وَالشِّينُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ أَنْ يَكُونَ الشَّيْءُ ذَا نُقَطٍ مُتَفَرِّقَةٍ بِيضٍ. وَكَانَ جَذِيمَةُ أَبْرَصَ، فَكُنِّيَ بِالْأَبْرَشِ.

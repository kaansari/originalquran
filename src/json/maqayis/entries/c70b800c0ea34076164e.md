# ذَمَّهُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D9%85%D9%91%D9%8E%D9%87%D9%8F/?book=9

(ذَمَّهُ) الذَّالُ وَالْمِيمُ وَالْهَاءُ لَيْسَ أَصْلًا، وَلَا مِنْهُ مَا يَصِحُّ ; إِلَّا أَنَّهُمْ يَقُولُونَ ذَمِهَ، إِذَا تَحَيَّرَ; وَيُقَالُ ذَمَهَتْهُ الشَّمْسُ: آلَمَتْ دِمَاغَهُ.

وَاللَّهُ أَعْلَمُ.

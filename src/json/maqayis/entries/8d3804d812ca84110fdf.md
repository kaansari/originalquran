# فَرِهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B1%D9%90%D9%87%D9%8E/?book=9

(فَرِهَ) الْفَاءُ وَالرَّاءُ وَالْهَاءُ كَلِمَةٌ تَدُلُّ عَلَى أَشَرٍ وَحِذْقٍ. مِنْ ذَلِكَ الْفَارِهُ الْحَاذِقُ بِالشَّيْءِ. وَالْفَرِهُ: الْأَشِرُ. وَالْفَارِهَةُ: الْقَيْنَةُ. وَنَاقَةٌ مُفْرِهٌ وَمُفْرِهَةٌ، إِذَا كَانَتْ تُنْتِجُ الْفُرْهَ.

# تَوَيَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D9%88%D9%8E%D9%8A%D9%8E/?book=9

(تَوَيَ) التَّاءُ وَالْوَاوُ وَالْيَاءُ كَلِمَةٌ وَاحِدَةٌ. وَهُوَ بُطْلَانُ الشَّيْءِ. يُقَالُ تَوِيَ يَتْوَى تَوًى وَتَوَاءً. قَالَ:

وَكَانَ لِأُمِّهِمْ صَارَ التَّوَاءُ

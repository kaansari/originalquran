# قَذَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%B0%D9%8E%D9%85%D9%8E/?book=9

(قَذَمَ) الْقَافُ وَالذَّالُ وَالْمِيمُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى سَعَةٍ وَكَثْرَةٍ. مِنْ ذَلِكَ الْقَذْمُ: الْعَطَاءُ الْكَثِيرُ، يُقَالُ قَذَمَ لَهُ. وَمِنَ الْبَابِ الْقِذَمُّ: الْفَرَسُ السَّرِيعُ. وَرَجُلٌ قُذَمٌ: كَثِيرُ الْأَخْذِ مِنَ الشَّيْءِ إِذَا تَمَكَّنَ مِنْهُ.

# حُلْقُومُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8F%D9%84%D9%92%D9%82%D9%8F%D9%88%D9%85%D9%8F/?book=9

(الْحُلْقُومُ) وَلَيْسَ ذَلِكَ مَنْحُوتًا وَلَكِنَّهُ مِمَّا زِيدَتْ فِيهِ الْمِيمُ، وَالْأَصْلُ الْحَلْقُ، وَقَدْ مَرَّ. وَالْحَلْقَمَةُ: قَطْعُ الْحُلْقُومِ.

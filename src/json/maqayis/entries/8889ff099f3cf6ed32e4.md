# وَعَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B9%D9%8E%D8%B1%D9%8E/?book=9

(وَعَرَ) الْوَاوُ وَالْعَيْنُ وَالرَّاءُ: كَلِمَةٌ تَدُلُّ عَلَى صَلَابَةٍ وَخُشُونَةٍ. وَمَكَانٌ وَعْرٌ بَيِّنُ الْوُعُورَةِ، وَوَعِرَ يَوْعُرُ وَتَوَعَّرَ. وَفُلَانٌ وَعْرُ الْمَعْرُوفِ: نَكِدُهُ. وَسَأَلْنَاهُ حَاجَةً فَتَوَعَّرَ عَلَيْنَا، أَيْ تَشَدَّدَ.

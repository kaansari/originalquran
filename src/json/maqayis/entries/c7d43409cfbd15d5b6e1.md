# وَضَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B6%D9%8E%D8%B1%D9%8E/?book=9

( [وَضَرَ) الْوَاوُ وَالضَّادُ وَالرَّاءُ] : كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى لَطْخِ شَيْءٍ بِشَيْءٍ. فَالْوَضَرُ مِثْلُ الدَّرَنِ وَالزَّهَمِ. قَالَ:

أَبَارِيقُ لَمْ يَعْلَقْ بِهَا وَضَرُ الزُّبْدِ

قَالَ أَبُو عُبَيْدَةَ: يُقَالُ لِبَقِيَّةِ الشَّيْءِ عَلَى الشَّيْءِ: الْوَضَرُ، كَبَقِيَّةِ الْهِنَاءِ عَلَى الْبَعِيرِ.

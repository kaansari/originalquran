# نَوَضَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%88%D9%8E%D8%B6%D9%8E/?book=9

(نَوَضَ) النُّونُ وَالْوَاوُ وَالضَّادُ فِيهِ كَلِمَاتٌ مُتَبَايِنَةٌ.

الْأُولَى النَّوْضُ: وُصْلَةٌ مَا بَيْنَ الْعَجُزِ وَالْمَتْنِ. وَالثَّانِيَةُ قَوْلُهُمْ: نَاضَ فِي الْبِلَادِ: ذَهَبَ. وَالثَّالِثَةُ الْأَنْوَاضُ: الْأَوْدِيَةُ، وَاحِدُهَا نَوْضٌ.

# أَسَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%B3%D9%91%D9%8E/?book=9

(أَسَّ) الْهَمْزَةُ وَالسِّينُ يَدُلُّ عَلَى الْأَصْلِ وَالشَّيْءِ الْوَطِيدِ الثَّابِتِ، فَالْأُسلُ الْبِنَاءِ، وَجَمْعُهُ آسَاسٌ، وَيُقَالُ لِلْوَاحِدِ: أَسَاسٌ، بِقَصْرِ الْأَلِفِ، وَالْجَمْعُ أُسُسٌ. قَالُوا: الْأُسُّ أَصْلُ الرَّجُلِ، وَالْأُسُّ وَجْهُ الدَّهْرِ، وَيَقُولُونَ: كَانَ ذَلِكَ عَلَى أُسِّ الدَّهْرِ. قَالَ الْكَذَّابُ الْحِرْمَازِيُّ:

وَأُسُّ مَجْدٍ ثَابِتٌ وَطِيدُ ... نَالَ السَّمَاءَ فَرْعُهُ الْمَدِيدُ

فَأَمَّا الْآسُ فَلَيْسَ هَذَا بَابَهُ، وَقَدْ ذُكِرَ فِي مَوْضِعِهِ.

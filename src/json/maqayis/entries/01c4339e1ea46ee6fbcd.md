# كَمَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%85%D9%8E%D8%AA%D9%8E/?book=9

(كَمَتَ) الْكَافُ وَالْمِيمُ وَالتَّاءُ كَلِمَةٌ صَحِيحَةٌ تَدُلُّ عَلَى لَوْنٍ مِنَ الْأَلْوَانِ مِنْ ذَلِكَ الْكُمْتَةِ، وَهِيَ لَوْنٌ لَيْسَ بِأَشْقَرَ وَلَا أَدْهَمَ. يُقَالُ: فَرَسٌ كُمَيْتٌ. وَلَمْ يَجِئْ إِلَّا كَذَا عَلَى صُورَةِ الْمُصَغَّرِ. وَالْكُمَيْتُ: الْخَمْرُ فِيهَا سَوَادٌ وَحُمْرَةٌ.

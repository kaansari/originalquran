# دَبَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%A8%D9%8E%D8%B4%D9%8E/?book=9

(دَبَشَ) الدَّالُ وَالْبَاءُ وَالشِّينُ لَيْسَ بِشَيْءٍ. عَلَى أَنَّهُمْ يَقُولُونَ أَرْضٌ مَدْبُوشَةٌ: أَكَلَ الْجَرَادُ نَبْتَهَا. قَالَ:

فِي مُهْوَأَنٍّ بالدَِّبَا مَدْبُوشِ

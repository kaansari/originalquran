# سَأَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%A3%D9%8E%D8%A8%D9%8E/?book=9

(سَأَبَ) السِّينُ وَالْهَمْزَةُ وَالْبَاءُ لَيْسَ أَصْلًا يَتَفَرَّعُ، لَكِنَّهُمْ يَقُولُونَ سَأَبَهُ سَأْبًا، إِذَا خَنَقَهُ. وَالسَّأْبُ: السِّقَاءُ، وَكَذَلِكَ الْمِسْأَبُ.

فَأَمَّا التَّاءُ فَيَقُولُونَ أَيْضًا سَأَتَهُ إِذَا خَنَقَهُ. وَفِي جَمِيعِ ذَلِكَ نَظَرٌ.

# سَيُدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%8A%D9%8F%D8%AF%D9%8E/?book=9

(سَيُدَ) السِّينُ وَالْيَاءُ وَالدَّالُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ السِّيدُ. قَالَ قَوْمٌ: السِّيدُ الذِّئْبُ. وَقَالَ آخَرُونَ: وَقَدْ يُسَمَّى الْأَسَدُ سِيدًا. وَيُنْشِدُونَ:

كَالسِّيدِ ذِي اللِّبْدَةِ الْمُسْتَأْسِدِ الضَّارِي

# طَمَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D9%85%D9%8E%D8%B3%D9%8E/?book=9

(طَمَسَ) الطَّاءُ وَالْمِيمُ وَالسِّينُ أَصْلٌ يَدُلُّ عَلَى مَحْوِ الشَّيْءِ وَمَسْحِهِ. يُقَالُ: طَمَسْتُ الْخَطَّ، وَطَمَسْتُ الْأَثَرَ. وَالشَّيْءُ طَامِسٌ أَيْضًا. وَقَدْ طَمَسَ هُوَ بِنَفْسِهِ.

# رَخَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%AE%D9%8E%D9%84%D9%8E/?book=9

(رَخَلَ) الرَّاءُ وَالْخَاءُ وَاللَّامُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الرَّخِلُ: الْأُنْثَى مِنْ أَوْلَادِ الضَّأْنِ، وَالذَّكَرُ حَمَلٌ، وَيُجْمَعُ الرَّخِلُ رِخَالًا.

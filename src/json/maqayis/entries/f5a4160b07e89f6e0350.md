# مَرَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B1%D9%8E%D8%B4%D9%8E/?book=9

(مَرَشَ) الْمِيمُ وَالرَّاءُ وَالشِّينُ. يَقُولُونَ: الْمَرْشُ: خَرْقُ الْجِلْدِ بِأَطْرَافِ الْأَظَافِيرِ. وَالْمَرْشُ أَيْضًا: الْخَدْشُ الْخَفِيفُ. وَالْمَرْشُ: الْأَرْضُ تَسِيلُ مِنْ أَدْنَى مَطَرٍ.

# وَثَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AB%D9%8E%D8%B1%D9%8E/?book=9

(وَثَرَ) الْوَاوُ وَالثَّاءُ وَالرَّاءُ: كَلِمَةٌ تَدُلُّ عَلَى وَطَاءَةٍ فِي شَيْءٍ. وَفِرَاشٌ وَثْرٌ وَوَثِيرٌ: وَطِيٌّ. وَالْمَيَاثِرُ: ثِيَابٌ حُمْرٌ تَكُونُ فِي مَرَاكِبِ الْأَعَاجِمِ. وَقَوْلُهُمْ: وَثَرَ الْجَمَلُ النَّاقَةَ: ضَرَبَهَا، كَأَنَّهَا لَهُ فِرَاشٌ وَثِيرٌ.

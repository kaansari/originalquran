# ضَبَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D8%A8%D9%8E%D8%AB%D9%8E/?book=9

(ضَبَثَ) الضَّادُ وَالْبَاءُ وَالثَّاءُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى قَبْضٍ. يُقَالُ: ضَبَثَ إِذَا قَبَضَ عَلَى الشَّيْءِ. وَيُقَالُ: نَاقَةٌ ضَبُوثٌ: يُشَكُّ فِي سِمَنِهَا، فَتُضْبَثُ بِالْأَيْدِي. وَيَقُولُونَ: ضُبِثَ، أَيْ ضُرِبَ. وَهُوَ قَرِيبٌ مِمَّا ذَكَرْنَاهُ.

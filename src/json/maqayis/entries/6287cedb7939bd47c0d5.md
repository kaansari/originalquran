# وَفَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%81%D9%8E%D8%B2%D9%8E/?book=9

(وَفَزَ) الْوَاوُ وَالْفَاءُ وَالزَّاءُ: كَلِمَةٌ تَدُلُّ عَلَى عَجَلَةٍ وَقِلَّةِ اسْتِقْرَارٍ. وَأَنَا عَلَى وَفْزٍ وَأَوْفَازٍ، أَيْ عَجَلَةٍ. قَالَ الشَّيْبَانِيُّ: هُوَ عَلَى أَوْفَازٍ، وَلَمْ يُقَلْ مِنْهُ وَاحِدٌ. وَالْوَفَزُ: النَّشْزُ مِنَ الْأَرْضِ. وَكَذَلِكَ يُقَالُ: جَلَسَ مُسْتَوْفِزًا، كَأَنَّهُ غَيْرُ مُسْتَقِرٍّ.

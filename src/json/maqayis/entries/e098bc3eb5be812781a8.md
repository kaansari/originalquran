# وَكَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%83%D9%8E%D8%B3%D9%8E/?book=9

(وَكَسَ) الْوَاوُ وَالْكَافُ وَالسِّينُ: كَلِمَةٌ تَدُلُّ عَلَى نَقْصٍ وَخُسْرَانٍ. فَالْوَكْسُ: النَّقْصُ. وَكَسْتُهُ: نَقَصْتُهُ. وَوُكِسَ الرَّجُلُ وَأُوكِسَ: خَسِرَ. وَبَرَأَتِ الشَّجَّةُ عَلَى وَكْسٍ، إِذَا لَمْ يَتِمَّ بُرْؤُهَا.

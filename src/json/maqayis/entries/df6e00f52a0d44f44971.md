# الْعِفْضَاجُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%90%D9%81%D9%92%D8%B6%D9%8E%D8%A7%D8%AC%D9%8F/?book=9

(الْعِفْضَاجُ) : السَّمِينُ الرِّخْوُ. وَهَذَا مِمَّا زِيدَتْ فِيهِ الضَّادُ، وَهُوَ مِنَ الْعَيْنِ وَالْفَاءِ وَالْجِيمِ، كَأَنَّهُ مُمْتَلِئُ الْأَعْفَاجِ، وَهِيَ الْأَمْعَاءُ.

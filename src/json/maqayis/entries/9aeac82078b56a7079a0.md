# فَسِرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B3%D9%90%D8%B1%D9%8E/?book=9

(فَسِرَ) الْفَاءُ وَالسِّينُ وَالرَّاءُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى بَيَانِ شَيْءٍ وَإِيضَاحِهِ. مِنْ ذَلِكَ الْفَسْرُ، يُقَالُ: فَسَرْتُ الشَّيْءَ وَفَسَّرْتُهُ. وَالْفَسْرُ وَالتَّفْسِرَةُ: نَظَرُ الطَّبِيبِ إِلَى الْمَاءِ وَحُكْمُهُ فِيهِ. وَاللَّهُ أَعْلَمُ بِالصَّوَابِ.

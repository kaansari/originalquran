# نَجَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%AC%D9%8E%D8%AE%D9%8E/?book=9

(نَجَخَ) النُّونُ وَالْجِيمُ وَالْخَاءُ كَلِمَةٌ تَدُلُّ عَلَى حِكَايَةِ صَوْتٍ. يُقَالُ: سَمِعْتُ نَجِيخَ الْمَاءِ وَنَاجِخَتَهُ: صَوْتَهُ. وَالنُّجَاخُ: صَوْتُ السَّاعِلِ. وَمَنْجِخٌ: مَوْضِعٌ.

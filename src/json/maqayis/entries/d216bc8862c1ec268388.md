# تَأَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%A3%D9%8E%D8%B1%D9%8E/?book=9

(تَأَرَ) التَّاءُ وَالْهَمْزَةُ وَالرَّاءُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ أَتْأَرْتُ عَلَيْهِ النَّظَرَ إِذَا حَدَدْتُهُ. قَالَ:

مَازِلْتُ أَنْظُرُهُمْ وَالْآلُ يَرْفَعُهُمْ ... حَتَّى اسْمَدَرَّ بِطَرْفِ الْعَيْنِ إِتْآرِي

فَأَمَّا قَوْلُهُمْ (اتَّأَبَ) إِذَا اسْتَحْيَا، فَلَهُ فِي كِتَابِ الْوَاوِ مَوْضِعٌ غَيْرُ هَذَا.

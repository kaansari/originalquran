# هَسَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B3%D9%91%D9%8E/?book=9

(هَسَّ) الْهَاءُ وَالسِّينُ: أُصَيْلٌ يَدُلُّ عَلَى أَصْوَاتٍ وَاخْتِلَاطٍ، كَالْهَسِيسِ. وَهَسَاهِسُ الْجِنِّ مِثْلُ هَثَاهِثِهِمْ. وَقَوْلُهُمْ: رَاعٍ هَسْهَاسٌ، مِنْ بَابِ الْإِبْدَالِ، مِثْلُ قَسْقَاسٌ، إِذَا رَعَى الْغَنَمَ اللَّيْلَ كُلَّهُ.

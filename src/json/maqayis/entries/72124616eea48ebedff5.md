# فَذَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B0%D9%8E%D8%AD%D9%8E/?book=9

(فَذَحَ) الْفَاءُ وَالذَّالُ وَالْحَاءُ. ذَكَرَ ابْنُ دُرَيْدٍ: تَفَذَّحَتِ النَّاقَةُ وَانْفَذَحَتْ، إِذَا تَفَاجَّتْ لِتَبُولَ. وَاللَّهُ أَعْلَمُ بِالصَّوَابِ.

# وَبَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%A8%D9%8E%D8%AF%D9%8E/?book=9

(وَبَدَ) الْوَاوُ وَالْبَاءُ وَالدَّالُ كَلِمَةٌ تَدُلُّ عَلَى سُوءِ حَالٍ. يُقَالُ: أَرْضٌ وَبِدَةٌ، إِذَا سَاءَتْ حَالُ أَهْلِهَا. وَيَقُولُونَ: الْوَبْدُ: نُقْرَةٌ فِي صَخْرَةٍ. وَرَجُلٌ مُسْتَوْبِدُ الْمَكَانِ: جَاهِلٌ بِهِ.

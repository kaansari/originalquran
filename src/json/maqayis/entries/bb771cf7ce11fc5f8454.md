# زَفَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%81%D9%8E%D9%86%D9%8E/?book=9

(زَفَنَ) الزَّاءُ وَالْفَاءُ وَالنُّونُ لَيْسَ عِنْدِي أَصْلًا، وَلَا فِيهِ مَا يُحْتَاجُ إِلَيْهِ. يَقُولُونَ: الزَّفْنُ: الرَّقْصُ. وَيَقُولُونَ: الزِّيَفْنُ: الشَّدِيدُ. وَلَيْسَ هَذَا بِشَيْءٍ.

# صَيَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%8A%D9%91%D9%8E/?book=9

(صَيَّ) الصَّادُ وَالْيَاءُ كَلِمَةٌ وَاحِدَةٌ مُطَابَقَةٌ، وَهِيَ كُلُّ شَيْءٍ يُتَحَصَّنُ بِهِ. مِنْ ذَلِكَ تَسْمِيَتُهُمُ الْحُصُونَ صَيَاصِيَ، ثُمَّ شُبِّهَ بِذَلِكَ مَا يُحَارِبُ وَيَتَحَصَّنُ بِهِ الدِّيكُ [وَسُمِّيَ] صِيصِيَةً، وَكَذَلِكَ قَرْنُ الثَّوْرِ يُسَمَّى بِذَلِكَ ; لِأَنَّهُ يَتَحَصَّنُ وَيُحَارِبُ بِهِ.

# دَرَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%B1%D9%8E%D8%AF%D9%8E/?book=9

(دَرَدَ) الدَّالُ وَالرَّاءُ وَالدَّالُ أُصَيْلٌ فِيهِ كَلَامٌ يَسِيرٌ. فَالدَّرَدُ مِنَ الْأَسْنَانِ: لُصُوقُهَا بِالْأَسْنَاخِ وَتَأْكُلُ مَا فَضَلَ مِنْهَا. وَقَدْ دَرِدَتْ وَهِيَ دُرْدٌ. وَرَجُلٌ أَدْرَدُ وَامْرَأَةٌ دَرْدَاءُ.

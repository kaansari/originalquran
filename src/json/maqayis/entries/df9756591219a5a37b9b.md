# نَحَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%AD%D9%8E%D8%B5%D9%8E/?book=9

(نَحَصَ) النُّونُ وَالْحَاءُ وَالصَّادُ كَلِمَةٌ وَاحِدَةٌ، هِيَ النَّحُوصُ: الْأَتَانُ الْحَائِلُ فِي شِعْرِ امْرِئِ الْقَيْسِ. قَالَ:

أَرَنَّ عَلَيْهِ قَارِبًا وَانْتَحَتْ لَهُ ... طُوَالَةُ أَرْسَاغِ الْيَدَيْنِ نَحُوصُ.

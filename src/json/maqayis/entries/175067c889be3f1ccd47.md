# ثَلَغَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D9%84%D9%8E%D8%BA%D9%8E/?book=9

(ثَلَغَ) الثَّاءُ وَاللَّامُ وَالْغَيْنُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ شَدْخُ الشَّيْءِ. يُقَالُ ثَلَغْتُ رَأْسَهُ أَيْ شَدَخْتُهُ. وَيَقُولُونَ لِمَا سَقَطَ مِنَ الرُّطَبِ فَانْشَدَخَ مُثَلَّغٌ.

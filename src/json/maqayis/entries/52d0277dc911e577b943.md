# ضَوَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D9%88%D9%8E%D8%A8%D9%8E/?book=9

(ضَوَبَ) الضَّادُ وَالْوَاوُ وَالْبَاءُ شَيْءٌ يُقَالُ مَا أَدْرِي مَا صِحَّتُهُ. الضُّوبَانُ: الْجَمَلُ الْقَوِيُّ، وَيُقَالُ: بَلِ الضُّوبَانُ كَاهِلُ الْبَعِيرِ.

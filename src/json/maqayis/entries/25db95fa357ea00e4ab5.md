# زَأَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%A3%D9%8E%D9%85%D9%8E/?book=9

(زَأَمَ) الزَّاءُ وَالْهَمْزَةُ وَالْمِيمُ أَصْلٌ يَدُلُّ عَلَى صَوْتٍ وَكَلَامٍ. فَالزَّأْمَةُ: الصَّوْتُ الشَّدِيدُ. وَيُقَالُ زَأَمَ لِي فُلَانٌ زَأْمَةً، إِذَا طَرَحَ لِي كَلِمَةً لَا أَدْرِي أَحَقٌّ هِيَ أَمْ بَاطِلٌ.

وَمِمَّا يُحْمَلُ عَلَيْهِ الزَّأَمُ: الذُّعْرُ. وَيُقَالُ أَزْأَمْتُهُ عَلَى كَذَا، أَيْ أَكْرَهْتُهُ.

وَمِمَّا شَذَّ عَنِ الْبَابِ الزَّأْمُ: شِدَّةُ الْأَكْلِ. وَاللَّهُ أَعْلَمُ.

# فَتَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AA%D9%8E%D9%83%D9%8E/?book=9

(فَتَكَ) الْفَاءُ وَالتَّاءُ وَالْكَافُ كَلِمَةٌ تَدُلُّ عَلَى خِلَافِ النُّسُكِ وَالصَّلَاحِ. مِنْ ذَلِكَ الْفَتْكُ، وَهُوَ الْغَدْرُ، وَهُوَ الْفِتْكُ أَيْضًا. يُقَالُ: فَتَكَ بِهِ: اغْتَالَهُ. وَفِي الْحَدِيثِ: «الْإِيمَانُ قَيْدُ الْفَتْكِ ".» وَقَالَ الشَّاعِرُ: لَا مَهْرَ أَغْلَى مِنْ عَلِيٍّ وَإِنْ غَلَا ... وَلَا فَتْكَ إِلَّا دُونَ فَتْكِ ابْنِ مُلْجِمِ

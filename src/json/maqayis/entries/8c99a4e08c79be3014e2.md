# حَوَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%88%D9%8E%D8%B7%D9%8E/?book=9

(حَوَطَ) الْحَاءُ وَالْوَاوُ وَالطَّاءُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ الشَّيْءُ يُطِيفُ بِالشَّيْءِ. فَالْحَوْطُ مِنْ حَاطَهُ حَوْطًا. وَالْحِمَارُ يَحُوطُ عَانَتَهُ: يَجْمَعُهَا. وَحَوَّطْتُ حَائِطًا. وَيُقَالُ إِنَّ الْحُوَاطَةَ حَظِيرَةٌ تُتَّخَذُ لِلطَّعَامِ. وَالْحَوْطُ: شَيْءٌ مُسْتَدِيرٌ تُعَلِّقُهُ الْمَرْأَةُ عَلَى جَبِينِهَا، مِنْ فِضَّةٍ.

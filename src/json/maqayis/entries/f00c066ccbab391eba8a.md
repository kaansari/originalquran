# هَذَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B0%D9%8E%D9%84%D9%8E/?book=9

(هَذَلَ) الْهَاءُ وَالذَّالُ وَاللَّامُ: أُصَيْلٌ يَدُلُّ عَلَى صِغَرٍ وَخِفَّةٍ وَسُرْعَةٍ. مِنْهُ الْهُذْلُولُ: الرَّجُلُ الْخَفِيفُ. وَهَوْذَلَ الرَّجُلُ: مَشَى بِسُرْعَةٍ. وَهَوْذَلَ السِّقَاءُ: تَمَخَّضَ.

وَمِنَ الْبَابِ: الْهَذَالِيلُ: تِلَالٌ صِغَارٌ، الْوَاحِدُ هُذْلُولٌ، سُمِّيَتْ بِهَا لِصِغَرِهَا. وَمِنْ بَعْضِ هَذَا قِيَاسُ اسْمِ هُذَيْلٍ.

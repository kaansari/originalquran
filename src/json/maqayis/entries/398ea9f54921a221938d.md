# خَسَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B3%D9%8E%D9%82%D9%8E/?book=9

(خَسَقَ) الْخَاءُ وَالسِّينُ وَالْقَافُ لَيْسَ أَصْلًا ; لِأَنَّ السِّينَ فِيهِ مُبْدَلَةٌ مِنَ الزَّاءِ، وَإِنَّمَا يُغَيَّرُ اللَّفْظُ لِيُغَيَّرَ بَعْضُ الْمَعْنَى. فَالْخَازِقُ مِنَ السِّهَامِ: الَّذِي يَرْتَزُّ إِذَا أَصَابَ الْهَدَفَ. وَالْخَاسِقُ: الَّذِي يَتَعَلَّقُ وَلَا يَرْتَزُّ. وَيَقُولُونَ - وَاللَّهُ أَعْلَمُ بِصِحَّتِهِ - إِنَّ النَّاقَةَ الْخَسُوقَ السَّيِّئَةُ الْخُلُقُ.

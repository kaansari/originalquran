# طَرَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%B1%D9%8E%D8%B3%D9%8E/?book=9

(طَرَسَ) الطَّاءُ وَالرَّاءُ وَالسِّينُ فِيهِ كَلَامٌ لَعَلَّهُ أَنْ يَكُونَ صَحِيحًا. يَقُولُونَ الطِّرْسُ: الْكِتَابُ الْمَمْحُوُّ. وَيُقَالُ: كُلُّ صَحِيفَةٍ طِرْسٌ. وَيَقُولُونَ: التَّطَرُّسُ: أَنْ لَا يَطْعَمَ الْإِنْسَانُ وَلَا يَشْرَبَ إِلَّا طَيِّبًا.

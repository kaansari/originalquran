# فَسَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B3%D9%8E%D8%AD%D9%8E/?book=9

(فَسَحَ) الْفَاءُ وَالسِّينُ وَالْحَاءُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى سَعَةٍ وَاتِّسَاعٍ. مِنْ ذَلِكَ الْفَسِيحُ: الْوَاسِعُ. وَتَفَسَّحْتُ فِي الْمَجْلِسِ، وَفَسَّحْتُ الْمَجْلِسَ.

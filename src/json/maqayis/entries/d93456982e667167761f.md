# شَأَيَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%A3%D9%8E%D9%8A%D9%8E/?book=9

(شَأَيَ) الشِّينُ وَالْهَمْزَةُ وَالْيَاءُ كَلِمَةٌ مِنْ بَابِ الْإِبْدَالِ، عَلَى اخْتِلَافٍ فِيهَا. قَالَ قَوْمٌ: شَأَيْتُ مِثْلُ شَأَوْتُ فِي السَّبْقِ ; يُقَالُ مِنْهُ شَأَى وَاشْتَأَى. [قَالَهُ الْمُفَضَّلُ] وَأَنْشَدَ:

فَأَيِّهْ بِكِنْدِيرٍ حِمَارُ ابْنِ وَاقِعِ ... رَآكَ بِكِيرٍ فَاشْتَأَى مِنْ عُتَائِدِ

وَقَالَ قَوْمٌ: اشْتَأَى: أَشْرَفَ. وَالَّذِي قَالَهُ الْمُفَضَّلُ أَصْوَبُ وَأَقْيَسُ.

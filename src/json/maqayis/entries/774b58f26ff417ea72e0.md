# عَطِشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%B7%D9%90%D8%B4%D9%8E/?book=9

(عَطِشَ) الْعَيْنُ وَالطَّاءُ وَالشِّينُ أَصْلٌ وَاحِدٌ صَحِيحٌ، وَهُوَ الْعَطَشُ، يُقَالُ لَهُ: عَطِشَ يَعْطَشُ عَطَشًا. وَيُقَالُ إِنَّ الْمَعَاطِشَ: مَوَاقِيتُ الظَّمَأِ. قَالَ ذُو الرُّمَّةِ:

لَا تَشْتَكِي سَقْطَةً مِنْهَا وَقَدْ رَقَصَتْ ... بِهَا الْمَعَاطِشُ حَتَّى ظَهْرُهَا حَدِبُ

# نَأَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%A3%D9%8E%D9%84%D9%8E/?book=9

(نَأَلَ) النُّونُ وَالْهَمْزَةُ وَاللَّامُ، لَيْسَ فِيهِ إِلَّا النَّأَلَانُ: الْمَشْيُ السَّرِيعُ. يَنْهَضُ الْمَاشِي بِرَأْسِهِ إِلَى فَوْقٍ. وَرَجُلٌ نَؤُولٌ، وَضَبُعٌ نَؤُولٌ، إِذَا فَعَلْتَ ذَلِكَ.

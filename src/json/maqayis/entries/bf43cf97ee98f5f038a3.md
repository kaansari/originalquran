# وَلَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%84%D9%8E%D9%85%D9%8E/?book=9

(وَلَمَ) الْوَاوُ وَاللَّامُ وَالْمِيمُ، فِيهِ كَلِمَاتٌ تَتَشَاكَلُ. يَقُولُونَ: الْوَلْمُ: الْحِزَامُ. وَالْوَلْمُ: حَبْلٌ يُشَدُّ بَيْنَ التَّصْدِيرِ وَالسَّفِيفِ لِئَلَّا يَقْلَقَا. وَيُقَالُ الْوَلْمُ: كُلُّ خَيْطٍ شَدَدْتَ بِهِ شَيْئًا. وَلَيْسَ يَبْعُدُ أَنْ يَكُونَ اشْتِقَاقُ الْوَلِيمَةِ مِنْ هَذَا، لِأَنَّهُ يَكُونُ عِنْدَ عَقْدِ النِّكَاحِ. وَأَهْلُ اللُّغَةِ يَقُولُونَ: طَعَامُ الْعُرْسِ وَلِيمَةٌ.

# نَصَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B5%D9%8E%D8%AA%D9%8E/?book=9

(نَصَتَ) النُّونُ وَالصَّادُ وَالتَّاءُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى السُّكُوتِ. وَأَنْصَتَ لِاسْتِمَاعِ الْحَدِيثِ، وَنَصَتَ يَنْصِتُ. وَفِي كِتَابِ اللَّهِ تَعَالَى: وَأَنْصِتُوا.

# لَوَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%88%D9%8E%D9%82%D9%8E/?book=9

(لَوَقَ) اللَّامُ وَالْوَاوُ وَالْقَافُ كَلِمَةٌ تَدُلُّ عَلَى تَطْيِيبِ شَيْءٍ. يُقَالُ: لَوَّقَ الطَّعَامَ، إِذَا طَيَّبَهُ بِإِدَامِهِ. وَيَقُواللُّوَقَةُ: الزُّبْدَةُ، وَيُقَالُ لِلْمَرْأَةِ، إِذَا لَمْ تَحْظَ عِنْدَ زَوْجِهَا: مَا لَاقَتْ، أَيْ كَأَنَّهُ لَمْ يَسْتَطِبْ صُحْبَتَهَا. وَمِنَ الْبَابِ: لَاقَتِ الدَّوَاةُ وَأَلْقُتُهَا.

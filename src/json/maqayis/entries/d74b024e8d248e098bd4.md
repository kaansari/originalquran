# مَقَوَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%82%D9%8E%D9%88%D9%8E/?book=9

(مَقَوَ) الْمِيمُ وَالْقَافُ وَالْحَرْفُ الْمُعْتَلُّ. يُقَالُ فِيهِ: امْقُ هَذَا مَقْوَكَ مَالَكَ، أَيْ صُنْهُ صِيَانَتَكَ مَالَكَ. وَمَقَوْتُ السَّيْفَ: جَلَوْتُهُ، وَكَذَا الْمِرْآةُ. قَالَ ابْنُ دُرَيْدٍ: جَاءَ بِهِمَا يُونُسُ وَأَبُو الْخَطَّابِ.

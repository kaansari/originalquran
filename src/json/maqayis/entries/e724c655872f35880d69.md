# بَسَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B3%D9%8E%D9%85%D9%8E/?book=9

(بَسَمَ) الْبَاءُ وَالسِّينُ وَالْمِيمُ أَصْلٌ وَاحِدٌ، وَهُوَ إِبْدَاءُ مُقَدَّمِ الْفَمِ لِمَسَرَّةٍ; وَهُوَ دُونَ الضَّحِكِ يُقَالُ: بَسَمَ يَبْسِمُ وَتَبَسَّمَ وَابْتَسَمَ.

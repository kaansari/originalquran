# دَيَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%8A%D9%8E%D9%83%D9%8E/?book=9

(دَيَكَ) الدَّالُ وَالْيَاءُ وَالْكَافُ لَيْسَ أَصْلًا يَتَفَرَّعُ مِنْهُ، إِنَّمَا هُوَ الدِّيكُ. وَيَقُولُونَ: هُوَ عُظَيْمٌ نَاتِئٌ فِي جَبْهَةِ الْفَرَسِ. وَلَيْسَ هَذَا بِشَيْءٍ.

# لَأَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%A3%D9%91%D9%8E/?book=9

( [لَأَّ] ) وَأَمَّا اللَّامُ وَالْهَمْزَةُ فَيَدُلُّ عَلَى صَفَاءٍ وَبَرِيقٍ. مِنْ ذَلِكَ تَلَأْلَأَتِ اللُّؤْلُؤَةُ، وَسُمِّيَتْ لِأَنَّهَا تَلَأْلَأُ. وَالْعَرَبُ تَقُولُ: " لَا أَفْعَلُهُ مَا لَأْلَأَتِ الْفُورُ بِأَذْنَابِهَا " أَيْ مَا حَرَّكَتْهَا وَلَمَعَتْ بِهَا.

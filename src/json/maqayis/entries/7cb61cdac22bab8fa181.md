# دَأَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%A3%D9%8E%D8%AB%D9%8E/?book=9

(دَأَثَ) الدَّالُ وَالْهَمْزَةُ وَالثَّاءُ لَيْسَ أَصْلًا; لِأَنَّ الدَّأْثَاءَ - وَهِيَ الْأَمَةُ - مَقْلُوبَةٌ مِنَ الثَّأْدَاءِ. عَلَى أَنَّهُمْ يَقُولُونَ: دَأَثْتُ الطَّعَامَ: أَكَلْتُهُ.

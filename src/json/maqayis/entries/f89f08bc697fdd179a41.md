# دَنَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%86%D9%8E%D9%85%D9%8E/?book=9

(دَنَمَ) الدَّالُ وَالنُّونُ وَالْمِيمُ أَصْلٌ يَدُلُّ عَلَى ضَعْفٍ وَقِلَّةٍ. فَالتَّدْنِيمُ: الْإِسْفَافُ لِلْأُمُورِ الدَّنِيَّةِ. وَالدِّنَّامَةُ: الرَّجُلُ الْقَصِيرُ; ذَكَرَهُ الْفَرَّاءُ. وَيَقُولُونَ: الدِّنَّامَةُ: النَّمْلَةُ الصَّغِيرَةُ.

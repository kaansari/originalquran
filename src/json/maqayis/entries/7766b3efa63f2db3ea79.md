# حَمَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%85%D9%8E%D8%B5%D9%8E/?book=9

(حَمَصَ) الْحَاءُ وَالْمِيمُ وَالصَّادُ لَيْسَ أَصْلًا يُقَاسُ عَلَيْهِ، وَمَا فِيهِ قِيَاسٌ وَيَجُوزُ أَنْ يَكُونَ مِنْ جَفَافٍ فِي الشَّيْءِ. وَيَقُولُونَ: انْحَمَصَ الْوَرَمُ، إِذَا سَكَنَ. هَذَا أَصَحُّ مَا فِيهِ. وَالْحَمَصِيصُ: بَقْلَةٌ.

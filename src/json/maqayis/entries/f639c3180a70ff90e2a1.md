# جَيَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%8A%D9%8E%D8%AF%D9%8E/?book=9

(جَيَدَ) الْجِيمُ وَالْيَاءُ وَالدَّالُ أَصْلٌ وَاحِدٌ، وَهُوَ الْعُنُقُ. يُقَالُ جِيدٌ وَأَجْيَادٌ. وَالْجَيْدُ: طُولُ الْجِيدِ. وَالْجَيْدَاءُ: الطَّوِيلَةُ الْجِيدِ. وَأَمَّا قَوْلُ الْأَعْشَى:

رِجَالَ إِيَادٍ بَأَجْيَادِهَا

فَيُقَالُ إِنَّهَا مُعَرَّبَةٌ وَإِنَّهُ أَرَادَ الْأَكْسِيَةَ.

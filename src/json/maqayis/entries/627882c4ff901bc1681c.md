# مَرَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B1%D9%8E%D8%B2%D9%8E/?book=9

(مَرَزَ) الْمِيمُ وَالرَّاءُ وَالزَّاءُ أَصْلٌ يَدُلُّ عَلَى تَقْطِيعِ شَيْءٍ وَخَدْشِهِ. وَمَرَزَتِ الْمَرْأَةُ الْعَجِينَ: قَطَّعَتْهُ، وَكُلُّ قِطْعَةٍ مَِرْزَةٌ. وَيَقُولُونَ فِي الْقِيَاسِ عَلَى هَذَا: امْتَرَزَ عِرْضَهُ، إِذَا نَالَ مِنْهُ. وَمَرَزَ جِلْدَهُ: خَدَشَهُ.

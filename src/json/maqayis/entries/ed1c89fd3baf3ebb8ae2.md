# أَكَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D9%83%D9%8E%D8%AF%D9%8E/?book=9

(أَكَدَ) الْهَمْزَةُ وَالْكَافُ وَالدَّالُ لَيْسَتْ أَصْلًا، لِأَنَّ الْهَمْزَةَ مُبْدَلَةٌ مِنْ وَاوٍ، يُقَالُ: وَكَّدْتُ الْعَقْدَ. وَقَدْ ذُكِرَ فِي بَابِهِ.

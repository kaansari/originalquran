# خَبَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%A8%D9%8E%D8%B3%D9%8E/?book=9

(خَبَسَ) الْخَاءُ وَالْبَاءُ وَالسِّينُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى أَخْذِ الشَّيْءِ قَهْرًا وَغَلَبَةً. يُقَالُ تَخَبَّسْتُ الشَّيْءَ: أَخَذْتُهُ. وَذَلِكَ الشَّيْءُ خُبَاسَةً. وَالْخُبَاسَةُ: الْمَغْنَمُ ; يُقَالُ اخْتَبَسَ الشَّيْءَ: أَخَذَهُ مُغَالَبَةً. وَأَسَدٌ خَبُوسٌ. قَالَ:

وَلَكِنِّي ضُبَارِمَةٌ جَمُوحٌ ... عَلَى الْأَقْرَانِ مُجْتَرِئٌ خَبُوسُ

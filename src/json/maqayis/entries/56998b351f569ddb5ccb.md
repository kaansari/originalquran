# قَثَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%AB%D9%8E%D9%85%D9%8E/?book=9

(قَثَمَ) الْقَافُ وَالثَّاءُ وَالْمِيمُ أَصْلٌ يَدُلُّ عَلَى جَمْعٍ وَإِعْطَاءٍ. مِنْ ذَلِكَ قَوْلُهُمْ: قَثَمَ مِنْ مَالِهِ، إِذَا أَعْطَاهُ. وَرَجُلٌ قُثَمٌ: مِعْطَاءٌ. وَالْقَثُومُ: الرَّجُلُ الْجَمُوعُ لِلْخَيْرِ. قَالَ:

فَلِلْكُبَرَاءِ أَكْلٌ كَيْفَ شَاؤُوا ... وَلِلصُّغَرَاءِ أَكْلٌ وَاقْتِثَامُ.

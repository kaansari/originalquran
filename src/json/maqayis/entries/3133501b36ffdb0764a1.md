# أَطَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%B7%D9%8E%D9%84%D9%8E/?book=9

(أَطَلَ) الْهَمْزَةُ وَالطَّاءُ وَاللَّامُ، أَصْلٌ وَاحِدٌ وَكَلِمَةٌ وَاحِدَةٌ، وَهُوَ الْإِطِلُ والْإِطْلُ، وَهِيَ الْخَاصِرَةُ; وَجَمْعُهُ آطَالٌ. وَكَذَلِكَ الْأَيْطَلُ. قَالَ امْرُؤُ الْقَيْسِ:

لَهُ أَيْطَلَا ظَبْيٍ وَسَاقَا نَعَامَةٍ ... وَإِرْخَاءُ سِرْحَانٍ وَتَقْرِيبُ تَتْفُلِ

وَذَا لَا يُقَاسُ عَلَيْهِ.

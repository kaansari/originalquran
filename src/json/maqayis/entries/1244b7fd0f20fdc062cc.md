# نَحَضَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%AD%D9%8E%D8%B6%D9%8E/?book=9

(نَحَضَ) النُّونُ وَالْحَاءُ وَالضَّادُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ اللَّحْمُ. يُقَالُ لِلَّحْمِ نَحْضٌ. وَامْرَأَةٌ نَحِيضَةٌ: كَثِيرَةُ اللَّحْمِ، فَإِذَا ذَهَبَ لَحْمُهَا فَمَنْحُوضَةٌ، مِنْ قَوْلِهِمْ: نَحَضْتُ الْعَظْمَ: أَخَذْتُ مَا عَلَيْهِ مِنْ لَحْمٍ. وَيَقُولُونَ: نَحَضْتُ السِّنَانَ: رَقَّقْتُهُ، كَأَنَّكَ لَمَّا رَقَّقْتَهُ أَخَذْتَ عَنْهُ نَحْضَهُ.

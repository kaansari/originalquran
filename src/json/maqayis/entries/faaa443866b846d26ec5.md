# هَيَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%8A%D9%8E%D9%81%D9%8E/?book=9

(هَيَفَ) الْهَاءُ وَالْيَاءُ وَالْفَاءُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى حَرَارَةٍ وَعَطَشٍ، ثُمَّ يُسْتَعَارُ ذَلِكَ. فَالْهَيْفُ: رِيحٌ حَارَّةٌ تَجِيءُ فِي قُبُلِ الصَّيْفِ، تُعْطِشُ الْمَالَ وَتُوبِسُ الرَّطْبَ. وَرَجُلٌ مِهْيَافٌ: لَا يَصْبِرُ عَنِ الْمَاءِ. وَأَهَافُوا: عَطِشَتْ إِبِلُهُمْ. وَاسْتُعِيرَفَقِيلَ لِمَنْ دَقَّ خَصْرُهُ: أَهْيَفُ، كَأَنَّ ثَمَّ عَطَشًا ; وَالْجَمْعُ هِيفٌ. وَفَرَسٌ هَيْفَاءُ: ضَامِرَةٌ.

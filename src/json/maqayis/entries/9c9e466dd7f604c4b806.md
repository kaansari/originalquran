# ثَأَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%A3%D9%8E%D8%B7%D9%8E/?book=9

(ثَأَطَ) الثَّاءُ وَالْهَمْزَةُ وَالطَّاءُ كَلِمَةٌ وَاحِدَةٌ لَيْسَتْ أَصْلًا. فَالثَّأْطَةُ الْحَمْأَةُ وَالْجَمْعُ ثَأْطٌ. وَيُنْشِدُونَ:

فِي عَيْنِ ذِي خُلُبٍ وَثَأْطٍ حَرْمَدِ

وَإِنَّمَا قُلْنَا لَيْسَتْ أَصْلًا لِأَنَّهُمْ يَقُولُونَهَا بِالدَّالِ، فَكَأَنَّهَا مِنْ بَابِ الْإِبْدَالِ.

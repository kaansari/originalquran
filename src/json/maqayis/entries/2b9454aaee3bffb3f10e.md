# شَحَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%AD%D9%8E%D8%B5%D9%8E/?book=9

(شَحَصَ) الشِّينُ وَالْحَاءُ وَالصَّادُ كَلِمَةٌ وَاحِدَةٌ، يُقَالُ " إِنَّ الشَّحَصَ الشَّاةُ لَا لَبَنَ لَهَا، وَيُقَالُ: هِيَ الَّتِي لَمْ يُنْزَ عَلَيْهَا قَطُّ. وَفِي كِتَابِ الْخَلِيلِ: الشَّحْصَاءُ.

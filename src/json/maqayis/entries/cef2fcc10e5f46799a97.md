# رَهَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%87%D9%8E%D9%83%D9%8E/?book=9

(رَهَكَ) الرَّاءُ وَالْهَاءُ وَالْكَافُ أَصْلٌ يَدُلُّ عَلَى اسْتِرْخَاءٍ. فَالرَّهْوَكُ: السَّمِينُ مِنَ الْجِدَاءِ وَالظِّبَاءِ. وَالتَّرَهْوُكُ: التَّحَرُّكُ فِي رَخَاوَةٍ. وَيَقُولُونَ: رَهَكْتُ الشَّيْءَ، إِذَا سَحَقْتَهُ.

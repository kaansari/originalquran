# سَخَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%AE%D9%8E%D8%A8%D9%8E/?book=9

(سَخَبَ) السِّينُ وَالْخَاءُ وَالْبَاءُ كَلِمَةٌ لَا يُقَاسُ عَلَيْهَا. يَقُولُونَ: السِّخَابُ: قِلَادَةٌ مِنْ قُرُنْفُلٍ أَوْ غَيْرِهِ، وَلَيْسَ فِيهَا مِنَ الْجَوَاهِرِ شَيْءٌ، وَالْجَمْعُ سُخُبٌ.

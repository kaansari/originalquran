# طَرَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%B1%D9%8E%D8%B4%D9%8E/?book=9

(طَرَشَ) الطَّاءُ وَالرَّاءُ وَالشِّينُ كَلِمَةٌ مَعْرُوفَةٌ، وَهِيَ الطَّرَشُ، مَعْرُوفٌ. وَقَالَ أَبُو عَمْرٍو: تَطَرَّشَ النَّاقِهُ مِنَ الْمَرَضِ، إِذَا قَامَ وَقَعَدَ.

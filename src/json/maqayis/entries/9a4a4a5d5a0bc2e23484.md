# رَطَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B7%D9%91%D9%8E/?book=9

(رَطَّ) الرَّاءُ وَالطَّاءُ لَيْسَ هُوَ بِأَصْلٍ عِنْدَنَا. يَقُولُونَ: الرَّطِيطُ: الْجَلَبَةُ وَالصِّيَاحُ. وَأَرَطَّ، إِذَا جَلَّبَ. وَيُقَالُ الرَّطِيطُ: الْأَحْمَقُ. وَيُقَالُ الْإِرْطَاطُ: اللُّزُومُ. وَفِي كُلِّ ذَلِكَ نَظَرٌ.

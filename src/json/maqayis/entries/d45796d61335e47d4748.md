# الْعُفَاهِمُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8F%D9%81%D9%8E%D8%A7%D9%87%D9%90%D9%85%D9%8F/?book=9

(وَالْعُفَاهِمُ) : الْجَلْدُ الْقَوِيُّ. وَكُلُّ قَوِيٍّ عُفَاهِمٌ. قَالَ:

مِنْ عُنْفُوَانِ جَرْيِهِ الْعُفَاهِمِ

وَهَذَا مِمَّا زِيدَتْ فِيهِ الْفَاءُ، وَهُوَ مِنَ الْعَيْهَمَةِ أَيْضًا.

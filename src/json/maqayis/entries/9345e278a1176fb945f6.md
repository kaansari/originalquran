# بَسَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B3%D9%8E%D8%A3%D9%8E/?book=9

(بَسَأَ) الْبَاءُ وَالسِّينُ وَالْهَمْزَةُ أَصْلٌ وَاحِدٌ، وَهُوَ الْأُنْسُ بِالشَّيْءِ، يُقَالُ: بَسَأْتُ بِهِ وَبَسِئْتُ أَيْضًا. وَنَاقَةٌ بَسُوءٌ لَا تَمْنَعُ الْحَالِبَ.

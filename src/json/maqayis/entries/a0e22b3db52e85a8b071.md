# تَنَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D9%86%D9%8E%D9%81%D9%8E/?book=9

(تَنَفَ) التَّاءُ وَالنُّونُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ، التَّنُوفَةُ الْمَفَازَةُ، وَكَذَلِكَ التَّنُوفِيَّةُ. قَالَ ابْنٌ احْمَرَ:

كَمْ دُونَ لَيْلَى مِنْ تَنُوفِيَّةٍ ... لَمَّاعَةٍ تُنْذَرُ فِيهَا النُّذُرُ وَرَوَى ابْنُ قُتَيْبَةَ " تَنُوفَى " وَقَالَ: ثَنِيَّةٌ مُشْرِفَةٌ. قَالَ: وَنَاسٌ يَقُولُونَ يَنُوفَى. وَأَنْشَدَ:

كَأَنَّ بَنِي نَبْهَانَ أَوْدَتْ بِجَارِهِمْ ... عُقَابٌ تَنُوفَى لَا عُقَابُ الْقَوَاعِلِ

وَالْقَوَاعِلُ: ثَنَايَا صِغَارٌ. يَقُولُ: كَأَنَّ جَارَهُمْ طَارَتْ بِهِ هَذِهِ الْعُقَابُ. وَمِثْلُهُ قَوْلُ الْمُسَيَّبِ:

أَنْتَ الْوَفِيُّ فَمَا تُذَمُّ وَبَعْضُهُمْ ... تُوفِي بِذِمَّتِهِ عُقَابُ مَلَاعِ

قَالَ: مَلَاعِ، أَخْرَجَهُ مَخْرَجَ حَذَامِ. يُقَالُ امْتَلَعَهُ اخْتَلَسَهُ.

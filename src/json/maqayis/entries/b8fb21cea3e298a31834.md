# الْعَبَاهِلُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D8%A8%D9%8E%D8%A7%D9%87%D9%90%D9%84%D9%8F/?book=9

(الْعَبَاهِلُ) : جَمْعُ الْعَبْهَلِ، وَهُوَ الْإِبِلُ الَّتِي أُهْمِلَتْ تَرِدُ كَيْفَ شَاءَتْ، وَمَتَّى شَاءَتْ. قَالَ: عَبَاهِلٌ عَبْهَلَهَا الْوُرَّادُ

وَبِهِ شُبِّهَتِ الْمُلُوكُ الَّذِينَ لَا فَوْقَ يَدِهِمْ يَدٌ. هَذَا مِمَّا زِيدَتْ فِيهِ الْبَاءُ. وَالْأَصْلُ الْعَيْهَلُ وَالْعَيْهَلَةُ: الَّتِي لَا تَسْتَقِرُّ. وَقَدْ فَسَّرْنَاهُ.

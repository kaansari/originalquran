# جَوَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%88%D9%8E%D8%B3%D9%8E/?book=9

(جَوَسَ) الْجِيمُ وَالْوَاوُ وَالسِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ تَخَلُّلُ الشَّيْءِ. يُقَالُ: جَاسُوا خِلَالَ الدِّيَارِ يَجُوسُونَ. قَالَ اللَّهُ تَعَالَى: {فَجَاسُوا خِلَالَ الدِّيَارِ} [الإسراء: 5] . وَأَمَّا الْجُوسُ فَلَيْسَ أَصْلًا ; لِأَنَّهُ إِتْبَاعٌ لِلْجُوعِ ; يُقَالُ: جُوعًا لَهُ وَجُوسًا لَهُ.

# أَنَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D9%86%D9%8E%D8%AB%D9%8E/?book=9

(أَنَثَ) وَأَمَّا الْهَمْزَةُ وَالنُّونُ وَالثَّاءُ فَقَالَ الْخَلِيلُ وَغَيْرُهُ: الْأُنْثَى خِلَافُ الذَّكَرِ. وَيُقَالُ: سَيْفٌ [أَنِيثُ] الْحَدِيدِ: إِذَا كَانَتْ حَدِيدَتُهُ أُنْثَى. وَالْأُنْثَيَانِ: الْخُصْيَتَانِ. وَالْأُنْثَيَانِ أَيْضًا: الْأُذُنَانِ. قَالَ:

وَكُنَّا إِذَا الْجَبَّارُ صَعَّرَ خَدَّهُ ... ضَرَبْنَاهُ تَحْتَ الْأُنْثَيَيْنِ عَلَى الْكَرْدِ

وَأَرْضٌ أَنِيثَةٌ: حَسَنَةُ النَّبَاتِ.

# هَضَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B6%D9%8E%D9%84%D9%8E/?book=9

(هَضَلَ) الْهَاءُ وَالضَّادُ وَاللَّامُ لَيْسَ فِيهِ إِلَّا الْهَيْضَلَةُ، وَهِيَ الْجَمَاعَةُ الْمُتَسَلِّحَةُ ذَاتُ الْجَلَبَةِ. وَرُبَّمَا قَالُوا لِلنَّاقَةِ الْعَظِيمَةِ: هَيْضَلَةٌ.

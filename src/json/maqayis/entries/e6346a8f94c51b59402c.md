# وَشَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B4%D9%8E%D8%AD%D9%8E/?book=9

(وَشَحَ) الْوَاوُ وَالشِّينُ وَالْحَاءُ: كَلِمَةٌ وَاحِدَةٌ الْوِشَاحُ. وَتَوَشَّحَ بِثَوْبِهِ، كَأَنَّهُ جَعَلَهُ وِشَاحَهُ، وَكَذَا اتَّشَحَ بِهِ. وَشَاةٌ مُوَشَّحَةٌ: بِجَنْبَيْهَا خَطَّانِ.

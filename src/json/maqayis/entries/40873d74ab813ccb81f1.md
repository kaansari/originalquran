# ازْلَغَبَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D8%B2%D9%92%D9%84%D9%8E%D8%BA%D9%8E%D8%A8%D9%91%D9%8E/?book=9

قَوْلُ الْخَلِيلِ: (ازْلَغَبَّ) الشَّعْرُ، وَذَلِكَ إِذَا نَبَتَ بَعْدَ الْحَلْقِ. وَازْلَغَبَّ الطَّائِرُ. إِذَا شَوَّكَ. وَهَذَا مِمَّا نُحِتَ مِنْ كَلِمَتَيْنِ، مِنْ زَغَبَ وَلَغَبَ. وَالزَّغَبُ مَعْرُوفٌ، وَاللَّغْبُ: أَضْعَفُ الرِّيشِ.

# جَسَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%B3%D9%91%D9%8E/?book=9

(جَسَّ) الْجِيمُ وَالسِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ تَعَرُّفُ الشَّيْءِ بِمَسٍّ لِطَيْفٍ. يُقَالُ جَسَسْتُ الْعِرْقَ وَغَيْرَهُ جَسًّا. وَالْجَاسُوسُ فَاعُولٌ مِنْ هَذَا ; لِأَنَّهُ يَتَخَبَّرُ مَا يُرِيدُهُ بِخَفَاءٍ وَلُطْفٍ. وَذُكِرَ عَنِ الْخَلِيلِ أَنَّ الْحَوَاسَّ الَّتِي هِيَ مَشَاعِرُ الْإِنْسَانِ رُبَّمَا سُمِّيَتْ جَوَاسَّ. قَالَ ابْنُ دُرَيْدٍ: وَقَدْ يَكُونُ الْجَسُّ بِالْعَيْنِ. وَهَذَا يُصَحِّحُ مَا قَالَهُ الْخَلِيلُ. وَأَنْشَدَ:

فَاعْصَوْصَبُوا ثُمَّ جَسُّوهُ بِأَعْيُنِهِمْ

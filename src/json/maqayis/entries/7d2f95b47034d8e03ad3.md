# هَصَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B5%D9%8E%D9%85%D9%8E/?book=9

(هَصَمَ) الْهَاءُ وَالصَّادُ وَالْمِيمُ: كَلِمَةٌ تَدُلُّ عَلَى الْكَسْرِ، هَصَمْتُ الشَّيْءَ: كَسَرْتُهُ. وَبِهِ سُمِّيَ الْأَسَدُ هَيْصَمًا. وَاللَّهُ أَعْلَمُ.

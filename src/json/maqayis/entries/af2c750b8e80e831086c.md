# فَعَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B9%D9%8E%D9%85%D9%8E/?book=9

(فَعَمَ) الْفَاءُ وَالْعَيْنُ وَالْمِيمُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى اتِّسَاعٍ وَامْتِلَاءٍ. فَالْفَعْمُ: الْمَلْآنُ. فَعُمَ يَفْعُمُ فَعَامَةً وَفُعُومَةً. وَامْرَأَةٌ فَعْمَةُ السَّاقَيْنِ، إِذَا امْتَلَأَتْ سَاقُهَا لَحْمًا وَأَفْعَمْتُ الشَّيْءَ: مَلَأْتُهُ.

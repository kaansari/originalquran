# ذَرَوَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B0%D9%8E%D8%B1%D9%8E%D9%88%D9%8E/?book=9

(ذَرَوَ) الذَّالُ وَالرَّاءُ وَالْحَرْفُ الْمُعْتَلُّ أَصْلَانِ: أَحَدُهُمَا الشَّيْءُ يُشْرِفُ عَلَى الشَّيْءِ وَيُظِلُّهُ، وَالْآخَرُ الشَّيْءُ يَتَسَاقَطُ مُتَفَرِّقًا.

فَالذُِّرْوَةُ: أَعْلَى السَّنَامِ وَغَيْرِهِ، وَالْجَمْعُ ذُرًى. وَالذَّرَا: كُلُّ شَيْءٍ اسْتَتَرْتَ بِهِ. تَقُولُ: أَنَا فِي ظِلِّ فُلَانٍ، أَيْ ذَرَاهُ. وَالْمِذْرَوَانُ: أَطْرَافُ الْأَلْيَتَيْنِ; لِأَنَّهُمَا يُشْرِفَانِ عَلَى [مَا] بَيْنَهُمَا.

وَأَمَّا الْآخَرُ فَيَقُولُ: ذَرَا نَابُ الْجَمَلِ، إِذَا انْكَسَرَ حَدُّهُ. قَالَ أَوْسٌ:

إِذَا مُقْرَمٌ مِنَّا ذَرَا حَدُّ نَابِهِ ... تَخَمَّطَ فِينَا نَابُ آخَرَ مُقْرَمِ

وَمِنَ الْبَابِ ذَرَتِ الرِّيحُ الشَّيْءَ تَذْرُوهُ. وَالذَّرَا: اسْمٌ لِمَا ذَرَتْهُ الرِّيحُ. وَيُقَالُ أَذْرَتِ الْعَيْنُ دَمْعَهَا تُذْرِيهِ. وَأَذْرَيْتُ الرَّجُلَ عَنْ فَرَسِهِ: رَمَيْتُهُ. وَيُقَالُ إِنَّ الذَّرَى اسْمٌ لِمَا صُبَّ مِنَ الدَّمْعِ.

وَمِنَ الْبَابِ قَوْلُهُمْ: بَلَغَنِي عَنْهُ ذَرْوٌ مِنْ قَوْلٍ، وَذَلِكَ مَا يُسَاقِطُهُ مِنْ أَطْرَافِ كَلَامِهِ غَيْرَ مُتَكَامِلٍ.

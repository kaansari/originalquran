# أَصَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%B5%D9%91%D9%8E/?book=9

(أَصَّ) وَأَمَّا الْهَمْزَةُ وَالصَّادُ فَلَهُ مَعْنَيَانِ، أَحَدُهُمَا أَصْلُ الشَّيْءِ وَمُجْتَمَعُهُ، وَالْأَصْلُ الْآخَرُ الرِّعْدَةُ. قَالَ أَهْلُ اللُّغَةِ: الْإِصُّ الْأَصْلُ. وَيُقَالُ لِلنَّاقَةِ الْمُجْتَمِعَةِ الْخَلْقِ: أَصُوصٌ. وَجَمْعُ الْإِصِّ الَّذِي هُوَ الْأَصْلُ: آصَاصٌ. قَالَ:

قِلَالُ مَجْدٍ فَرَّعَتْ آصَاصَا ... وَعِزَّةٌ قَعْسَاءُ لَا تُنَاصَى

وَالْأَصِيصُ: أَصْلُ الدَّنِّ يُجْعَلُ فِيهِ شَرَابٌ. قَالَ عَدِيٌّ:

مَتَى أَرَى شَرْبًا حَوَالَيْ أَصِيصْ

فَهَذَا أَصْلٌ. وَأَمَّا الْآخَرُ فَقَالُوا: أَفْلَتَ فُلَانٌ وَلَهُ أَصِيصٌ، أَيْ رِعْدَةٌ.

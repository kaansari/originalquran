# لَكِدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%83%D9%90%D8%AF%D9%8E/?book=9

(لَكِدَ) اللَّامُ وَالْكَافُ وَالدَّالُ. يَقُولُونَ: لَكِدَ الشَّيْءُ بِالشَّيْءِ: لَازَمَهُ وَلَزِقَ بِهِ. وَيَقُولُونَ: الْمِلْكَدُ: شَيْءٌ يُدَقُّ فِيهِ الْأَشْيَاءُ. وَاللَّكَدُ: الْتِزَاقُ الدَّمِ وَجُمُودُهُ وَأَكَلْتُ الصَّمْغَ فَلَكِدَ بِفَمِي. وَقَالَ أَبُو بَكْرِ بْنُ دُرَيْدٍ: اللَّكَدُ: الضَّرْبُ بِالْيَدِ. وَمَشَى وَهُوَ يُلَاكِدُ قَيْدَهُ، إِذَا مَشَى فَنَازَعَهُ الْقَيْدُ خُطَاهُ.

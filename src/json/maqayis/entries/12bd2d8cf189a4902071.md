# رَدَغَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%AF%D9%8E%D8%BA%D9%8E/?book=9

(رَدَغَ) الرَّاءُ وَالدَّالُ وَالْغَيْنُ أُصَيْلٌ يَدُلُّ عَلَى اسْتِرْخَاءٍ وَاضْطِرَابٍ. مِنْ ذَلِكَ الرَّدْغُ: الْمَاءُ وَالطِّينُ. وَمِنْهُ الرَّدِيغُ، وَهُوَ الْأَحْمَقُ، وَالْأَحْمَقُ مُضْطَرِبُ الرَّأْيِ.

وَمِمَّا شَذَّ عَنْ ذَلِكَ الْمَرَادِغُ: مَا بَيْنَ الْعُنُقِ وَالتَّرْقُوَةِ.

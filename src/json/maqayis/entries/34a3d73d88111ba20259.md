# خَثَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%AB%D9%8E%D8%A7/?book=9

(خَثَا) الْخَاءُ وَالثَّاءُ وَالْحَرْفُ الْمُعْتَلُّ لَيْسَ أَصْلًا. وَرُبَّمَا قَالُوا امْرَأَةٌ خَثْوَاءُ: مُسْتَرْخِيَةُ الْبَطْنِ. وَوَاحِدُ الْأَخْثَاءِ خِثْيٌ. وَلَيْسَ بِشَيْءٍ. وَاللَّهُ أَعْلَمُ.

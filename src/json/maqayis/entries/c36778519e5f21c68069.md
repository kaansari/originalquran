# دَنَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%86%D9%8E%D8%B9%D9%8E/?book=9

(دَنَعَ) الدَّالُ وَالنُّونُ وَالْعَيْنُ أَصْلٌ يَدُلُّ عَلَى ضَعْفٍ وَقِلَّةٍ وَدَنَاءَةٍ. فَالرَّجُلُ الدَّنِعُ: الْفَسْلُ الَّذِي لَا خَيْرَ فِيهِ. وَالدَّنَعُ: الذُّلُّ. وَيَزْعُمُونَ أَنَّ الدَّنَعَ مَا يَطْرَحُهُ الْجَازِرُ مِنَ الْبَعِيرِ إِذَا جُزِرَ.

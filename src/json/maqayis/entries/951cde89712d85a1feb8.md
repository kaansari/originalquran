# خَدِلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%AF%D9%90%D9%84%D9%8E/?book=9

(خَدِلَ) الْخَاءُ وَالدَّالُ وَاللَّامُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى الدِّقَّةِ وَاللِّينِ. يُقَالُ امْرَأَةٌ خَدْلَةٌ، أَيْ دَقِيقَةُ الْعِظَامِ وَفِي لَحْمِهَا امْتِلَاءٌ، وَهِيَ بَيِّنَةُ الْخَدَلِ وَالْخَدَالَةِ. وَذُكِرَ عَنِ السِّجِسْتَانِيِّ عِنَبَةٌ خَدْلَةٌ، أَيْ ضَئِيلَةٌ.

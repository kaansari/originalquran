# سَمُجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%85%D9%8F%D8%AC%D9%8E/?book=9

(سَمُجَ) السِّينُ وَالْمِيمُ وَالْجِيمُ أَصْلٌ يَدُلُّ عَلَى خِلَافِ الْحُسْنِ. يُقَالُ هُوَ سَمِجٌ وَسَمْجٌ، وَالْجَمْعُ سِمَاجٌ وَسَمَاجَى. وَمِنَ الْبَابِ السَّمْجُ مِنَ الْأَلْبَانِ، وَهُوَ الْخَبِيثُ الطَّعْمِ.

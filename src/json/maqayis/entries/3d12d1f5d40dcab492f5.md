# رَبَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%A8%D9%8E%D9%83%D9%8E/?book=9

(رَبَكَ) الرَّاءُ وَالْبَاءُ وَالْكَافُ كَلِمَةٌ تَدُلُّ عَلَى خَلْطٍ وَاخْتِلَاطٍ. فَالرَّبْكُ: إِصْلَاحُ الثَّرِيدِ وَخَلْطُهُ. وَيُقَالُ لَهُ حِينَ يُفْعَلُ بِهِ ذَلِكَ الرَّبِيكَةُ. وَيُقَالُ ارْتَبَكَ فِي الْأَمْرِ، إِذَا لَمْ يَكَدْ يَتَخَلَّصُ مِنْهُ.

# أَضَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%B6%D9%8E%D8%A7/?book=9

(أَضَا) الْهَمْزَةُ وَالضَّادُ مَعَ اعْتِلَالِ مَا بَعْدَهُمَا كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْأَضَاةُ، مَكَانٌ يَسْتَنْقِعُ فِيهِ الْمَاءُ كَالْغَدِيرِ. قَالَ أَبُو عُبَيْدٍ: الْأَضَاةُ الْمَاءُ الْمُسْتَنْقِعُ، مِنْ سَيْلٍ أَوْ غَيْرِهِ، وَجَمْعُهُ أَضًا، وَجَمْعُ الْأَضَا إِضَاءٌ مَمْدُودٌ، وَهُوَ نَادِرٌ.

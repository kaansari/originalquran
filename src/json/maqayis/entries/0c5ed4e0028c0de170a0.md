# شَأَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%A3%D9%8E%D9%81%D9%8E/?book=9

(شَأَفَ) الشِّينُ وَالْهَمْزَةُ وَالْفَاءُ كَلِمَةٌ تَدُلُّ عَلَى الْبِغْضَةِ. مِنْ ذَلِكَ الشَّآفَةُ وَهِيَ الْبِغْضَةُ ; يُقَالُ شَأَفْتُهُ شَأَفًا. قَالَ: وَمِنَ الْبَابِ الشَّأْفَةُ، وَهِيَ قَرْحَةٌ تَخْرُجُ بِالْأَسْنَانِ فَتُكْوَى وَتَذْهَبُ، يَقُولُونَ: اسْتَأْصَلَ اللَّهُ شَأْفَتَهُ، يُقَالُ شُئِفَتْ رِجْلُهُ، فَمَعْنَاهُ أَذْهَبَهُ اللَّهُ كَمَا أَذْهَبَ ذَاكَ. وَإِنَّمَا سُمِّيَتْ شَأْفَةً لِمَا ذَكَرْنَاهُ مِنَ الْكَرَاهَةِ وَالْبِغْضَةِ.

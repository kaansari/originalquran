# سَلَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%84%D9%8E%D8%AD%D9%8E/?book=9

(سَلَحَ) السِّينُ وَاللَّامُ وَالْحَاءُ السِّلَاحُ، وَهُوَ مَا يُقَاتَلُ بِهِ، وَكَانَ أَبُو عُبَيْدَةَ يُفَرِّقُ بَيْنَ السِّلَاحِ وَالْجُنَّةِ، فَيَقُولُ: السِّلَاحُ مَا قُوتِلَ بِهِ، وَالْجُنَّةُ مَا اتُّقِيَ بِهِ، وَيَحْتَجُّ بِقَوْلِهِ:

حَيْثُ تَرَى الْخَيْلَ بِالْأَبْطَالِ عَابِسَةً ... يَنْهَضْنَ بِالْهِنْدَوَانِيَّاتِ وَالْجُنَنِ

فَجَعَلَ الْجُنَنَ غَيْرَ السُّيُوفِ. وَالْإِسْلِيحُ: شَجَرَةٌ تَغْزُرُ عَلَيْهَا الْإِبِلُ. وَقَالَتِ الْأَعْرَابِيَّةُ: " الْإِسْلِيحُ، رُغْوَةٌ وَسَرِيحٌ، وَسَنَامٌ وَإِطْرِيحٌ ".

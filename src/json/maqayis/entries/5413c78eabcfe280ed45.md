# وَأَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%A3%D9%8E%D9%84%D9%8E/?book=9

(وَأَلَ) الْوَاوُ وَالْهَمْزَةُ وَاللَّامُ: كَلِمَةٌ تَدُلُّ عَلَى تَجَمُّعٍ وَالْتِجَاءٍ. يُقَالُ اسْتَوْأَلَتِ الْإِبِلُ: اجْتَمَعَتْ. وَالْمَوْئِلُ: الْمَلْجَأُ مِنْ وَأَلَ إِلَيْهِ يَئِلُ. وَالْوَأْلَةُ: الْبَنَّةُ مِنَ الْبَعْرِ الْمُتَجَمِّعِ.

# لَقِنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%82%D9%90%D9%86%D9%8E/?book=9

(لَقِنَ) اللَّامُ وَالْقَافُ وَالنُّونُ كَلِمَةٌ صَحِيحَةٌ تَدُلُّ عَلَى أَخْذِ عِلْمٍ وَفَهْمِهِ. وَلَقِنَ الشَّيْءَ لَقْنًا: أَخَذَهُ وَفَهِمَهُ. وَلَقَّنْتُهُ تَلْقِينًا: فَهَّمْتُهُ. وَغُلَامٌ لَقِنٌ: سَرِيعُ الْفَهْمِ وَاللَّقَانَةِ.

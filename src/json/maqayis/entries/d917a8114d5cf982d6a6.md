# مَتَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AA%D9%8E%D8%B1%D9%8E/?book=9

(مَتَرَ) الْمِيمُ وَالتَّاءُ وَالرَّاءُ. يَقُولُونَ، وَمَا أَدْرِي مَا هُوَ: مَتَرْتُ الشَّيْءَ: قَطَعْتُهُ ; وَلَعَلَّهُ مِنَ الْإِبْدَالِ. وَقَالَ ابْنُ دُرَيْدٍ: مَتَرْتُهُ مَتْرًا. وَامْتَرَّ الْحَبْلُ: امْتَدَّ.

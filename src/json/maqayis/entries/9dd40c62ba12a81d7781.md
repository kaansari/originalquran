# يَزَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%8A%D9%8E%D8%B2%D9%8E%D9%86%D9%8E/?book=9

(يَزَنَ) الْيَاءُ وَالزَّاءُ وَالنُّونُ. لَيْسَ فِيهِ إِلَّا ذُو يَزَنَ، مِنْ مُلُوكِ حِمْيَرَ، يُنْسَبُ إِلَيْهِ الرِّمَاحُ، فَيُقَالُ يَزَنِيَّةٌ وَأَزَنِيَّةٌ.

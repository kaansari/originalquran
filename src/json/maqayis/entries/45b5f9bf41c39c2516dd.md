# شَحَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%AD%D9%8E%D9%86%D9%8E/?book=9

(شَحَنَ) الشِّينُ وَالْحَاءُ وَالنُّونُ أَصْلَانِ مُتَبَايِنَانِ، أَحَدُهُمَا يَدُلُّ عَلَى الْمَلْءِ، وَالْآخَرُ عَلَى الْبُعْدِ. فَالْأَوَّلُ قَوْلُهُمْ: شَحَنْتُ السَّفِينَةَ، إِذَا مَلَأْتَهَا. وَمِنَ الْبَابِ أَشْحَنَ فُلَانٌ لِلْبُكَاءِ، إِذَا تَهَيَّأَ لَهُ، كَأَنَّهُ اجْتَمَعَ لَهُ.

وَأَمَّا الْآخَرُ فَالشَّحْنُ: الطَّرْدُ، يُقَالُ: شَحَنَهُمْ، إِذَا طَرَدَهُمْ. وَيُقَالُ لِلشَّيْءِ الشَّدِيدِ الْحُمُوضَةِ: إِنَّهُ لَيَشْحَنُ الذِّبَّانَ، أَيْ يَطْرُدُهَا، وَمِنَ الْبَابِ: الشَّحْنَاءُ، وَهِيَ الْعَدَاوَةُ. وَعَدُوٌّ مُشَاحِنٌ، أَيْ مُبَاعِدٌ. وَالْعَدَاوَةُ تَبَاعُدٌ.

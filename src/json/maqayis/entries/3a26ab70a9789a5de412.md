# كَشَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D8%B4%D9%91%D9%8E/?book=9

(كَشَّ) الْكَافُ وَالشِّينُ لَيْسَ بِشَيْءٍ، وَفِيهِ كَلِمَةٌ تَجْرِي مَجْرَىَ الْحِكَايَةِ، يُقَالُ لِهَدِيرِ الْبَكْرِ: الْكَشِيشُ. وَالْكَشْكَشَةُ: كَلِمَةٌ مُوَلَّدَةٌ فِيمَنْ يُبْدِلُ الْكَافَ فِي كَلَامِهِ شِينًا.

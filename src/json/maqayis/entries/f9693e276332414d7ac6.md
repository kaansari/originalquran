# هَوَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%88%D9%8E%D8%B9%D9%8E/?book=9

(هَوَعَ) الْهَاءُ وَالْوَاوُ وَالْعَيْنُ: كَلِمَتَانِ: الْهَوْعُ: سُوءُ الْحِرْصِ. يُقَالُ رَجُلٌ هَاعٌ.

وَالْكَلِمَةُ الْأُخْرَى: الْهُوَاعُ: الْقَيْءُ. يُقَالُ: هَاعَ يَهُوعُ وَتَهَوَّعَ. قَالَ الْخَلِيلُ: لَأُهَوِّعَنَّهُ مَا أَكَلَ، أَيْ لَأَسْتَخْرِجَنَّ مِنْ حَلْقِهِ مَا أَكَلَ.

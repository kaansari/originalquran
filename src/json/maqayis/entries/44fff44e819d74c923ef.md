# ثَغْبٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%BA%D9%92%D8%A8%D9%8C/?book=9

(ثَغْبٌ) الثَّاءُ وَالْغَيْنُ وَالْبَاءُ أَصْلٌ وَاحِدٌ، وَهُوَ غَدِيرٌ فِي غِلَظٍ مِنْ أَرْضٍ. يُقَالُ لَهُ ثَغْبٌ وَثَغَبٌ، وَجَمْعُهُ ثِغَابٌ وَأَثْغَابٌ، وَيُقَالُ ثُِغْبَانٌ. وَقَالَ عُبَيْدٌ:

وَلَقَدْ تَحِلُّ بِهَا كَأَنَّ مُجَاجَهَا ... ثَغْبٌ يُصَفَّقُ صَفْوُهُ بِمُدَامِ

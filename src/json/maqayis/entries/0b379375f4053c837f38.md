# قَسَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%B3%D9%8E%D8%B1%D9%8E/?book=9

(قَسَرَ) الْقَافُ وَالسِّينُ وَالرَّاءُ يَدُلُّ عَلَى قَهْرٍ وَغَلَبَةٍ بِشِدَّةٍ. مِنْ ذَلِكَ الْقَسْرُ: الْغَلَبَةُ وَالْقَهْرُ. يُقَالُ: قَسَرْتُهُ قَسْرًا، وَاقْتَسَرْتُهُ اقْتِسَارًا. وَبَعِيرٌ قَيْسَرِيٌّ: صُلْبٌ. وَالْقَسْوَرَةُ: الْأَسَدُ، لِقُوَّتِهِ وَغَلَبَتِهِ.

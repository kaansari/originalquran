# تَأَمَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%A3%D9%8E%D9%85%D9%91%D9%8E/?book=9

(تَأَمَّ) التَّاءُ وَالْهَمْزَةُ وَالْمِيمُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ التَّوْأَمَانِ: الْوَلَدَانِ فِي بَطْنٍ تَقُولُ أَتْأَمَتِ الْمَرْأَةُ، وَهِيَ مُتْئِمٌ. وَالتُّؤَامُ جَمْعٌ. وَقَوْلُ سُوِيدٍ:

كَالتُّؤَامِيَّةِ إِنْ بَاشَرْتَهَا

فَيُقَالُ إِنَّ التُّؤَامَ قَصَبَةُ عُمَانَ.

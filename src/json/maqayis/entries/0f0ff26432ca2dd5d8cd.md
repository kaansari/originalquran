# دَظَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%B8%D9%91%D9%8E/?book=9

(دَظَّ) الدَّالُ وَالظَّاءُ لَيْسَ أَصْلًا يُعَوَّلُ عَلَيْهِ وَلَا يَنْقَاسُ مِنْهُ. ذَكَرُوا عَنِ الْخَلِيلِ أَنَّ الدَّظَّ الشَّلُّ; يُقَالُ دَظَظْنَاهُمْ، إِذَا شَلَلْنَاهُمْ. وَلَيْسَ ذَا بِشَيْءٍ.

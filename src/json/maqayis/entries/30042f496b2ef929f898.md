# شَثَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%AB%D9%8E%D9%86%D9%8E/?book=9

(شَثَنَ) الشِّينُ وَالثَّاءُ وَالنُّونُ. الشَّثْنُ: الْغَلِيظُ الْأَصَابِعِ. وَكُلُّ مَا غَلُظَ مِنْ عُضْوٍ فَهُوَ شَثْنٌ. وَقَدْ شَثَنَ وَشَثِنَ. وَاللَّهُ أَعْلَمُ.

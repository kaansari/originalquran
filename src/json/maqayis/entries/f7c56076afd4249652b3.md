# صَحَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D8%AD%D9%8E%D9%85%D9%8E/?book=9

(صَحَمَ) الصَّادُ وَالْحَاءُ وَالْمِيمُ أُصَيْلٌ صَحِيحٌ يَدُلُّ عَلَى لَوْنٍ. فَالْأَصْحَمُ:

الْأَغْبَرُ إِلَى السَّوَادِ. وَبَلْدَةٌ صَحْمَاءُ: مُغْبَرَّةٌ. وَاصْحَامَّتِ الْبَقْلَةُ: اخْضَارَّتْ. وَإِنَّمَا قِيلَ لَهَا ذَاكَ لِأَنَّهَا إِذَا رَوِيَتْ فَكَأَنَّهَا سَوْدَاءُ. وَلِذَلِكَ يُقَالُ: إِدْهَامَّتْ.

# سَبِقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%A8%D9%90%D9%82%D9%8E/?book=9

(سَبِقَ) السِّينُ وَالْبَاءُ وَالْقَافُ أَصْلٌ وَاحِدٌ صَحِيحٌ يَدُلُّ عَلَى التَّقْدِيمِ. يُقَالُ سَبَقَ يَسْبِقُ سَبْقًا. فَأَمَّا السَّبَقُ فَهُوَ الْخَطَرُ الَّذِي يَأْخُذُهُ السَّابِقُ.

# مَهَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%87%D9%8E%D9%83%D9%8E/?book=9

(مَهَكَ) الْمِيمُ وَالْهَاءُ وَالْكَافُ لَيْسَ فِيهِ إِلَّا الْمُمَّهِكُ، وَهُوَ الطَّوِيلُ الْمُضْطَرِبُ. وَيَقُولُونَ لِلْقَوْسِ اللَّيِّنَةِ مَهُوكٌ. وَيَقُولُونَ لِلْفَرَسِ الذَّرِيعِ: مُمَّهِكٌ أَيْضًا، وَالْقِيَاسُ وَاحِدٌ.

# لَخَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AE%D9%8E%D8%AC%D9%8E/?book=9

(لَخَجَ) اللَّامُ وَالْخَاءُ وَالْجِيمُ. يَقُولُونَ: لَخِجَتْ عَيْنُهُ، إِذَا الْتَزَقَتْ. وَاللَّخَجُ: أَسْوَأُ الْغَمَصِ، وَلَيْسَ هَذَا عِنْدِي مُشْبِهًا كَلَامَ الْعَرَبِ.

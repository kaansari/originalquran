# صَدَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D8%AF%D9%8E%D8%AD%D9%8E/?book=9

(صَدَحَ) الصَّادُ وَالدَّالُ وَالْحَاءُ أُصَيْلٌ يَدُلُّ عَلَى صَوْتٍ. يُقَالُ: صَدَحَ الدِّيكُ وَالْغُرَابُ. وَكَانَ اللِّحْيَانِيُّ يَقُولُ: إِنَّهُ لَصَيْدَحٌ، أَيْ مُرْتَفِعُ الصَّوْتِ. وَيَقُولُونَ - وَلَيْسَ هُوَ مِنْ هَذَا الْقِيَاسِ -: إِنَّ الصُّدْحَةَ خَرَزَةٌ يُؤَخَّذُ بِهَا. وَيُقَالُ: الصَّدَحُ: الْإِكَامُ. وَاللَّهُ أَعْلَمُ.

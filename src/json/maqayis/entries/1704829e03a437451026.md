# زَغْرَبُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%BA%D9%92%D8%B1%D9%8E%D8%A8%D9%8F/?book=9

(الزَّغْرَبُ) وَهُوَ الْمَاءُ الْكَثِيرُ. فَهَذَا مِمَّا زِيدَتْ فِيهِ الزَّاءُ، وَالْأَصْلُ رَاجِعٌ إِلَى الْغَرَبِ، وَهُوَ مِنْ بَابِ كَثْرَةِ الْمَاءِ.

# زَيَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%8A%D9%8E%D9%85%D9%8E/?book=9

(زَيَمَ) الزَّاءُ وَالْيَاءُ وَالْمِيمُ أَصْلٌ يَدُلُّ عَلَى تَجَمُّعٍ. يُقَالُ لَحْمٌ زِيَمٌ، أَيْ مُكْتَنِزٌ. وَيُقَالُ اجْتَمَعَ النَّاسُ فَصَارُوا زِيَمًا. قَالَ الْخَلِيلُ:

وَالْخَيْلُ تَعْدُو زِيَمًا حَوْلَنَا

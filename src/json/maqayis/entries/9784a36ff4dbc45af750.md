# مَوَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%88%D9%8E%D9%86%D9%8E/?book=9

(مَوَنَ) الْمِيمُ وَالْوَاوُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ وَهِيَ الْمَوْنُ: أَنْ تَمُونَ عَيَالَكَ، أَيْ تَقُومَ بِكِفَايَتِهِمْ وَتَتَحَمَّلَ مَؤُونَتَهُمْ ; وَ [أَمَّا] الْمَؤُونَةُ فَمِنَ الْمَوْنِ، وَالْأَصْلُ فِيهَا مَوُونَةٌ بِغَيْرِ هَمْزَةٍ.

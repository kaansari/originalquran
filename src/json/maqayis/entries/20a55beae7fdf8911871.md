# خَطُوأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B7%D9%8F%D9%88%D8%A3%D9%8E/?book=9

(خَطُوأَ) الْخَاءُ وَالطَّاءُ وَالْحَرْفُ الْمُعْتَلُّ وَالْمَهْمُوزُ، يَدُلُّ عَلَى تَعَدِّي الشَّيْءِ، وَالذَّهَابِ عَنْهُ. يُقَالُ خَطَوْتُ أَخْطُو خُطْوَةً. وَالْخُطْوَةُ: مَا بَيْنَ الرِّجْلَيْنِ. وَالْخَطْوَةُ: الْمَرَّةُ الْوَاحِدَةُ.

وَالْخَطَاءُ مِنْ هَذَا ; لِأَنَّهُ مُجَاوَزَةُ حَدِّ الصَّوَابِ. يُقَالُ أَخْطَأَ إِذَا تَعَدَّى الصَّوَابَ. وَخَطِئَ يَخْطَأُ، إِذَا أَذْنَبَ، وَهُوَ قِيَاسُ الْبَابِ ; لِأَنَّهُ يَتْرُكُ الْوَجْهَ الْخَيْرَ.

# طَسَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%B3%D9%8E%D9%85%D9%8E/?book=9

(طَسَمَ) الطَّاءُ وَالسِّينُ وَالْمِيمُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ: طَسَمَ، مِثْلٌ طَمَسَ. وَطَسْمُ: قَبِيلَةٌ مِنْ عَادٍ.

مِنْ ذَلِكَ (الطَّلَنْفَحُ) وَهُوَ السَّمِينُ. وَهَذَا إِنِّمَا هُوَ تَهْوِيلٌ وَتَقْبِيحٌ، وَالزَّائِدُ فِيهِ اللَّامُ وَالنُّونُ، وَهُوَ مِنْ طَفَحَ، إِذَا امْتَلَأَ. وَمِنْهُ السَّكْرَانُ الطَّافِحُ، وَقَدْ مَرَّ.

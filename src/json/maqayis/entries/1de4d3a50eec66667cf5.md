# دَعَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%B9%D9%8E%D8%B3%D9%8E/?book=9

(دَعَسَ) الدَّالُ وَالْعَيْنُ وَالسِّينُ أُصَيْلٌ. وَهُوَ يَدُلُّ عَلَى دَفْعٍ وَتَأْثِيرٍ. فَالْمُدَاعَسَةُ: الْمُطَاعَنَةُ; لِأَنَّ الطَّاعِنَ يَدْفَعُ الْمَطْعُونَ. وَرُمْحٌ مِدْعَسٌ وَرِمَاحٌ مَدَاعِسُ. وَالدَّعْسُ: النِّكَاحُ; وَهَذَا تَشْبِيهٌ. وَالدَّعْسُ: الْأَثَرُ، وَهُوَ ذَاكَ; لِأَنَّ الْمُؤَثِّرَ يَدْفَعُ ذَلِكَ الشَّيْءَ حِينَ يُؤَثَّرُ فِيهِ.

# تَرِزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%B1%D9%90%D8%B2%D9%8E/?book=9

(تَرِزَ) التَّاءُ وَالرَّاءُ وَالزَّاءُ كَلِمَةٌ وَاحِدَةٌ صَحِيحَةٌ. تَرِزَ الشَّيْءُ صَلُبَ. وَكُلُّ مُسْتَحْكِمٍ تَارِزٌ. وَالْمَيِّتُ تَارِزٌ ; لِأَنَّهُ قَدْ يَبِسَ. قَالَ:

كَأَنَّ الَّذِي يُرْمَى مِنَ الْوَحْشِ تَارِزٌ

وَقَالَ امْرُؤُ الْقَيْسِ - وَيَدُلُّ عَلَى أَنَّ التَّارِزَ الصُّلْبُ -:

بِعَجْلَِزَةٍ قَدْ أَتْرَزَ الْجَرْيُ لَحْمَهَا ... كَمَيْتٍ كَأَنَّهَا هِرَاوَةُ مِنْوَالِ

وَيُقَالُ أَتْرَزَتِ الْمَرْأَةُ حَبْلَهَا: فَتَلَتْهُ فَتْلًا شَدِيدًا. وَأَتْرَزَتْ عَجِينَهَا إِذَا مَلَكَتْهُ.

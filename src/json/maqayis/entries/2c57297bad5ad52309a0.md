# فَحَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AD%D9%8E%D8%AC%D9%8E/?book=9

(فَحَجَ) الْفَاءُ وَالْحَاءُ وَالْجِيمُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْفَحَجُ، وَهُوَ تَبَاعُدُ مَا بَيْنَ أَوْسَاطِ السَّاقَيْنِ فِي الْإِنْسَانِ وَالدَّابَّةِ. وَالنَّعْتُ أَفْحَجُ وَفَحْجَاءُ، وَالْجَمْعُ فُحْجٌ.

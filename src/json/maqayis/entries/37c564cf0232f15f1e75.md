# الْعَثْجَلُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D8%AB%D9%92%D8%AC%D9%8E%D9%84%D9%8F/?book=9

(الْعَثْجَلُ) : الْوَاسِعُ الضَّخْمُ مِنَ الْأَسْقِيَةِ وَالْأَوْعِيَةِ. قَالَ:

يَسْقِي بِهِ ذَاتَ فُرُوغٍ عَثْجَلَا

وَهَذَا مِمَّا زِيدَتْ فِيهِ الْعَيْنُ، وَإِنَّمَا هُوَ مِنَ الثُّجْلَةِ. وَالْأَثْجَلُ: الْبَطْنُ الْوَاسِعُ.

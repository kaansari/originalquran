# شَوَذَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%88%D9%8E%D8%B0%D9%8E/?book=9

(شَوَذَ) الشِّينُ وَالْوَاوُ وَالذَّالُ لَيْسَ فِيهِ إِلَّا الْمِشْوَذُ، وَهِيَ الْعِمَامَةُ. قَالَ الْوَلِيدُ بْنُ عُقْبَةَ: إِذَا مَا شَدَدْتُ الرَّأْسَ مِنِّي بِمِشْوَذٍ ... فَغَيَّكِ مِنِّي تَغْلِبَ ابْنَةَ وَائِلِ

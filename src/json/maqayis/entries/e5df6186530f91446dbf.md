# رَمَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%85%D9%8E%D8%B7%D9%8E/?book=9

(رَمَطَ) الرَّاءُ وَالْمِيمُ وَالطَّاءُ لَيْسَ أَصْلًا، لَكِنَّهُمْ يُسَمُّونَ مَا اجْتَمَعَ مِنَ الْعُرْفُطِ وَغَيْرِهِ مِنْ شَجَرِ الْعِضَاهِ رَمْطًا. وَرُبَّمَا قَالُوا رَمَطْتُ الرَّجُلَ، إِذَا عِبْتَهُ رَمْطًا. وَفِيهِ نَظَرٌ.

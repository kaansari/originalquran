# رَثَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%AB%D9%8E%D8%B9%D9%8E/?book=9

(رَثَعَ) الرَّاءُ وَالثَّاءُ وَالْعَيْنُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى جَشَعٍ وَطَمَعٍ. كَذَا قَالَ الْخَلِيلُ: إِنَّ الرَّثَعَ الطَّمَعُ وَالْحِرْصُ. قَالَ الْكِسَائِيُّ: رَجُلٌ رَاثِعٌ، وَهُوَ الَّذِي يَرْضَى مِنَ الْعَطِيَّةِ بِالطَّفِيفِ وَيُخَادِنُ أَخْدَانَ السَّوْءِ. يُقَالُ رَثِعَ رَثَعًا.

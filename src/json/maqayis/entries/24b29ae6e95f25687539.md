# لَقَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%82%D9%8E%D8%B3%D9%8E/?book=9

(لَقَسَ) اللَّامُ وَالْقَافُ وَالسِّينُ كَلِمَةٌ تَدُلُّ عَلَى نَعْتٍ غَيْرِ مَرْضِيٍّ. وَلَقِسَتْ نَفْسُهُ مِنَ الشَّيْءِ: غَثَتْ. وَاللَّقِسُ: الرَّجُلُ السَّيِّئُ الْخُلُقِ، الشَّرِهُ الْحَرِيصُ. وَاللَّقَسُ الْمَصْدَرُ. وَاللَّاقِسُ: الْعَيَّابُ. وَلَقَسْتُ الرَّجُلَ أَلْقُسُهُ: عِبْتُهُ.

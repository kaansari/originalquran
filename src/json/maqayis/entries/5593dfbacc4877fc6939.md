# شَبَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%A8%D9%8E%D9%87%D9%8E/?book=9

(شَبَهَ) الشِّينُ وَالْبَاءُ وَالْهَاءُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى تَشَابُهِ الشَّيْءِ وَتَشَاكُلِهِ لَوْنًا وَوَصْفًا. يُقَالُ شِبْهٌ وَشَبَهٌ وَشَبِيهٌ. وَالشَّبَهُ مِنَ الْجَوَاهِرِ: الَّذِي يُشْبِهُ الذَّهَبَ. وَالْمُشَبِّهَاتُ مِنَ الْأُمُورِ: الْمُشْكِلَاتُ. وَاشْتَبَهَ الْأَمْرَانِ، إِذَا أَشْكَلَا.

وَمِمَّا شَذَّ عَنْ ذَلِكَ الشَّبَهَانُ.

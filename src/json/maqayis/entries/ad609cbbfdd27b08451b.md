# الْعِنْفِصُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%90%D9%86%D9%92%D9%81%D9%90%D8%B5%D9%8F/?book=9

(الْعِنْفِصُ) : الْمَرْأَةُ الْقَلِيلَةُ، وَيُقَالُ هِيَ الْخَبِيثَةُ الدَّاعِرَةُ. قَالَ الْأَعْشَى:

لَيْسَتْ بِسَوْدَاءَ وَلَا عِنْفِصٍ ... تُسَارِقُ الطَرْفَ إِلَى دَاعِرِ

وَهَذَا الْقَوْلُ الثَّانِي أَقْيَسُ، وَهُوَ مِنْ عَفَصْتُ الشَّيْءَ، إِذَا لَوَيْتُهُ، كَأَنَّهَا عَوْجَاءُ الْخُلُقِ وَتَمِيلُ إِلَى ذَوِي الدَّعَارَةِ.

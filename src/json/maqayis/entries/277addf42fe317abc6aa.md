# شَيَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%8A%D9%8E%D9%82%D9%8E/?book=9

(شَيَقَ) الوَالْيَاءُ وَالْقَافُ كَلِمَةٌ. يُقَالُ إِنَّ الشِّيقَ الشَّقُّ الضَّيِّقُ فِي رَأْسِ الْجَبَلِ. قَالَ:

شَغْوَاءُ تُوطَنُ بَيْنَ الشِّيقِ وَالنِّيقِ

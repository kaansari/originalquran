# طَمَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D9%85%D9%8E%D9%86%D9%8E/?book=9

(طَمَنَ) الطَّاءُ وَالْمِيمُ وَالنُّونُ أُصَيْلٌ بِزِيَادَةِ هَمْزَةٍ. يُقَالُ: اطْمَأَنَّ الْمَكَانُ يَطْمَئِنُّ طُمَأْنِينَةً. وَطَامَنْتُ مِنْهُ: سَكَّنْتُ.

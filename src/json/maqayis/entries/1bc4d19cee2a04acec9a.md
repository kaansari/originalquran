# لَحَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AD%D9%8E%D8%B5%D9%8E/?book=9

(لَحَصَ) اللَّامُ وَالْحَاءُ وَالصَّادُ كَلِمَةٌ تَدُلُّ عَلَى ضِيقٍ فِي شَيْءٍ. يُقَالُ: لَحِصَ يَلْحَصُ لَحَصًا. قَالَ:

قَدْ كُنْتُ خَرَّاجًا وَلُوجًا صَيْرَفًا ... لَمْ تَلْتَحِصْنِي حَيْصَ بَيْصَ لَحَاصِ

أَيْ لَمْ أَنْشَبْ فِيهَا. وَلَحَاصِ فَعَالٍ مِنْهُ. وَيُقَالُ: الْتَحَصَتِ الْإِبْرَةُ، إِذَا انْسَدَّ سَمُّهَا.

# دَأَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%A3%D9%8E%D9%84%D9%8E/?book=9

(دَأَلَ) الدَّالُ وَالْهَمْزَةُ وَاللَّامُ يَدُلُّ عَلَى خِفَّةٍ وَنَشْطَةٍ. فَالدَّأَلَانُ: الْمَشْيُ بِنَشَاطٍ. يُقَالُ مِنْهُ دَأَلْتُ أَدْأَلُ. وَالدَّأْلُ: الْخَتْلُ. وَيَقُولُونَ: الدُّؤْلُولُ الدَّاهِيَةُ; وَهُوَ قَرِيبٌ مِنَ الْبَابِ. وَالدُّؤَلُ قَبِيلَةٌ.

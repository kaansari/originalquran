# رَيَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%8A%D9%8E%D8%B3%D9%8E/?book=9

(رَيَسَ) الرَّاءُ وَالْيَاءُ وَالسِّينُ كَلِمَتَانِ مُتَفَاوِتٌ مَا بَيْنَهُمَا. فَالرِّيَاسُ: قَائِمُ السَّيْفِ. [قَالَ] :

إِلَى بَطَلَيْنِ يَعْثُرَانِ كِلَاهُمَا ... يُدِيرُ رِيَاسَ السَّيْفِ وَالسَّيْفُ نَادِرُ وَقَالَ آخَرُ:

وَمِرْفَقٍ كِرِيَاسِ السَّيْفِ إِذْ شَسَفَا

وَالْكَلِمَةُ الْأُخْرَى: الرَّيْسُ وَالرَّيَسَانُ: التَّبَخْتُرُ. قَالَ:

أَتَاهُمْ بَيْنَ أَرْحُلِهِمْ يَرِيسُ

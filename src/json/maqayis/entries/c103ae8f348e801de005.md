# لَهَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%87%D9%8E%D9%81%D9%8E/?book=9

(لَهَفَ) اللَّامُ وَالْهَاءُ وَالْفَاءُ كَلِمَةٌ تَدُلُّ عَلَى تَحَسُّرٍ. يُقَالُ: تَلَهَّفَ عَلَى الشَّيْءِ، وَلَهِفَ، إِذَا حَزِنَ وَتَحَسَّرَ. وَالْمَلْهُوفُ: الْمَظْلُومُ يَسْتَغِيثُ.

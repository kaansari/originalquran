# طَوَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D9%88%D9%8E%D8%AD%D9%8E/?book=9

(طَوَحَ) الطَّاءُ وَالْوَاوُ وَالْحَاءُ لَيْسَ بِأَصْلٍ، وَكَأَنَّهُ مِنْ بَابِ الْإِبْدَالِ. يُقَالُ: طَاحَ يَطِيحُ. ثُمَّ يَقُولُونَ: طَاحَ يَطُوحُ، أَيْ هَلَكَ.

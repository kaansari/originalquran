# حَبَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%A8%D9%8E%D8%B5%D9%8E/?book=9

(حَبَصَ) الْحَاءُ وَالْبَاءُ وَالصَّادُ لَيْسَ أَصْلًا. وَيَزْعُمُونَ أَنَّ فِيهِ كَلِمَةً وَاحِدَةً.

ذَكَرَ ابْنُ دُرَيْدٍ: حَبَصَ الْفَرَسُ، إِذَا عَدَا عَدْوًا شَدِيدًا.

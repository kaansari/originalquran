# كَأَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D8%A3%D9%8E%D8%AF%D9%8E/?book=9

(كَأَدَ) الْكَافُ وَالْأَلِفُ وَالدَّالُ يَدُلُّ عَلَى شِدَّةٍ وَمَشَقَّةٍ. يَقُولُونَ: تَكَاءَدَهُ الْأَمْرُ، إِذَا صَعُبَ عَلَيْهِ. وَالْعَقَبَةُ الْكَؤُودُ: الصَّعْبَةُ.

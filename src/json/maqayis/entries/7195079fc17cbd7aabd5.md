# وَصَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B5%D9%91%D9%8E/?book=9

(وَصَّ) الْوَاوُ وَالصَّادُ: كَلِمَةٌ تَدُلُّ عَلَى نَظَرٍ مِنْ خَرْقٍ، أَوْ خَرْقٍ يُنْظَرُ مِنْهُ. الْوَصْوَاصُ: الْبُرْقُعُ. وَوَصْوَصَ الْجَرْوُ: فَتَّحَ عَيْنَيْهِ. وَوَصْوَصَ فُلَانٌ: نَظَرَ بِعَيْنَيْهِ يُصَغِّرُهُمَا. وَحِجَارَةٌ الْأَيَادِيمِ، أَيْ مُتُونِ الْأَرْضِ: وَصَاوِصُ عَلَى التَّشْبِيهِ، لِأَنَّهَا تَبْرُقُ كَالْعُيُونِ. قَالَ:

بِصُلَّبَاتٍ تَقِصُ الْوَصَاوِصَا

# مَثَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AB%D9%91%D9%8E/?book=9

(مَثَّ) الْمِيمُ وَالثَّاءُ كَلِمَتَانِ. يَقُولُونَ: مَثَّ يَدَهُ: مَسَحَهَا وَمَثَّ الشَّيْءُ، إِذَا كَانَ يَرْشَحُ دَسَمًا. وَقَالَ ابْنُ دُرَيْدٍ: مَثَّ شَارِبُهُ، إِذَا أَكَلَ دَسَمَاً فَبَقِيَ عَلَيْهِ.

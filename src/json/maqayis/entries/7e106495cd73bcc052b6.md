# سَأَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%A3%D9%8E%D8%AF%D9%8E/?book=9

(سَأَدَ) السِّينُ وَالْهَمْزَةُ وَالدَّالُ كَلِمَتَانِ لَا يَنْقَاسَانِ. فَالْإِسْآدُ: دَأَبُ السَّيْرِ بِاللَّيْلِ.

وَالْكَلِمَةُ الْأُخْرَى السَّأَدُ: انْتِقَاضُ الْجُرْحِ. وَأَنْشَدَ:

فَبِتُّ مِنْ ذَاكَ سَاهِرًا أَرِقًا ... أَلْقَى لِقَاءَ اللَّاقِي مِنَ السَّأَدِ

وَرُبَّمَا قَالُوا: سَأَدَتِ الْإِبِلُ الْمَاءَ: عَافَتْهُ.

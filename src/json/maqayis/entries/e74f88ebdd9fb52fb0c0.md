# قَحَوَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%AD%D9%8E%D9%88%D9%8E/?book=9

(قَحَوَ) الْقَافُ وَالْحَاءُ وَالْوَاوُ كَلِمَةٌ وَاحِدَةٌ. يَقُولُونَ: الْقَحْوُ تَأْسِيسُ الْأُقْحُوَانِ، وَتَقْدِيرُهُ أُفْعُلَانُ، وَلَوْ جُعِلَ فِي دَوَاءٍ لَقِيلَ مَقْحُوٌّ، وَجَمْعُهُ الْأَقَاحِي. وَالْأُقْحُوَانَةُ: مَوْضِعٌ.

# زَقَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%82%D9%8E%D9%84%D9%8E/?book=9

(زَقَلَ) الزَّاءُ وَالْقَافُ وَاللَّامُ لَيْسَ بِشَيْءٍ. عَلَى أَنَّهُ حُكِيَ عَنْ بَعْضِ الْعَرَبِ: زَوْقَلَ فُلَانٌ عِمَامَتَهُ، إِذَا أَرْخَى طَرَفَيْهَا مِنْ نَاحِيَتَيْ رَأْسِهِ.

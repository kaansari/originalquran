# لَسَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B3%D9%8E%D9%85%D9%8E/?book=9

(لَسَمَ) اللَّامُ وَالسِّينُ وَالْمِيمُ لَيْسَ بِأَصْلٍ. يَقُولُونَ فِي بَابِ الْإِبْدَالِ، أَلْسَمْتُ الرَّجُلَ الْحُجَّةَ: أَلْزَمْتُهُ إِيَّاهَا. وَأَلْسَمْتُهُ الطَّرِيقَ: أَلْزَمْتُهُ إِيَّاهُ.

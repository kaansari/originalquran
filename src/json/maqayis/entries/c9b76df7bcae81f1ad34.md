# أَذَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%B0%D9%91%D9%8E/?book=9

(أَذَّ) وَأَمَّا الْهَمْزَةُ وَالذَّالُ فَلَيْسَ بِأَصْلٍ، وَذَلِكَ أَنَّ الْهَمْزَةَ فِيهِ مُحَوَّلَةٌ مِنْ هَاءٍ، وَقَدْ ذُكِرَ فِي الْهَاءِ. قَالَ ابْنُ دُرَيْدٍ: أَذَّ يَؤُذُّ أَذًّا: قَطَعَ، مِثْلَ هَذَّ. وَشَفْرَةٌ أَذُوذٌ: قَطَّاعَةٌ. أَنْشَدَ الْمُفَضَّلُ:

يَؤُذُّ بِالشَّفْرَةِ أَيَّ أَذِّ ... مِنْ قَمَعٍ وَمَأْنَةٍ وَفَلْذِ

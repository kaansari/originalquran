# زَوُحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%88%D9%8F%D8%AD%D9%8E/?book=9

(زَوُحَ) الزَّاءُ وَالْوَاوُ وَالْحَاءُ أَصْلٌ يَدُلُّ عَلَى تَنَحٍّ وَزَوَالٍ. يَقُولُ زَاحَ عَنْ مَكَانِهِ يَزُوحُ، إِذَا تَنَحَّى، وَأَزَحْتُهُ أَنَا. وَرُبَّمَا قَالُوا: أَزَاحَ يُزِيحُ.

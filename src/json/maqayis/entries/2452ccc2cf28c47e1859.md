# الْعَمَلَّطُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D9%85%D9%8E%D9%84%D9%91%D9%8E%D8%B7%D9%8F/?book=9

(الْعَمَلَّطُ) : الشَّدِيدُ مِنَ الرِّجَالِ وَكَذَلِكَ مِنَ الْإِبِلِ. وَقَالَ:

أَمَا رَأَيْتَ الرَّجُلَ الْعَمَلَّطَا وَهَذَا مِمَّا زِيدَتْ فِيهِ الْعَيْنُ، وَإِنَّمَا هُوَ مِنَ الْمِلْطِ وَقَدْ ذُكِرَ فِي بَابِهِ.

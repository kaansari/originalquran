# مَلَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%84%D9%8E%D8%AC%D9%8E/?book=9

(مَلَجَ) الْمِيمُ وَاللَّامُ وَالْجِيمُ كَلِمَةٌ. يُقَالُ: مَلَجَ الصَّبِيُّ: تَنَاوَلَ الثَّدْيَ لِلرَّضَاعِ بِأَدْنَى فَمِهِ. وَفِي الْحَدِيثِ: " لَا تُحَرِّمُ الْإِمْلَاجَةُ وَالْإِمْلَاجَتَانِ " وَهِيَ أَنْ تُمِصَّهُ لَبَنَهَا مَرَّةً أَوْ مَرَّتَيْنِ.

# حَتَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%AA%D9%8E%D9%81%D9%8E/?book=9

(حَتَفَ) الْحَاءُ وَالتَّاءُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ لَا يُقَاسُ عَلَيْهَا ; وَذَلِكَ أَنَّهُ إِلَّا يُبْنَى مِنْهَا فِعْلٌ، وَهُوَ الْحَتْفُ، وَجَمْعُهُ حُتُوفٌ، وَهُوَ الْهَلَاكُ.

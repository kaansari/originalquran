# ضَطَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D8%B7%D9%8E%D8%B1%D9%8E/?book=9

(ضَطَرَ) الضَّادُ وَالطَّاءُ وَالرَّاءُ كَلِمَةٌ تَدُلُّ عَلَى ضِخَمٍ. وَيَقُولُونَ: وَيَكُونُ مَعَ ذَلِكَ لُؤْمٌ. وَقَالَ أَبُو عُبَيْدٍ: الضَّيْطَرُ: الْعَظِيمُ، وَجَمْعُهُ ضَيْطَارُونَ وَضَيَاطِرَةٌ. وَأَنْشَدَ: تَعَرَّضَ ضَيْطَارُو فُعَالَةَ دُونَنَا ... وَمَا خَيْرَ ضَيْطَارٍ يُقَلِّبُ مِسْطَحَا

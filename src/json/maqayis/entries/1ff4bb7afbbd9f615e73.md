# ثَرْمٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%B1%D9%92%D9%85%D9%8C/?book=9

(ثَرْمٌ) الثَّاءُ وَالرَّاءُ وَالْمِيمُ كَلِمَةٌ وَاحِدَةٌ يُشْتَقُّ مِنْهَا، يُقَالُ ثَرَمْتُ الرَّجُلَ فَثَرِمَ، وَثَرَمْتُ ثَنِيَّتَهُ فَانْثَرَمَتْ. وَالثَّرْمَاءُ: مَاءٌ لِكِنْدَةَ.

# هَقَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%82%D9%8E%D9%85%D9%8E/?book=9

(هَقَمَ) الْهَاءُ وَالْقَافُ وَالْمِيمُ: يَدُلُّ عَلَى اتِّسَاعٍ وَعِظَمٍ. وَيُقَالُ لِلْبَحْرِ هِقَمٌّ، لِعِظَمِهِ وَبُعْدِ قَعْرِهِ. وَصَوْتُهُ هَيْقَمٌ. قَالَ:

كَالْبَحْرِ يَدْعُو هَيْقَمًا وَهَيْقَمًا.

وَيُقَالُ: الْهِقَمُّ: الرَّجُلُ الْكَثِيرُ الْأَكْلِ. وَيُقَالُ: الْهَيْقَمُ: الظَّلِيمُ الْعَظِيمُ.

# نَأَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%A3%D9%8E%D8%AA%D9%8E/?book=9

(نَأَتَ) النُّونُ وَالْهَمْزَةُ وَالتَّاءُ كَلِمَةٌ تَدُلُّ عَلَى حِكَايَةِ صَوْتٍ. يُقَالُ: نَأَتَ الرَّجُلُ نَئِيتًا، مِثْلُ نَهَتَ، إِذَا أَنَّ. وَرَجُلٌ نَآتٌ مِثْلُ نَهَّاتٍ.

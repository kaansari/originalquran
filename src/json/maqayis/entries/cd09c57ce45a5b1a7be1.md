# تَنَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D9%86%D9%8E%D8%AE%D9%8E/?book=9

(تَنَخَ) التَّاءُ وَالنُّونُ وَالْخَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ الْإِقَامَةُ. يُقَالَ تَنَخَ بِالْمَكَانِ تُنُوخًا، وَتَتَنَّخَ تَتَنُّخًا إِذَا أَقَامَ بِهِ، وَبِذَلِكَ سُمِّيَتْ تَنُوخُ، وَهِيَ أَحْيَاءٌ مِنَ الْعَرَبِ اجْتَمَعُوا وَتَحَالَفُوا، فَتَنَخُوا، أَيْ أَقَامُوا فِي مَوَاضِعِهِمْ.

# كَدَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D8%AF%D9%8E%D8%A8%D9%8E/?book=9

(كَدَبَ) الْكَافُ وَالدَّالُ وَالْبَاءُ، يُقَالُ فِيهِ كَلِمَةٌ. قَالُوا: إِنَّ الْكَدِبَ: الدَّمُ الطَّرِيُّ. وَرُوِيَ أَنَّ بَعْضَهُمْ قَرَأَ: وَجَاؤُوا عَلَى قَمِيصِهِ بِدَمٍ كَدِبٍ.

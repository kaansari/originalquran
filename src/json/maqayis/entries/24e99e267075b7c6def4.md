# شَيَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%8A%D9%8E%D8%A3%D9%8E/?book=9

(شَيَأَ) الشِّينُ وَالْيَاءُ وَالْهَمْزَةُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ شَيَّأَ اللَّهُ وَجْهَهُ ; إِذَا دَعَا عَلَيْهِ بِالْقُبْحِ. وَوَجْهٌ مُشَيَّأٌ. وَأَنْشَدَ: إِنَّ بَنِي فَزَارَةَ بْنِ ذُبْيَانْ ... قَدْ طَرَّقَتْ نَاقَتُهُمْ بِإِنْسَانْ

مُشَيَّأٍ أَعْجِبْ بِخَلْقِ الرَّحْمَنِ

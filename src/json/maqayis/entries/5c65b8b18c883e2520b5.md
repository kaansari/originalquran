# ثَدَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%AF%D9%8E%D9%82%D9%8E/?book=9

(ثَدَقَ) الثَّاءُ وَالدَّالُ وَالْقَافُ كَلِمَةٌ وَاحِدَةٌ. ثَدَقَ الْمَطَرُ، وَسَحَابٌ ثَادِقٌ. وَثَادِقٌ اسْمُ فُرْسٍ، كَأَنَّ صَاحِبَهُ شَبَّهَهُ بِالسَّحَابِ. قَالَ:

بَاتَتْ تَلُومُ عَلَى ثَادِقٍ ... لِيُشْرَى فَقَدْ جَدَّ عِصْيَانُهَا

أَيْ عِصْيَانِي لَهَا. لِيُشْرَى: لِيُبَاعَ.

# حَثِلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%AB%D9%90%D9%84%D9%8E/?book=9

(حَثِلَ) الْحَاءُ وَالثَّاءُ وَاللَّامُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى سُوءٍ وَحَقَارَةٍ. فَحُثَالَةُ الْبُرِّ: رَدِيُّهُ. وَحُثَالَةُ الدُّهْنِ وَمَا أَشْبَهَهُ: ثُفْلُهُ. وَالْمُحْثَلُ: السَّيِّئُ الْغِذَاءِ. قَالَ مُتَمِّمٌ:

وَأَرْمَلَةٍ تَمْشِي بَأَشْعَثَ مُحْثَلٍ ... كَفَرْخِ الْحُبَارَى رَأْسُهُ قَدْ تَصَوَّعَا

شَبَّهَهُ بِفَرْخِ الْحُبَارَى لِأَنَّهُ قَبِيحُ الْمَنْظَرِ مُنَتَّفُ الرِّيشِ.

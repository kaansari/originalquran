# مَطَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B7%D9%91%D9%8E/?book=9

(مَطَّ) الْمِيمُ وَالطَّاءُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى مَدِّ الشَّيْءِ. وَمَطَّهُ: مَدَّهُ. وَالْقِيَاسُ فِيهِ وَفِي الْمُطَيْطَاءِ وَاحِدٌ، وَهُوَ الْمَشْيُ بِتَبَخْتُرٍ، لِأَنَّهُ إِذَا فَعَلَ مَطَّ أَطْرَافَهُ. قَالَ اللَّهُ تَعَالَى: ثُمَّ ذَهَبَ إِلَى أَهْلِهِ يَتَمَطَّى، قَالُوا: أَصْلُهُ يَتَمَطَّطُ، فَجُعِلَتِ الطَّاءُ الثَّالِثَةُ يَاءً لِلتَّخْفِيفِ، وَمَطَّ حَاجِبَيْهِ: تَكَبَّرَ، وَهُوَ مِنْهُ. وَمِنْهُ الْمَطِيطَةُ: الْمَاءُ الْمُخْتَلِطُ بِالطِّينِ ; وَهَذَا يَكُونُ إِذَا مَدَّ الْمَاءَ مِيَاهُ سَيْلٍ كَدِرَةٍ.

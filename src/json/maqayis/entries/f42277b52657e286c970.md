# كَيَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%8A%D9%8E%D8%AD%D9%8E/?book=9

(كَيَحَ) الْكَافُ وَالْيَاءُ وَالْحَاءُ كَلِمَةٌ وَاحِدَةٌ. يَقُولُونَ: الْكِيحُ: سَنَدُ الْجَبَلِ. قَالَ الشَّنْفَرَى:

وَيَرْكُضْنَ بِالْآصَالِ حَوْلِي كَأَنَّنِي ... مِنَ الْعُصْمِ أَدْفَى يَنْتَحِي الْكِيحَ أَعْقَلُ.

وَقَدْ تَكُونُ الْأَلِفُ مُنْقَلِبَةً وَتُكْتَبُ هَاهُنَا لِلَّفْظِ، وَقَدْ تَكُونُ مَهْمُوزَةً.

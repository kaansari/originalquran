# ضَبَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D8%A8%D9%8E%D8%B7%D9%8E/?book=9

(ضَبَطَ) الضَّادُ وَالْبَاءُ وَالطَّاءُ أَصْلٌ صَحِيحٌ. ضَبَطَ الشَّيْءَ ضَبْطًا. وَالْأَضْبَطُ: الَّذِي يَعْمَلُ بِيَدَيْهِ جَمِيعًا. وَيُقَالُ: نَاقَةٌ ضَبْطَاءُ. قَالَ: عُذَافِرَةٌ ضَبْطَاءُ تَخْدِي كَأَنَّهَا ... فَنِيقٌ غَدَا يَحْوِي السَّوَامَ السَّوَارِحَا

وَفِي الْحَدِيثِ: «أَنَّهُ سُئِلَ عَنِ الْأَضْبَطِ» .

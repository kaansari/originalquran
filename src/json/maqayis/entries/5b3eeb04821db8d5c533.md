# نَتَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%AA%D9%8E%D8%AC%D9%8E/?book=9

(نَتَجَ) النُّونُ وَالتَّاءُ وَالْجِيمُ كَلِمَةٌ وَاحِدَةٌ، هِيَ النِّتَاجُ. وَنُتِجَتِ النَّاقَةُ ; وَنَتَجَهَا أَهْلُهَا. وَفَرَسٌ نَتُوجٌ: اسْتَبَانَ نِتَاجُهَا.

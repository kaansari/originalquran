# جَأَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%A3%D9%8E%D9%81%D9%8E/?book=9

(جَأَفَ) الْجِيمُ وَالْهَمْزَةُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى الْفَزَعِ. وَكَأَنَّ الْفَاءَ [بَدَلٌ] مِنَ الثَّاءِ، يُقَالُ جُئِفَ الرَّجُلُ مِثْلَ جُئِثَ.

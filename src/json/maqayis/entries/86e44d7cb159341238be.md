# حَلَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%84%D9%8E%D8%B2%D9%8E/?book=9

(حَلَزَ) الْحَاءُ وَاللَّامُ وَالزَّاءُ أَصْلٌ صَحِيحٌ. يُقَالُ لِلرَّجُلِ الْقَصِيرِ حِلِّزٌ، وَيُقَالُ هُوَ السَّيِّئُ الْخُلُقُ. وَيُقَالُ الْحَلْزُ ; الْقَشْرُ ; حَلَزْتُ الْأَدِيمَ قَشَرْتُهُ. قَالَ ابْنُ الْأَعْرَابِيِّ: وَمِنْهُ الْحَارِثُ بْنُ حِلِّزَةَ.

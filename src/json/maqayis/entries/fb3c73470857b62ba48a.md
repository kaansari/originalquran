# صَمَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%85%D9%8E%D8%AC%D9%8E/?book=9

(صَمَجَ) الصَّادُ وَالْمِيمُ وَالْجِيمُ لَيْسَ بِشَيْءٍ، عَلَى أَنَّهُمْ يَقُولُونَ: الصَّمَجُ: الْقَنَادِيلُ، الْوَاحِدَةُ صَمَجَةٌ. وَيُنْشِدُونَ:

وَالنَّجْمُ مِثْلُ الصَّمَجِ الرُّومِيَّاتْ

# فَجَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AC%D9%8E%D9%85%D9%8E/?book=9

(فَجَمَ) الْفَاءُ وَالْجِيمُ وَالْمِيمُ. زَعَمَ ابْنُ دُرَيْدٍ: تَفَجَّمَ الْوَادِي وَانْفَجَمَ، إِذَا اتَّسَعَ. وَهَذِهِ فُجْمَةُ الْوَادِي، أَيْ مُتَّسَعُهُ.

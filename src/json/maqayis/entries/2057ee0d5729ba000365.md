# دَلَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%84%D9%8E%D8%B9%D9%8E/?book=9

(دَلَعَ) الدَّالُ وَاللَّامُ وَالْعَيْنُ أُصَيْلٌ يَدُلُّ عَلَى خُرُوجٍ. تَقُولُ: دَلَعَ لِسَانُهُ: خَرَجَ. وَدَلَعَهُ هُوَ، إِذَا أَخْرَجَهُ. وَالدَّلِيعُ: الطَّرِيقُ السَّهْلُ. وَيُقَالُ انْدَلَعَ بَطْنُهُ، إِذَا أَخْرَجَ أَمَامَهُ.

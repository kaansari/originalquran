# خَوَضَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%88%D9%8E%D8%B6%D9%8E/?book=9

(خَوَضَ) الْخَاءُ وَالْوَاوُ وَالضَّادُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى تَوَسُّطِ شَيْءٍ وَدُخُولٍ. يُقَالُ خُضْتُ الْمَاءَ وَغَيْرَهُ. وَتَخَاوَضُوا فِي الْحَدِيثِ وَالْأَمْرِ، أَيْ تَفَاوَضُوا وَتَدَاخَلَ كَلَامُهُمْ.

# رَشَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%B4%D9%8E%D8%AD%D9%8E/?book=9

(رَشَحَ) الرَّاءُ وَالشِّينُ وَالْحَاءُ أَصْلٌ وَاحِدٌ; وَهُوَ النَّدَى يَبْدُو مِنَ الشَّيْءِ. فَالرَّشْحُ: الْعَرَقُ. يُقَالُ رَشَحَ بَدَنُهُ بِعَرَقِهِ. فَأَمَّا قَوْلُهُمْ يُرَشَّحُ لِكَذَا، فَهُوَ مِنْ هَذَا، وَأَصْلُهُ الْوَحْشِيَّةُ إِذَا بَلَغَ وَلَدُهَا أَنْ يَمْشِيَ مَعَهَا مَشَتْ بِهِ حَتَّى يَرْشَحَ عَرَقًا فَيَقْوَى; ثُمَّ اسْتُعِيرَ ذَلِكَ لِكُلِّ مَنْ رُبِّيَ، فَقِيلَ يُرَشَّحُ لِلْخِلَافَةِ; كَأَنَّهُ يُرَبَّى لَهَا. وَالرَّاشِحُ: الْجَبَلُ يَنْدَى أَصْلُهُ. وَرَشَّحَ النَّدَى النَّبْتَ، إِذَا رَبَّاهُ. وَأَرْشَحَتِ النَّاقَةُ، إِذَا دَنَا فِطَامُ وَلَدِهَا، وَذَلِكَ هُوَ عِنْدَمَا تَفْعَلُ. وَقَالَ: كَأَنَّ فِيهِ عِشَارًا جِلَّةً شُرُفًا ... مِنْ آخِرِ الصَّيْفِ قَدْ هَمَّتْ بِإِرْشَاحِ

# جَبَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%A8%D9%8E%D9%86%D9%8E/?book=9

(جَبَنَ) الْجِيمُ وَالْبَاءُ وَالنُّونُ ثَلَاثُ كَلِمَاتٍ لَا يُقَاسُ بَعْضُهَا بِبَعْضٍ. فَالْجُبْنُ: الَّذِي يُؤْكَلُ، وَرُبَّمَا ثُقِّلَتْ نُونُهُ مَعَ ضَمِّ الْبَاءِ. وَالْجُبْنُ: صِفَةُ الْجَبَانِ. وَالْجَبِينَانُ: مَا عَنْ يَمِينِ الْجَبْهَةِ وَشِمَالِهَا، كُلُّ وَاحِدٍ مِنْهُمَا جَبِينٌ.

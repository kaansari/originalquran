# ضَخَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D8%AE%D9%91%D9%8E/?book=9

(ضَخَّ) الضَّادُ وَالْخَاءُ لَيْسَ بِشَيْءٍ. عَلَى أَنَّهُمْ يَقُولُونَ: الضَّخُّ: امْتِدَادُ الْبَوْلِ. وَالْمِضَخَّةُ: قَصَبَةٌ يُرْمَى بِهَا الْمَاءُ فَيَمْتَدُّ.

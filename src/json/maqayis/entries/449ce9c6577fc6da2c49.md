# نَكَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%83%D9%8E%D9%87%D9%8E/?book=9

(نَكَهَ) النُّونُ وَالْكَافُ وَالْهَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ نَكْهَةُ الْإِنْسَانِ. وَاسْتَنْكَهْتُهُ: تَشَمَّمْتُ رِيحَ فَمِهِ. وَيَقُولُونَ وَمَا أَدْرِي كَيْفَ هُوَ: إِنَّ النُّكَّهَ مِنَ الْإِبِلِ: الَّتِي ذَهَبَتْ أَصْوَاتُهَا مِنَ الضَّعْفِ. قَالَ:

بَعْدَ اهْتِضَامِ الرَّاغِيَاتِ النُّكَّهِ.

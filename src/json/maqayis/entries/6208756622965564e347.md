# عَظَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%B8%D9%8E%D8%A8%D9%8E/?book=9

(عَظَبَ) الْعَيْنُ وَالظَّاءُ وَالْبَاءُ. يَقُولُونَ: عَظَبَ الطَّائِرُ، إِذَا حَرَّكَ زِمِكَّاهُ. وَهُوَ كَلَامٌ. وَالْعُنْظُبُ: الْجَرَادُ الضَّخْمُ، النُّونُ زَائِدَةٌ.

# زَحَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%AD%D9%8E%D8%B1%D9%8E/?book=9

(زَحَرَ) الزَّاءُ وَالْحَاءُ وَالرَّاءُ تَنَفُّسٌ بِشِدَّةٍ لَيْسَ إِلَّا هَذَا. يُقَالُ زَحَرَ يَزْحَرُ زَحِيرًا، وَهُوَ صَوْتُ نَفَسِهِ إِذَا تَنَفَّسَ بِشِدَّةٍ. وَزَحَرَتِ الْمَرْأَةُ بِوَلَدِهَا عِنْدَ الْوِلَادَةِ.

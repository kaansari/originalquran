# غَضَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D8%B6%D9%8E%D8%A7/?book=9

(غَضَا) الْغَيْنُ وَالضَّادُ وَالْحَرْفُ الْمُعْتَلُّ كَلِمَتَانِ: فَالْأُولَى: الْإِغْضَاءُ: إِدْنَاءُ الْجُفُونِ. وَهَذَا مُشْتَقٌّ مِنَ اللَّيْلَةِ الْغَاضِيَةِ، وَهِيَ الشَّدِيدَةُ الظُّلْمَةِ.

وَالْكَلِمَةُ الْأُخْرَى: الْغَضَا، وَهُوَ شَجَرٌ مَعْرُوفٌ. يُقَالُ: أَرْضٌ غَضْيَاءُ: كَثِيرَةُ الْغَضَا. وَيُقَالُ: إِبِلٌ غَضِيَةٌ: اشْتَكَتْ عَنْ أَكْلِ الْغَضَا.

# رَهَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%87%D9%8E%D9%85%D9%8E/?book=9

(رَهَمَ) الرَّاءُ وَالْهَاءُ وَالْمِيمُ يَدُلُّ عَلَى خِصْبٍ وَنَدًى. فَالرِّهْمَةُ: الْمَطْرَةُ الصَّغِيرَةُ الْقَطْرِ; وَالْجَمْعُ رِهَمٌ وَرِهَامٌ. وَرَوْضَةٌ مَرْهُومَةٌ. وَأَرْهَمَتِ السَّمَاءُ: أَتَتْ بِالرِّهَامِ. وَنَزَلْنَا بِفُلَانٍ فَكُنَّا فِي أَرْهَمِ جَانِبَيْهِ، أَيْ أَخْصَبِهِمَا.

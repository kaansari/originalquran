# حِنْزَقْرَةُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%90%D9%86%D9%92%D8%B2%D9%8E%D9%82%D9%92%D8%B1%D9%8E%D8%A9%D9%8F/?book=9

(الْحِنْزَقْرَةُ) ، وَهُوَ الْقَصِيرُ. وَهَذَا مِنَ الْحَزْقِ وَالْحَقْرِ، مَعَ زِيَادَةِ النُّونِ. فَالْحَقْرُ مِنَ الْحَقَارَةِ وَالصِّغَرِ، وَالْحَزْقُ كَأَنَّ خَلْقَهُ حُزِقَ بَعْضُهُ إِلَى بَعْضٍ.

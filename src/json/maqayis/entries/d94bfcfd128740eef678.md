# مَكَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%83%D9%8E%D8%AB%D9%8E/?book=9

(مَكَثَ) الْمِيمُ وَالْكَافُ وَالثَّاءُ كَلِمَةٌ تَدُلُّ عَلَى تَوَقُّفٍ وَانْتِظَارٍ. وَمَكَثَ مَكْثًا وَمُكْثًا وَرَجُلٌ مَكِيثٌ: رَزِينٌ غَيْرُ عَجُولٍ. وَمَكَثَ وَمَكُثَ وَالتَّمَكُّثُ: الِانْتِظَارُ.

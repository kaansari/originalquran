# نَفَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%81%D9%8E%D8%AE%D9%8E/?book=9

(نَفَخَ) النُّونُ وَالْفَاءُ وَالْخَاءُ: أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى انْتِفَاخٍ وَعُلُوٍّ. مِنْهُ انْتَفَخَ الشَّيْءُ انْتِفَاخًا. وَيُقَالُ انْتَفَخَ النَّهَارُ: عَلَا. وَنَفْخَةُ الرَّبِيعِ: إِعْشَابُهُ ; لِأَنَّ الْأَرْضَ تَرْبُو فِيهِ وَتَنْتَفِخُ. وَالْمَنْفُوخُ: الرَّجُلُ السَّمِينُ. وَالنَّفْخَاءُ مِنَ الْأَرْضِ مِثْلُ النَّبْخَاءِ ; وَقَدْ مَضَى.

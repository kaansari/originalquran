# دَحَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%AD%D9%8E%D9%85%D9%8E/?book=9

(دَحَمَ) الدَّالُ وَالْحَاءُ وَالْمِيمُ لَيْسَ بِشَيْءٍ. عَلَى أَنَّهُمْ يَقُولُونَ: دَحَمَهُ، إِذَا دَفَعَهُ دَفْعًا شَدِيدًا. وَبِهِ سُمِّيَ الرَّجُلُ دَحْمَانَ وَدُحَيْمًا.

# حَتَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%AA%D9%8E%D8%AF%D9%8E/?book=9

(حَتَدَ) الْحَاءُ وَالتَّاءُ وَالدَّالُ أَصْلٌ وَاحِدٌ، وَهُوَ اسْتِقْرَارُ الشَّيْءِ وَثَبَاتُهُ. فَالْحَتْدُ: الْمُقَامُ بِالْمَكَانِ. حَتَدٌ يَحْتِدُ. وَمِنْهُ الْمَحْتِدُ، وَهُوَ الْأَصْلُ ; يُقَالُ: هُوَ فِي مَحْتِدِ صِدْقٍ. وَالْحُتُدُ: الْعَيْنُ لَا يَنْقَطِعُ مَاؤُهَا، وَهُوَ قِيَاسُ الْبَابِ.

# زَتَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%AA%D9%91%D9%8E/?book=9

(زَتَّ) الزَّاءُ وَالتَّاءُ كَلِمَةٌ لَا قِيَاسَ لَهَا. يُقَالُ زَتَتُّ الْعَرُوسَ، إِذَا زَيَّنْتَهَا. قَالَ:

بَنِي تَمِيمٍ زَهْنِعُوا فَتَاتَكُمْ ... إِنَّ فَتَاةَ الْحَيِّ بِالتَّزَتُّتِ

قَدْ تَزَتَّتَتْ، أَيْ تَزَيَّنَتْ.

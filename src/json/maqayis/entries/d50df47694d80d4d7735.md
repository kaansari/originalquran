# وَطَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B7%D9%8E%D9%86%D9%8E/?book=9

(وَطَنَ) الْوَاوُ وَالطَّاءُ وَالنُّونُ: كَلِمَةٌ صَحِيحَةٌ. فَالْوَطَنُ: مَحَلُّ الْإِنْسَانِ. وَأَوْطَانُ الْغَنَمِ: مَرَابِضُهَا. وَأَوْطَنْتُ الْأَرْضَ: اتَّخَذْتُهَا وَطَنًا. وَالْمِيطَانُ: الْغَايَةُ.

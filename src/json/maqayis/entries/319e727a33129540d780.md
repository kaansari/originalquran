# جَلَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%84%D9%8E%D8%AE%D9%8E/?book=9

(جَلَخَ) الْجِيمُ وَاللَّامُ وَالْخَاءُ لَيْسَ أَصْلًا، وَلَا فِيهِ عَرَبِيَّةٌ صَحِيحَةٌ. فَإِنْ كَانَ شَيْءٌ فَالْخَاءُ مُبْدَلَةٌ مِنْ حَاءٍ. وَقَدْ مَضَى ذِكْرُهُ.

# وَشَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B4%D9%8E%D8%B1%D9%8E/?book=9

(وَشَرَ) الْوَاوُ وَالشِّينُ وَالرَّاءُ: كَلِمَةٌ وَاحِدَةٌ. الْوَشْرُ وَالتَّوْشِيرُ: أَنْ تُحَدِّدَ الْمَرْأَةُ أَسْنَانَهَا. وَالْمِيشَارُ بِلَا هَمْزٍ مِنْ هَذَا.

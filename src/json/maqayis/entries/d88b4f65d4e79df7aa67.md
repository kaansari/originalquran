# هَجَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%AC%D9%8E%D8%AF%D9%8E/?book=9

(هَجَدَ) الْهَاءُ وَالْجِيمُ وَالدَّالُ أُصَيْلٌ يَدُلُّ عَلَى رُكُودٍ فِي مَكَانٍ. يُقَالُ: هَجَدَ، إِذَا نَامَ هُجُودًا. وَالْهَاجِدُ: النَّائِمُ ; وَإِنْ صَلَّى لَيْلًا فَهُوَ مُتَهَجِّدٌ، كَأَنَّهُ بِصَلَاتِهِ تَرَكَ الْهُجُودَ عَنْهُ. وَهَذَا قِيَاسٌ مُسْتَعْمَلٌ، كَمَا يُقَالُ رَجُلٌ آثِمٌ ; فَإِذَا كَرِهَ الْإِثْمَ وَانْتَفَى مِنْهُ قِيلَ مُتَأَثِّمٌ. وَالْعَرَبُ تَقُولُ: أَهْجَدَ الْبَعِيرُ: أَلْقَى جِرَانَهُ بِالْأَرْضِ.

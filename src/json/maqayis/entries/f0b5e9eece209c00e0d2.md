# حَجَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%AC%D9%8E%D9%81%D9%8E/?book=9

(حَجَفَ) الْحَاءُ وَالْجِيمُ وَالْفَاءُ كَلِمَةٌ وَاحِدَةٌ لَا قِيَاسَ، وَهِيَ الْحَجَفَةُ، وَهِيَ التُّرْسُ الصَّغِيرُ يُطَارَقُ بَيْنَ جِلْدَيْنِ وَتُجْعَلُ مِنْهُمَا حَجَفَةٌ. وَالْجَمْعُ حَجَفٌ. قَالَ:

أَيَمْنَعُنَا الْقَوْمُ مَاءَ الْفُرَاتِ ... وَفِينَا السُّيُوفُ وَفِينَا الْحَجَفْ

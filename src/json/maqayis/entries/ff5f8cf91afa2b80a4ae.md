# مَيَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%8A%D9%8E%D8%B3%D9%8E/?book=9

(مَيَسَ) الْمِيمُ وَالْيَاءُ وَالسِّينُ كَلِمَةٌ تَدُلُّ عَلَى مَيَلَانٍ. وَمَاسَ مَيَسَانًا: تَبَخْتَرَ. وَمَاسَ الْغُصْنُ أَيْضًا. وَالْمَيْسُ: شَجَرٌ يُقَالُ إِنَّهُ أَجْوَدُ خَشَبٍ.

# غَطَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D8%B7%D9%8E%D9%85%D9%8E/?book=9

(غَطَمَ) الْغَيْنُ وَالطَّاءُ وَالْمِيمُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى كَثْرَةٍ وَاجْتِمَاعٍ. مِنْ ذَلِكَ الْبَحْرُ الْغِطَمُّ. وَيُقَالُ لِمُعْظَمِ الْبَحْرِ. غُطَامِطٌ. وَرَجُلٌ غِطَمٌّ: وَاسِعُ الْخُلُقُ.

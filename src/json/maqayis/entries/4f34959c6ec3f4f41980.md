# هَقَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%82%D9%8E%D8%A8%D9%8E/?book=9

(هَقَبَ) الْهَاءُ وَالْقَافُ وَالْبَاءُ. يَقُولُونَ: الْهِقَبُّ: الضَّخْمُ الطَّوِيلُ الرَّغِيبُ الْبَطْنِ. وَقَالَ أَبُو بَكْرٍ: الْهِقَبُّ: الصُّلْبُ. وَالْهَقَبُ: السَّعَةُ.

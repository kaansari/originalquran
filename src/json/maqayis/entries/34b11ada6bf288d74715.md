# دَمَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%85%D9%8E%D8%AE%D9%8E/?book=9

(دَمَخَ) الدَّالُ وَالْمِيمُ وَالْخَاءُ لَيْسَ أَصْلًا. إِنَّمَا هُوَ دَمْخٌ: جَبَلٌ، فِي قَوْلِ الْقَائِلِ: كَفَى حَزَنًا أَنِّي تَطَالَلْتُ كَيْ أَرَى ... ذُرَى عَلَمَيْ دَمْخٍ فَمَا يُرِيَانِ

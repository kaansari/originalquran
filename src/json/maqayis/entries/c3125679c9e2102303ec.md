# نَضَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B6%D9%8E%D8%AE%D9%8E/?book=9

(نَضَخَ) النُّونُ وَالضَّادُ وَالْخَاءُ قَرِيبٌ مِنَ الَّذِي قَبْلَهُ، إِلَّا أَنَّهُ أَكْثَرُ مِنْهُ. يَقُولُونَ: النَّضْخُ كَاللَّطْخِ مِنَ الشَّيْءِ يُبْقَى لَهُ أَثَرٌ. وَنَضَخَ ثَوْبَهُ بِالطِّيبِ. وَغَيْثٌ نَضَّاخٌ: غَزِيرٌ. وَعَيْنٌ نَضَّاخَةٌ: كَثِيرَةُ الْمَاءِ.

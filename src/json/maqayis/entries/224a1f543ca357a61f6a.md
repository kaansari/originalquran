# لَيَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%8A%D9%8E%D9%85%D9%8E/?book=9

(لَيَمَ) اللَّامُ وَالْيَاءُ وَالْمِيمُ. يَقُولُونَ: اللِّيمُ. الصُّلْحُ. وَأَنْشَدْنَا عَلِيُّ بْنُ إِبْرَاهِيمَ الْقَطَّانُ قَالَ: أَنْشَدَ ثَعْلَبٌ:

إِذَا دُعِيَتْ يَوْمًا نُمَيْرُ بْنُ عَامِرٍ ... رَأَيْتَ وُجُوهًا قَدْ تَبَيَّنَ لِيمُهَّا.

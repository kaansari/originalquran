# حَلَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%84%D9%8E%D9%86%D9%8E/?book=9

(حَلَنَ) الْحَاءُ وَاللَّامُ وَالنُّونُ إِنْ جَعَلْتَ النُّونَ زَائِدَةً فَقَدْ ذَكَرْنَاهُ فِيمَا مَضَى، وَإِنْ جَعَلْتَ النُّونَ أَصْلِيَّةً فَهُوَ فُعَّالٌ، وَهُوَ الْجَدْيُ، وَلَيْسَتِ الْكَلِمَةُ أَصْلًا يُقَاسُ. وَقَدْ مَضَى فِي بَابِهِ.

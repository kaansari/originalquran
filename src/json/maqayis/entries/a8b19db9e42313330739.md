# لَهَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%87%D9%8E%D9%86%D9%8E/?book=9

(لَهَنَ) اللَّامُ وَالْهَاءُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ، اللُّهْنَةُ: مَا يَتَعَجَّلُهُ الرَّجُلُ قَبْلَ غَدَائِهِ. وَقَدْ تَلَهَّنَ. وَيُقَالُ بَلِ اللُّهْنَةُ: مَا يُهْدِيهِ الرَّجُلُ إِذَا قَدِمَ مِنْ سَفَرِهِ.

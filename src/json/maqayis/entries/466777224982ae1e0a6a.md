# حَقَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%82%D9%8E%D9%86%D9%8E/?book=9

(حَقَنَ) الْحَاءُ وَالْقَافُ وَالنُّونُ أَصْلٌ وَاحِدٌ، وَهُوَ جَمْعُ الشَّيْءِ. يُقَالُ لِكُلِّ شَيْءٍ [جُمِعَ] وَشُدَّ حُقَّيْنِ. وَلِذَلِكَ سُمِّيَ حَابِسُ اللَّبَنِ حَاقِنًا. وَيُقَالُ اللَّبَنُ الْحَقِينِ الَّذِي صُبَّ حَلِيبُهُ عَلَى رَائِبِهِ. وَالْحَوَاقِنُ: مَا سَفَلَ عَنِ الْبَطْنِ. وَقَالَ قَوْمٌ: الْحَاقِنَتَانِ مَا تَحْتَ التَّرْقَوَتَيْنِ.

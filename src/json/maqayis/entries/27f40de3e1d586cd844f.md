# فَسَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B3%D9%8E%D8%AC%D9%8E/?book=9

(فَسَجَ) الْفَاءُ وَالسِّينُ وَالْجِيمُ، كَلِمَةٌ وَاحِدَةٌ. يَقُولُونَ: قَلُوصٌ فَاسِجَةٌ، إِذَا أَعْجَلَهَا الْفَحْلُ فَضَرَبَهَا قَبْلَ وَقْتِ الْمَضْرِبِ. وَيُقَالُ بَلْ هِيَ الْحَائِلُ السَّمِينَةُ.

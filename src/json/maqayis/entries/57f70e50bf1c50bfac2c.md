# رَخَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%AE%D9%8E%D9%81%D9%8E/?book=9

(رَخَفَ) الرَّاءُ وَالْخَاءُ وَالْفَاءُ أُصَيْلٌ يَدُلُّ عَلَى رَخَاوَةٍ وَلِينٍ. فَيُقَالُ: إِنَّ الرَّخْفَةَ: الزُّبْدَةُ الرَّقِيقَةُ. وَيُقَالُ أَرْخَفْتُ الْعَجِينَ، إِذَا كَثَّرْتَ مَاءَهُ حَتَّى يَسْتَرْخِيَ. وَيُقَالُ مِنْهُ رَخَفَ يَرْخُفُ. وَيَقُولُونَ صَارَ الْمَاءُ رُخْفَةً، أَيْ طِينًا رَقِيقًا. وَالرَّخْفَةُ: حِجَارَةٌ خِفَافٌ جُوفٌ.

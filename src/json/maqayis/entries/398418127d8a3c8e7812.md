# وَذَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B0%D9%8E%D8%AD%D9%8E/?book=9

(وَذَحَ) الْوَاوُ وَالذَّالُ وَالْحَاءُ كَلِمَةٌ. فَالْوَذَحُ: مَا تَعَلَّقَ بِأَصْوَافِ الْغَنَمِ مِنَ الْبَعَرِ، ثُمَّ يُقَالُ امْرَأَةٌ وَذَاحٌ: غَيْرُ عَفِيفَةٍ.

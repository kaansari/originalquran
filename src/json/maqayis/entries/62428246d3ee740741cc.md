# بَرَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B1%D9%8E%D8%AB%D9%8E/?book=9

(بَرَثَ) الْبَاءُ وَالرَّاءُ وَالثَّاءُ أَصْلٌ وَاحِدٌ، وَهِيَ الْأَرْضُ السَّهْلَةُ، يُقَالُ لِلْأَرْضِ السَّهْلَةِ بَرْثٌ، وَالْجَمْعُ بِرَاثٌ. وَجَعَلَهَا رُؤْبَةُ الْبَرَارِثُ، وَيُقَالُ: إِنَّهُ خَطَأٌ.

# عَطَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%B7%D9%8E%D8%AF%D9%8E/?book=9

(عَطَدَ) الْعَيْنُ وَالطَّاءُ وَالدَّالُ ذُكِرَتْ فِيهِ كَلِمَةٌ وَالْقِيَاسُ لَا يُسَوِّغُهَا، لَكِنَّهُمْ يَقُولُونَ: الْعَطَوَّدُ: السيَّرُ السَّرِيعُ الشَّاقُّ. وَيُنْشِدُونَ:

إِلَيْكَ أَشْكُو عَنَقًا عَطَوَّدَا

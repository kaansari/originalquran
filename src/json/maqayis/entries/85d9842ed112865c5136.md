# طَلَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D9%84%D9%8E%D9%85%D9%8E/?book=9

(طَلَمَ) الطَّاءُ وَاللَّامُ وَالْمِيمُ أَصْلٌ صَحِيحٌ، وَهُوَ ضَرْبُ الشَّيْءِ بِبَسْطِ الشَّيْءِ الْمَبْسُوطِ. مِثَالُ ذَلِكَ: الطَّلْمُ، وَهُوَ ضَرْبُكَ خُبْزَةَ الْمَلَّةِ بِيَدِكَ تَنْفُضُ مَا عَلَيْهَا مِنَ الرَّمَادِ. وَمَا أَقْرَبَ مَا بَيْنَ الطَّلْمِ وَاللَّطْمِ. وَالدَّلِيلُ عَلَى ذَلِكَ قَوْلُ حَسَّانَ:تُطَلِّمُهُنَّ بِالْخُمُرِ النِّسَاءُ

فَإِنَّ نَاسًا يَرَوْنَهُ كَذَا، وَآخَرُونَ يَرَوْنَهُ: " تُلَطِّمُهُنَّ ". وَذَلِكَ دَلِيلٌ عَلَى أَنَّ الْمَعْنَى وَاحِدٌ. وَيُقَالُ إِنَّ الطَّلْمَةَ الْخُبْزَةُ، وَإِنِّمَا سُمِّيَتْ بِذَلِكَ لِأَنَّهَا تُلْطَمُ.

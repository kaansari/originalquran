# صَنَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%86%D9%8E%D9%82%D9%8E/?book=9

(صَنَقَ) الصَّادُ وَالنُّونُ وَالْقَافُ كَلِمَةٌ إِنْ صَحَّتْ. يَقُولُونَ إِنَّ الصَّنَقَ: الذَّفَرُ. وَحَكَى بَعْضُهُمْ: أَصْنَقَ الرَّجُلُ فِي مَالِهِ، إِذَا أَحْسَنَ الْقِيَامَ عَلَيْهِ.

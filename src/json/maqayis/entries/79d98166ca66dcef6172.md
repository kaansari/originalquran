# وَثَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AB%D9%8E%D9%86%D9%8E/?book=9

(وَثَنَ) الْوَاوُ وَالثَّاءُ وَالنُّونُ. كَلِمَةٌ وَاحِدَةٌ، هِيَ الْوَثَنُ وَاحِدُ الْأنِ: حِجَارَةٌ كَانَتْ تُعْبَدُ. وَأَصْلُهَا قَوْلُهُمُ اسْتَوْثَنَ الشَّيْءُ: قَوِيَ. وَأَوْثَنَ فُلَانٌ الْحِمْلَ: كَثَّرَهُ. وَأَوْثَنْتُ لَهُ: أَعْطَيْتُهُ جَزِيلًا.

# هَذَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B0%D9%91%D9%8E/?book=9

(هَذَّ) الْهَاءُ وَالذَّالُ: أُصَيْلٌ يَدُلُّ عَلَى قَطْعٍ. وَهَذَّهُ: قَطَعَهُ. وَسِكِّينٌ هَذُوذٌ. وَهَذَاذَيْكَ مِنَ الْهَذِّ: سُرْعَةُ الْقَطْعِ، كَأَنَّهُ يَقُولُ: أَحْكِمِ الْأَمْرَ وَاقْطَعْهُ.

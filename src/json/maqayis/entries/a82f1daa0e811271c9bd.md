# نَخَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%AE%D9%8E%D8%B3%D9%8E/?book=9

(نَخَسَ) النُّونُ وَالْخَاءُ وَالسِّينُ كَلِمَةٌ تَدُلُّ عَلَى بَزْلِ شَيْءٍ بِشَيْءٍ حَادٍّ. وَنَخَسَهُ بِعُودٍ أَوْ حَدِيدَةٍ نَخْسًا. وَمِنْهُ النَّخَّاسُ. وَالنَّاخِسُ: جَرَبٌ يَكُونُ عِنْدَ ذَنَبِ الْبَعِيرِ أَوْ صَدْرِهِ، كَأَنَّهُ نُخِسَ بِهِ وَبَعِيرٌ مَنْخُوسٌ. وَمِمَّا شَذَّ عَنْهُ النَّخِيسَةُ.

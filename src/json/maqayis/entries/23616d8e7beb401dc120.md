# وَشَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%B4%D9%8E%D9%82%D9%8E/?book=9

(وَشَقَ) الْوَاوُ وَالشِّينُ وَالْقَافُ: كَلِمَةٌ وَاحِدَةٌ، هِيَ الْوَشِيقَةُ: لَحْمٌ يُقَدَّدُ. يُقَالُ وَشَقْتُ وَاتَّشَقْتُ. قَالَ:

إِذَا عَرَضَتْ مِنْهَا كَهَاةٌ سَمِينَةٌ ... فَلَا تُهْدِ مِنْهَا وَاتَّشِقْ وَتَجَبْجَبِ

وَوَاشِقٌ: اسْمُ كَلْبٍ.

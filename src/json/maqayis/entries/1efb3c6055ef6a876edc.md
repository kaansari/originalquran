# وَفَضَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%81%D9%8E%D8%B6%D9%8E/?book=9

(وَفَضَ) الْوَاوُ وَالْفَاءُ وَالضَّادُ: ثَلَاثُ كَلِمَاتٍ مُتَبَايِنَةٌ: الْأُولَى أَوْفَضَ إِيفَاضًا: أَسْرَعَ. وَجَاءَ عَلَى وَفْضٍ وَأَوْفَاضٍ، أَيْ عَجَلَةٍ.

وَالثَّانِيَةُ الْأَوْفَاضُ: الْفِرَقُ مِنَ النَّاسِ.

وَالثَّالِثَةُ الْوَفْضَةُ: الْكِنَانَةُ، وَجَمْعُهَا وِفَاضٌ.

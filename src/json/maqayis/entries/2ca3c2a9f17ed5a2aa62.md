# رَنَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%86%D9%8E%D8%B9%D9%8E/?book=9

(رَنَعَ) الرَّاءُ وَالنُّونُ وَالْعَيْنُ كَلِمَةٌ وَاحِدَةٌ صَحِيحَةٌ، وَهِيَ الْمَرْنَعَةُ لِأَصْوَاتٍ تَكُونُ لَعِبًا وَلَهْوًا. قَالَهُ الْفَرَّاءُ. وَقَالَ أَبُو حَاتِمٍ: رَنَعَ الْحَرْثُ، إِذَا احْتَبَسَ الْمَاءُ عَنْهُ فَضَمَُرَ. وَفِيهِ نَظَرٌ.

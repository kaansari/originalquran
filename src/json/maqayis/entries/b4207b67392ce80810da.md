# وَأَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%A3%D9%8E%D9%85%D9%8E/?book=9

(وَأَمَ) الْوَاوُ وَالْهَمْزَةُ وَالْمِيمُ. كَلِمَةٌ تَدُلُّ عَلَى مُوَافَقَةٍ وَمُقَارَبَةٍ. يَقُولُونَ: الْوِئَامُ: الْمُوَافَقَةُ ; وَوَاءَمْتُهُ. وَمَثَلُهُمْ:

لَوْلَا الْوِئَامُ هَلَكَ الْأَنَامُ

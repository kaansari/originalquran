# طَحَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%AD%D9%8E%D9%85%D9%8E/?book=9

(طَحَمَ) الطَّاءُ وَالْحَاءُ وَالْمِيمُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى تَجَمُّعٍ وَتَكَاثُفٍ. مِنْ ذَلِكَ الطُّحْمَةُ مِنَ النَّاسِ، وَهِيَ الْجَمَاعَةُ الْكَثِيفَةُ. وَطُحْمَةُ اللَّيْلِ وَطَحْمَتُهُ، وَطُحْمَةُ السَّيْلِ وَطَحْمَتُهُ: مُعْظَمُهُ. قَالَ الْخَلِيلُ: طَحْمَةُ الْفِتْنَةِ: جَوْلَةُ النَّاسِ عِنْدَهَا. وَيُقَالُ لِلرَّجُلِ الشَّدِيدِ الْعِرَاكِ: طُحَمَةٌ. وَالْبَابُ كُلُّهُ وَاحِدٌ.

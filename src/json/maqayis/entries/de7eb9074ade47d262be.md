# غَوَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D9%88%D9%8E%D8%AB%D9%8E/?book=9

(غَوَثَ) الْغَيْنُ وَالْوَاوُ وَالثَّاءُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْغَوْثُ مِنَ الْإِغَاثَةِ، وَهِيَ الْإِغَاثَةُ وَالنُّصْرَةُ عِنْدَ الشِّدَّةِ. وَغَوْثٌ: قَبِيلَةٌ.

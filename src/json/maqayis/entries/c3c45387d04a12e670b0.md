# فَدَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AF%D9%8E%D8%AC%D9%8E/?book=9

(فَدَجَ) الْفَاءُ وَالدَّالُ وَالْجِيمُ. يَقُولُونَ: إِنَّ الْفَوْدَجَ: الْهَوْدَجُ. قَالَ الْخَلِيلُ: الْفَوْدَجُ: النَّاقَةُ الْوَاسِعَةُ الْأَرْفَاغِ. وَشَاةٌ مُفَوْدَجَةٌ: يَنْتَصِبُ قَرْنَاهَا وَيَلْتَقِي طَرَفَاهُمَا.

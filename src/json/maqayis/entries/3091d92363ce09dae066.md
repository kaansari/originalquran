# الْعُنَابِلُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8F%D9%86%D9%8E%D8%A7%D8%A8%D9%90%D9%84%D9%8F/?book=9

(الْعُنَابِلُ) : الْوَتَرُ الْغَلِيظُ. قَالَ:

وَالْقَوْسُ فِيهَا وَتَرٌ عُنَابِلُ

وَهَذَا مَنْحُوتٌ مِنْ عَنَبَ وَعَبَلَ، وَكِلَاهُمَا يَدُلُّ عَلَى امْتِدَادٍ وَشِدَّةٌ.

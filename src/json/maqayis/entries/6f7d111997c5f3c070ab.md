# نَتَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%AA%D9%8E%D8%A8%D9%8E/?book=9

(نَتَبَ) النُّونُ وَالتَّاءُ وَالْبَاءُ لَيْسَ بِشَيْءٍ، لِأَنَّ الْبَاءَ فِيهِ زَائِدَةٌ. يَقُولُونَ: نَتَبَ الشَّيْءُ، مِثْلُ نَهَدَ. قَالَ:

أَشْرَفَ ثَدْيَاهَا عَلَى التَّرَيُّبِ ... لَمْ يَعْدُوَا التَّفْلِيكَ فِي النُّتُوبِ

إِنَّمَا أَرَادَ النُّتُوَّ فَزَادَ الْقَافِيَةَ. وَاللَّهُ أَعْلَمُ.

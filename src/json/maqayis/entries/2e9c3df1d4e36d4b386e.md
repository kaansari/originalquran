# ثَدَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%AF%D9%8E%D9%86%D9%8E/?book=9

(ثَدَنَ) الثَّاءُ وَالدَّالُ وَالنُّونُ كَلِمَةٌ. يَقُولُونَ: الثَّدِنُ الرَّجُلُ الْكَثِيرُ اللَّحْمِ. وَيُقَالُ بَلِ الثَّدَنُ تَغَيُّرُ رَائِحَةِ اللَّحْمِ.

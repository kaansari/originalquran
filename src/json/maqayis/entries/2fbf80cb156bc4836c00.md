# سَمَِتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%85%D9%90%D9%8E%D8%AA%D9%8E/?book=9

(سَمَِتَ) السِّينُ وَالْمِيمُ وَالتَّاءُ أَصْلٌ يَدُلُّ عَلَى نَهْجٍ وَقَصْدٍ وَطَرِيقَةٍ. يُقَالُ سَمَتَ، إِذَا أَخَذَ النَّهْجَ. وَكَانَ بَعْضُهُمْ يَقُولُ: السَّمْتُ: السَّيْرُ بِالظَّنِّ وَالْحَدْسِ. وَهُوَ قَوْلُ الْقَائِلِ:

لَيْسَ بِهَا رُبْعٌ لِسَمْتِ السَّامِتِ

وَيُقَالُ إِنَّ فُلَانًا لَحَسَنُ السَّمْتِ، إِذَا كَانَ مُسْتَقِيمَ الطَّرِيقَةِ مُتَحَرِّيًا لِفِعْلِ الْخَيْرِ. وَالْفِعْلُ مِنْهُ سَمَتَ. وَيُقَالُ سَمَتَ سَمْتَهُ، إِذَا قَصَدَ قَصْدَهُ.

# خَصَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B5%D9%8E%D9%89/?book=9

(خَصَى) الْخَاءُ وَالصَّادُ وَالْحَرْفُ الْمُعْتَلُّ كَلِمَةٌ وَاحِدَةٌ لَا يُقَاسُ عَلَيْهَا إِلَّا مَجَازًا، وَهِيَ قَوْلُهُمْ خَصَيْتُ الْفَحْلَ خَصْيًا. وَ " بَرِئْتُ إِلَيْكَ مِنَ الْخِصَاءِ ". وَمَعْنَى خَصَيْتُ فِعْلٌ مُشْتَقٌّ مِنَ الْخُصْيِ ; وَهُوَ إِيقَاعٌ بِهِ، كَمَا يُقَالُ ظَهَرْتُهُ وَبَطَنْتُهُ، إِذَا ضَرَبْتَ ظَهْرَهُ وَبَطْنَهُ. فَكَذَلِكَ خَصَيْتُهُ: نَزَعْتُ خُصْيَيْهِ.

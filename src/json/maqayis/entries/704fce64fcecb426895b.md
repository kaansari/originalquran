# بَنَيَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%86%D9%8E%D9%8A%D9%8E/?book=9

(بَنَيَ) الْبَاءُ وَالنُّونُ وَالْيَاءُ أَصْلٌ وَاحِدٌ، وَهُوَ بِنَاءُ الشَّيْءِ بِضَمِّ بَعْضِهِ إِلَى بَعْضٍ. تَقُولُ بَنَيْتُ الْبِنَاءَ أَبْنِيهِ. وَتُسَمَّى مَكَّةُ الْبَنِيَّةَ. وَيُقَالُ قَوْسٌ بَانِيَةٌ، وَهِيَ الَّتِي بَنَتْ عَلَى وَتَرِهَا، وَذَلِكَ أَنْ يَكَادَ وَتَرُهَا يَنْقَطِعُ لِلُصُوقِهِ بِهَا. وَطَيِّئٌ تَقُولُ مَكَانُ بَانِيَةٍ: بَانَاةٌ ; وَهُوَ قَوْلُ امْرِئِ الْقَيْسِ:

غَيْرِ بَانَاةٍ عَلَى وَتَرِهْ وَيُقَالُ بُنْيَةٌ وَبُنًى، وَبِنْيَةٌ وَبِنًى بِكَسْرِ الْبَاءِ كَمَا يُقَالَ: جِزْيَةٌ وَجِزًى، وَمِشْيَةٌ وَمِشًى.

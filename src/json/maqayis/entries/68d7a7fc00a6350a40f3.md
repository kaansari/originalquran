# جَفَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%81%D9%8E%D9%86%D9%8E/?book=9

(جَفَنَ) الْجِيمُ وَالْفَاءُ وَالنُّونُ أَصْلٌ وَاحِدٌ، وَهُوَ شَيْءٌ يُطِيفُ بِشَيْءٍ وَيَحْوِيهِ. فَالْجَفْنُ جَفْنُ الْعَيْنِ. وَالْجَفْنُ جَفْنُ السَّيْفِ. وَجَفْنٌ: مَكَانٌ. وَسُمِّيَ الْكَرْمُ جَفْنًا لِأَنَّهُ يَدُورُ عَلَى مَا يَعْلَقُ بِهِ. وَذَلِكَ مُشَاهَدٌ.

# وَلَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%84%D9%8E%D8%AB%D9%8E/?book=9

(وَلَثَ) الْوَاوُ وَاللَّامُ وَالثَّاءُ، فِيهِ كَلِمَتَانِ. يُقَالُ: بَيْنَهُمْ وَلْثٌ، أَيْ عَهْدٌ

وَالْأُخْرَى وَلَثَهُ بِالْعَصَا يَلِثُهُ وَلْثًا. وَوَلَثَتِ الْمَطَرَةُ الْأَرْضَ، إِذَا ضَرَبَتْ

# فَسَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B3%D9%8E%D8%A3%D9%8E/?book=9

(فَسَأَ) الْفَاءُ وَالسِّينُ وَالْهَمْزَةُ. يُقَالُ فِيهِ: تَفَسَّأَ الثَّوْبُ، إِذَا بَلِيَ. وَفَسَأْتُهُ أَنَا: مَدَدْتُهُ حَتَّى تَفَزَّرَ. وَيَقُولُونَ: فَسَأَهُ بِالْعَصَا: ضَرَبَهُ. وَيَقُولُونَ فِي غَيْرِ الْمَهْمُوزِ: تَفَاسَى الرَّجُلُ تَفَاسِيًا، إِذَا أَخْرَجَ عَجِيزَتَهُ.

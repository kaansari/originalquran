# جَأَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%A3%D9%91%D9%8E/?book=9

(جَأَّ) الْجِيمُ وَالْهَمْزَةُ لَيْسَ أَصْلًا لِأَنَّهُ حِكَايَةُ صَوْتٍ. يُقَالُ جَأْجَأْتُ بِالْإِبِلِ إِذَا دَعَوْتُهَا لِلشُّرْبِ. وَالِاسْمُ الْجِيءُ. قَالَ:

وَمَا كَانَ عَلَى الْجِيءِ ... وَلَا الْهِيءِ امْتِدَاحِيكَا

# عَشَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%B4%D9%8E%D9%82%D9%8E/?book=9

(عَشَقَ) الْعَيْنُ وَالشِّينُ وَالْقَافُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى تَجَاوُزِ حَدِّ الْمَحَبَّةِ. تَقُولُ: عَشِقَ يَعْشَقُ عِشْقًا وَعَشَقًا. قَالَ رُؤْبَةُ:

وَلَمْ يُضِعْهَا بَيْنَ فِرْكٍ وَعَشَقْ

وَيُقَالُ: امْرَأَةٌ عَاشِقٌ أَيْضًا، حَمَلُوهُ عَلَى قَوْلِهِمْ: رَجُلٌ بَادِنٌ وَامْرَاةٌ بَادِنٌ. وَزَعَمَ نَاسٌ أَنَّ الْعَشَقَةَ اللَّبْلَابَةُ، قَالُوا: وَمِنْهَا اشْتُقَّ اسْمُ الْعَاشِقِ لِذُيُولِهِ وَهُوَ كَلَامٌ.

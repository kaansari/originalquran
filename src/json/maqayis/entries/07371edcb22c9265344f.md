# دَوَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%88%D9%8E%D8%AE%D9%8E/?book=9

(دَوَخَ) الدَّالُ وَالْوَاوُ وَالْخَاءُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى التَّذْلِيلِ. يُقَالُ دَوَّخْنَاهُمْ; أَيْ أَذْلَلْنَاهُمْ وَقَهَرْنَاهُمْ. وَدَاخُوا، أَيْ ذَلُّوا.

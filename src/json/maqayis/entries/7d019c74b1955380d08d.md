# عَلَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D9%84%D9%8E%D8%AF%D9%8E/?book=9

(عَلَدَ) الْعَيْنُ وَاللَّامُ وَالدَّالُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى قُوَّةٍ وَشِدَّةٍ. مِنْ ذَلِكَ الْعَلْدُ، وَهُوَ الصُّلْبُ مِنَ الشَّيْءِ، يُقَالُ لِعَصَبِ الْعُنُقِ عَلْدٌ. وَرَجُلٌ عَلْوَدٌّ: رَزِينٌ. وَيُقَالُ مِنْهُ اعْلَوَّدَ. وَمَا لَمْ نَذْكُرْهُ مِنْهُ فَهُوَ هَذَا الْقِيَاسُ.

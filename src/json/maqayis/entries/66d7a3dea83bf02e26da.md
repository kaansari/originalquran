# وَهَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%87%D9%8E%D9%84%D9%8E/?book=9

(وَهَلَ) الْوَاوُ وَالْهَاءُ وَاللَّامُ كَلِمَاتٌ لَا تَنْقَاسُ، وَهِيَ الْوَهَلُ: الْفَزَعُ. يُقَالُ: وَهِلَ يَوْهَلُ. قَالَ أَبُو زَيْدٍ: وَهَلْتُ عَنِ الشَّيْءِ: نَسِيتُهُ. وَوَهَلْتُ إِلَيْهِ: ذَهَبَ وَهْمِي إِلَيْهِ. وَلَقِيتُهُ أَوَّلَ وَهْلَةٍ، أَيْ قَبْلَ كُلِّ شَيْءٍ.

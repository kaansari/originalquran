# نَزَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B2%D9%8E%D9%87%D9%8E/?book=9

(نَزَهَ) النُّونُ وَالزَّاءُ وَالْهَاءُ كَلِمَةٌ تَدُلُّ عَلَى بُعْدٍ فِي مَكَانٍ وَغَيْرِهِ. وَرَجُلٌ نَزِيهُ الْخُلُقِ: بَعِيدٌ عَنِ الْمَطَامِعِ الدَّنِيَّةِ. قَالَ ابْنُ دُرَيْدٍ: وَنَزِهُ النَّفْسِ وَنَازِهُ النَّفْسِ: ظَلِفُهَا عَنِ الْمَدَانِسِ. قَالَ ابْنُ السِّكِّيتِ: خَرَجْنَا نَتَنَزَّهُ، إِذَا تَبَاعَدُوا عَنِ الْمَاءِ وَالرِّيفِ. وَمَكَانٌ نَزِيهٌ: خَلَاءٌ لَيْسَ بِهِ أَحَدٌ.

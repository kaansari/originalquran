# طَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%A3%D9%8E/?book=9

(طَأَ) الطَّاءُ وَالْهَمْزَةُ، وَهُوَ يَدُلُّ عَلَى هَبْطِ شَيْءٍ. مِنْ ذَلِكَ قَوْلُهُمْ: طَأْطَأَ رَأْسَهُ. وَهُوَ مَأْخُوذٌ مِنَ الطَّأْطَاءِ، وَهُوَ مُنْهَبَطٌ مِنَ الْأَرْضِ. وَهُوَ فِي قَوْلِ الْكُمَيْتِ.

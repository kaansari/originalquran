# مَعَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B9%D9%8E%D8%AC%D9%8E/?book=9

(مَعَجَ) الْمِيمُ وَالْعَيْنُ وَالْجِيمُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى تَقَلُّبٍ وَسُرْعَةٍ فِي شَيْءٍ. وَمَعَجَ الْحِمَارُ مَعْجًا: تَقَلَّبَ فِي جَرْيِهِ. وَيَقُولُونَ قِيَاسًا عَلَى هَذَا: مَعَجَ الْفَصِيلُ ضَرْعَ أُمِّهِ: ضَرَبَهُ بِرَأْسِهِ عِنْدَ الرَّضَاعِ.

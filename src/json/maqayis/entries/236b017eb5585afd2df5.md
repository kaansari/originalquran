# جَهَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%87%D9%8E%D8%B4%D9%8E/?book=9

(جَهَشَ) الْجِيمُ وَالْهَاءُ وَالشِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ التَّهَيُّؤُ لِلْبُكَاءِ. يُقَالُ جَهَشَ يَجْهَشُ وَأَجْهَشَ يُجْهِشُ، إِذَا تَهَيَّأَ لِلْبُكَاءِ. قَالَ:

قَامَتْ تَشَكَّى إِلَيَّ النَّفْسُ مُجْهِشَةً ... وَقَدْ حَمَلْتُكِ سَبْعًا بَعْدَ سَبْعِينَا

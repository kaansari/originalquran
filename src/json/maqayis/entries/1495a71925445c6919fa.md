# بَغَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%BA%D9%91%D9%8E/?book=9

(بَغَّ) الْبَاءُ وَالْغَيْنُ فِي الْمُضَاعَفِ أَصْلَانِ مُتَبَايِنَانِ عِنْدَ الْخَلِيلِ وَابْنِ دُرَيْدٍ. فَالْأَوَّلُ الْبَغْبَغَةُ، وَهِيَ حِكَايَةُ ضَرْبٍ مِنَ الْهَدِيرِ، وَأَنْشَدَ الْخَلِيلُ:

بِرَجْسِ بَغْبَاغِ الْهَدِيرِ الْبَهْبَهِ

وَالْأَصْلُ الثَّانِي ذَكَرَهُ ابْنُ دُرَيْدٍ قَالَ: الْبَغْبَغُ وَتَصْغِيرُهَا بُغَيْبِغٌ وَهِيَ الرَّكِيَّةُ الْقَرِيبَةُ الْمَنْزَعِ. قَالَ:

يَا رُبَّ مَاءٍ لَكَ بِالْأَجْبَالِ ... بُغَيْبِغٍ يُنْزَعُ بِالْعِقَالِ

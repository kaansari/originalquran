# نَمَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%85%D9%8E%D8%B5%D9%8E/?book=9

(نَمَصَ) النُّونُ وَالْمِيمُ وَالصَّادُ أُصَيْلٌ يَدُلُّ عَلَى رِقَّةِ الشَّعْرِ أَوْ نَتْفٍ لَهُ. فَالنَّمَصُ: رِقَّةُ الشَّعْرِ. وَالْمِنْمَاصُ: الْمِنْقَاشُ. وَشَعْرٌ نَمِيصٌ، وَنَبْتٌ نَمِيصٌ: نَتَفَتْهُ الْمَاشِيَةُ بِأَفْوَاهِهَا.

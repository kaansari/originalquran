# مَدَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AF%D9%8E%D8%AE%D9%8E/?book=9

(مَدَخَ) الْمِيمُ وَالدَّالُ وَالْخَاءُ. يَقُولُونَ: الْمَدْخُ: الْعَظَمَةُ. وَالتَّمَادُخُ: الْبَغْيُ. قَالَ:

تَمَادَخُ بِالْحِمَى جَهْلًا عَلَيْنَا ... فَهَلَّا بِالْقَنَانِ تُمَادِخِينَا

وَحَكَى ابْنُ دُرَيْدٍ: تَمَدَّخَتِ النَّاقَةُ: تَلَوَّتْ فِي سَيْرِهَا. وَتَمَدَّخَتْ: امْتَلَأَتْ شَحْمًا.

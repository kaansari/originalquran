# مَلَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%84%D9%8E%D8%B5%D9%8E/?book=9

(مَلَصَ) الْمِيمُ وَاللَّامُ وَالصَّادُ قَرِيبٌ مِنْ مَلَسَ، وَهُوَ يَدُلُّ عَلَى إِفْلَاتِ الشَّيْءِ بِسُرْعَةٍ. وَامَّلَصَ الشَّيْءُ مِنْ يَدِي: أَفْلَتَ، امِّلَاصًا. وَمَلِصَ الرِّشَاءُ مِنَ الْيَدِ يَمْلَصُ. قَالَ:

فَرَّ وَأَعْطَانِي رِشَاءً مَلِصًا

وَمِنْهُ أَمْلَصَتِ الْمَرْأَةُ: رَمَتْ بِوَلَدِهَا إِمْلَاصًا ; وَالْوَلَدُ مَلِيصٌ. وَمِنْهُ سَيْرٌ إِمْلِيصٌ: سَرِيعٌ.

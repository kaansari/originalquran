# الْعَيْهَرَةُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8E%D9%8A%D9%92%D9%87%D9%8E%D8%B1%D9%8E%D8%A9%D9%8F/?book=9

(الْعَيْهَرَةُ) : الْمَرْأَةُ الْفَاجِرَةُ، وَالزَّائِدَةُ فِي ذَلِكَ الْيَاءُ، وَإِنَّمَا هُوَ مِنَ الْعَهْرِ.

# خَفَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%81%D9%8E%D8%AC%D9%8E/?book=9

(خَفَجَ) الْخَاءُ وَالْفَاءُ وَالْجِيمُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى خِلَافِ الِاسْتِقَامَةِ. فَالْأَخْفَجُ: الْأَعْوَجُ الرِّجْلِ ; وَالْمَصْدَرُ الْخَفَجُ، وَيُقَالُ إِنَّ الْخَفَجَ الرِّعْدَةُ. وَهُوَ ذَاكَ الْقِيَاسُ.

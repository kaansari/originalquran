# نَمَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%85%D9%8E%D8%B4%D9%8E/?book=9

(نَمَشَ) النُّونُ وَالْمِيمُ وَالشِّينُ أَصْلٌ يَدُلُّ عَلَى تَخْطِيطٍ فِي شَيْءٍ. مِنْهُ النَّمَشُ، وَهِيَ خُطُوطُ النُّقُوشِ، وَالنَّعْتُ نَمِشٌ. وَمِنَ الْبَابِ النَّمْشُ كَمَا يَفْعَلُهُ الْعَابِثُ إِذَا الْتَقَطَ شَيْئًا وَخَطَّطَ بِأَصَابِعِهِ. قَالَ:

قُلْتُ لَهَا وَأُولِعَتْ بِالنَّمْشِ

وَنَمَشَ الْجَرَادُ الْأَرْضَ: جَرَدَهَا.

# يَقَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%8A%D9%8E%D9%82%D9%8E%D9%87%D9%8E/?book=9

(يَقَهَ) الْيَاءُ وَالْقَافُ وَالْهَاءُ. سَمِعْتُ عَلِيَّ بْنَ إِبْرَاهِيمَ الْقَطَّانَ يَقُولُ: سَمِعْتُ ثَعْلَبًا يَقُولُ: أَيْقَهَ يُوقِهُ إِيقَاهًا، إِذَا فَهِمَ. يُقَالُ أَيْقِهْ لِهَذَا، أَيِ افْهَمْهُ. وَيُقَالُ بَلْ ذَلِكَ مِنَ الطَّاعَةِ. قَالَ:

وَاسْتَيْقَهُوا لِلْمُحَلِّمِ

# رَدَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%AF%D9%8E%D9%83%D9%8E/?book=9

(رَدَكَ) الرَّاءُ وَالدَّالُ وَالْكَافُ لَيْسَ أَصْلًا، لَكِنَّهُمْ يَقُولُونَ: خَلْقٌ مُرَوْدَكٌ; أَيْ سَمِينٌ. قَالَ:

قَامَتْ تُرِيكَ خَلْقَهَا الْمُرَوْدَكَا

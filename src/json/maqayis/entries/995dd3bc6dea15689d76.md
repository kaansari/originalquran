# مَحَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AD%D9%8E%D8%B4%D9%8E/?book=9

(مَحَشَ) الْمِيمُ وَالْحَاءُ وَالشِّينُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى إِحْرَاقِ النَّارِ شَيْئًا حَتَّى يَنْسَحِجَ جِلْدُهُ. يُقَالُ: مَحَشَتِ النَّارُ الشَّيْءَ تَمْحَشُهُ. وَامْتَحَشَ الْخُبْزُ: احْتَرَقَ. وَرَوَى ابْنُ السِّكِّيتِ: أَمْحَشَهُ الْحَرُّ. وَيُقَالُ: امْتَحَشَ، إِذَا غَضِبَ ; وَمَعْنَاهُ أَنَّ الْغَضَبَ لِحَرَارَتِهِ بَلَغَ ذَلِكَ الْمَبْلَغَ، كَأَنَّهُ أَحْرَقَ. وَيُقَالُ لِلسَّنَةِ الْجَدْبِ: قَدْ أَمْحَشَتْ كُلَّ شَيْءٍ. فَأَمَّا قَوْلُ النَّابِغَةِ:

جَمِّعْ مِحَاشَكَ يَا يَزِيدُ، فَإِنَّنِي ... أَعْدَدْتُ يَرْبُوعًا لَكُمْ وَتَمِيمَا فَقَالُوا: مَعْنَاهُ جَمِّعْ هَذِهِ الْقَبَائِلَ، وَكَانُوا قَبَائِلَ تَحَالَفُوا بِالنَّارِ.

وَمِمَّا قِيسَ عَلَى هَذَا: مَحَشَ وَجْهَهُ بِالسَّيْفِ مَحْشَةً: ضَرَبَهُ فَقَشَرَ الْجِلْدَ. وَمَرَّتْ غِرَارَةٌ فَمَحَشَتْنِي، أَيْ سَحَجَتْنِي.

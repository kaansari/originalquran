# كَلَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%84%D9%8E%D8%AA%D9%8E/?book=9

(كَلَتَ) الْكَافُ وَاللَّامُ وَالتَّاءُ لَيْسَ بِأَصْلٍ أَصِيلٍ، لَكِنَّهُمْ يَقُولُونَ: الْكَلْتُ: الْجَمْعُ، يُقَالُ امْرَأَةٌ كَلُّوتٌ. وَيَقُولُونَ: الْكِلِّيتُ حَجَرٌ يُسَدُّ بِهِ وِجَارُ الضَّبُعِ. وَكُلُّ هَذَا لَيْسَ بِشَيْءٍ.

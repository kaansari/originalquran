# زَوَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%88%D9%8E%D9%82%D9%8E/?book=9

(زَوَقَ) الزَّاءُ وَالْوَاوُ وَالْقَافُ لَيْسَ بِشَيْءٍ. وَقَوْلُهُمْ زَوَّقْتُ الشَّيْءَ إِذَا زَيَّنْتَهُ وَمَوَّهْتَهُ، لَيْسَ بِأَصْلٍ، يَقُولُونَ إِنَّهُ مِنَ الزَّاوُوقِ، وَهُوَ الزِّئْبَقُ. وَكُلُّ هَذَا كَلَامٌ.

# عَنْقَفِيرٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D9%86%D9%92%D9%82%D9%8E%D9%81%D9%90%D9%8A%D8%B1%D9%8C/?book=9

(عَنْقَفِيرٌ) : الدَّاهِيَةُ. وَهَذَا مِمَّا هُوِّلَ أَيْضًا بِالزِّيَادَةِ. يَقُولُونَ لِلدَّاهِيَةِ عَنْقَاءُ، ثُمَّ يَزِيدُونَ هَذِهِ الزِّيَادَاتِ كَمَا قَدْ كَرَّرْنَا الْقَوْلَ فِيهِ غَيْرَ مَرَّةٍ.

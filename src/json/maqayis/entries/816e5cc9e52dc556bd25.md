# خَزَوَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B2%D9%8E%D9%88%D9%8E/?book=9

(خَزَوَ) الْخَاءُ وَالزَّاءُ وَالْحَرْفُ الْمُعْتَلُّ أَصْلَانِ: أَحَدُهُمَا السِّيَاسَةُ، وَالْآخَرُ الْإِبْعَادُ.

فَأَمَّا الْأَوَّلُ فَقَوْلُهُمْ خَزَوْتُهُ، إِذَا سُسْتَهُ. قَالَ لَبِيدٌ:

وَاخْزُهَا بِالْبِرِّ لِلَّهِ الْأَجَلِّ

وَقَالَ ذُو الْأُصْبُعِ:

لَاهِ ابْنُ عَمِّكَ لَا أَفْضَلْتَ فِي حَسَبٍ ... عَنِّي وَلَا أَنْتَ دَيَّانِي فَتَخِزُونِي

وَأَمَّا الْآخَرُ فَقَوْلُهُمْ: أَخْزَاهُ اللَّهُ، أَيْ أَبْعَدَهُ وَمَقَتَهُ. وَالِاسْمُ الْخِزْيُ. وَمِنْ هَذَا الْبَابِ قَوْلُهُمْ خَزِيَ الرَّجُلُ: اسْتَحْيَا مِنْ قُبْحِ فِعْلِهِ خَزَايَةً، فَهُوَ خَزْيَانُ ; وَذَلِكَ أَنَّهُ إِذَا فَعَلَ ذَلِكَ وَاسْتَحْيَا تَبَاعَدَ وَنَأَى. قَالَ جَرِيرٌ:

وَإِنَّ حِمًى لَمْ يَحْمِهِ غَيْرُ فَرْتَنَى ... وَغَيْرُ ابْنِ ذِي الْكِيرَيْنِ خَزْيَانُ ضَائِعُ

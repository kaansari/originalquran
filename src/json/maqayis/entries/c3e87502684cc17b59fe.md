# خَدَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%AF%D9%8E%D8%B4%D9%8E/?book=9

(خَدَشَ) الْخَاءُ وَالدَّالُ وَالشِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ خَدْشُ الشَّيْءِ لِلشَّيْءِ. يُقَالُ خَدَشْتُ الشَّيْءَ خَدْشًا ; وَجَمْعُ الْخَدْشِ خُدُوشٌ. وَيُقَالُ لِأَطْرَافِ السَّفَا الْخَادِشَةُ ; لِأَنَّهَا تَخْدِشُ. وَيُقَالُ لِكَاهِلِ الْبَعِيرِ [مِخْدَشٌ] ; لِقِلَّةِ لَحْمِهِ، وَتَخْدِيشِهِ فَمَ مُتَعَرِّقِهِ.

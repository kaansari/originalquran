# كَوَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%88%D9%8E%D8%B9%D9%8E/?book=9

(كَوَعَ) الْكَافُ وَالْوَاوُ وَالْعَيْنُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْكُوعُ، وَهُوَ طَرَفُ الزَّنْدِ مِمَّا يَلِي الْإِبْهَامَ. وَالْكَوَعُ: خُرُوجُهُ وَنُتُوُّهُ وَعِظَمُهُ. رَجُلٌ أَكْوَعُ. وَيُقَالُ الْكَوَعُ: إِقْبَالُ الرُّسْغَيْنِ عَلَى الْمَنْكِبَيْنِ. وَكَوَّعَهُ بِالسَّيْفِ: ضَرَبَهُ. وَلَعَلَّهُ بِمَعْنَى أَنْ يُصِيبَ كُوعَهُ.

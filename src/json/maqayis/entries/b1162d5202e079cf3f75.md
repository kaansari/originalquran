# نَثَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%AB%D9%8E%D8%A7/?book=9

(نَثَا) النُّونُ وَالثَّاءُ وَالْحَرْفُ الْمُعْتَلُّ كَلِمَةٌ. يُقَالُ نَثَا الْكَلَامَ يَنْثُو: أَظْهَرَهُ. وَالنَّثَا يَقُولُونَ: أَنْ يُذْكَرَ الْإِنْسَانُ بِغَيْرِ جَمِيلٍ.

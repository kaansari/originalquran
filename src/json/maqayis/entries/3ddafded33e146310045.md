# نَشَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B4%D9%8E%D9%84%D9%8E/?book=9

(نَشَلَ) النُّونُ وَالشِّينُ وَاللَّامُ كَلِمَةٌ تَدُلُّ عَلَى رَفْعِ بَِضْعَةٍ مِنْ قَدْرٍ. وَنَشَلَ اللَّحْمَ مِنَ الْقِدْرِ بِالْمِنْشَلِ، وَهُوَ النَّشِيلُ. وَفَخْذٌ نَاشِلَةٌ: قَلِيلَةُ اللَّحْمِ ; وَالْمِنْشَلُ وَالْمِنْشَالُ: مَا يُنْشَلُ بِهِ. وَيَقُولُونَ: وَمَا أَدْرِي كَيْفَ صِحَّتُهُ: الْمَنْشَلَةُ: مَوْضِعُ الْخَاتَمِ مِنَ الْخِنْصَرِ.

# زَعَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%B9%D9%8E%D9%83%D9%8E/?book=9

(زَعَكَ) الزَّاءُ وَالْعَيْنُ وَالْكَافُ أُصَيْلٌ إِنْ صَحَّ يَدُلُّ عَلَى تَلَبُّثٍ وَحَقَارَةٍ وَلُؤْمٍ. يَقُولُونَ إِنَّ الْأَزْعَكِيَّ: الرَّجُلُ الْقَصِيرُ اللَّئِيمُ. وَكَذَلِكَ الزُّعْكُوكُ. قَالَ الْكِسَائِيُّ: يُقَالُ لِلْقَوْمِ زَعْكَةٌ، إِذَا لَبِثُوا سَاعَةً. وَالزَّعَاكِيكُ مِنَ الْإِبِلِ: الْمُتَرَدِّدَةُ الَخَلْقِ، الْوَاحِدَةُ زُعْكُوكٌ. قَالَ:

تَسْتَنُّ أَوْلَادٌ لَهَا زَعَاكِيكْ

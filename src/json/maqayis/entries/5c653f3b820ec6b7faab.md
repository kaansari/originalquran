# دَثَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D8%AB%D9%8E%D8%A3%D9%8E/?book=9

(دَثَأَ) الدَّالُ وَالثَّاءُ وَالْهَمْزَةُ لَيْسَ أَصْلًا; لِأَنَّهُ مِنْ بَابِ الْإِبْدَالِ. يَقُولُونَ مَطَرٌ دَثَئِيٌّ، وَهُوَ الَّذِي بَيْنَ الْحَمِيمِ وَالصَّيْفِ. وَإِنَّمَا الْأَصْلُ دَفَئِيٌّ، وَهُوَ مِنَ الدِّفْءِ.

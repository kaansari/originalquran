# لَزِمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B2%D9%90%D9%85%D9%8E/?book=9

(لَزِمَ) اللَّامُ وَالزَّاءُ وَالْمِيمُ أَصْلٌ وَاحِدٌ صَحِيحٌ، يَدُلُّ عَلَى مُصَاحَبَةِ الشَّيْءِ بِالشَّيْءِ دَائِمًا. يُقَالُ: لَزِمَهُ الشَّيْءُ يَلْزَمُهُ. وَاللِّزَامُ: الْعَذَابُ الْمُلَازِمُ لِلْكُفَّارِ.

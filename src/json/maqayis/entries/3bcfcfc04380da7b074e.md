# صَأَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D8%A3%D9%91%D9%8E/?book=9

(صَأَّ) الصَّادُ وَالْهَمْزَةُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ: صَأْصَأَ الْجَرْوُ، إِذَا حَرَّكَ عَيْنَيْهِ لِيَفْتَحَهُمَا. وَفِي حَدِيثِ بَعْضِ التَّابِعِينَ: " فَقَّحْنَا وَصَأْصَأْتُمْ ". وَيُقَالُ صَأْصَأَتِ النَّخْلَةُ، إِذَا لَمْ تَقْبَلِ اللَّقَاحَ.

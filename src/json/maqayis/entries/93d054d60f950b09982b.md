# ضَيَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D9%8A%D9%8E%D8%B2%D9%8E/?book=9

(ضَيَزَ) الضَّادُ وَالْيَاءُ وَالزَّاءُ قَدْ مَضَى ذِكْرُهُ، وَأَصْلُهُ فِيمَا يُقَالُ: الْوَاوُ. وَقَدْ قِيلَ: إِنَّهُ مِنْ بَنَاتِ الْيَاءُ، فَلِذَلِكَ ذَكَرْنَاهُ هَاهُنَا. فَالْقِسْمَةُ الضِّيزَى: النَّاقِصَةُ. يُقَالُ: ضِزْتُهُ حَقَّهُ، إِذَا مَنَعْتَهُ. وَحَكَى نَاسٌ ضَأَزَهُ، مَهْمُوزٌ. وَأَنْشَدُوا:

فَحَقُّكَ مَضْئُوزٌ وَأَنْفُكَ رَاغِمُ

لَيْسَ فِي الْبَابِ غَيْرُ هَذَا.

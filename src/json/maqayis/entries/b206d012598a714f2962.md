# ثَكَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D9%83%D9%8E%D9%85%D9%8E/?book=9

(ثَكَمَ) الثَّاءُ وَالْكَافُ وَالْمِيمُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ مُجْتَمَعُ الشَّيْءِ. وَيُقَالُ تَنَحَّ عَنْ ثَكَمِ الطَّرِيقِ، أَيْ مُعْظَمِهِ وَوَاضِحِهِ.

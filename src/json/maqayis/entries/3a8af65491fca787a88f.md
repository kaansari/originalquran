# زَغِبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%BA%D9%90%D8%A8%D9%8E/?book=9

(زَغِبَ) الزَّاءُ وَالْغَيْنُ وَالْبَاءُ أُصَيْلٌ صَحِيحٌ، وَهُوَ الزَّغَبُ، أَوَّلُ مَا يَنْبُتُ مِنَ الرِّيشِ. وَقَدْ يُزْغِبُ الْكَرْمُ، بَعْدَ جَرْيِ الْمَاءِ فِيهِ.

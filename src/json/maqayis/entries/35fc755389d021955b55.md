# مَأَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%A3%D9%8E%D9%84%D9%8E/?book=9

(مَأَلَ) الْمِيمُ وَالْهَمْزَةُ وَاللَّامُ. قَدْ ذَكَرُوا فِيهَا كَلِمَاتٍ مَا أَحْسَبُهَا صَحِيحَةً، لَكِنَّنِي كَتَبْتُهَا لِلْمَعْرِفَةِ. يَقُولُونَ: مَأَلْتُ لِلْأَمْرِ: اسْتَعْدَدْتُ. وَيَقُولُونَ: امْرَأَةٌ مَأْلَةٌ: سَمِينَةٌ. وَيَقُولُونَ: الْمَأْلَةُ: الرَّوْضَةُ، وَالْجَمْعُ مِئَالٌ. وَفِي كُلِّ ذَلِكَ نَظَرٌ.

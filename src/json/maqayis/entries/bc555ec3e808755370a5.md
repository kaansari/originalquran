# مَيَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%8A%D9%8E%D9%86%D9%8E/?book=9

(مَيَنَ) الْمِيمُ وَالْيَاءُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ، هِيَ الْمَيْنُ: الْكَذِبُ. وَمَانَ يَمِينُ. قَالَ:

وَزَعَمْتَ أَنَّكَ قَدْ قَتَلْ ... تَ سَرَاتَنَا كَذِبًا وَمَيْنَا.

# سَلَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%84%D9%8E%D8%B9%D9%8E/?book=9

(سَلَعَ) السِّينُ وَاللَّامُ وَالْعَيْنُ أَصْلٌ يَدُلُّ عَلَى انْصِدَاعِ الشَّيْءِ وَانْفِتَاحِهِ. مِنْ ذَلِكَ السَّلْعِ ; وَهُوَ شَقٌّ فِي الْجَبَلِ كَهَيْئَةِ الصَّدْعِ، وَالْجَمْعُ سُلُوعٌ. وَيُقَالُ تَسَلَّعَ عَقِبُهُ، إِذَا تَشَقَّقَ وَتَزَلَّعَ. وَيُقَالُ سَلَعَ رَأْسَهُ، إِذَا فَلَقَهُ. وَالسِّلْعَةُ: الشَّيْءُ الْمَبِيعُ، وَذَلِكَ أَنَّهَا لَيْسَتْ بِقُِنْيَةٍ تُمْسَكُ، فَالْأَمْرُ فِيهَا وَاسِعٌ. وَالسَّلَعُ: شَجَرَ.

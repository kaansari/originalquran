# كَمَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%85%D9%8E%D9%87%D9%8E/?book=9

(كَمَهَ) الْكَافُ وَالْمِيمُ وَالْهَاءُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ الْكَمَهُ، وَهُوَ الْعَمَى يُولَدُ بِهِ الْإِنْسَانُ، وَقَدْ يَكُونُ مِنْ عَرَضٍ يَعْرِضُ. قَالَ سُوَيْدٌ: كَمِهَتْ عَيْنَاهُ حَتَّى ابْيَضَّتَا ... وَهُوَ يَلْحَى نَفْسَهُ لَمَّا نَزَعْ.

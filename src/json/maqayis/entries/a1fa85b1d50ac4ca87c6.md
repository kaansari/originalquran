# بَيْصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%8A%D9%92%D8%B5%D9%8E/?book=9

(بَيْصَ) الْبَاءُ وَالْيَاءُ وَالصَّادُ لَيْسَ بِأَصْلٍ. لِأَنَّ بَيْصَ إِتْبَاعٌ لِحَيْصَ. يُقَالُ: وَقَعَ الْقَوْمُ فِي حَيْصَ بَيْصَ، أَيِ اخْتِلَاطٍ. قَالَ:

لَمْ تَلْتَحِصْنِي حَيْصَ بَيْصَ لَحَاصِ

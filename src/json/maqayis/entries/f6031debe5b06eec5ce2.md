# خَنَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%86%D9%8E%D8%AB%D9%8E/?book=9

(خَنَثَ) الْخَاءُ وَالنُّونُ وَالثَّاءُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى تَكَسُّرٍ وَتَثَنٍّ. فَالْخَنِثُ: الْمُسْتَرْخِي الْمُتَكَسِّرُ. وَيُقَالُ خَنَثْتُ السِّقَاءَ، إِذَا كَسَرْتَ فَمَهُ إِلَى خَارِجٍ فَشَرِبْتَ مِنْهُ. فَإِنْ كَسَرْتَهَا إِلَى دَاخِلِ فَقَدْ قَبَعْتَهُ. وَامْرَأَةٌ خُنُثٌ: مُتَثَنِّيَةٌ.

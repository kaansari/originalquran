# جَنَيَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%86%D9%8E%D9%8A%D9%8E/?book=9

(جَنَيَ) الْجِيمُ وَالنُّونُ وَالْيَاءُ أَصْلٌ وَاحِدٌ، وَهُوَ أَخْذُ الثَّمَرَةِ مِنْ شَجَرِهَا، ثُمَّ يُحْمَلُ عَلَى ذَلِكَ، تَقُولُ جَنَيْتُ الثَّمَرَةَ أَجْنِيهَا، وَاجْتَنَيْتُهَا. وَثَمَرٌ جَنِيٌّ، أَيْ أُخِذَ لِوَقْتِهِ.

وَمِنَ الْمَحْمُولِ عَلَيْهِ: جَنَيْتُ الْجِنَايَةَ أَجْنِيهَا.

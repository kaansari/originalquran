# خَثِرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%AB%D9%90%D8%B1%D9%8E/?book=9

(خَثِرَ) الْخَاءُ وَالثَّاءُ وَالرَّاءُ أَصْلٌ يَدُلُّ عَلَى غِلَظٍ فِي الشَّيْءِ مَعَ اسْتِرْخَاءٍ. يُقَالُ خَثِرَ اللَّبَنُ، وَهُوَ خَاثِرٌ. وَحَكَى بَعْضُهُمْ: خَثِرَ فُلَانٌ فِي الْحَيِّ، إِذَا أَقَامَ فَلَمْ يَكَدْ يَبْرَحُ. وَلَيْسَ هَذَا بِشَيْءٍ.

# مَرَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B1%D9%8E%D8%AB%D9%8E/?book=9

(مَرَثَ) الْمِيمُ وَالرَّاءُ وَالثَّاءُ كَلِمَةٌ لَيْسَتْ بِأَصْلٍ، بَلْ هِيَ مِنَ الْإِبْدَالِ. وَمَرَثَ الدَّوَاءَ يَمْرُِثُهُ مِثْلُ مَرَسَهُ يَمْرُسُهُ. وَمِنْهُ رَجُلٌ مِمْرَثٌ: صَبُورٌ عَلَى الْخُصُومَاتِ ; وَالْجَمْعُ مَمَارِثٌ، وَالْأَصْلُ السِّينُ وَقَدْ ذُكِرَتَا.

# غَلَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D9%84%D9%8E%D8%AC%D9%8E/?book=9

(غَلَجَ) الْغَيْنُ وَاللَّامُ وَالْجِيمُ كَلِمَةٌ تَدُلُّ عَلَى الْبَغْيِ وَالسَّطْوَةِ. تَقُولُ الْعَرَبُ: هُوَ يَتَغَلَّجُ عَلَيْنَا، أَيْ يَبْغِي. وَعَيْرٌ مِغْلَجٌ: شَلَّالٌ لِلْعَانَةِ. وَيَكُونُ تَغَلُّجُهُ أَيْضًا أَنْ يَشْرَبَ وَيَتَلَمَّظَ بِلِسَانِهِ.

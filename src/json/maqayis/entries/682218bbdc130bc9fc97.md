# قَتَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%AA%D9%8E%D9%86%D9%8E/?book=9

(قَتَنَ) الْقَافُ وَالتَّاءُ وَالنُّونُ كَلِمَةٌ صَحِيحَةٌ. يَقُولُونَ. الْقَتِينُ: الْمَرْأَةُ الْقَلِيلَةُ الطُّعْمِ، وَقَدْ قَتُنَتْ قَتَانَةً. قَالَ الشَّمَّاخُ:

وَقَدْ عَرِقَتْ مَغَابِنُهَا فَجَادَتْ ... بِدِرَّتِهَا قِرَى جَحِنٍ قَتِينِ

أَرَادَ بِهِ الْقُرَادَ الْقَلِيلَ الدَّمِ.

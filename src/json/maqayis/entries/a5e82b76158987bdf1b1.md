# زَغَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%BA%D9%8E%D8%B1%D9%8E/?book=9

(زَغَرَ) الزَّاءُ وَالْغَيْنُ وَالرَّاءُ أُصَيْلٌ. يُقَالُ زَغَرَ الْمَاءُ وَزَخَرَ. وَلَيْسَ هَذَا عِنْدِي مِنْ جِهَةِ الْإِبْدَالِ ; لِأَنَّ قِيَاسَ زَغَرَ قِيَاسٌ صَحِيحٌ، وَسَيَجِيءُ فِي الرُّبَاعِيِّ مَا يُصَحِّحُهُ. وَذَكَرَ ابْنُ دُرَيْدٍ أَنَّ الزَّغَرَ الِاغْتِصَابُ ; يُقَالُ زَغَرْتُ الشَّيْءَ زَغْرًا. قَالَ: وَالزَّغْرُ فِعْلٌ مُمَاتٌ. وَزُغَرُ: اسْمُ امْرَأَةٍ، يُقَالُ إِنَّ عَيْنَ زُغَرَ إِلَيْهَا تُنْسَبُ.

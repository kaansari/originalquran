# كَيَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%8A%D9%8E%D8%B1%D9%8E/?book=9

(كَيَرَ) الْكَافُ وَالْيَاءُ وَالرَّاءُ كَلِمَةٌ، وَهِيَ كِيرُ الْحَدَّادِ. قَالَ أَبُو عَمْرٍو: الْكُوَرُ: الْمَبْنِيُّ مِنَ الطِّينِ، وَالْكِيرُ: الزِّقُّ. قَالَ بِشْرٌ:

كَأَنَّ حَفِيفَ مَنْخَرِهِ إِذَا مَا ... كَتَمْنَ الرَّبْوَ كِيرٌ مُسْتَعَارٌ.

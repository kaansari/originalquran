# هَوَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%88%D9%8E%D9%87%D9%8E/?book=9

(هَوَهَ) الْهَاءُ وَالْوَاوُ وَالْهَاءُ. يَقُولُونَ: الْهَوْهَاءُ: الْأَحْمَقُ. وَيَقُولُونَ: الْهَوَاهِي: الْبَاطِلُ. قَالَ ابْنُ أَحْمَرَ:

فِي كُلِّ يَوْمٍ يَدْعُوَانِ أَطِبَّةً ... إِلَيَّ وَمَا يُجْدُونَ إِلَّا الْهَوَاهِيَا

قَالَ الْخَلِيلُ: وَبِئْرٌ هَوْهَاءُ، عَلَى زِنَةِ حَمْرَاءَ: كَثِيرَةُ الْمَاءِ.

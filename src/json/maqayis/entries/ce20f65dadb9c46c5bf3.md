# وَهَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%87%D9%8E%D8%A8%D9%8E/?book=9

(وَهَبَ) الْوَاوُ وَالْهَاءُ وَالْبَاءُ: كَلِمَاتٌ لَا يَنْقَاسُ بَعْضُهَا عَلَى بَعْضٍ. تَقُولُ: وَهَبْتُ الشَّيْءَ أَهَبُهُ هِبَةً وَمَوْهِبًا. وَاتَّهَبْتُ الْهِبَةَ: قَبِلْتُهَا. وَالْمَوْهِبَةُ: قَلْتٌ يَسْتَنْقِعُ فِيهِ الْمَاءُ ; وَالْجَمْعُ مَوَاهِبُ. وَيُقَالُ أَوْهَبَ إِلَيَّ مِنَ الْمَالِ كَذَا، أَيِ ارْتَفَعَ. وَأَصْبَحَ فُلَانٌ مُوهَبًا لِكَذَا، أَيْ مُعَدًّا لَهُ.

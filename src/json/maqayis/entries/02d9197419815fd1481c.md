# كَفَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%81%D9%8E%D8%A7/?book=9

(كَفَا) الْكَافُ وَالْفَاءُ وَالْحَرْفُ الْمُعْتَلُّ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى الْحَسْبِ الَّذِي لَا مُسْتَزَادَ فِيهِ. يُقَالُ: كَفَاكَ الشَّيْءُ يَكْفِيكَ. وَقَدْ كَفَى كِفَايَةً، إِذَا قَامَ بِالْأَمْرِ. وَالْكُفْيَةُ: الْقُوتُ الْكَافِي، وَالْجَمْعُ كُفًى. وَيُقَالُ حَسْبُكَ زَيْدٌ مِنْ رَجُلٍ، وَكَافِيكَ.

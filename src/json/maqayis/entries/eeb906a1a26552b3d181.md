# رَمَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%85%D9%8E%D9%86%D9%8E/?book=9

(رَمَنَ) الرَّاءُ وَالْمِيمُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ النُ. وَالرُّمَّانَتَانِ: هَضْبَتَانِ فِي بِلَادِ عَبْسٍ. قَالَ:

عَلَى الدَّارِ بِالرُّمَّانَتَيْنِ تَعُوجُ

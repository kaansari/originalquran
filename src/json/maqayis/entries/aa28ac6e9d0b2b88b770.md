# زَكَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%83%D9%8E%D9%85%D9%8E/?book=9

(زَكَمَ) الزَّاءُ وَالْكَافُ وَالْمِيمُ لَيْسَ فِيهِ إِلَّا الزُّكْمَةُ وَالزُّكَامُ، وَيَسْتَعِيرُونَ ذَلِكَ فَيَقُولُونَ: فُلَانٌ زُكْمَةُ أَبَوَيْهِ، وَهُوَ آخِرُ أَوْلَادِهِمَا.

# تَرَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%B1%D9%8E%D8%AD%D9%8E/?book=9

(تَرَحَ) التَّاءُ وَالرَّاءُ وَالْحَاءُ كَلِمَتَانِ مُتَقَارِبَتَانِ. قَالَ الْخَلِيلُ: التَّرَحُ نَقِيضُ الْفَرَحِ. وَيَقُولُونَ: " بَعْدَ كُلِّ فَرْحَةٍ تَرْحَةٌ، وَبَعْدَ كُلِّ حَبْرَةٍ عَبْرَةٌ "، قَالَ الشَّاعِرُ:

وَمَا فَرْحَةٌ إِلَّا سَتُعْقَبُ تَرْحَةً ... وَمَا عَامِرٌ إِلَّا وَشِيكًا سَيَخْرَبُ

وَالْكَلِمَةُ الْأُخْرَى: النَّاقَةُ الْمِتْرَاحُ، وَهِيَ الَّتِي يُسْرِعُ انْقِطَاعُ لَبَنِهَا ; وَالْجَمْعُ مَتَارِيحُ.

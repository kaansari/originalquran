# شَمَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%85%D9%8E%D8%B5%D9%8E/?book=9

(شَمَصَ) الشِّينُ وَالْمِيمُ وَالصَّادُ كَلِمَةٌ وَاحِدَةٌ. يُقَالُ شَمَصْتُ الْفَرَسَ، إِذَا نَزَّقْتَهُ لِيَتَحَرَّكَ. وَيُقَالُ شَمَّصَ إِبِلَهُ، إِذَا طَرَدَهَا طَرْدًا عَنِيفًا.

# فَطَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B7%D9%8E%D8%B3%D9%8E/?book=9

(فَطَسَ) الْفَاءُ وَالطَّاءُ وَالسِّينُ. فِيهِ الْفَطَسُ فِي الْأَنْفِ: انْفِرَاشُهُ. وَفِطِّيسَةُ الْخِنْزِيرِ: أَنْفُهُ. وَالْفِطِّيسُ: الْمِطْرَقَةُ، وَلَعَلَّهَا سُمِّيَتْ بِذَلِكَ لِأَنَّهَا يُكْسَرُ بِهَا الشَّيْءُ، وَيَتَطَامَنُ. وَيَقُولُونَ: فَطَسَ: مَاتَ. وَيَقُولُونَ: الْفَطْسَةُ: خَرَزَةٌ يُؤَخَّذُ بِهَا.

# وَجَذَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AC%D9%8E%D8%B0%D9%8E/?book=9

(وَجَذَ) الْوَاوُ وَالْجِيمُ وَالذَّالُ. كَلِمَةٌ صَحِيحَةٌ، هِيَ الْوَجْذُ، نُقْرَةٌ فِي الصَّخْرَةِ، وَالْجَمْعُ وِجَاذٌ. وَبَلَغَنَا أَنَّهُ يُقَالُ، أَوْجَذَهُ عَلَى الْأَمْرِ، أَكْرَهَهُ.

# مَتَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AA%D9%8E%D8%AD%D9%8E/?book=9

(مَتَحَ) الْمِيمُ وَالتَّاءُ وَالْحَاءُ أُصَيْلٌ يَدُلُّ عَلَى مَدِّ الشَّيْءِ وَإِطَالَتِهِ. وَمَتَحَ النَّهَارُ: امْتَدَّ. وَلَيْلٌ مَتَّاحٌ: طَوِيلٌ. وَمِنْهُ الْمَتْحُ وَهُوَ الِاسْتِقَاءُ ; مَتَحَ يَمْتَحُ مَتْحًا، وَهُوَ مَاتِحٌ وَمَتُوحٌ. وَإِنَّمَا قِيلَ ذَلِكَ لِمَدِّ الرِّشَاءِ. وَبِئْرٌ مَتُوحٌ: قَرِيبَةُ الْمَنْزَعِ.

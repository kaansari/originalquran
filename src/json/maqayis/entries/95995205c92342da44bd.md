# فَهَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D9%87%D9%91%D9%8E/?book=9

(فَهَّ) الْفَاءُ وَالْهَاءُ كَلِمَةٌ وَاحِدَةٌ تَدَلٍّ عَلَى الْعِيِّ وَمَا أَشْبَهَهُ، مِنْ ذَلِكَ الرَّجُلِ الْفَهُّ، وَهُوَ الْعَيِيُّ، وَالْمَرْأَةُ فَهَّةٌ، وَمَصْدَرُهُ الْفَهَاهَةُ. قَالَ:

فَلَمْ تَلْقَنِي فَهًّا وَلَمْ تَلْقَ حُجَّتِي ... مُلَجْلَجَةً أَبْغِي لَهَا مَنْ يُقِيمُهَا

وَيُقَالُ: خَرَجْتُ لِحَاجَةٍ فَأَفَهَّنِي فُلَانٌ حَتَّى فَهِهْتُ، أَيْ أَنْسَانِيهَا.

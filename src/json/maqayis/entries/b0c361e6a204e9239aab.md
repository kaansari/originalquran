# فَوَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D9%88%D9%8E%D8%AD%D9%8E/?book=9

(فَوَحَ) الْفَاءُ وَالْوَاوُ وَالْحَاءُ كَلِمَةٌ تَدُلُّ عَلَى ثَوْرٍ وَغَلَيَانٍ. يُقَالُ: فَاحَتِ الرِّيحُ تَفُوحُ فَوْحًا. وَحَكَى نَاسٌ: فَاحَتِ الْقِدْرُ: غَلَتْ. وَأَفَحْتُهَا أَنَا.

# غَرَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D8%B1%D9%8E%D9%84%D9%8E/?book=9

(غَرَلَ) الْغَيْنُ وَالرَّاءُ وَاللَّامُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْغُرْلَةُ، وَهِيَ الْقُلْفَةُ. وَالْأَغْرَلُ: الْأَقْلَفُ، وَيَقُولُونَ: إِنَّ الْغَرِلَ: الْمُسْتَرْخِي الْخَلْقِ.

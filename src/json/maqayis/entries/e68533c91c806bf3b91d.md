# صَنَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%86%D9%8E%D8%AF%D9%8E/?book=9

(صَنَدَ) الصَّادُ وَالنُّونُ وَالدَّالُ أَصْلٌ صَحِيحٌ، يَدُلُّ عَلَى عِظَمِ قَدْرٍ وَعِظَمِ جِسْمٍ. مِنْ ذَلِكَ الصِّنْدِيدُ، وَهُوَ السَّيِّدُ الشَّرِيفُ، وَالْجَمْعُ: صَنَادِيدُ. وَيُقَالُ صَنَادِيدُ الْبَرَدِ: بَابَاتٌ مِنْهُ ضِخَامٌ. وَغَيْثٌ صِنْدِيدٌ: عَظِيمُ الْقَطْرِ. وَيُقَالُ لِلدَّوَاهِي الْكِبَارِ: صَنَادِيدُ. وَيُرْوَى عَنِ الْحَسَنِ فِي دُعَائِهِ: " نَعُوذُ بِكَ مِنْ صَنَادِيدِ الْقَدَرِ " أَيْ دَوَاهِيهِ.

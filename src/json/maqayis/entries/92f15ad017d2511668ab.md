# كَثَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D8%AB%D9%8E%D9%81%D9%8E/?book=9

(كَثَفَ) الْكَافُ وَالثَّاءُ وَالْفَاءُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى تَرَاكُبِ شَيْءٍ عَلَى شَيْءٍ وَتَجَمُّعٍ. يُقَالُ: هَذَا شَيْءٌ كَثِيفٌ. وَسَحَابٌ كَثِيفٌ وَشَجَرٌ كَثِيفٌ.

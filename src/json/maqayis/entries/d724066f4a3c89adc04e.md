# غَوَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D9%88%D9%8E%D8%AF%D9%8E/?book=9

(غَوَدَ) الْغَيْنُ وَالْوَاوُ وَالدَّالُ أُصَيْلٌ يَدُلُّ عَلَى لِينِ شَيْءٍ وَتَثَنٍّ. فَالْأَغْيَدُ: الْوَسْنَانُ الْمَائِلُ الْعُنُقِ، وَالْجَمْعُ غِيدٌ. وَالْغَيْدَاءُ: الْفَتَاةُ النَّاعِمَةُ، كَأَنَّهَا تَتَثَنَّى. وَالْمَصْدَرُ الْغَيَدُ.

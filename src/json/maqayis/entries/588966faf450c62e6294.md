# عَسَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%B3%D9%8E%D9%83%D9%8E/?book=9

(عَسَكَ) الْعَيْنُ وَالسِّينُ وَالْكَافُ قَرِيبٌ مِنَ الَّذِي قَبْلَهُ. قَالَ الْخَلِيلُ عَسِكَ بِهِ، إِذَا لَزِمَهُ، مِثْلُ سَدِكَ بِهِ. وَأَنْشَدَ الْأَصْمَعِيُّ:

إِذَا شَرَكُ الطَّرِيقِ تَجَشَّمَتْهُ ... عَسِكْنَ بِجَنْبِهِ حَذَرَ الْإِكَامِ

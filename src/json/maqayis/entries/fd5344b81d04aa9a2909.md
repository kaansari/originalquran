# خَتَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%AA%D9%8E%D9%86%D9%8E/?book=9

(خَتَنَ) الْخَاءُ وَالتَّاءُ وَالنُّونُ كَلِمَتَانِ: إِحْدَاهُمَا خَتْنُ الْغُلَامِ الَّذِي يُعْذَرُ. وَالْخِتَانُ: مَوْضِعُ الْقَطْعِ مِنَ الذَّكَرِ.

وَالْكَلِمَةُ الْأُخْرَى الْخَتَنُ، وَهُوَ الصِّهْرُ، وَهُوَ الَّذِي يَتَزَوَّجُ فِي الْقَوْمِ.

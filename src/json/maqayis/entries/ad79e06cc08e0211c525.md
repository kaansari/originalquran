# تَمَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D9%85%D9%8E%D9%83%D9%8E/?book=9

(تَمَكَ) التَّاءُ وَالْمِيمُ وَالْكَافُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ ارْتِفَاعُ الشَّيْءِ. يُقَالُ تَمَكَ السَّنَامُ إِذَا عَلَا ; وَهُوَ سَنَامٌ تَامِكٌ. وَذَكَرَ ابْنُ دُرَيْدٍ: أَتْمَكَهَا الْكَلَأُ إِذَا أَسْمَنَهَا. وَاللَّهُ أَعْلَمُ.

# لَيَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%8A%D9%8E%D8%A7/?book=9

(لَيَا) اللَّامُ وَالْيَاءُ وَالْأَلِفُ، يُقَالُ إِنَّهُ شَيْءٌ مِنَ النَّبْتِ. يَقُولُونَ: اللِّيَاءُ: شَيْءٌ كَالْحِمَّصِ شَدِيدُ الْبَيَاضِ. يُقَالُ لِلْمَرْأَةِ: كَأَنَّهَا لِيَاءَةٌ.

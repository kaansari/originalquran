# جَثَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%AB%D9%8E%D9%84%D9%8E/?book=9

(جَثَلَ) الْجِيمُ وَالثَّاءُ وَاللَّامُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى لِينِ الشَّيْءِ. يُقَالُ شَعْرٌ جَثْلٌ: كَثِيرٌ لَيِّنٌ. وَاجْثَأَلَّ النَّبْتُ: طَالَ. وَاجْثَأَلَّ الطَّائِرُ: نَفَشَ رِيشَهُ. وَمِمَّا شَذَّ عَنِ الْأَصْلِ: " ثَكِلَتْهُ الْجَثَلُ " وَهِيَ أُمُّهُ. وَيُقَالُ الْجَثْلَةُ: النَّمْلَةُ السَّوْدَاءُ.

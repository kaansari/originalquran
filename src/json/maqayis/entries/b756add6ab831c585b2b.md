# سَدَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D8%AF%D9%8E%D8%AC%D9%8E/?book=9

(سَدَجَ) السِّينُ وَالدَّالُ وَالْجِيمُ، يَقُولُونَ إِنَّ الْمُسْتَعْمَلَ مِنْهُ حَرْفٌ وَاحِدٌ، وَهُوَ التَّسَدُّجُ، يُقَالُ [رَجُلٌ] سَدَّاجٌ، إِذَا قَالَ الْأَبَاطِيلَ وَأَلَّفَهَا.

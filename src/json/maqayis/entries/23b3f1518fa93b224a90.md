# شَنَِصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%86%D9%90%D9%8E%D8%B5%D9%8E/?book=9

(شَنَِصَ) الشِّينُ وَالنُّونُ وَالصَّادُ كَلِمَةٌ إِنْ صَحَّتْ. يَقُولُونَ: فَرَسٌ شَنَاصِيٌّ، أَيْ طَوِيلٌ. قَالَ:

وَشَنَاصِيٌّ إِذَا هِيجَ طَمَرْ

وَيُقَالُ: إِنَّمَا هُوَ نَشَاصِيٌّ. وَحُكِيَ: شَنَِصَ بِهِ، مِثْلُ سَدِكَ.

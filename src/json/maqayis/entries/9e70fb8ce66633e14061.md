# غَلَطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D9%84%D9%8E%D8%B7%D9%8E/?book=9

(غَلَطَ) الْغَيْنُ وَاللَّامُ وَالطَّاءُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْغَلَطُ: خِلَافُ الْإِصَابَةِ. يُقَالُ: غَلِطَ يَغْلَطُ غَلَطًا. وَبَيْنَهُمْ أُغْلُوطَةٌ، أَيْ شَيْءٌ يُغَالِطُ بِهِ بَعْضُهُمْ بَعْضًا.

# خَمَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%85%D9%8E%D8%B9%D9%8E/?book=9

(خَمَعَ) الْخَاءُ وَالْمِيمُ وَالْعَيْنُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى قِلَّةِ الِاسْتِقَامَةِ، [وَ] عَلَى الِاعْوِجَاجِ. فَمِنْ ذَلِكَ خَمَعَ الْأَعْرَجُ. وَيُقَالُ لِلضِّبَاعِ الْخَوَامِعُ ; لِأَنَّهُنَّ عُرْجٌ. وَالْخِمْعُ: اللِّصُّ. وَالْخِمْعُ: الذِّئْبُ. وَالْقِيَاسُ وَاحِدٌ.

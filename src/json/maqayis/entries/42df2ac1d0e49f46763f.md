# مَوَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D9%88%D9%8E%D8%AC%D9%8E/?book=9

(مَوَجَ) الْمِيمُ وَالْوَاوُ وَالْجِيمُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى اضْطِرَابٍ فِي الشَّيْءِ، وَمَاجَ النَّاسُ يَمُوجُونَ، إِذَا اضْطَرَبُوا. وَمَاجَ أَمْرُهُمْ وَمَرِجَ: اضْطَرَبَ ; وَالْمَوْجُ: مَوْجُ الْبَحْرِ، سُمِّيَ لِاضْطِرَابِهِ، وَمَاجَ يَمُوجُ مَوْجًا وَمَوَجَانًا، وَكُلُّ شَيْءٍ اضْطَرَبَ فَقَدْ مَاجَ.

# لَبَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%A8%D9%8E%D8%AC%D9%8E/?book=9

(لَبَجَ) اللَّامُ وَالْبَاءُ وَالْجِيمُ كَلِمَتَانِ لَا تَنْقَاسَانِ. فَالْأُولَى قَوْلُهُمْ: لُبِجَ بِهِ، إِذَا صُرِعَ: وَحَيٌّ لَبِيجٌ، لِلْحَيِّ إِذَا نَزَلَ وَاسْتَقَرَّ مَكَانَهُ. قَالَ:

كَأَنَّ ثِقَالَ الْمُزْنِ بَيْنَ تَضَارُعٍ ... وَشَابَةَ بَرْكٌ مِنْ جُذَامَ لَبِيجُ

وَالْأُخْرَى اللُّبْجَةُ: حَدِيدَةٌ ذَاتُ شُعَبٍ، كَأَنَّهَا كَفٌّ بِأَصَابِعِهَا.

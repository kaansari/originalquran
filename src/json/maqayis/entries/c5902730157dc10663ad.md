# رَهَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%87%D9%8E%D8%AF%D9%8E/?book=9

(رَهَدَ) الرَّاءُ وَالْهَاءُ وَالدَّالُ أُصَيْلٌ يَدُلُّ عَلَى نَعْمَةٍ، وَهِيَ الرَّهَادَةُ. وَيُقَالُ هِيَ رَهِيدَةٌ، أَيْ رَخْصَةٌ. فَأَمَّا ابْنُ دُرَيْدٍ فَقَدْ ذَكَرَ مَا يُقَارِبُ هَذَا الْقِيَاسَ، قَالَ: يُقَالُ رَهَدْتُ الشَّيْءَ رَهْدًا، إِذَا سَحَقْتَهُ سَحْقًا شَدِيدًا. قَالَ: وَالرَّهِيدَةُ: بُرٌّ يُدَقُّ وَيُصَبُّ عَلَيْهِ اللَّبَنُ.

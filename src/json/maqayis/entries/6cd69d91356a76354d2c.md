# قَضَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%B6%D9%8E%D9%85%D9%8E/?book=9

(قَضَمَ) الْقَافُ وَالضَّادُ وَالْمِيمُ كَلِمَتَانِ مُتَبَايِنَتَانِ لَا مُنَاسَبَةَ بَيْنَهُمَا: إِحْدَاهُمَا الْقَضْمُ: قَضْمُ الدَّابَّةِ شَعِيرَهَا; يُقَالُ قَضِمَتْ تَقْضَمُ. وَيَقُولُونَ: مَا ذُقْتُ قَضَامًا. وَيُقَالُ: الْقَضْمُ: الْأَكْلُ بِأَطْرَافِ الْأَسْنَانِ، وَالْخَضْمُ بِالْفَمِ كُلِّهِ. وَالْكَلِمَةُ الْأُخْرَى: الْقَضِيمُ، يُقَالُ إِنَّهُ الْجِلْدُ الْأَبْيَضُ، أَوِ الصَّحِيفَةُ الْبَيْضَاءُ. قَالَ النَّابِغَةُ:

كَأَنَّ مَجَرَّ الرَّامِسَاتِ ذُيُولَهَا ... عَلَيْهِ قَضِيمٌ نَمَّقَتْهُ الصَّوَانِعُ.

# يَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%8A%D9%8E%D8%A7/?book=9

( [يَا] ) الْيَاءُ وَالْأَلِفُ: أَدَاةٌ، وَهِيَ يَاءٌ تَصْلُحُ لِلنِّدَاءِ نَحْوَ يَا زَيْدُ، وَقَدْ يَكُونُ تَعَجُّبًا وَتَلَذُّذًا نَحْوَ قَوْلِهِمْ: يَا بَرْدَهَا عَلَى الْفُؤَادِ. وَيَكُونُ تَلَهُّفًا كَقَوْلِ الْقَائِلِ: يَا حَسْرَتَا عَلَى كَذَا.

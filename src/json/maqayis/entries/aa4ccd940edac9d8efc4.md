# بَوْشٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%88%D9%92%D8%B4%D9%8C/?book=9

(بَوْشٌ) الْبَاءُ وَالْوَاوُ وَالشِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ التَّجَمُّعُ مِنْ أَصْنَافٍ مُخْتَلِفِينَ. يُقَالُ: بَوْشٌ بَائِشٌ، وَلَيْسَ هُوَ عِنْدَنَا مِنْ صَمِيمِ كَلَامِ الْعَرَبِ.

# مَرَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B1%D9%8E%D8%B9%D9%8E/?book=9

(مَرَعَ) الْمِيمُ وَالرَّاءُ وَالْعَيْنُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى خِصْبٍ وَخَيْرٍ. وَمَرَعَ الْمَكَانُ. وَأَمْرَعَ الْقَوْمُ: أَصَابُوهُ مَرِيعًا. وَأَمْرَعَ الْوَادِي: أَكْلَأَ.

# وَجَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AC%D9%8E%D9%89/?book=9

(وَجَى) الْوَاوُ وَالْجِيمُ وَالْحَرْفُ الْمُعْتَلُّ: يَقُولُونَ: تَرَكْتُهُ وَمَا فِي قَلْبِي مِنْهُ أَوْجَى، أَيْ يَئِسْتُ مِنْهُ. وَيَقُولُونَ: سَأَلْتُهُ فَأَوْجَى عَلَيَّ، أَيْ بَخِلَ عَلَيَّ.

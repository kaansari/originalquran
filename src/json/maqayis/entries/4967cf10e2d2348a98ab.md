# وَقَذَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%82%D9%8E%D8%B0%D9%8E/?book=9

(وَقَذَ) الْوَاوُ وَالْقَافُ وَالذَّالُ: كَلِمَةٌ تَدُلُّ عَلَى ضَرْبٍ بِخَشَبٍ. مِنْهُ الْوَقْذُ: الْإِيلَامُ بِالضَّرْبِ. وَشَاةٌ مَوْقُوذَةٌ: ضُرِبَتْ بِالْخَشَبِ حَتَّى مَاتَتْ.

وَمِمَّا لَيْسَ مِنْ هَذَا الْقِيَاسِ وُقِذَتِ النَّاقَةُ: دَرَّتْ عَلَى كَرْهٍ فَقَلَّ لَبَنُهَا.

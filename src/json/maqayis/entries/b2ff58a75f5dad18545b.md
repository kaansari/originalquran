# خَمَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%85%D9%8E%D8%B4%D9%8E/?book=9

(خَمَشَ) الْخَاءُ وَالْمِيمُ وَالشِّينُ أَصْلٌ وَاحِدٌ، وَهُوَ الْخَدْشُ وَمَا قَارَبَهُ. يُقَالُ خَمَشْتُ خَمْشًا. وَالْخُمُوشُ: جَمَعَ خَمْشٍ. قَالَ:

هَاشِمٌ جَدُّنَا فَإِنْ كُنْتِ غَضْبَى ... فَامْلَئِي وَجْهَكِ الْجَمِيلَ خُمُوشًا

وَالْخُمُوشُ: الْبَعُوضُ. قَالَ:

كَأَنَّ وَغَى الْخَمُوشِ بِجَانِبَيْهِ ... وَغَى رَكْبٍ أُمَيْمُ ذَوِي زِيَاطِ

وَالْخُمَاشَةُ مِنَ الْجِرَاحَةِ، وَالْجَمْعُ خُمَاشَاتٌ: مَا كَانَ مِنْهَا لَيْسَ لَهُ أَرْشٌ مَعْلُومٌ. وَهُوَ قِيَاسُ الْبَابِ، كَأَنَّ ذَلِكَ يَكُونُ كَالْخَدْشِ.

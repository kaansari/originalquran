# هَكَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%83%D9%8E%D9%84%D9%8E/?book=9

(هَكَلَ) الْهَاءُ وَالْكَافُ وَاللَّامُ يَدُلُّ عَلَى إِشْرَافٍ وَعُلُوٍّ. مِنْهُ الْهَيْكَلُ: الْفَرَسُ الطَّوِيلُ. قَالَ:

وَقَدْ أَغْدُو بِطِرْفٍِ هَيْ ... كَلٍ ذِي مَيْعَةٍ سَكْبِ

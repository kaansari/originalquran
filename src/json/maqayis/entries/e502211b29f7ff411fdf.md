# مَحَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AD%D9%8E%D9%84%D9%8E/?book=9

(مَحَلَ) الْمِيمُ وَالْحَاءُ وَاللَّامُ أَصْلٌ صَحِيحٌ لَهُ مَعْنَيَانِ: أَحَدُهُمَا قِلَّةُ الْخَيْرِ، وَالْآخَرُ الْوِشَايَةُ وَالسِّعَايَةُ.

فَالْمَحْلُ: انْقِطَاعُ الْمَطَرِ وَيُبْسُ الْأَرْضِ مِنَ الْكَلَأِ. يُقَالُ: أَرْضٌ مُحُولٌ، عَلَى فُعُولٍ بِالْجَمْعِ. قَالَ الْخَلِيلُ: يُحْمَلُ ذَلِكَ عَلَى الْمَوَاضِعِ. وَأَمْحَلَتْ فَهِيَ مُمْحِلٌ. وَأَمْحَلَ الْقَوْمُ. وَزَمَانٌ مَاحِلٌ.

وَالْمَعْنَى الْآخَرُ مَحَلَ بِهِ، إِذَا سَعَى بِهِ. وَفِي الدُّعَاءِ: " «لَا تَجْعَلِ الْقُرْآنَ بِنَا مَاحِلًا» "، أَيْ لَا تَجْعَلْهُ يَشْهَدُ عِنْدَكَ عَلَيْنَا بِتَرْكِنَا اتِّبَاعَهُ، أَيِ اجْعَلْنَا مِمَّنْ يَتْبَعُ الْقُرْآنَ وَيَعْمَلُ بِهِ.

وَمَا يُبَايِنُ هَذَيْنِ الْمَعْنَيَيْنِ: لَبَنٌ مُمَحَّلٌ، مَحَّلَهُ الْقَوْمُ، أَيْ حَقَنُوهُ.

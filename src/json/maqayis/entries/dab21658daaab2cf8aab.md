# وَتَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%AA%D9%8E%D8%AD%D9%8E/?book=9

(وَتَحَ) الْوَاوُ وَالتَّاءُ وَالْحَاءُ: كَلِمَةٌ تَدُلُّ عَلَى قِلَّةٍ فِي شَيْءٍ. فَالْوَتْحُ وَالْوَتَحُ الْقَلِيلُ. يُقَالُ وَتَحَ الْعَطِيَّةَ. وَتَوَتَّحْتُ مِنَ الشَّرَابِ: شَرِبْتُ مِنْهُ قَلِيلًا. وَأَوْتَحْتُ حَظَّهُ: أَقْلَلْتُهُ.

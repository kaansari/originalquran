# حَيَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%8A%D9%8E%D9%82%D9%8E/?book=9

(حَيَقَ) الْحَاءُ وَالْيَاءُ وَالْقَافُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ نُزُولُ الشَّيْءِ بِالشَّيْءِ، يُقَالُ حَاقَ بِهِ السُّوءُ يَحِيقُ. قَالَ اللَّهُ تَعَالَى: {وَلَا يَحِيقُ الْمَكْرُ السَّيِّئُ إِلَّا بِأَهْلِهِ} [فاطر: 43] .

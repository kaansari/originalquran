# خَوِثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%88%D9%90%D8%AB%D9%8E/?book=9

(خَوِثَ) الْخَاءُ وَالْوَاوُ وَالثَّاءُ أُصَيْلٌ لَيْسَ بِمُطَّرِدٍ وَلَا يُقَاسُ عَلَيْهِ. يَقُولُونَ خَوِثَتِ الْمَرْأَةُ، إِذَا عَظُمَ بَطْنُهَا. وَيُقَالُ بَلِ الْخَوْثَاءُ النَّاعِمَةُ. قَالَ:

عَلِقَ الْقَلْبَ حُبُّهَا وَهَوَاهَا ... وَهِيَ بِكْرٌ غَرِيرَةٌ خَوْثَاءُ

# بَذَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B0%D9%8E%D8%AE%D9%8E/?book=9

(بَذَخَ) الْبَاءُ وَالذَّالُ وَالْخَاءُ أَصْلٌ وَاحِدٌ، وَهُوَ الْعُلُوُّ وَالتَّعَظُّمُ. يُقَالُ: بَذَخَ: إِذَا تَعَظَّمَ، وَفُلَانٌ [فِي] بَاذِخٍ مِنَ الشَّرَفِ، أَيْ: عَالٍ.

# وَبَشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D8%A8%D9%8E%D8%B4%D9%8E/?book=9

(وَبَشَ) الْوَاوُ وَالْبَاءُ وَالشِّينُ كَلِمَةٌ تَدُلُّ عَلَى اخْتِلَاطٍ. يُقَالُ: جَاءَ أَوْبَاشٌ مِنَ النَّاسِ، أَيْ أَخْلَاطٌ. وَأَوْبَشَتِ الْأَرْضُ: اخْتَلَطَ نَبَاتُهَا.

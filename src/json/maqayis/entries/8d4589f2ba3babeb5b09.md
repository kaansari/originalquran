# خَثَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%AB%D9%91%D9%8E/?book=9

(خَثَّ) الْخَاءُ وَالثَّاءُ لَيْسَ أَصْلًا وَلَا فَرْعًا صَحِيحًا يُعَرَّجُ عَلَيْهِ، وَلَكُنَّا نَذْكُرُ مَا يَذْكُرُونَهُ. يَقُولُونَ: الْخُثُّ مَا أُوخِفَ مِنْ أَخْثَاءِ الْبَقْرِ وَطُلِيَ بِهِ شَيْءٌ، وَلَيْسَ هَذَا بِشَيْءٍ، وَيُقَالُ الْخُثُّ: غُثَاءُ السَّيْلِ إِذَا تَرَكَهُ السَّيْلُ فَيَبِسَ وَاسْوَدَّ.

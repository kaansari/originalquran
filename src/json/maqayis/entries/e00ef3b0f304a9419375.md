# جَلَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%84%D9%8E%D9%82%D9%8E/?book=9

(جَلَقَ) الْجِيمُ وَاللَّامُ وَالْقَافُ لَيْسَ أَصْلًا وَلَا فَرْعًا. وَجِلَّقٌ: بَلَدٌ، وَلَيْسَ عَرَبِيًّا. قَالَ:

لِلَّهِ دَرُّ عِصَابَةٍ نَادَمْتُهُمْ ... يَوْمًا بِجِلَّقَ فِي الزَّمَانِ الْأَوَّلِ

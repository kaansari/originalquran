# بَهَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%87%D9%8E%D9%86%D9%8E/?book=9

(بَهَنَ) الْبَاءُ وَالْهَاءُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ، وَفِيهَا أَيْضًا رِدَّةٌ يُقَالُ الْبَهْنَانَةُ الْمَرْأَةُ الضَّحَّاكَةُ، وَيُقَالُ الطَّيِّبَةُ الرِّيحِ. وَقَوْلُهُ:

أَلَا قَالَتْ بَهَانِ وَلِمَ تَأَبَّقْ ... بَلِيتَ وَلَا يَلِيقُ بِكَ النَّعِيمُ

فَإِنَّهُ أَرَادَ الِاسْمَ الَّذِي ذَكَرْنَاهُ، فَأَخْرَجَهُ عَلَى فَعَالِ.

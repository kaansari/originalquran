# بَلَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%84%D9%8E%D8%B2%D9%8E/?book=9

(بَلَزَ) الْبَاءُ وَاللَّامُ وَالزَّاءُ لَيْسَ بِأَصْلٍ، وَفِيهِ كُلَيْمَاتٌ، فَالْبِلِزُ الْمَرْأَةُ الْقَصِيرَةُ. وَيَقُولُونَ الْبَلْأَزُ: الْقَصِيرُ مِنَ الرِّجَالِ وَالْبَلْأَزَةُ: الْأَكْلُ. وَفِي جَمِيعِ ذَلِكَ نَظَرٌ.

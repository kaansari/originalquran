# حَضَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%B6%D9%8E%D9%84%D9%8E/?book=9

(حَضَلَ) الْحَاءُ وَالضَّادُ وَاللَّامُ كَلِمَةٌ وَاحِدَةٌ لَيْسَتْ أَصْلًا وَلَا يُقَاسُ عَلَيْهَا ; يُقَالُ حَضِلَتِ النَّخْلَةُ، إِذَا فَسَدَ أُصُولُ سَعَفِهَا.

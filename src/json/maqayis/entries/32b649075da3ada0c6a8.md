# ثَعِطَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%B9%D9%90%D8%B7%D9%8E/?book=9

(ثَعِطَ) الثَّاءُ وَالْعَيْنُ وَالطَّاءُ كَلِمَةٌ صَحِيحَةٌ. يُقَالُ ثَعِطَ اللَّحْمُ إِذَا تَغَيَّرَ وَأَنْتَنَ. وَقَالَ:

يَأْكُلُ لَحْمًا بَائِتًا قَدْ ثَعِطَا

وَمِمَّا حُمِلَ عَلَيْهِ الثَّعِيطُ دُقَاقُ التُّرَابِ الَّذِي تَسْفِيهِ الرِّيحُ.

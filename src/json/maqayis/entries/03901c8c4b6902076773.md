# لَكَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D9%83%D9%8E%D9%86%D9%8E/?book=9

(لَكَنَ) اللَّامُ وَالْكَافُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ، هِيَ اللُّكْنَةُ، وَهِيَ الْعِيُّ فِي اللِّسَانِ. وَرَجُلٌ أَلْكَنُ وَامْرَأَةٌ لَكْنَاءُ، وَهُوَ اللَّكَنُ أَيْضًا.

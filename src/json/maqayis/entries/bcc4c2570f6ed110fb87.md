# صَلَغَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%84%D9%8E%D8%BA%D9%8E/?book=9

(صَلَغَ) الصَّادُ وَاللَّامُ وَالْغَيْنُ لَيْسَ بِأَصْلٍ ; لِأَنَّهُ مِنْ بَابِ الْإِبْدَالِ. يُقَالُ لِلَّذِي تَمَّ سِنُّهُ مِنَ الضَّأْنِ فِي السَّنَةِ الْخَامِسَةِ: صَالِغٌ. وَقَدْ صَلَغَ صُلُوغًا.

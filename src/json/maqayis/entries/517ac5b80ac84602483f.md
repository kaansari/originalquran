# عَدَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D8%AF%D9%8E%D8%B3%D9%8E/?book=9

(عَدَسَ) الْعَيْنُ وَالدَّالُ وَالسِّينُ لَيْسَ فِيهِ مِنَ اللُّغَةِ شَيْءٌ، لَكِنَّهُمْ يُسَمُّونَ الْحَبَّ الْمَعْرُوفَ عَدَسًا. وَيَقُولُونَ: عَدَسْ، زَجْرٌ لِلْبِغَالِ. قَالَ:

عَدَسْ مَا لِعَبَّادٍ عَلَيْكِ إِمَارَةٌ ... نَجَوْتِ وَهَذَا تَحْمِلِينَ طَلِيقُ

وَقَوْلُهُ:

إِذَا حَمَلْتُ بِزَّتِي عَلَى عَدَسْ

فَإِنَّهُ يُرِيدُ الْبَغْلَةَ، سَمَّاهَا " عَدَسْ " بِزَجْرِهَا.

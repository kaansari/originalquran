# شَعَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%B9%D9%8E%D8%AB%D9%8E/?book=9

(شَعَثَ) الشِّينُ وَالْعَيْنُ وَالثَّاءُ أَصْلٌ يَدُلُّ عَلَى انْتِشَارٍ فِي الشَّيْءِ. يَقُولُونَ: لَمِ اللَّهُ شَعَثَكُمْ، وَجَمَعَ شَعَثَكُمْ. أَيْ مَا تَفَرَّقَ مِنْ أَمْرِكُمْ. وَالشَّعَثُ شَعَثُ رَأْسِ السِّوَاكِ وَالْوَتِدِ. وَيُسَمُّونَ الْوَتِدَ أَشْعَثَ لِذَلِكَ.

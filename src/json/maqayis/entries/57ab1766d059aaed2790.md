# عَمَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D9%85%D9%8E%D9%86%D9%8E/?book=9

(عَمَنَ) الْعَيْنُ وَالْمِيمُ وَالنُّونُ لَيْسَ بِأَصْلٍ، وَفِيهِ عُمَانُ: بَلَدٌ. وَيَقُولُونَ أَعْمَنَ، إِذَا أَتَى عُمَانَ. قَالَ:

فَإِنْ تُتْهِمُوا أُنْجِدْ خِلَافًا عَلَيْكُمْ ... وَإِنْ تُعْمِنُوا مُسْتَحْقِبِي الشَّرِّ أُعْرِقِ

# فَيَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D9%8A%D9%8E%D8%AE%D9%8E/?book=9

(فَيَخَ) الْفَاءُ وَالْيَاءُ وَالْخَاءُ كَلِمَةٌ. يَقُولُونَ: أَفَاخَ يُفِيخُ بِرِيحِهِ. وَفِي الْحَدِيثِ: «كُلُّ بَائِلَةٍ تُفِيخُ ".» وَيَقُولُونَ - وَمَا أُرَاهَا صَحِيحَةً - إِنَّ الْفَيْخَةَ: السُّكُرُّجَةُ.

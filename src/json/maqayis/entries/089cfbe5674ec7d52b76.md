# فَخَذَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AE%D9%8E%D8%B0%D9%8E/?book=9

(فَخَذَ) الْفَاءُ وَالْخَاءُ وَالذَّالُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ الْفَخِذُ مِنَ الْإِنْسَانِ، مَعْرُوفَةٌ، وَاسْتُعِيرَ فَقِيلَ الْفَخِذُ بِسُكُونِ الْخَاءِ، دُونَ الْقَبِيلَةِ وَفَوْقَ الْبَطْنِ، وَالْجَمْعُ أَفْخَاذٌ.

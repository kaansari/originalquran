# تَوَلَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D9%88%D9%8E%D9%84%D9%8E/?book=9

(تَوَلَ) التَّاءُ وَالْوَاوُ وَاللَّامُ كَلِمَةٌ مَا أَحْسَبُهَا صَحِيحَةً، لَكِنَّهَا قَدْ رُوِيَتْ قَالُوا: التُِّوَلَةُ جِنْسٌ مِنَ السِّحْرِ. وَقَالُوا: هُوَ شَيْءٌ تَجْعَلُهُ الْمَرْأَةُ فِي عُنُقِهَا تَتَحَسَّنُ بِهِ عِنْدَ زَوْجِهَا.

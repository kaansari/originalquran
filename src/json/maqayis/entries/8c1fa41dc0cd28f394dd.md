# حَنَاتِمُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D9%86%D9%8E%D8%A7%D8%AA%D9%90%D9%85%D9%8F/?book=9

(وَالْحَنَاتِمُ) : سَحَائِبُ سُودٌ. وَكُلُّ أَسْوَدَ حَنْتَمٌ. وَكَذَلِكَ الْخُضْرُ عِنْدَ الْعَرَبِ سُودٌ، وَمِنْهَا سُمِّيَتِ الْجِرَارَ حَنَاتِمَ، وَكَانَتِ الْجِرَارُ فِي الْجَاهِلِيَّةِ خُضْرًا، فَسَمَّتْهَا الْعَرَبُ حَنَاتِمَ.

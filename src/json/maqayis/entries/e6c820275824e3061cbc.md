# الْعُسْقُولُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8F%D8%B3%D9%92%D9%82%D9%8F%D9%88%D9%84%D9%8F/?book=9

(الْعُسْقُولُ) : قِطْعَةُ السَّرَابِ. وَهَذَا مِمَّا زِيدَتْ فِيهِ اللَّامُ. وَالْأَصْلُ الْعَسَقُ، يُقَالُ إِنَّهُ الْإِطَاقَةُ بِالشَّيْءِ، مِنَ اللُّزُومِ الَّذِي ذَكَرْنَاهُ.

(الْعَسَلَّقُ) : الظَّلِيمُ. مُمْكِنٌ أَنْ يَكُونَ مِنَ السُّرْعَةِ وَيَكُونُ الْقَافُ زَائِدَةٌ، وَيَكُونُ مِنَ الْعَسَلَانِ ; وَيُمْكِنُ أَنْ يَكُونَ الْعَيْنُ زَائِدَةٌ، وَيَكُونُ مِنَ السَّلْقِ وَالتَّسَلُّقِ. وَكُلُّ ذَلِكَ جَيِّدٌ.

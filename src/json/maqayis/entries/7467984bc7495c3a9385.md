# سَلَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B3%D9%8E%D9%84%D9%8E%D8%AA%D9%8E/?book=9

(سَلَتَ) السِّينُ وَاللَّامُ وَالتَّاءُ أَصْلٌ وَاحِدٌ، وَهُوَ جَلْفُ الشَّيْءِ عَنِ الشَّيْءِ وَقَشْرُهُ. يُقَالُ سَلَتَتِ الْمَرْأَةُ خِضَابَهَا عَنْ يَدِهَا. وَمِنْهُ سَلَتَ فُلَانٌ أَنْفَ فُلَانٍ بِالسَّيْفِ سَلْتًا، وَذَلِكَ إِذَا أَخَذَهُ كُلَّهُ. وَالرَّجُلُ أَسْلَتُ. وَيُقَالُ إِنَّ الْمَرْأَةَ الَّتِي لَا تَتَعَهَّدُ الْخِضَابَ يُقَالُ لَهَا السَّلْتَاءُ. وَمِنَ الْبَابِ السُّلْتُ: ضَرْبٌ مِنَ الشَّعِيرِ لَا يَكَادُ [يَكُونُ] لَهُ قِشْرٌ، وَالْعَرَبُ تُسَمِّيهِ الْعُرْيَانَ.

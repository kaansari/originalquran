# وَيَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%8A%D9%8E%D8%AD%D9%8E/?book=9

(وَيَحَ) الْوَاوُ وَالْيَاءُ وَالْحَاءُ. يُقَالُ وَيْحَ: كَلِمَةُ رَحْمَةٍ لِمَنْ تَنْزِلُ بِهِ بَلِيَّةٌ. قَالَ الْخَلِيلُ: لَمْ يُسْمَعْ عَلَى بِنَائِهِ إِلَّا وَيْحَ، وَوَيْسَ، وَوَيْهَ، وَوَيْلَ، وَوَيْبَ. وَهِيَ مُتَقَارِبَةُ الْمَعْنَى.

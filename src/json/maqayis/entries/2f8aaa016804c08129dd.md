# جَيْضٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%8A%D9%92%D8%B6%D9%8C/?book=9

(جَيْضٌ) الْجِيمُ وَالْيَاءُ وَالضَّادُ كَلَامٌ قَلِيلٌ يَدُلُّ عَلَى جِنْسٍ مِنَ الْمَشْيِ. يُقَالُ مَشَى مِشْيَةً جِيَضًّا، وَهِيَ مِشْيَةٌ فِيهَا اخْتِيَالٌ. وَجَاضَ يَجِيضُ، إِذَا مَرَّ مُرُورَ الْفَارِّ.

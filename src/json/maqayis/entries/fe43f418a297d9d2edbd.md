# حَضْرَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%B6%D9%92%D8%B1%D9%8E%D9%85%D9%8E/?book=9

(حَضْرَمَ) فِي كَلَامِهِ حَضْرَمَةً، فَقَدْ قِيلَ كَذَا بِالضَّادِ. فَإِنْ كَانَتْ صَحِيحَةً فَالْمِيمُ زَائِدَةٌ، كَأَنَّهُ تَشَبَّهَ بِالْحَاضِرَةِ الَّذِينَ لَا يُقِيمُونَ إِعْرَابَ الْكَلَامِ. وَالْحَضْرَمَةُ: مُخَالَفَةُ الْإِعْرَابِ، وَاللَّحْنُ.

# الثُّفْرُوقُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D8%AB%D9%91%D9%8F%D9%81%D9%92%D8%B1%D9%8F%D9%88%D9%82%D9%8F/?book=9

(الثُّفْرُوقُ) : قِمَعُ التَّمْرَةِ. وَهَذَا مَنْحُوتٌ مِنَ الثَّفْرِ وَهُوَ الْمُؤَخَّرُ، وَمِنْ فَرَقَ ; لِأَنَّهُ شَيْءٌ فِي مُؤَخَّرِ التَّمْرَةِ يُفَارِقُهَا. وَهَذَا احْتِمَالٌ لَيْسَ بِالْبَعِيدِ.

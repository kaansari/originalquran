# فَخَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%AE%D9%8E%D9%85%D9%8E/?book=9

(فَخَمَ) الْفَاءُ وَالْخَاءُ وَالْمِيمُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى جَزَالَةٍ وَعِظَمٍ. يُقَالُ: مَنْطِقٌ فَخْمٌ: جَزْلٌ. وَيَقُولُونَ: الْفَخْمُ مِنَ الرِّجَالِ: الْكَثِيرُ لَحْمِ الْوَجْنَتَيْنِ.

# الْعُلْكُومُ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A7%D9%84%D9%92%D8%B9%D9%8F%D9%84%D9%92%D9%83%D9%8F%D9%88%D9%85%D9%8F/?book=9

(الْعُلْكُومُ) : النَّاقَةُ الْجَسِيمَةُ السَّمِينَةُ. قَالَ لَبِيدٌ:

تُرْوِي الْحَدَائِقَ بَازِلٌ عُلْكُومُ

وَهَذَا مِنْ عَكَمَ، وَاللَّامُ زَائِدَةٌ، كَأَنَّهَا عُكِمَتْ بِاللَّحْمِ عَكْمًا.

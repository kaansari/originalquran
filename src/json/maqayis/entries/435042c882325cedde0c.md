# بَغَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%BA%D9%8E%D8%AA%D9%8E/?book=9

(بَغَتَ) الْبَاءُ وَالْغَيْنُ وَالتَّاءُ أَصْلٌ وَاحِدٌ لَا يُقَاسُ عَلَيْهِ، مِنْهُ الْبَغْتُ، وَهُوَ أَنْ يَفْجَأَ الشَّيْءُ. قَالَ:

وَأَعْظَمُ شَيْءٍ حِينَ يَفْجَؤُكَ الْبَغْتُ

# كَثَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D8%AB%D9%8E%D8%B9%D9%8E/?book=9

(كَثَعَ) الْكَافُ وَالثَّاءُ وَالْعَيْنُ قَرِيبُ الْمَعْنَى مِنَ الَّذِي قَبْلَهُ. يُقَالُ شَفَةٌ كَاثِعَةٌ، إِذَا كَثُرَ دَمُهَا. وَكَثَعَ اللَّبَنُ: عَلَا دَسَمُهُ. وَكَثَّعَتْ لِحْيَتُهُ: طَالَتْ وَكَثُرَتْ.

# رَكَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D9%83%D9%8E%D9%85%D9%8E/?book=9

(رَكَمَ) الرَّاءُ وَالْكَافُ وَالْمِيمُ أَصْلٌ وَاحِدٌ يَدُلُّ عَلَى [تَجَمُّعِ] الشَّيْءِ. تَقُولُ رَكَمْتُ الشَّيْءَ: أَلْقَيْتَ بَعْضَهُ عَلَى بَعْضٍ. وَسَحَابٌ مُرْتَكِمٌ وَرُكَامٌ. وَالرُّكَمَةُ: الطِّينُ الْمَجْمُوعُ. وَمُرْتَكَمُ الطَّرِيقِ: سَنَنُهُ; لِأَنَّ الْمَارَّةَ تَرْتَكِمُ فِيهِ.

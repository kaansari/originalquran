# كَمَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%85%D9%8E%D8%AD%D9%8E/?book=9

(كَمَحَ) الْكَافُ وَالْمِيمُ وَالْحَاءُ كَلِمَاتٌ لَا تَنْقَاسُ، وَفِي بَعْضِهَا شَكٌّ، غَيْرَ أَنَّا ذَكَرْنَا مَا ذَكَرُوهُ. قَالُوا: أَكْمَحَ الْكَرْمُ، إِذَا تَحَرَّكَ لِلْإِيرَاقِ. وَقَالُوا رَجُلٌ كَوْمَحٌ: عَظِيمُ الْأَلْيَتَيْنِ. وَيَقُولُونَ: كَمَحَ الْفَرَسَ، إِذَا كَبَحَهُ.

# نَسَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D8%B3%D9%8E%D9%83%D9%8E/?book=9

(نَسَكَ) النُّونُ وَالسِّينُ وَالْكَافُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى عِبَادَةٍ وَتَقَرُّبٍ إِلَى اللَّهِ تَعَالَى. وَرَجُلٌ نَاسِكٌ. وَالذَّبِيحَةُ الَّتِي تَتَقَرَّبُ بِهَا إِلَى اللَّهِ نَسِيكَةٌ. وَالْمَنْسَِكُ: الْمَوْضِعُ يُذْبَحُ فِيهِ النَّسَائِكُ، وَلَا يَكُونُ ذَلِكَ إِلَّا فِي الْقُرْبَانِ. وَزَعَمَ نَاسٌ أَنَّ الْمَنْسَِكَ: الْمَكَانُ يَأْلَفُهُ. وَفِيهِ نَظَرٌ.

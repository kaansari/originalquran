# فَلَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D9%84%D9%8E%D8%B9%D9%8E/?book=9

(فَلَعَ) الْفَاءُ وَاللَّامُ وَالْعَيْنُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى شَقِّ الشَّيْءِ. تَقُولُ: فَلَعْتُ الشَّيْءَ: شَقَقْتُهُ. وَتَفَلَّعَتِ الْبَيْضَةُ وَانْفَلَعَتْ.

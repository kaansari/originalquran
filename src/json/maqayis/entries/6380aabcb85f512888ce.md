# فَشَا

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B4%D9%8E%D8%A7/?book=9

(فَشَا) الْفَاءُ وَالشِّينُ وَالْحَرْفُ الْمُعْتَلُّ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ ظُهُورُ الشَّيْءِ، يُقَالُ: فَشَا الشَّيْءُ: ظَهَرَ.

وَحَكَى ابْنُ دُرَيْدٍ: فَشَأَ الْمَرَضُ فِيهِمْ فُشُوءًا، وَتَفَشَّأَ تَفَشُّؤًا.

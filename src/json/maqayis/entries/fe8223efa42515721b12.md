# شَدَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D8%AF%D9%8E%D8%AD%D9%8E/?book=9

(شَدَحَ) الشِّينُ وَالدَّالُ وَالْحَاءُ لَيْسَ بِشَيْءٍ. وَحُكِيَ أَنَّ الشَّوْدَحَ: الطَّوِيلُ مِنَ النُّوقِ. وَيُقَالُ: بَلْ هِيَ السَّرِيعَةُ. وَانْشَدَحَ الرَّجُلُ، إِذَا اسْتَلْقَى عَلَى ظَهْرِهِ. وَهَذَا لَيْسَ بِشَيْءٍ، وَلَعَلَّهُ أَنْ يَكُونَ انْسَدَحَ. وَقَدْ ذَكَرْنَاهُ.

# لَعَنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%B9%D9%8E%D9%86%D9%8E/?book=9

(لَعَنَ) اللَّامُ وَالْعَيْنُ وَالنُّونُ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى إِبْعَادٍ وَإِطْرَادٍ. وَلَعَنَ اللَّهُ الشَّيْطَانَ: أَبْعَدَهُ عَنِ الْخَيْرِ وَالْجَنَّةِ. وَيُقَالُ لِلذِّئْبِ لَعِينٌ، وَالرَّجُلُ الطَّرِيدُ لَعِينٌ. وَرَجُلٌ لُعْنَةٌ بِالسُّكُونِ: يَلْعَنُهُ النَّاسُ، [وَلُعَنَةٌ] : كَثِيرُ اللَّعْنِ. وَاللِّعَانُ: الْمُلَاعَنَةُ. وَقَالَ فِي الطَّرِيدِ:

ذَعَرْتُ بِهِ الْقَطَا وَنَفَيْتُ عَنْهُ ... مَقَامَ الذِّئْبِ كَالرَّجُلِ اللَّعِينِ.

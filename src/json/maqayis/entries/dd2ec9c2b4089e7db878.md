# وَهَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%88%D9%8E%D9%87%D9%8E%D8%B3%D9%8E/?book=9

(وَهَسَ) الْوَاوُ وَالْهَاءُ وَالسِّينُ: كَلِمَتَانِ: إِحْدَاهُمَا الشِّدَّةُ فِي الْأُمُورِ، وَالثَّانِيَةُ مِنَ السِّرَارِ.

فَالْأُولَى الْوَهْسُ: شِدَّةُ السَّيْرِ. وَالْوَهْسُ: شِدَّةُ الْأَكْلِ. وَالْوَهْسُ: شِدَّةُ الْوَطْءِ. وَقَالَ حُمَيْدٌ: بِتَنَقُّصِ الْأَعْرَاضِ وَالْوَهْسِ

فَهَذَا مِنَ التَّوَهُّسِ، وَهُوَ التَّشَدُّدُ وَالتَّطَاوُلُ عَلَى الْعَشِيرَةِ.

وَالْكَلِمَةُ الْأُخْرَى: الْوَهْسُ السِّرَارُ. وَالْوَهْسُ: النَّمِيمَةُ.

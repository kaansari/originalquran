# يَبَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%8A%D9%8E%D8%A8%D9%91%D9%8E/?book=9

(يَبَّ) الْيَاءُ وَالْبَاءُ كَلِمَةٌ وَاحِدَةٌ وَهِيَ الْيَبَابُ، إِتْبَاعٌ لِلْخَرَابِ، وَرُبَّمَا أَفْرَدُوهَا فَقَالُوا:

أَخْبَرَتْ عَنْ فِعَالِهِ الْأَرْضُ وَاسْتَنْ ... طَقَ مِنْهَا الْيَبَابَ وَالْمَعْمُورَا

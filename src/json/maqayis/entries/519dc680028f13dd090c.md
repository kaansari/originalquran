# مَطَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%B7%D9%8E%D8%AD%D9%8E/?book=9

(مَطَحَ) الْمِيمُ وَالطَّاءُ وَالْحَاءُ كَلِمَةٌ وَاحِدَةٌ، حَكَاهَا ابْنُ دُرَيْدٍ، هِيَ الْمَطْحُ: الضَّرْبُ بِالْيَدِ، وَرُبَّمَا كُنِّيَ بِهِ عَنِ الْجِمَاعِ.

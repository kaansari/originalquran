# زَمَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D9%85%D9%8E%D9%82%D9%8E/?book=9

(زَمَقَ) الزَّاءُ وَالْمِيمُ وَالْقَافُ لَيْسَ بِشَيْءٍ، وَإِنْ كَانُوا يَقُولُونَ: زَمَقَ شَعْرَهُ، إِذَا نَتَفَهُ. فَإِنْ صَحَّ فَالْأَصْلُ زَبَقَ. وَقَدْ ذُكِرَ.

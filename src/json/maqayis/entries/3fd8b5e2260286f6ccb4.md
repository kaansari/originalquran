# هَيَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D9%8A%D9%8E%D8%AA%D9%8E/?book=9

(هَيَتَ) الْهَاءُ وَالْيَاءُ وَالتَّاءُ كَلِمَةٌ تَدُلُّ عَلَى الصَّيْحَةِ. يَقُولُونَ: هَيَّتَ بِهِ، إِذَا صَاحَ. قَالَ: لَوْ كَانَ مَعْنِيَّا بِهَا لَهَيَّتَا

وَيَقُولُونَ فِي مَعْنَى هَيْتَ لَكَ: هَلُمَّ.

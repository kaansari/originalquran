# خَوِشَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D9%88%D9%90%D8%B4%D9%8E/?book=9

(خَوِشَ) الْخَاءُ وَالْوَاوُ وَالشِّينُ أَصْلٌ يَدُلُّ عَلَى ضَمْرٍ وَشِبْهِهِ. فَالْمُتَخَوِّشُ: الضَّامِرُ، وَلِذَلِكَ تُسَمَّى الْخَاصِرَتَانِ الْخَوْشَيْنِ.

# بَيَظَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D9%8A%D9%8E%D8%B8%D9%8E/?book=9

(بَيَظَ) الْبَاءُ وَالْيَاءُ وَالظَّاءُ كَلِمَةٌ مَا أَعْرِفُهَا فِي صَحِيحِ كَلَامِ الْعَرَبِ، وَلَوْ أَنَّهُمْ ذَكَرُوهَا مَا كَانَ لِإِثْبَاتِهَا وَجْهٌ. قَالُوا: الْبَيْظُ مَاءُ الْفَحْلِ.

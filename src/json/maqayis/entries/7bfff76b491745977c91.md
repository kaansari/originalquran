# كَيَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%83%D9%8E%D9%8A%D9%8E%D8%B5%D9%8E/?book=9

(كَيَصَ) الْكَافُ وَالْيَاءُ وَالصَّادُ إِنْ صَحَّ فَهُوَ يَدُلُّ عَلَى انْقِبَاضٍ وَضِيقٍ. وَيَقُولُونَ: كَاصَ يَكِيصُ، مِثْلَ كَاعَ. وَيَقُولُونَ: إِنَّ الْكِيصَ: الرَّجُلُ الضَّيِّقُ الْخُلُقِ. وَحُكِيَتْ كَلِمَةٌ أَنَا أَرْتَابُ بِهَا، يَقُولُونَ: كِصْنَا عِنْدَ فُلَانٍ مَا شِئْنَا، [أَيْ] أَكَلْنَا.

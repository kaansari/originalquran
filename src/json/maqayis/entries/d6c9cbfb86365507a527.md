# عَفَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D9%81%D9%8E%D8%AA%D9%8E/?book=9

(عَفَتَ) الْعَيْنُ وَالْفَاءُ وَالتَّاءُ كَلِمَةٌ تَدُلُّ عَلَى كَسْرِ شَيْءٍ، يَقُولُونَ: عَفَتَ الْعَظْمَ: كَسَرَهُ. ثُمَّ يَقُولُونَ الْعَفَتُ فِي الْكَلَامِ: كَسْرُهُ لُكْنَةً، كَكَلَامٍ الْحَبَشِيِّ.

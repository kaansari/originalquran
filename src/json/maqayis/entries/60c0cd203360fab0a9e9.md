# مَحَوَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AD%D9%8E%D9%88%D9%8E/?book=9

(مَحَوَ) الْمِيمُ وَالْحَاءُ وَالْحَرْفُ الْمُعْتَلُّ أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى الذَّهَابِ بِالشَّيْءِ. والرِّيحُ السَّحَابَ: ذَهَبَتْ بِهِ. وَتُسَمَّى الشَّمَالُ مَحْوَةً، لِأَنَّهَا تَمْحُو السَّحَابَ. وَمَحَوْتُ الْكِتَابَ أَمْحُوهُ مَحْوًا. وَامَّحَى الشَّيْءُ: ذَهَبَ أَثَرُهُ، كَذَلِكَ امْتَحَى.

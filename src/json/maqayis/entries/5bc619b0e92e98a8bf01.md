# شَمَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%85%D9%8E%D9%82%D9%8E/?book=9

(شَمَقَ) الشِّينُ وَالْمِيمُ وَالْقَافُ يَقُولُونَ إِنَّهُ أَصْلٌ صَحِيحٌ، وَيَذْكُرُونَ فِيهِ الشَّمَقَ، وَهُوَ إِمَّا النَّشَاطُ، وَإِمَّا الْوَلُوعُ بِالشَّيْءِ.

# هَشَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B4%D9%91%D9%8E/?book=9

(هَشَّ) الْهَاءُ وَالشِّينُ: أَصْلٌ صَحِيحٌ يَدُلُّ عَلَى رَخَاوَةٍ وَلِينٍ. وَالرِّخْوُ اللَّيِّنُ هَشٌّ. وَمِنْهُ رَجُلٌ هَشٌّ: طَلْقُ الْمُحَيَّا، وَقَدْ هَشِشْتَ، وَذُو هَشَاشٍ. وَالْفَرَسُ الْهَشُّ: الْكَثِيرُ الْعَرَقِ. وَشَاةٌ هَشُوشٌ: ثَرَّةٌ.

وَمِنَ الْبَابِ هَشَشْتُ الْوَرَقَ هَشًّا: خَبَطْتُهُ بِعَصَا.

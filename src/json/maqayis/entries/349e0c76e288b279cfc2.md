# ثَدَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AB%D9%8E%D8%AF%D9%8E%D9%85%D9%8E/?book=9

(ثَدَمَ) الثَّاءُ وَالدَّالُ وَالْمِيمُ كَلِمَةٌ لَيْسَتْ أَصْلًا. زَعَمُوا أَنَّ الثَّدْمَ هُوَ الْفَدْمُ. وَهَذَا إِنْ صَحَّ فَهُوَ مِنْ بَابِ الْإِبْدَالِ.

# ضَيَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B6%D9%8E%D9%8A%D9%8E%D8%B1%D9%8E/?book=9

(ضَيَرَ) الضَّادُ وَالْيَاءُ وَالرَّاءُ كَلِمَةٌ وَاحِدَةٌ، وَهُوَ مِنَ الضَّيْرِ وَالْمَضَرَّةِ. وَلَا يَضِيرُنِي كَذَا، أَيْ لَا يَضُرُّنِي. قَالَ اللَّهُ تَعَالَى: " {وَإِنْ تَصْبِرُوا وَتَتَّقُوا لَا يَضُرُّكُمْ كَيْدُهُمْ شَيْئًا} [آل عمران: 120] ".

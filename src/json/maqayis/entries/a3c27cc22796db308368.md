# شَيَدَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B4%D9%8E%D9%8A%D9%8E%D8%AF%D9%8E/?book=9

(شَيَدَ) الشِّينُ وَالْيَاءُ وَالدَّالُ أَصْلٌ وَاحِدٌ يَدُلُ عَلَى رَفْعِ الشَّيْءِ. يُقَالُ شِدْتُ الْقَصْرَ أَشِيدُهُ شَيْدًا. وَهُوَ قَصْرٌ مَشِيدٌ، أَيْ مَعْمُولٌ بِالشِّيدِ. وَسُمِّيَ شِيدًا لِأَنَّ بِهِ يُرْفَعُ الْبِنَاءُ. يُقَالُ قَصْرٌ مَشِيدٌ أَيْ مُطَوَّلٌ. وَالْإِشَادَةُ: رَفْعُ الصَّوْتِ وَالتَّنْوِيهُ.

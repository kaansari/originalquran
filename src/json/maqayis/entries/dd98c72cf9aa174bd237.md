# خَبَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%A8%D9%8E%D8%B9%D9%8E/?book=9

(خَبَعَ) الْخَاءُ وَالْبَاءُ وَالْعَيْنُ لَيْسَ أَصْلًا ; وَذَلِكَ أَنَّ الْعَيْنَ فِيهِ مُبْدَلَةٌ مِنْ هَمْزَةٍ. يُقَالُ خَبَأْتُ الشَّيْءَ وَخَبَعْتُهُ. وَيُقَالُ خَبَعَ الرَّجُلُ بِالْمَكَانِ: أَقَامَ بِهِ. وَرُبَّمَا قَالُوا: خَبَعَ الصَّبِيُّ خُبُوعًا، وَذَلِكَ إِذَا فُحِمَ مِنَ الْبُكَاءِ. فَإِنْ كَانَ صَحِيحًا فَهُوَ مِنَ الْبَابِ، كَأَنَّ بُكَاءَهُ خُبِئَ.

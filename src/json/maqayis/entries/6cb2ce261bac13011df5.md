# لَحَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AD%D9%8E%D9%81%D9%8E/?book=9

(لَحَفَ) اللَّامُ وَالْحَاءُ وَالْفَاءُ أَصْلٌ يَدُلُّ عَلَى اشْتِمَالٍ وَمُلَازَمَةٍ. يُقَالُ: الْتَحَفَ بِاللِّحَافِ يَلْتَحِفُ. وَلَاحَفَهُ: لَازَمَهُ. وَأَلْحَفَ السَّائِلَ: أَلَحَّ.

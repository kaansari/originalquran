# بَرَخَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A8%D9%8E%D8%B1%D9%8E%D8%AE%D9%8E/?book=9

(بَرَخَ) الْبَاءُ وَالرَّاءُ وَالْخَاءُ أَصْلٌ وَاحِدٌ، إِنْ كَانَ عَرَبِيًّا فَهُوَ النَّمَاءُ وَالزِّيَادَةُ، وَيُقَالُ: إِنَّهَا مِنَ الْبَرَكَةِ وَهِيَ لُغَةٌ نَبَطِيَّةٌ.

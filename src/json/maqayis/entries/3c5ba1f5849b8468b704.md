# فَطَحَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%81%D9%8E%D8%B7%D9%8E%D8%AD%D9%8E/?book=9

(فَطَحَ) الْفَاءُ وَالطَّاءُ وَالْحَاءُ كَلِمَةٌ وَاحِدَةٌ. يَقُولُونَ: فَطَّحْتُ الْعُودَ وَغَيْرَهُ، إِذَا عَرَّضْتَهُ. وَهُوَ مُفَطَّحٌ. وَرَأْسٌ مُفَطَّحٌ: عَرِيضٌ.

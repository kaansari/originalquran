# تَيْزٌ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D9%8A%D9%92%D8%B2%D9%8C/?book=9

(تَيْزٌ) التَّاءُ وَالْيَاءُ وَالزَّاءُ كَلِمَةٌ وَاحِدَةٌ. قَالُوا: التَّيَّازُ الْغَلِيظُ الْجِسْمِ مِنَ الرِّجَالِ. وَقَالَ الْقُطَامِيُّ:

إِذَا التَّيَّازُ ذُو الْعَضَلَاتِ قُلْنَا ... إِلَيْكَ إِلَيْكَ ضَاقَ بِهَا ذِرَاعًا

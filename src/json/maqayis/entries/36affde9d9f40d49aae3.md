# دَلَهَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%84%D9%8E%D9%87%D9%8E/?book=9

(دَلَهَ) الدَّالُ وَاللَّامُ وَالْهَاءُ أُصَيْلٌ يَدُلُّ عَلَى ذَهَابِ الشَّيْءِ. يُقَالُ ذَهَبَ دَمُ فُلَانٍ دَلْهًا، أَيْ بُطْلًا. وَدَلَّهَ عَقْلَهُ الْحُبُّ وَغَيْرُهُ، أَيْ أَذْهَبَ.

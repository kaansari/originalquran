# خَزَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B2%D9%8E%D8%B1%D9%8E/?book=9

(خَزَرَ) الْخَاءُ وَالزَّاءُ وَالرَّاءُ أَصْلَانِ. أَحَدُهُمَا جِنْسٌ [مِنَ] الطَّبِيخِ، وَالْآخَرُ ضِيقٌ فِي الشَّيْءِ.

فَالْأَوَّلُ الْخَزِيرُ، وَهُوَ دَقِيقٌ يُلْبَكُ بِشَحْمٍ. وَكَانَتِ الْعَرَبُ تُعَيِّرُ آكِلَهُ.

وَالثَّانِي الْخَزَرُ، وَهُوَ ضِيقُ الْعَيْنِ وَصِغَرُهَا. يُقَالُ رَجُلٌ أَخْزَرُ وَامْرَأَةٌ خَزْرَاءُ. وَتَخَازَرَ الرَّجُلُ، إِذَا قَبَضَ جَفْنَيْهِ لِيُحَدِّدَ النَّظَرَ. قَالَ:

إِذَا تَخَازَرْتُ وَمَا بِي مِنْ خَزَرْ

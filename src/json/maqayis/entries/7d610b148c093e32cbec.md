# مَغَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%BA%D9%8E/?book=9

(مَغَ) الْمِيمُ وَالْغَيْنُ يَدُلُّ عَلَى شِبْهِ مَا مَضَى ذِكْرُهُ. يَقُولُونَ: الْمَغْمَغَةُ: الِاخْتِلَاطُ. قَالَ رُؤْبَةُ:

الْخُلُقِ الْمُمَغْمَغِ

وَيَقُولُونَ: مَغْمَغَ طَعَامَهُ، إِذَا رَوَّاهُ دَسَمًا.

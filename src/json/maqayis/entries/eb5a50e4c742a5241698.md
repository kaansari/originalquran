# لَجَأَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%84%D9%8E%D8%AC%D9%8E%D8%A3%D9%8E/?book=9

(لَجَأَ) اللَّامُ وَالْجِيمُ وَالْهَمْزَةُ كَلِمَةٌ وَاحِدَةٌ، وَهِيَ اللَّجَأُ وَالْمَلْجَأُ: الْمَكَانُ يُلْتَجَأُ إِلَيْهِ. يُقَالُ: لَجَأَتْ وَالْتَجَأَتْ. وَقَالَ فِي اللَّجَأِ: جَاءَ الشِّتَاءُ وَلَمَّا أَتَّخِذْ لَجَأَ ... يَا حَرَّ كَفَّيَّ مِنْ حَفْرِ الْقَرَامِيصِ.

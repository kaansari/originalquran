# هَزَبَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%87%D9%8E%D8%B2%D9%8E%D8%A8%D9%8E/?book=9

(هَزَبَ) الْهَاءُ وَالزَّاءُ وَالْبَاءُ كَلِمَةٌ وَاحِدَةٌ. الْهَوْزَبُ: الْبَعِيرُ الْمُسِنُّ، فِي قَوْلِ الْأَعْشَى:

وَالْهَوْزَبَ الْعَوْدَ أَمْتَطِيهِ بِهَا ... وَالْعَنْتَرِيسَ الْوَجْنَاءَ وَالْجَمَلَا

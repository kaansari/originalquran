# زَرَى

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B2%D9%8E%D8%B1%D9%8E%D9%89/?book=9

(زَرَى) الزَّاءُ وَالرَّاءُ وَالْحَرْفُ الْمُعْتَلُّ يَدُلُّ عَلَى احْتِقَارِ الشَّيْءِ وَالتَّهَاوُنِ بِهِ. يُقَالُ زَرَيْتُ عَلَيْهِ، إِذَا عِبْتَ عَلَيْهِ. وَأَزْرَيْتُ بِهِ: قَصَّرْتَ بِهِ.

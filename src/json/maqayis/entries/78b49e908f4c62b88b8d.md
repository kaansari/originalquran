# عَفَزَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B9%D9%8E%D9%81%D9%8E%D8%B2%D9%8E/?book=9

(عَفَزَ) الْعَيْنُ وَالْفَاءُ وَالزَّاءُ لَيْسَ بِشَيْءٍ، وَلَا يُشْبِهُ كَلَامَ الْعَرَبِ. عَلَى أَنَّهُمْ يَقُولُونَ: الْعَفْزُ: مُلَاعَبَةُ الرَّجُلِ امْرَأَتَهُ، وَإِنَّ الْعَفْزَ: الْجَوْزُ. وَهَذَا لَا مَعْنَى لِذِكْرِهِ.

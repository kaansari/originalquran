# قَحَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D8%AD%D9%91%D9%8E/?book=9

(قَحَّ) الْقَافُ وَالْحَاءُ لَيْسَ هُوَ عِنْدَنَا أَصْلًا، وَلَكِنَّهُمْ يَقُولُونَ: الْقُحُّ: الْجَافِي مِنَ النَّاسِ وَالْأَشْيَاءِ، حَتَّى يَقُولُونَ لِلْبِطِّيخَةِ الَّتِي لَمْ تَنْضَجُ: إِنَّهَا لَقُحٌّ.

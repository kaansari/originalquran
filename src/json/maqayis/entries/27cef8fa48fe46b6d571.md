# نَوَّنَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%86%D9%8E%D9%88%D9%91%D9%8E%D9%86%D9%8E/?book=9

(نَوَّنَ) النُّونُ وَالْوَاوُ وَالنُّونُ كَلِمَةٌ وَاحِدَةٌ. وَالنُّونُ: الْحُوتُ. وَ [ذُو] النُّونِ: سَيْفٌ لِبَعْضِ الْعَرَبِ، كَأَنَّهُ شُبِّهَ بِالنُّونِ.

# تَحْتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AA%D9%8E%D8%AD%D9%92%D8%AA%D9%8E/?book=9

(تَحْتَ) التَّاءُ وَالْحَاءُ وَالتَّاءُ كَلِمَةٌ وَاحِدَةٌ، تَحْتَ الشَّيْءِ. وَالتُّحُوتُ: الدُّونُ مِنَ النَّاسِ وَفِي الْحَدِيثِ: «تَهْلِكُ الْوُعُولُ وَتَظْهَرُ التُّحُوتُ» . وَالْوُعُولُ: الْكِبَارُ وَالْعِلْيَةُ.

# صَهَمَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B5%D9%8E%D9%87%D9%8E%D9%85%D9%8E/?book=9

(صَهَمَ) الصَّادُ وَالْهَاءُ وَالْمِيمُ أَصْلٌ صَحِيحٌ قَلِيلُ الْفُرُوعِ، لَكِنَّهُمْ يَقُولُونَ: الصِّهْمِيمُ: السَّيِّئُ الْخُلُقِ مِنَ الْإِبِلِ، وَيُشَبِّهُونَ بِهِ الرَّجُلَ الَّذِي لَا يَثْبُتُ عَلَى رَأْيٍ وَاحِدٍ. وَاللَّهُ أَعْلَمُ.

# أَدَرَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%AF%D9%8E%D8%B1%D9%8E/?book=9

(أَدَرَ) الْهَمْزَةُ وَالدَّالُ وَالرَّاءُ كَلِمَةٌ وَاحِدَةٌ، فَهِيَ الْأَدْرَةُ وَالْأَدَرَةُ، يُقَالُ: أَدِرَ يَأْدَرُ، وَهُوَ آدَرُ. قَالَ:

نُبِّئْتُ عُتْبَةَ خَضَّافًا تَوَعَّدَنِي ... يَا رُبَّ آدَرَ مِنْ مَيْثَاءَ مَأْفُونِ

# مَحَجَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%85%D9%8E%D8%AD%D9%8E%D8%AC%D9%8E/?book=9

(مَحَجَ) الْمِيمُ وَالْحَاءُ وَالْجِيمُ. يَقُولُونَ: مَحَجَتِ الْأَرْضَ الرِّيحُ: مَسَحَتِ التُّرَابَ عَنْهَا. وَمَحَجْتُ اللَّحْمَ: قَشَرْتُهُ. قَالَ الْخَلِيلُ: وَالْمَحْجُ: مَسْحُ شَيْءٍ عَنْ شَيْءٍ. قَالَ ابْنُ دُرَيْدٍ: وَمَحَجْتُ الْأَدِيمَ وَالْحَبْلَ، إِذَا دَلَّكْتُهُ لِيَلِينَ. قَالَ: وَمَاحَجْتُهُ مُمَاحَجَةً وَمِحَاجًا، إِذَا مَاطَلْتُهُ. وَإِنْ صَحَّ الْبَابُ فَأَصْلُهُ الْمَسْحُ.

# جَوَتَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D9%88%D9%8E%D8%AA%D9%8E/?book=9

(جَوَتَ) الْجِيمُ وَالْوَاوُ وَالتَّاءُ لَيْسَ أَصْلًا ; لِأَنَّهُ حِكَايَةُ صَوْتٍ، وَالْأَصْوَاتُ لَا تُقَاسُ وَلَا يُقَاسُ عَلَيْهَا. قَالَ:

كَمَا رُعْتَ بِالْجَوْتِ الظِّمَاءَ الصَّوَادِيَا

قَالَ أَبُو عُبَيْدٍ: إِنَّمَا كَانَ الْكِسَائِيُّ يُنْشِدُ هَذَا الْبَيْتَ لِأَجْلِ النَّصْبِ، فَكَانَ يَقُولُ: " كَمَا رُعْتَ بِالْجَوْتَ " فَحَكَى مَعَ الْأَلِفِ وَاللَّامِ.

# خَزَفَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AE%D9%8E%D8%B2%D9%8E%D9%81%D9%8E/?book=9

(خَزَفَ) الْخَاءُ وَالزَّاءُ وَالْفَاءُ لَيْسَ بِشَيْءٍ. فَالْخَزَفُ هَذَا الْمَعْرُوفُ، وَلَسْنَا نَدْرِي أَعَرَبِيٌّ هُوَ أَمْ لَا. قَالَ ابْنُ دُرَيْدٍ: الْخَزْفُ الْخَطْرُ بِالْيَدِ عِنْدَ الْمَشْيِ. وَهَذَا مِنْ أَعَاجِيبِ أَبِي بَكْرٍ.

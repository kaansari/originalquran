# حَدَقَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AD%D9%8E%D8%AF%D9%8E%D9%82%D9%8E/?book=9

(حَدَقَ) الْحَاءُ وَالدَّالُ وَالْقَافُ أَصْلٌ وَاحِدٌ، [وَهُوَ الشَّيْءُ] يُحِيطُ بِشَيْءٍ. يُقَالُ حَدَقَ الْقَوْمُ بِالرَّجُلِ وَأَحْدَقُوا بِهِ. قَالَ:

الْمُطْعِمُونَ بَنُو حَرْبٍ وَقَدْ حَدَقَتْ ... بِيَ الْمَنِيَّةُ وَاسْتَبْطَأْتُ أَنْصَارِي

وَحَدَقَةُ الْعَيْنِ مِنْ هَذَا، وَهِيَ السَّوَادُ، لِأَنَّهَا تُحِيطُ بِالصَّبِيِّ ; وَالْجَمْعُ حِدَاقٌ. قَالَ: فَالْعَيْنُ بَعْدَهُمُ كَأَنقَهَا ... سُمِلَتْ بِشَوْكٍ فَهْيَ عَوَرٌ تَدْمَعُ

وَالتَّحْدِيقُ: شِدَّةُ النَّظَرِ. وَالْحَدِيقَةُ: الْأَرْضُ ذَاتُ الشَّجَرِ. وَالْحِنْدِيقَةُ: الْحَدَقَةُ.

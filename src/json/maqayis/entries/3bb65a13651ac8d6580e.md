# قَنَصَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D9%82%D9%8E%D9%86%D9%8E%D8%B5%D9%8E/?book=9

(قَنَصَ) الْقَافُ وَالنُّونُ وَالصَّادُ كَلِمَةٌ وَاحِدَةٌ تَدُلُّ عَلَى الصَّيْدِ قَطْ. فَالْقَانِصُ: الصَّائِدُ. وَالْقَنَصُ: الصَّيْدُ. وَالْقَنْصُ: فِعْلُ الْقَانِصِ. قَالَ ابْنُ دُرَيْدٍ: الْقَنِيصُ: الصَّائِدُ. وَبَنُو قَنَصِ بْنِ مَعَدٍّ: قَوْمٌ دَرَجُوا.

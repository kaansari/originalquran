# أَنَضَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D9%86%D9%8E%D8%B6%D9%8E/?book=9

(أَنَضَ) الْهَمْزَةُ وَالنُّونُ وَالضَّادُ كَلِمَةٌ وَاحِدَةٌ لَا يُقَاسُ عَلَيْهَا، يُقَالُ: لَحْمٌ أَنِيضٌ: إِذَا بَقِيَ فِيهِ نُهُوءَةٌ، أَيْ: لَمْ يَنْضَجْ. وَقَالَ زُهَيْرٌ:

يُلَجْلِجُ مُضْغَةً فِيهَا أَنِيضٌ ... أَصَلَّتْ فَهِيَ تَحْتَ الْكَشْحِ دَاءُ

تَقُولُ: آنَضْتُهُ إِينَاضًا، وَأَنُضَ أَنَاضَةً.

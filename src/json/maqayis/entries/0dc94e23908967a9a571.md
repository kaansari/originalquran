# دَلَثَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AF%D9%8E%D9%84%D9%8E%D8%AB%D9%8E/?book=9

(دَلَثَ) الدَّالُ وَاللَّامُ وَالثَّاءُ أَصْلٌ يَدُلُّ عَلَى الِانْدِفَاعِ. يُقَالُ لِمَدَافِعِ السَّيْلِ الْمَدَالِثُ; الْوَاحِدُ مَدْلَثٌ. وَالنَّاقَةُ الدِّلَاثُ: السَّرِيعَةُ. يُقَالُ انْدَلَثَتِ النَّاقَةُ تَنْدَلِثُ انْدِلَاثًا. وَحَكَى بَعْضُهُمْ: دَلَثَ الشَّيْخُ، مِثْلُ دَلَفَ. وَيُقَالُ: انْدَلَثَ فُلَانٌ عَلَى فُلَانٍ، إِذَا انْدَرَأَ عَلَيْهِ وَانْصَبَّ.

# غَمَيَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%BA%D9%8E%D9%85%D9%8E%D9%8A%D9%8E/?book=9

(غَمَيَ) الْغَيْنُ وَالْمِيمُ وَالْحَرْفُ الْمُعْتَلُّ يَدُلُّ عَلَى تَغْطِيَةٍ وَتَغْشِيَةٍ. مِنْ ذَلِكَ: غَمَيْتُ الْبَيْتَ، إِذَا سَقَفْتَهُ، وَالسَّقْفُ غِمَاءٌ. وَمِنْهُ أُغْمِيَ [عَلَى] الْمَرِيضِ فَهُوَ مُغْمًى عَلَيْهِ إِذَا غُشِيَ عَلَيْهِ.

# جَشَعَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%AC%D9%8E%D8%B4%D9%8E%D8%B9%D9%8E/?book=9

(جَشَعَ) الْجِيمُ وَالشِّينُ وَالْعَيْنُ أَصْلٌ وَاحِدٌ، وَهُوَ الْحِرْصُ الشَّدِيدُ. يُقَالُ رَجُلٌ جَشِعٌ بَيِّنُ الْجَشَعِ، وَقَوْمٌ جَشِعُونَ. قَالَ سُوَيْدٌ:

وَكِلَابُ الصَّيْدِ فِيهِنَّ جَشَعْ

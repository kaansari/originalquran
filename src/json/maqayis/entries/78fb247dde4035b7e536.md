# أَسَكَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%A3%D9%8E%D8%B3%D9%8E%D9%83%D9%8E/?book=9

(أَسَكَ) الْهَمْزَةُ وَالسِّينُ وَالْكَافُ بِنَاؤُهُ فِي الْكِتَابَيْنِ. وَقَالَ أَهْلُ اللُّغَةِ: الْمَأْسُوكَةُ الَّتِي أَخْطَأَتْ خَافِضَتُهَا فَأَصَابَتْ غَيْرَ مَوْضِعِ الْخَفْضِ.

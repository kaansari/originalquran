# رَتَّ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B1%D9%8E%D8%AA%D9%91%D9%8E/?book=9

(رَتَّ) الرَّاءُ وَالتَّاءُ لَيْسَ أَصْلًا، لَكِنَّهُمْ يَقُولُونَ: الرُّتَّةُ: الْعَجَلَةُ فِي الْكَلَامِ. وَيُقَالُ هِيَ الْحُكْلَةُ فِيهِ. وَيَقُولُونَ: الرُّتُوتُ: الْخَنَازِيرُ. وَقَالَ ابْنُ الْأَعْرَابِيِّ: الرَّتُّ: الرَّئِيسُ; وَالْجَمْعُ رُتُوتٌ. وَكُلُّ هَذَا فَمِمَّا يَنْبَغِي أَنْ يُنْظَرَ فِيهِ.

# طَبَسَ

Dictionary: Ibn Faris, Maqayis al-Lugha

Source: https://arabiclexicon.hawramani.com/%D8%B7%D9%8E%D8%A8%D9%8E%D8%B3%D9%8E/?book=9

(طَبَسَ) الطَّاءُ وَالْبَاءُ وَالسِّينُ لَيْسَ بِشَيْءٍ. عَلَى أَنَّهُمْ يَقُولُونَ: الطَّبَسَانِ: كُورَتَانِ. وَهَذَا وَشِبْهُهُ مِمَّا لَا مَعْنَى لِذِكْرِهِ ; لِأَنَّهُ إِذَا ذُكِرَ مَا أَشْبَهَ كُلُّهُ حُمِلَ عَلَى كَلَامِ الْعَرَبِ مَا لَيْسَ هُوَ مِنْهُ. وَكَذَلِكَ قَوْلُ مَنْ قَالَ: إِنَّ التَّطْبِيسَ: التَّطْبِينُ.

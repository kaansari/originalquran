So the very clear **R-G-L** sequence exists:

**Latin rēgula → Old High German regula → MHG regel → German Regel**

with the basic semantic idea:

**straight measuring stick → standard → rule / guideline / norm.** [Old High German Dictionary](https://ewa.saw-leipzig.de/articles/115410/de?utm_source=chatgpt.com)

There is also a different Germanic **RGN/RGN** family:

**Old Norse regn** = “rain”  
**Old English regn / rēgn** → English **rain**  
**Old High German regan** → German **Regen**

That one is native Germanic and unrelated to **Regel**. [Wikisource](https://en.wikisource.org/wiki/An_Etymological_Dictionary_of_the_German_Language/Annotated/R_%28full_text%29?utm_source=chatgpt.com)

LAW, light

If you mean a consonantal skeleton like **L-W-H / L-W-Ḥ**, there is **no standard Old Norse, Old High German, or Old English root written exactly “LWH.”** But there is a very interesting nearby Germanic family built around **L-U/EO-H/T**, meaning **light, brightness, shining**.

- **Old English:** **lēoht** = “light, brightness” → Modern English **light**
- **Old High German:** **lioht** = “light, brightness” → Modern German **Licht**
- **Old Saxon:** **lioht**
- **Gothic:** **liuhaþ** = “light”
- **Old Norse / Old Icelandic:** **ljós** = “light” [Wikisource](https://en.wikisource.org/wiki/An_Etymological_Dictionary_of_the_German_Language/Annotated/L_%28full_text%29?utm_source=chatgpt.com)

The reconstructed Proto-West-Germanic form is approximately **\*leuht** “light.” [Wiktionary](https://en.wiktionary.org/wiki/Reconstruction%3AProto-West_Germanic/leuht?utm_source=chatgpt.com)

There is also an old Germanic word related to **flame**:
**Old High German \*loho / loug** = “flame, flare,” ancestor/relative of German **Lohe** “flame.” [Wiktionary](https://en.wiktionary.org/wiki/Reconstruction%3AOld_High_German/loho?utm_source=chatgpt.com)

So if you are comparing a form like **LWH** with a meaning such as **shine / illumination / flame**, the closest Germanic pattern is quite strong:

**LWH ≈ \*leuht / liuht / lioht → light, brightness**

Historically, the **h** here represents a guttural/fricative sound, while the **w/u** element appears in older forms such as Gothic **liuhaþ** and reconstructed **\*leuht**. The deeper Indo-European root is usually reconstructed as **\*leuk-**, “light, brightness, shine.” [Wikisource](https://en.wikisource.org/wiki/An_Etymological_Dictionary_of_the_German_Language/Annotated/L_%28full_text%29?utm_source=chatgpt.com)

If you're comparing this specifically with Arabic **لوح / لوه (L-W-Ḥ / L-W-H)**, there is a striking **sound-and-meaning resemblance around shining/light**, though that by itself does **not prove an etymological relationship**.
